# TKY2JGD・PatchJGD の座標補正を測量計算サイトと照らす

国土地理院のパラメーターを手元で `ShiftGrid::read` に渡し、`ShiftGrid::correction` が返す緯度・経度の補正量（秒）を入力に足します。1 点ごとの計算で表示される経緯度と、秒の小数 5 桁で比較します。パラメーター、格子から選んだ点、各点の計算結果はリポジトリ外に置き、記録には件数と差の最大だけを使います。

## 点の一覧を作る

リポジトリのルートで、パラメーターごとに別の出力フォルダーを指定します。

```sh
cargo xtask datum points /path/to/kit /path/to/parameters.par
```

`zumen.tsv` は UTF-8 で、各行に ID、入力緯度、入力経度、補正後の緯度、補正後の経度をタブ区切りで書きます。囲む四隅がそろわず補間できない点は、最後の 2 列が `-` になります。経緯度は度分秒の区切りを省き、秒の小数を 5 桁にそろえます。

| ID | 格子から選ぶ位置 |
| --- | --- |
| `N0`・`N1`・`N2` | 周囲 3 × 3 の格子点がそろう別々の位置。各位置から格子点（`node`）、東西の線（`ew-line`）、南北の線（`ns-line`）、区画内（`cell`）を選ぶ |
| `E1` | 北東の隅が欠けた区画の中 |
| `E2`・`E3` | 北の側が欠けた東西の線の上と、その線の西端の格子点 |
| `E4` | 東の側が欠けた南北の線の上 |
| `E5`・`E6` | 南の側が欠けた東西の線の上と、西の側が欠けた南北の線の上。補間に使う四隅はそろう |
| `OUT` | 格子の外で囲む格子点が 1 つもない位置 |

3 次メッシュとその 5 倍の間隔の両方で、渡したファイルの格子点から最大 19 点を選びます。該当する形がないときはその点を省きます。以前の観測と同じ範囲外の点を使うときは、コマンドの最後に `--outside <十進の緯度> <十進の経度>` を加えます。

## サイトの結果を照らす

1. [国土地理院の測量計算サイト](https://vldb.gsi.go.jp/sokuchi/surveycalc/main.html)で「世界測地系座標変換（TKY2JGD）」または水平位置の「PatchJGD」を開きます。1 点ごとの計算に緯度・経度を使い、PatchJGD は手元のファイルに対応する地震・補正方向を選びます。
2. `zumen.tsv` の各点の入力緯度と入力経度を入れます。結果を別の `site.tsv` に、下の列順でタブ区切りで記入します。見出しは付けません。ID と入力座標を記録するので、行の順序は任意です。
3. 次のコマンドで全行を比較します。PatchJGD では `tky2jgd` を `patchjgd` に替えます。点の欠落・重複、入力座標や補正可否の違い、表示の桁での数値の違いがあれば失敗します。

| サイトの結果 | `site.tsv` の列順 |
| --- | --- |
| 補正後の数値を表示 | ID、入力緯度、入力経度、`ok`、結果の緯度、結果の経度 |
| TKY2JGD で海域のため変換できない | ID、入力緯度、入力経度、`sea` |
| PatchJGD で対象地域外のため補正しない | ID、入力緯度、入力経度、`unchanged`。結果に入力と同じ数値がある場合は `ok` とその数値でも照合できる |

```sh
python xtask/verify/datum/compare.py tky2jgd /path/to/kit/zumen.tsv /path/to/kit/site.tsv
```

2026-11-21 に国土地理院の 3 ファイルから各 19 点の入力を再生成し、2026-11-19 にサイトで実測した同じ 57 点に照らしました。補正後の値がある 42 点は差の最大が 0.00000 秒、補正量がない 15 点はサイトの扱いと一致しました。[ファイルの版・補間と座標変換の違い](../../../docs/formats/crs.md#測量計算サイトとの照合)

## 経緯度の一括計算

同じ `zumen.tsv` から、入力する経緯度と点名だけのファイルを作ります。サイトの「一括計算」で「緯度・経度 → 緯度・経度」を選び、「入力値を出力する」を有効にします。PatchJGD では対応するパラメーターを選びます。ダウンロードした出力をそのまま比較します。

```sh
python xtask/verify/datum/batch.py input /path/to/kit/zumen.tsv /path/to/kit/latlon.in
python xtask/verify/datum/batch.py compare tky2jgd /path/to/kit/zumen.tsv /path/to/kit/latlon.out
```

2026-11-21 の一括計算は 3 ファイル各 19 点で、補正できた 42 点の差の最大は 0.00000 秒でした。残る 15 点はサイトの両方の結果列が `-9999.` で、zumen も補間しませんでした。TKY2JGD の一括出力ヘッダーには Ver.2.1.1、手元の格子には Ver.2.1.2 と記されています。[TKY2JGD の入出力](https://vldb.gsi.go.jp/sokuchi/surveycalc/tky2jgd/help/infile.htm)・[PatchJGD の入出力](https://vldb.gsi.go.jp/sokuchi/surveycalc/patchjgd/helpweb/infile.htm)

# PLY の公開サンプルと実機確認キット

[#870](https://github.com/zumen-jp/zumen/issues/870) の公開 PDAL サンプルを、変更せずキットへ移します。既存の `zumen-ply` の外部照合 4 本を実行し、通過した場合だけ入力・期待値・出典・利用条件・実行コードのハッシュ・実測用の様式を保存します。ply-rs 0.1.3 との一致と MeshLab の確認は別に数えます。

```powershell
python -I -m unittest discover -s xtask/verify/ply -p test_make.py
python -I xtask/verify/ply/make.py --out <Gitの外の新しいフォルダー>
```

生成器は新しいフォルダーか空のフォルダーだけを受け付け、既存ファイルを上書きしません。サンプル・台帳のハッシュと外部実装の版を照合し、4 本の名前と終了状態を検査します。Cargo の標準出力や端末の絶対パスはキットへ保存しません。

期待値は、頂点が `(1,1,0)`、`(2,1,0)`、`(1,2,0)`、`(2,2,2)` の 4 点、ファイルの面が 2 件です。コアは点群へ移し、面 2 件の欠落と CRS の欠落を診断します。公開サンプルの精度・合成サンプルの ASCII/両エンディアン・属性・入力/要素/作業量の予算は、既存の[外部照合テスト](../../../crates/zumen-ply/tests/external.rs)が担当します。

MeshLab の操作は **待ち: 利用者** です。生成器は起動しません。許可された環境で、キットの README に従って開き、頂点・面の数、座標、範囲を `application-report.json` に記録します。座標を読めない場合は未確認にし、開けただけで合格にしません。期待値表を観測値へ転記せず、製品のメッセージ全文・画面・個人名・絶対パスを公開記録へ含めません。

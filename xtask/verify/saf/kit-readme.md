# SAF 付き P2Z・SFZ の実機確認（#494）

このキットの入力は `fixtures.py` で自作しました。Autodesk などの製品に付属する資源は含みません。`manifest.json` に生成器・照合器のハッシュと検査の結果があります。

## 比べる値

SFZ（SFC）と P2Z（P21）、SAF の名前の 2 通り、ZIP の無圧縮と deflate を組み合わせた 8 組です。各フォルダーの `input` と `edited` の図面を開き、次の値を比べます。

| 項目 | 入力 | 編集後 |
| --- | --- | --- |
| 線分 | 始点 (0, 0)、終点 (100, 0)、画層 L | 同じ |
| 円 | 中心 (50, 25)、半径 10、画層 L | 中心 (55, 22)、半径 10、画層 L |
| 属性の対象 | 図形識別番号 10、名前「検証線分」の線分 | 同じ |
| 属性セット | 検証セット、版 1.0、作成者 zumen | 同じ |
| 属性グループ | 測点 | 同じ |
| 測点名 | 型 STR、値 No.1 | 同じ |
| 現地盤高 | 型 LEN、単位 m、値 102.0400 | 同じ |

SAF の名前は `DRAWING.SAF` と `DRAWING.SFC.SAF` または `DRAWING.P21.SAF` です。属性 XML・非対象の線分と表・`control.txt` は変更しません。

## 利用者が行う実機の操作

許可した SXF ブラウザで、各フォルダーの `input.sfz`/`input.p2z` と `edited.sfz`/`edited.p2z` を開きます。属性を開けるソフトの名前と版を `report-template.json` に記録し、形、画層、属性の値と結び先を上の表と照らします。アーカイブを直接開けない場合は、同じフォルダーに展開済みの `input/` と `edited/` を使い、その制約を結果に記録します。

開けた項目だけを確認済みにします。見られない属性や未実行の組は `not_run` として残します。製品のメッセージ全文、画面、利用者名を含むパス、非公開図面は報告に入れません。保存し直す場合は Git の外に置きます。

## 自動で確かめた範囲

Python の ZIP 実装でメンバー・CRC・非対象のバイト列、ElementTree で XML の構造・属性値、ezsxf 0.3.7 で図形・画層と変更の期待値を照合しました。コアの `lift` の結果から取り出した属性を XML と照らし、同じ線分への結び付けと属性の有効性を確かめました。同じ入力と変更を 2 回実行し、出力のバイト列の一致も確認しました。

これはネイティブ CLI の検査です。別 OS・wasm との一致、SAF DTD の適合性、実機での表示・印刷は未確認です。`application` の初期値は `not_run` です。

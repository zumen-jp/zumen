# 2D シーンの塊の測定

[#219](https://github.com/zumen-jp/zumen/issues/219) で塊の大きさを決めるための測定です。現在の仮値と比較値を同じ図面モデルに渡し、シーン生成の時間・大きさ・線分の座標精度を比較します。コアの workspace と公開パッケージには入れていません。新しい外部の依存はありません。

## 再現する手順

リポジトリのルートで、固定した Rust と Node.js 22 以降を使います。`wasm32-unknown-unknown` が必要です。

```powershell
cargo run --manifest-path bench/chunks/Cargo.toml --bin measure --release --locked -- bench/chunks/out 7
cargo build --manifest-path bench/chunks/Cargo.toml --lib --target wasm32-unknown-unknown --release --locked
node bench/chunks/run.mjs bench/chunks/out bench/chunks/target/wasm32-unknown-unknown/release/zumen_bench_chunks.wasm 7
```

`out/results.json` に機械とツールのバージョン、入力のサイズ・SHA-256、各設定の中央値と検査結果を書きます。入力はコードに名指しした公開サンプルか、実行時に生成した DXF だけです。外部のファイルや環境変数から図面を探しません。公開入力のハッシュとサイズは `samples/ledger.toml` と照合します。出所・再配布の条件はその台帳にあります。生成したシーンのバイト列も `out/` に置き、ネイティブと wasm で全バイトを比較します。`out/` は Git に入れません。

## 測るもの

- L1 の読み取り、図面モデルへの lift、比較元の線分の収集は準備段階です。時間に含めません。
- 許容差は実寸の空間の 0.01 単位、起点は実寸の空間、表示用の設定です。フォントは渡さず、範囲では絞りません。許容差の単位は各図面の実寸の単位です。
- 1 回ウォームアップし、7 回のシーン生成の中央値を取ります。ネイティブは `Instant`、wasm は Node.js の `performance.now()` を使います。予算・診断は各回で作り直します。シーン生成と診断の code・件数の集計を時間に含め、入力の準備、結果の比較、ファイルの読み書きは含めません。
- 仮値の描くもの 4096 個・許容差の 65536 倍を基準に、件数だけを 1024・16384 個、範囲だけを 16384・262144 倍に変えて比較します。比較する設定を測定用の `Options` に渡し、`Chunking::PROVISIONAL` と API は変えません。
- 合成入力は線分 1 万本と 10 万本です。メートルを宣言し、原点 (100000, 50000) の近くに、小数の端点を持つ線分を格子状に並べます。1 万本は幅が約 1 m の狭い範囲に置いて件数上限を、10 万本は約 1 km 四方に置いて範囲上限を比較します。実物の図面の代わりには数えません。

## 結果の検査

`walked` は部品を含めて配置をたどった数、`entities` はシーンの要素の行数です。塊・線・頂点などの数と、シーン全体のバイト数を記録します。

設定を変えても、要素の ID・種類・配置の道筋、描く単位の表、文字列、種類ごとの描く単位の順が同じことを列の全バイトで比較します。塊の順と、塊内の描く単位の順を組み合わせた順序も比較します。すべてのシーンの ID が入力の走査にあることも検査します。`identity_order_fnv1a` は比較対象の要約です。設定が違えば塊の数や座標の量子化が変わるため、シーン全体のバイト列は同じとは限りません。同じ設定の繰り返しとネイティブ・wasm の間では、シーン全体のバイト列と検査結果が一致することを確かめます。

座標精度は、表示する実線の線分を対象にします。線の ID と配置の道筋から元の f64 の端点を引き、配置のアフィン変換を当てた点と比較します。塊の f64 の原点に f32 の相対座標を戻した点との差を軸ごとに記録します。対象の線がすべて出力にあること、最大誤差が許容差を超えないことも検査します。`checked_lines` に対象の本数を示し、対象がない場合の誤差は `null` にします。曲線の分割、破線への展開、文字と字形の精度は、この値には含めません。

## 残る確認

この測定では、[シーンの配置](../../schema/scene.toml) と公開された Rust の設定を使います。[コアの設計](../../docs/architecture.md) に沿い、配置・ID・既存 API の新しい設計は選んでいません。測定だけで塊の既定値を採用し直すことはしません。

公開サンプルは小さく、大規模な実物の SFC・JWW・DXF・DWG、曲線やハッチングの多い図面は未確認です。用紙・ビュー、許容差を省いた場合、フォントを渡した場合、ブラウザーでの描画・範囲選択・転送時間、メモリの最大も対象外です。これらを測り、仮値を維持するか変えるかを判断する作業は #219 に残します。#343 の描き方のサンプル調査は、この測定で繰り返しません。

# zumen.dev のサイト

<https://zumen.dev> に置く案内のページです。HTML と CSS だけで作り、ビルドの手順・依存・JavaScript を持ちません。

## 見た目の考え方

建設の実務者と企業の担当者が見慣れた書式に合わせます。

- 図面の図枠・表題欄・特記事項・通り芯・寸法線を、見出しの下地にする。
- 色は紺と白を基本にし、朱色は状態と通り芯にだけ使う。
- 概要は会社概要と同じ見出しつきの表、対応形式は「○・△・―・×」の表で示す。
- 外部のフォント・アクセス解析・クッキーを使わない。文字は Windows 10 以降の BIZ UD ゴシック、macOS のヒラギノの順に使う。

## 手元で見る

```bash
python3 -m http.server 24150 --bind 127.0.0.1 --directory site
```

<http://127.0.0.1:24150/> を開きます。

## 公開

Cloudflare Pages で、このリポジトリの `main` から公開する想定です。

- ビルドのコマンド: なし
- 出力のディレクトリ: `site`

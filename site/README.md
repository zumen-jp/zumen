# zumen.dev のサイト

<https://zumen.dev> に置く案内のサイトです。[Astro](https://astro.build/) で作り、静的な HTML として公開します。依存は Astro だけで、ページの中で JavaScript を動かしません。

## 見た目の考え方

建設の実務者と、企業の担当者が見慣れた形に合わせます。

- 並びは、日本の企業・製品のサイトの定番に合わせる。上にロゴとグローバルナビと目立つボタン、トップにメインビジュアル・お知らせ・3 つの特長・早見表・よくある質問・行動を促す帯、下の階層に見出しの帯とパンくずを置く。
- メインビジュアルは図面にする。図枠・表題欄・特記事項・通り芯・寸法線を使う。
- 色は紺と白を基本にし、朱色は状態と強調にだけ使う。
- 概要は会社概要と同じ見出しつきの表、対応形式は「○・△・―・×」の表で示す。
- 外部のフォント・アクセス解析・クッキーを使わない。文字は Windows 10 以降の BIZ UD ゴシック、macOS のヒラギノの順に使う。

## 手元で見る

Node.js 22 以降を使います。

```bash
cd site
npm ci
npm run dev
```

<http://localhost:24150/> を開きます。`npm run check` で型を、`npm run build` で `site/dist` への出力を確かめます。CI の「サイト」でも同じことを確かめます。

## 置き場所

| 場所 | 中身 |
| --- | --- |
| `src/pages/` | ページ。ファイル名が URL になる |
| `src/layouts/Base.astro` | 上の帯・ナビ・フッター |
| `src/components/` | 見出し・お知らせ・対応形式の表・よくある質問などの部品 |
| `src/data/site.ts` | お知らせ・対応形式・ホストアプリ・よくある質問の中身 |
| `src/styles/global.css` | 見た目 |

## 公開

Cloudflare Pages で、このリポジトリの `main` から公開する想定です。

- ルートのディレクトリ: `site`
- ビルドのコマンド: `npm ci && npm run build`
- 出力のディレクトリ: `dist`

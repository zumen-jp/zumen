01

zumen の概要

About

名称zumen（ずめん）
内容日本の建設のデータ（図面・BIM・土木・点群・納品）を読み書きする、寛容なライセンスのライブラリ群
仕組み読み書きと解析を Rust の 1 つの実装にし、ネイティブ・wasm・各言語の結合で、ビット単位で同じ出力を返します。
使い方の形ネイティブのライブラリ・ブラウザーの wasm・プロセスの外・HTTP の 4 つから、用途に合わせて選べます。
ファイルの扱い図面を外部のサービスへ送らず、手元の環境で読みます。
ライセンスMIT License または Apache License 2.0（選んで使えます）
状態作り直しの開発中です。パッケージはまだ公開していません。SXF・JWW・DXF・DWG・PDF を今すぐ読み書きしたい場合は、旧版の zumen-legacy を使ってください。
リポジトリgithub.com/zumen-jp/zumen
02

5 つの方針

Principles

  1. 01どこでも同じ結果

    ブラウザー・サーバー・Python・.NET などで、同じファイルから同じ結果を返します。

  2. 02黙って捨てない

    読めなかったもの、形を変えて書いたものは、種類と件数と場所を報告します。

  3. 03ID は契約

    同じバイト列からは、どの版でも同じ ID を返します。

  4. 04ファイルを信用しない

    大きさ・数・作業量に上限を付けて読みます。壊れた図面でも止まりません。

  5. 05日本の実務を優先

    電子納品の SXF、Jw_cad、日本語の文字、国土交通省の基準を先に扱います。

03

仕組み

Architecture

使う所

  • ブラウザー・Node.js
  • Python・.NET・Java
  • Excel（VBA）
  • Revit・AutoCAD・Rhino
  • CLI・MCP
⇄

境界（API）

  • 数個の関数
  • スキーマで定めたメッセージ
  • ネイティブ・wasm・プロセスの外・HTTP
  • 足すだけで、消さない
⇄

Rust の核

  • 読み書き・解析を 1 つの実装に
  • ビット単位で同じ出力
  • 作業量で数える予算
  • 診断を code と場所で返す
⇄

形式

  • SXF（SFC・P21）
  • JWW・JWC・JWS
  • DXF・DWG
  • IFC・PDF ほか

文言は核に持たせず、日本語と英語のカタログから引きます。各言語への約束は、適合試験のハッシュで確かめます。

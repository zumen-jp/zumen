# プロファイル

基準・要領・社内標準を、コードとは別の、版のあるデータとして持ちます。照合は、API の `check` の op に `profile.json` を `zm_push` で渡して行います。

| id | 版 | 対象 |
| --- | --- | --- |
| `mlit-cad` | [2025-12](mlit-cad/2025-12/profile.toml) | CAD製図基準（土木、令和 7 年 12 月） |
| `mlit-earthwork` | [2026-03](mlit-earthwork/2026-03/profile.toml) | 土木工事施工管理基準及び規格値（案）の土工の面管理（令和 8 年 3 月） |
| `mlit-delivery-const` | [2026-02](mlit-delivery-const/2026-02/profile.toml) | 工事完成図書の電子納品等要領（令和 8 年 2 月、`delivery_check` の op） |
| `mlit-delivery-design` | [2026-02](mlit-delivery-design/2026-02/profile.toml) | 土木設計業務等の電子納品要領（令和 8 年 2 月、`delivery_check` の op） |

## 直し方

- 元は `<id>/<edition>/profile.toml` です。直したら `cargo xtask codegen` で `profile.json` を作り直し、両方をコミットします。
- 値には出典の文書・節・項を書きます。出典が列挙しない値は `basis = "chosen"` にします。
- 基準の新しい版は、新しいフォルダーにします。同じ版のデータを直したら `revision` を上げます。
- 値には、出典の文書・節・表の番号を書きます。

## 確認申請のプロファイル

[#426](https://github.com/zumen-jp/zumen/issues/426) で実装する `mlit-bim-drawing` の初版は `edition = "2026-03"` です。BIM 図面審査のガイドライン・入出力基準・表現標準の項とページ、施行令を出典とします。規則に文や表を転載せず、表現標準が第三者から引用した部分は出典にしません。申請前に IFC のデータで確認できる項目だけを扱います。

| 規則 | 種類 | 出典 | 確かめること |
| --- | --- | --- | --- |
| `ifc-schema` | IFC のバージョン | 入出力基準 2-2-2 | ファイルの `FILE_SCHEMA` が `IFC2X3` であること。違えば warning |
| `models-aligned` | ファイルの重なり | 入出力基準 2-2-2、ガイドライン 6-3 | 複数の IFC の長さの単位と、建物の配置の原点と軸がそろうこと |
| `representation-present` | 形の有無 | ガイドライン 6-3 | 形を持つはずの要素（壁・柱・梁・床・屋根・扉・窓・空間）が、形状表現を持つこと |
| `room-use` | 属性の有無 | 入出力基準 意-012① | 空間の要素に、用途の属性があること |
| `area-region-code` | 属性の有無 | 入出力基準 意-013①の 2、意-014①の 2 | 面積の領域の要素に、符号の属性があること |
| `floor-area-ratio` | 属性の有無 | 入出力基準 意-014② | 床面積の領域の要素に、容積率の対象内外の別の属性があること |
| `fire-compartment` | 属性の有無 | 入出力基準 意-015① | 壁・柱・床・扉・窓の要素に、防火区画等の種別の属性があること |

型への対応は下位の型を含め、プロファイルの語彙に `basis = "chosen"` で記録します。属性の名前と面積領域の型は基準が定めていないので、初版で空にし、利用者が `extends` で指定します。空なら規則ごとに確認できなかったことを返します。PDF の図書との一致や設計者の判断を要する法令適合は判定しません。

面積は領域の形のまま m² で求め、丸める前の値も返します。階別は区分の合計後、用途別は用途ごとの合計後に、10 進で小数点以下 2 桁に切り捨てます。丸めは表現標準の記載例に基づく選択です。建築面積の地階や軒の除外を検証していないことも結果に残します。BIM データ審査の基準が公表されたときは別の ID で扱います。

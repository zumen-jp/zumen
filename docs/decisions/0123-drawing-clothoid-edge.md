# 0123: クロソイドは、原点・パラメーター・向き・長さの範囲で持つ辺にする

| 日付 | 2026-10-28 |

## 背景

[決定 0022](0022-drawing2d-semantics-and-format-mapping.md) は、L2 が曲線の厳密な定義を保ち、近似するなら許容差を付けることを決めた。対応表の E8 は、1 区間のクロソイドを試す。[決定 0111](0111-drawing-curves.md) は、DXF に専用の要素がないので、クロソイドを扱わなかった。SXF の `clothoid_feature` は、原点（曲率が 0 の点）・パラメーター A・曲がる向き・原点での接線の向き・原点からの始まりと終わりの長さを持つ（#171）。

## 選択肢

1. `Edge` に、元の値のままのクロソイドを足す。
2. 点の列や円弧の列に近似し、許容差を付けて持つ。
3. スプラインに近似して持つ。

## 決定

選択肢 1 を採る。近似すると、元の定義に戻せず、許容差の選び方が表示側の事情に縛られる（決定 0111 と同じ理由）。

- `Edge::Clothoid` は、原点・パラメーター・原点での接線の向き（度）・曲がる向き・原点からの始まりと終わりの長さを持つ。長さとパラメーターは、点と同じ空間の長さにする。原点からの長さ s の点での接線の向きは、原点での向きから s²/2A² ラジアンだけ曲がる向きへ回る。原点より手前（負の長さ）は、原点について点対称に続く。
- SXF の `clothoid_feature` を、値のまま移す。曲がる向きのフラグは、円弧と同じく 0 を反時計回りとする（推定）。パラメーターが正でないもの、始まりと終わりの長さが同じものは `sxf.lift.invalid` で落とす。
- 境界の `entities` の範囲（[決定 0118](0118-entities-bbox-fields-region.md)）は、端点と、接線の向きが 90 度の倍数になる点（X か Y の極値）で囲む。点の位置は、接線の向きの積分をシンプソンの公式で求める。区間の数は、パラメーターに対する長さに比べて増やし、上限で止める。極値が 1024 を超えるものは、原点から長さの最大までの正方形で囲む（曲線上の点は、原点からたどった長さより遠くない）。

## 影響

- 範囲の値は、積分の誤差のぶん、厳密な値からずれる。区間の数の上限を超える長いものほど、ずれが大きい。
- DXF へ書き出すときは、出力先に専用の要素がないので、近似して許容差を付けるか、診断する。書き出しを作るときに決める。

# 0181: 書式つきの文字は枠の幅で折り返して置き、DXF の特殊な符号は呼び出し側が解き、縦書きは置かない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0176](0176-text-layout-with-glyph-metrics.md) は、1 行の文字（`Text`）を、呼び出し側が渡す字形の寸法で置いた。内容の文字を 1 つずつ並べるだけで、書式つきの文字（MTEXT、[決定 0109](0109-drawing-formatted-text.md)）・縦書き・DXF の特殊な符号（`%%d` など）・カーニングは扱わなかった。フォントのファイルから寸法を読めるようになった（[決定 0180](0180-read-truetype-metrics-without-dependency.md)）ので、これらの扱いを決める（#330）。

## 選択肢

1. 書式つきの文字を `zumen_drawing::layout` で置く。特殊な符号は、解く関数を別に用意して呼び出し側が使う。縦書きは、縦書きの字形の寸法を受け取るまで置かない。
2. 1 に加え、縦書きを、送りを em とみなして置く。
3. 書式つきの文字の配置は、表示する側に任せる。

## 決定

選択肢 1 を採る。2 の縦書きは、句読点の位置や縦書きの字形への置き換え（OpenType の `vert`）がない近似で、結果が表示と合うか確かめる方法がない。3 は、ネイティブ・wasm・各言語で同じ結果を返す約束（[決定 0007](0007-single-rust-implementation.md)）を表示する側に負わせる。

- **書式つきの文字。** `place_formatted` が、`FormattedText` を行に分けて置き、字形ごとに字形の単位から図面の座標への変換を返す。行（基準線の深さ・左からの位置・幅）、枠の幅と内容の高さ、フォントにない文字の数も返す。
- **フォント。** 呼び出し側が `Fonts` で、文字スタイルのフォントと、区間で指定されたフォント（`Font`）を渡す。区間のフォントを渡されなければ文字スタイルのフォントで置き、区間の数を返す。
- **区間の書式。** 字の高さ・幅の倍率・字の間隔・斜体・フォント・行の中の位置合わせを当てる。倍率（`Scaled::Factor`）は、文字全体の高さと、幅・間隔の既定値 1 にかける。字の間隔は、送りにかける（推定）。行の中の位置合わせは、中央と上を、行でいちばん高い大文字の高さに合わせ、下と基準線は基準線に置く。色と下線・上線・取り消し線は、区間の書式のまま表示する側が使う。
- **折り返し。** 枠の幅が正なら、その幅を超える前で折り返す。折り返す所は、空白の後と、全角の文字（漢字・かな・ハングル・全角形）の前後に限り、なければ文字の間で切る。空白は行の終わりにぶら下げ、行の幅に含めない。段落の区切りで改行し、段の区切りも段組みを移さない（決定 0109）ので改行にする。禁則（行頭の句読点など）は扱わない。
- **行送り（推定）。** 1 行目の基準線は、行でいちばん高い大文字の高さだけ枠の上から下げる。次の行は、文字の高さの 5/3 倍に行送りの倍率をかけた分だけ下げる。AutoCAD のヘルプの「1 行の行送りは文字の高さの 1.66 倍」から推定した。行送りを固定しない（`exact` が偽）ときは、その行でいちばん高い字の高さを使う。内容の高さは、最後の基準線にディセンダーを足したものにする。
- **位置合わせ。** 枠の幅（なければいちばん長い行の幅）の中で、行ごとに左・中央・右に揃える。基点には、枠の左上・中央・右下など 9 点のうち指定の点を合わせる。外形の中央は中央に、基準線は下に読み替える。宣言された枠の高さ（`frame_height`）は使わない。
- **置かない区間。** 上下に重ねた文字・寸法の測定値と寸法線の下の印・解釈できない符号は置かず、区間の位置を返す。上下に重ねた文字の大きさと位置は、表示と比べてから決める。
- **特殊な符号。** `decode` が DXF の特殊な符号を解く。図面モデルの内容は元の符号のまま持つ（決定 0109）ので、配置の関数は解かず、DXF・DWG の文字と知っている呼び出し側が、解いた内容を渡す。`%%d`・`%%p`・`%%c` は、AutoCAD のヘルプが同じ記号に当てる U+00B0・U+00B1・U+2205 にし、`%%%` は `%` にする。`%%nnn` は 127 以下の値だけを文字にし、大きい値は文字コードのページに依るので符号のまま残す。`%%u`・`%%o` は、1 行の文字では下線・上線の範囲（解いた内容の文字の位置）にし、書式つきの文字では解かない（推定）。解けない符号（GD&T の `%%v` など）は内容に残し、数を返す。
- **カーニング。** `Glyphs` に、並んだ 2 文字の間に足す送りを返す `kerning` を足す。既定は 0 で、既存の実装は変わらない。1 行の文字と、書式つきの文字の同じ区間の中で当て、区間をまたいでは当てない。折り返した行の始まりでも当てない。
- **縦書き。** 書き進める向きが縦書き（文字スタイルに従い、その文字スタイルが縦書きのときを含む）なら、置かずに理由（`Unplaced::Vertical`）を返す。`Glyphs` は縦書きの送りと字形の置き換えを受け取らず、AutoCAD の縦書きは形のファイル（SHX）だけが持つが、SHX はまだ読まない（後に[決定 0187](0187-vertical-text-stacks-and-kinsoku.md) で、縦書き・上下に重ねた文字・禁則を置くことにした）。
- **作業量。** 1 行の文字と同じく予算は取らない。作業量は内容の文字数に比例し、折り返しも 1 行の中を後ろから探すだけで、内容の長さは読み取りの予算で抑えている（[決定 0010](0010-budget-by-work.md)）。

## 影響

- 書式つきの文字の配置は、合成のフォントで試験した。行送り・字の間隔・行の中の位置合わせ・特殊な符号の規則は推定で、AutoCAD の表示とはまだ比べていない。
- `font` の TrueType の読み取りは、カーニングの表（`kern`・GPOS）を読まない。読むかは、表示と比べるときに決める。
- 残る作業は、縦書き（縦書きの寸法と字形の置き換え、または SHX）、上下に重ねた文字、禁則、カーニングの表の読み取り、表示との照合で、それぞれ issue で追う。シーン（[決定 0172](0172-scene-sections-and-op.md)）に字形の区画を足すかの判断も、それに続ける。

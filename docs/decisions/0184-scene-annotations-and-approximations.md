# 0184: シーンで寸法・表・引出線・ハッチングの線を描き、残る近似を診断で返す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0172](0172-scene-sections-and-op.md) と [決定 0178](0178-scene-layout-columns.md) の 2D のシーンは、寸法・引出線・注記・表とハッチングのパターンの線を描かず、線種に添える形と文字、DWF・DGN の下敷き、下敷きの切り抜きを落としていた。当てはめる点だけのスプラインは点を結ぶ折れ線、外側の島だけを残すハッチングは偶奇の塗り、書式つきの文字の区間の色と高さの意味は無視、範囲の絞り込みは塊だけで行っていた（#335）。

## 選択肢

1. 図面モデルにある値だけから描けるものを描き、描けないものは理由を診断で返す。
2. 元の形式の表示の規則（寸法スタイルの全体・形のファイルの字形など）を再現してから描く。
3. 今のまま落とし、表示する側に任せる。

## 決定

選択肢 1 を採る。描けるものは描き、描けないものと形を変えたものは診断で返す。

- **描いた部品をたどる。** `Drawing2D::walk_parts` は、`walk` と同じく配置をたどり、寸法の `block`（名前で探す。DXF の名前のないブロック）、表の `drawn`、引出線つきの注記の記号の中へも、要素を 1 段の配置として進む。寸法の部品は定義の空間の座標のまま、表の部品は挿入点へ移すだけで置く（推定。表の向きは部品が持つとみなす）、注記の記号は記号の配置で置く。部品の中の要素は、記号の中身と同じく、道筋に寸法・表・注記の要素を持つ。`walk` は変えない。
- **部品のない寸法。** 定義点から補助線と寸法線（角度・弧長は弧）を線種つきで描く。寸法値は、上書きの文字の区間が高さを持つときだけ置き、測定値の区間は測り直した値（小数第 2 位まで）にする。寸法スタイルは文字の高さ・矢印の形を十分に持たないので、端部記号と書式の高さのない寸法値は描かず、`scene.dimension.approximated` を返す。定義点から交点が決まらない寸法は `scene.dimension.dropped` を返す。
- **部品のない表。** 行の高さと列の幅から、覆われないセルごとに上と左の辺を、表の右と下の辺を描く。セルの文字は、セルか行の種類の書式が高さを持つときだけ、位置合わせの角から高さの半分だけ内に置く（推定）。枠の表示・色・塗りと記号のセルは描かず、`scene.table.approximated` を返す。
- **引出線と注記。** 経路を線種つきで描き、曲線の経路は点を通る 3 次のスプラインにする。既定の端部記号は、長さが寸法スタイル（注記は自分）の大きさ × 倍率、幅がその 1/3 の塗った三角にする。記号の定義の端部記号と、大きさの決まらない端部記号は `scene.arrowhead.dropped`。注記の文字は書式つきの文字として、線と中身の色はそれぞれの色で描く。注記の記号の属性の値は `scene.callout-value.dropped`。
- **ハッチングのパターンの線。** 線の組ごとに、輪の内側（偶奇の規則）に切った平行線を、要素の空間で作って起点へ写す。線と間の列は線の通る点から測る。`double` の重ねは、読む側が線の組に入れてあるものとする。線の間隔が許容差以下の組は塗りにし、`scene.hatch-pattern.approximated` を返す。作る線の数を見積もって予算の `segments` で先に数える。
- **外側の島。** `Islands::Outer` は、ほかの輪に囲まれる数（輪の最初の頂点で決める）が 1 以下の輪だけを、偶奇の規則で塗るか切る。
- **当てはめる点だけのスプライン。** The NURBS Book の 9.2.4 の、両端の接線を与える 3 次の補間で節点と制御点を作り、折れ線にする。媒介変数は節点の取り方（弦・平方根・等間隔）に従い、接線の長さは弦の長さの和にする。接線がなければ端の 3 点の 2 次式の接線にする。CAD の内部の計算は公開されていないので、これも推定で、点は必ず通る。許容差で近づけるスプラインは `scene.fit-tolerance.approximated`。補間できなければ、今までどおり点を結んで `scene.spline.approximated`。
- **線種に添える文字。** 列の要素の始まりごとに、ずれと回転（相対・絶対・読める向き）を当てて、左下の基準線で置く。高さは決定 0166 の高さに列の倍率を掛ける。形（形のファイルの字形）は字形を読まないので描かず、`scene.line-type-shape.dropped` を返す。
- **下敷き。** DWF・DGN も画像の行にし、`image_kind` に `dwf`・`dgn` を足す。資源の中身を描くのは表示する側。切り抜きは、画素の格子なら DXF の IMAGE と同じく左上の画素の中心を原点とする下向きの画素の座標、尺度で写す置き方なら内容の座標（推定）として起点の多角形にし、単位の切り抜きの組の内側に足す。内容の大きさの分からない置き方（四隅）の切り抜きは、今までどおり `scene.underlay-clip.dropped`。
- **書式の色と高さの意味。** 書式つきの文字の区間の色は、色だけを変えた単位（同じ要素を指す）にする。高さの意味は、`text_flag` に `height_frame`（文字枠の高さ）と `height_em`（em）を足して渡す。どちらもなければ大文字の高さか、形式の宣言値。字形の寸法を使う高さの換算と字形の描画は、フォントを境界で受け取る #337 で行う。（後に[決定 0188](0188-scene-fonts-and-glyph-outlines.md) で行った）
- **範囲の絞り込み。** 重なる塊の中でも、範囲に重なる描くものだけを残し、空になった塊は返さない。文字は基点から字数 × 高さ × 幅の倍率（枠の幅があればその幅）の大きめの範囲で、内容の大きさの分からない画像はいつも残す。要素ごとの表（単位・要素・道筋・色・切り抜き・レイヤ・フォント・文字列）も、残る描くものが引く行だけに絞り、番号を初めて引く順に振り直す。
- 使わなくなった `scene.table.dropped`・`scene.callout.dropped`・`scene.hatch-pattern.dropped`・`scene.underlay.dropped`・`scene.line-type-mark.dropped` は retired にする。

## 影響

- シーンの配置の小版を 1.1 にした。境界の op と欄は変えていない。シーンの応答のハッシュが変わったので、適合試験のハッシュを作り直した。
- 寸法の部品は名前だけで探すので、別の名前空間に同じ名前の定義があれば先のものを使う。表の部品の置き方と下敷きの切り抜きの座標は、実際の図面で確かめて直す。
- 字形の区画が要る文字の描画（形のファイルの形を含む）は #337 で扱う。

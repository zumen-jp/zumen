# 0169: 図面モデルの変更を SXF の P21 の実体に書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0167](0167-sxf-sfc-apply.md) の apply は、図面モデルの変更を SXF の SFC に書き戻す。P21 は読めるが、境界の `apply` は `change.format.unsupported` で断る。`capabilities` は SXF を書けると返すので、P21 の図面を直したい使い手と AI には、断る理由が分かりにくい。

P21 は、ISO 10303-21 の実体が互いを参照で指す（[決定 0120](0120-sxf-l1-exchange-structure.md)）。

- 図形の要素は、表記の実体（`ANNOTATION_CURVE_OCCURRENCE` など）である。表記の実体は、見え方の割り当て（`PRESENTATION_STYLE_ASSIGNMENT`）と幾何の実体を指す。
- 見え方の割り当て、曲線の見え方（`CURVE_STYLE`）、色、線種、点は、ほかの要素と共有しうる。
- 用紙（`DRAWING_SHEET_REVISION`）、レイヤ（`PRESENTATION_LAYER_ASSIGNMENT`）、非表示（`INVISIBILITY`）、複合図形の定義（`DRAUGHTING_SUBFIGURE_REPRESENTATION`）は、要素を参照の並びで持つ。
- 変換は、実体を SFC と同じ形のフィーチャに組み直して、SFC と同じ変換に通す（[決定 0132](0132-sxf-p21-through-sfc-features.md)）。要素の ID は、表記の実体の番号で作る（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）。

## 選択肢

1. P21 の実体を、図面モデルか組み直したフィーチャから書き直す。
2. 変える要素の表記の実体だけを書き直す。見え方と幾何は新しい実体を足して指し替え、元の実体は書き換えない。要素の並びは、参照を除くか足すかで書き直す。どこからも指されなくなった幾何と見え方の実体は除く。
3. 共有している実体を、その場で書き換える。

1 は、組み直しが移さない実体（見出し、組織、寸法の関係など）を保てない。3 は、同じ見え方や点を共有するほかの要素まで変えてしまう。

## 決定

選択肢 2 を採る。変更を受ける形と、何を当てて何を断るかは、SFC の書き戻し（決定 0167）と同じにする。表のコードの求め方と形の値の求め方は、SFC と共有する。書き方だけを P21 の実体に合わせる。

- **スタイルの変更（`Restyle`）。** 曲線の表記の実体が対象である。
  - 新しい曲線の見え方と見え方の割り当てを足し、表記の実体がそれを指すようにする。
  - 変えない欄は、元の曲線の見え方の値を写す。
  - 色と線種は、コードを持つ実体を指す。既定義の色と線種の実体がなければ、名前で足す（`DRAUGHTING_PRE_DEFINED_COLOUR`・`DRAUGHTING_PRE_DEFINED_CURVE_FONT`）。
  - 線幅は、同じ太さの `LENGTH_MEASURE_WITH_UNIT` があればそれを指す。なければ、型を付けた数（`POSITIVE_LENGTH_MEASURE`）で書く。
  - レイヤを変えるときは、ほかのレイヤの並びから表記の実体の参照を除き、求めたレイヤの並びへ足す。複合図形を入れる仮のレイヤ（`$$SXF_dummy`）の並びは変えない。
  - 割り当てが曲線の見え方のほかの見え方も持つときは断る。
- **置き換え（`Replace`）と移動（`Transform`）。** 線分・折線・円・円弧が対象である。幾何の実体を足し、表記の実体がそれを指すようにする。
  - 線分は、端点の `CARTESIAN_POINT`、`LINE`、点で端を決めた `TRIMMED_CURVE` で書く。
  - 折線は、`POLYLINE` で書く。
  - 円は、原点に中心を置いた `AXIS2_PLACEMENT_2D` と `CIRCLE` で書く。
  - 円弧は、円をラジアンの媒介変数で端を決めた `TRIMMED_CURVE` で書く。時計回りは、向きを `.F.` にする。
- **除去（`Remove`）。** 表記の実体を除き、用紙・レイヤ・非表示・複合図形の定義の並びから参照を除く。
  - ほかの実体が並びのほかの所から指す要素（寸法の関係が指す寸法など）は断る。
  - 並びは空にできない（ISO 10303 の `SET [1:?]`）。並びが空になる除去とレイヤの変更は断る。ただし非表示の並びは、空になれば非表示の実体ごと除く。
- **追加（`Add`）。** 用紙に、線分・折線・円・円弧を足す。
  - 幾何、曲線の見え方、見え方の割り当て、表記の実体（`ANNOTATION_CURVE_OCCURRENCE`）を足す。
  - 表記の実体を、用紙の並びの終わりと、レイヤの並びへ足す。
- **書き直し方。**
  - 足す実体には、ファイルの最大の番号の次から番号を付け、最後の実体の後に書く。
  - 書き直す実体は、元の値の範囲を写して書き直す。
  - 除くものと書き直すもののほかのバイトは写す。
  - 数は、読み直すと同じ値になる最短の 10 進に小数点を付けて書く。
- **後片付け。** 除いた実体と、指すのをやめた実体から参照をたどり、どこからも指されなくなった幾何と見え方の実体を除く。どこからも指されなくなった実体は、そのほかの種類（色・線種・線幅など）なら残す。
- **確かめ方。** 決定 0167 と同じく、読み直して図面モデルに変換し、変えた要素と足した要素が求めた値になり、ほかの要素の ID と値が変わらないことを確かめる。合わなければ、何も変えずに断る。
  - 円弧の角度は、ラジアンで書いて度で読むので、最後の桁が違いうる。角度だけは、相対誤差 1e-9 まで同じとみなす。
- **ID。** 表記の実体の番号を変えないので、変えていない要素の ID はずれない。
- **境界。** スキーマは変えない。`apply` は P21 も受ける。

## 影響

- 使い手と AI は、P21 の図面を P21 のまま直せる。見出しと、変えない実体のバイトは残る。
- 書き直した表記の実体と並びの実体は、元の改行と空白を保たない。値は同じである。
- 書き戻した円弧の角度は、求めた値と最後の桁が違いうる。apply が返すハッシュは、読み直した値のものである。
- レイヤの最後の要素は除けない。除くには、要素をほかのレイヤに移してから除くことになるが、レイヤの除去はまだない。
- 文字・寸法・記号などの形とスタイルの変更、楕円とスプラインの形の変更、表の変更は、SFC と同じく、まだ書き戻さない。
- 書き戻した P21 を SXF の対応ソフトウェアが開けるかは、そのソフトウェアを使える環境で確かめる必要がある。

# 0130: SFC の作図部品は記号の定義に、既定義シンボルは名前のキーに、部分図の中の部分図は重ねたビューにする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

[決定 0121](0121-sxf-sfc-lift-to-drawing.md) は、部分図（区分 1・2）を実寸の空間とビューに、作図グループ（区分 3）を置いた所への展開にしたが、作図部品（区分 4）の配置と、部分図の中に置いた部分図は、まだ移さなかった。既定義シンボル（`externally_defined_symbol_feature`）は、レイヤのコード・色を指定するか・色のコード・名前・配置の点・回転・尺度を持ち、形は既定義の表で決まり、ファイルは形を持たない。図面モデルのビューは用紙に置き、空間の中には置かない（#171）。

## 選択肢

1. 作図部品を、名前空間 `sxf.sfig` の名前のキーを持つ記号の定義にし、配置を記号の配置にする。既定義シンボルを、名前空間 `sxf.symbol` の名前のキーで指す配置にする。部分図の中の部分図は、外の部分図のビューの変換を重ねたビューにして、用紙に置く。
2. 作図部品を、作図グループと同じく、置いた所に展開する。部分図の中の部分図を、外の部分図の空間に展開する。

## 決定

選択肢 1 を採る。展開すると、同じ部品を何度も置いたことと、部品の名前が分からなくなる（[決定 0108](0108-drawing-symbols-hatches-arrowheads.md)）。部分図を外の空間に展開すると、部分図ごとの空間と縮尺が失われる。

- 作図部品の定義は、ほかの定義と重ならない ID の空間に中身を移し、基点を原点にする。配置は、点・X と Y の尺度・回転を持つ記号にし、色と線種はレイヤに従う。
- 既定義シンボルは、尺度を X と Y に同じ値で入れる。色を指定するなら、その色にし、指定しないなら、色はレイヤに従う（推定）。既定義の形は、記号の定義として持たない（点マーカーと同じ。[決定 0126](0126-sxf-splines-and-point-markers.md)）。
- 部分図の中の部分図は、外の部分図を用紙に置いたときに、外の変換と中の配置の変換を重ねたビューにして、外のビューの後に置く。外の部分図の中の作図グループの中も見る。外の部分図を用紙に置かなければ、中の部分図も置かない。
- 作図部品の中に置いた部分図は、置く用紙が決まらないので `sxf.lift.dropped` で報告する。区分が 1〜4 でない定義の配置は `sxf.lift.invalid` で落とす。診断の code は足さない。

## 影響

- 部品と既定義シンボルの形を描くのは、表示側が記号の定義と名前から引く。
- 部分図の中の部分図のビューには、外の部分図の切り抜きを付けない。SFC の部分図は切り抜きを持たない。

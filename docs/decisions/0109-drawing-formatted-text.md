# 0109: 図面モデルの書式つきの文字を、元の内容と書式の区間に分けて持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0022](0022-drawing2d-semantics-and-format-mapping.md) は、文字に元の内容・書式の区間・フォントの指定・縦書きと横書き・幅・間隔・行送り・斜体・回転を持たせ、元の制御文字と解釈できた書式を区別し、解釈できない書式を黙って削除しないことを決めた。配置は、9 点の枠への位置合わせ・基準線・2 点の間への配置を区別する。図面モデルの文字（`Text`）は 1 行の TEXT の欄だけを持ち、DXF・DWG の MTEXT と複数行の属性は移していなかった（[決定 0108](0108-drawing-symbols-hatches-arrowheads.md)）。

## 選択肢

1. 書式つきの文字を `Text` と別の要素にする。元の内容と、内容を解釈した区間を両方持ち、解釈できない符号は区間の中に元の符号のまま置く。枠・行送り・背景・書き進める向きは要素の値にする。
2. `Text` に区間と枠の欄を足し、1 行の文字と書式つきの文字を同じ要素にする。
3. 書式の符号を除いた文字列だけを持つ。

## 決定

選択肢 1 を採る。1 行の文字は 2 点の間への配置と反転を、書式つきの文字は枠と行送りを持ち、欄の意味が違う。同じ要素にすると、使わない欄の値を決めなければならない。3 は書式を黙って捨てる（決定 0022）。

- `Shape::Formatted` は `FormattedText` を持つ。元の内容・区間・宣言された高さ・基点・枠への水平と垂直の位置合わせ・向き・枠の幅と高さ・書き進める向き（`Flow`）・行送り（`LineSpacing`）・背景と枠の線（`Background`）・文字スタイルの名前を持つ。
- 向き（`Rotation`）は、角度か文字の X 軸の向きを、元の形式が持つ形のまま持つ。角度に直すと三角関数が要り、元の値も分からなくなる。
- 区間（`Span`）は、中身（`Piece`: 文字列・段落の区切り・段の区切り・上下に重ねた文字・解釈できない符号）と、効いている書式（`Format`）を持つ。書式は、文字全体の値から変えたものだけを持つ。字の高さ・幅・間隔は、値か文字全体の値への倍率（`Scaled`）にする。フォント（`Font`）は元の名前と、形のファイルか名前で指すフォントかを持ち、取得と字形の評価はしない。
- 解釈できない符号は `Piece::Unparsed` に元の符号のまま置き、診断を返さない。内容は捨てていないので、黙って捨てることにはならない。
- 記号の属性（`Attribute`）は、複数行の属性の書式つきの値を `formatted` に持つ。1 行の値（`text`）も、元の形式が持つので残す。
- DXF・DWG の MTEXT と複数行の属性（埋め込みの MTEXT）を移す。段組みのものは移さず、新しい診断 `dxf.mtext-columns.unsupported` を返す。内容の 250 バイトの区切り（3）も、作業量として数える（[決定 0010](0010-budget-by-work.md)）。
- 境界（`drawing` の op）の要約は、書式つきの文字を数えず、範囲にも入れない。要約の欄は、要素の一覧の op（#66）と合わせて決める。

## 影響

- 寸法の文字（DIMENSION の 1）と、引出線の注記の書式の符号は、まだ解釈しない。寸法の文字は、元の文字列のまま持つ。
- MULTILEADER と段組みの MTEXT は、まだ移さない。
- 真の色（`\c`）は値のバイト順を確かめていないので、段落の書式（`\p`）は区間の書式でないので、解釈しない符号として残す。
- 字形の大きさと、枠の中の折り返しは、L3 と `text` が、渡されたフォントで評価する（決定 0022）。

# 0049: DWG（R2000）への書き戻しは、LAYOUT のフィールドを DWG の並びのまま書き直し、レイアウトの名前は変えない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0048](0048-dwg-write-back-dictionary-mlinestyle.md) までで、OBJECTS のうち GROUP・DICTIONARYVAR・DICTIONARY・MLINESTYLE のフィールドを R2000 の DWG に書き戻せるようにした。LAYOUT と XRECORD は、まだ書き戻せない。

読む側は、LAYOUT の印刷の設定の 28 のフィールドと、レイアウトの 26 のフィールドを、すべて DWG の並びで置く。値の形は、文字列・BS・BD・RD のどれかで、度やビットの並べ直しはない。同じ番号（1・70）が 2 度出る。紙空間のブロックのレコードなどの 4 つのハンドルは、ハンドルの並びから作る。

## 選択肢

1. 値の番号の並びが元と同じときだけ受け付け、フィールドを DWG の並びのまま、すべて書き直す。
2. フィールドを除いたものも受け付け、除いたフィールドは既定の値で書く。

2 は、読む側がすべてのフィールドを置くので、除いたフィールドは読み直すと戻ってしまう。

## 決定

選択肢 1 を採る。

- 値の番号の並びが元と違う変更（フィールドの追加と削除）は受け付けない。
- 54 のフィールドを、DWG の並びのまま、それぞれの形で書き直す。BS に収まらない整数は受け付けない。
- レイアウトの名前（2 つめの 1）は、辞書の項目の名前で指されるので、変更を受け付けない。
- ハンドルの並びから作る値（330・331・345・346）の変更は受け付けない。

## 影響

- 手で組んだ R2000 の LAYOUT で、印刷の機器・紙の幅・印刷の単位・範囲・高さを変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。サンプルの図面のレイアウトの高さ（146）も変えて書き戻す。
- XRECORD のフィールドの変更は、まだ書き戻せない。

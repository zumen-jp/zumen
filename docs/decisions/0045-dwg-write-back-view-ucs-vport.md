# 0045: DWG（R2000）への書き戻しは、VIEW・UCS・VPORT の欄を DWG の並びで書き、UCS を伴う印は変えない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0044](0044-dwg-write-back-ltype.md) までで、LAYER・STYLE・LTYPE の表のレコードの欄を R2000 の DWG に書き戻せるようにした。VIEW・UCS・VPORT は、まだ書き戻せない。

読む側は、3 つの欄を DXF の順に並べ直して置く。角度は度に直し、見え方の 4 つのビットを 71 にまとめる。VIEW の紙空間の印は 70 の 1 に、VPORT の UCS に従う印は 71 の 8 に置く。VPORT の幅は、DWG では高さとの積で持つので、高さとの比（41）に直す。VIEW は、UCS を伴うときだけ UCS の欄を持ち、ハンドルの流れに 2 つのハンドルが続く。UCS の後に続く正投影の型と、VPORT の使い道の分からないビットは、表に置かない。

## 選択肢

1. 表の値を DWG の並びで書き、表にない欄は元のまま写す。UCS を伴う印は変えない。
2. UCS を伴う印の変更も受け付け、ハンドルの流れを作り直す。

2 は、ハンドルの流れの書き直しが要る。ハンドルの流れの変更は、まだどの書き戻しも扱わない。

## 決定

選択肢 1 を採る。

- 角度（VIEW の 50、VPORT の 50・51）は、度からラジアンに直す。見え方の印（71）は 1・2・4・16 と、VPORT では 8 だけを受け付ける。
- VIEW の 70 は 1 と、外部参照に依る印（16）だけを受け付ける。UCS と VPORT の 70 は、外部参照に依る印だけを受け付ける。外部参照に依る印は、元のものと同じでなければ受け付けない。
- VIEW の UCS を伴う印（72）は、元のものと同じでなければ受け付けない。
- VPORT の幅は、高さ（40）と比（41）の積で書く。高さと比が変わらなければ、元の幅を写す。UCS のアイコンの印（74）は 0〜3 だけを受け付ける。
- UCS の正投影の型と、VPORT の使い道の分からないビットは、元のまま写す。

## 影響

- 手で組んだ R2000 の VIEW・UCS・VPORT で、高さ・ねじれ・原点・アイコンの印を変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面のビューとビューポートの高さと、UCS の原点も変えて書き戻す。
- APPID・DIMSTYLE・BLOCK_RECORD の表のレコードと、OBJECTS のオブジェクトの欄の変更は、まだ書き戻せない。

# 0242: 地質・土質調査の成果は crate `zumen-geology` に置き、ボーリング交換用データを boring の op で読む

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

段階 4（[#305](https://github.com/zumen-jp/zumen/issues/305)）では、電子納品の成果品のうち、地質・土質調査の成果を読む（[#390](https://github.com/zumen-jp/zumen/issues/390)）。ボーリング交換用データ（BED）は、ボーリング 1 本ごとの XML で、地質・土質調査成果電子納品要領（令和 8 年 2 月）の BED0500.DTD が要素を決める。

- 要素の名前と構成は、要領の付属資料（公開の PDF）の構造図にある。DTD の zip は取らずに、構造図から名前を拾った（2026-11-02）。
- DTD と記入例は、電子納品の頁が転載を禁じる。同梱も転載もしない。
- 中身は、位置（経度・緯度の度・分・秒と測地系のコード）・孔口標高・総削孔長と、深さごとの記録（地層・色調・観察記事・標準貫入試験・孔内水位など 50 余りの様式）である。調査会社の技術者の名前も入る。

決めることは、次のとおり。

- 領域のモデルの置き場所（土木・地理との境目）。
- 位置と標高の型。
- どこまで読むか。

## 選択肢

置き場所の選択肢は、次の 3 つ。

1. **`zumen-civil` に入れる。** 線形と同じ土木の crate になる。ただし線形・横断の型と、深さの記録は関係がない。
2. **`zumen-geo` に入れる。** 地理の地物（CityGML）と同じ crate になる。ただし地物の型は面と立体で、柱状の記録とは違う。
3. **新しい crate `zumen-geology` を作る。** 地質・土質の型だけを持ち、位置と標高は `zumen-crs` の型を使う。

## 決定

3 を選ぶ。

### crate

- `zumen-geology` に、ボーリングの型（`Boring` と、深さごとの記録の型）と、BED の読み取りを置く。読み取りは `zumen-xml`（L0）の上の L1 で、ほかのコーデックと同じく `zumen-sdk` の `Error` を返す。
- 土木（`zumen-civil`）と地理（`zumen-geo`）には依存しない。柱状図を図面に描くとき（別の issue）は、描く側がこの crate の型を読む。
- 地質平面図・断面図（CAD）、ボーリングコア写真、土質試験結果一覧表は、要るときに同じ crate に足す。

### 位置と標高

- 位置は、度・分・秒を度にして `zumen-crs` の地理の点（`GeoPoint`、[決定 0019](0019-coordinate-systems-and-gsi-data.md)）にする。測地系は換算せず、コード（00〜03）を列挙の値で返す。日本測地系と JGD2000 の換算は、[決定 0237](0237-datum-transformations.md) の格子で利用者が行う。
- 孔口標高は、東京湾平均海面からの標高（`Height`）とする。BED は成果を書かないので、測地系が JGD2024 なら測地成果2024 とし、そうでなければ調査の終わりの日（なければ始まりの日）が 2025-04-01 より前か後かで仮定して、`crs.height-realization.assumed` を返す。

### 読む範囲

- 基礎情報（適用規格・公開フラグ）、標題情報（調査名・ボーリング名・位置・住所・調査期間・孔口標高・総削孔長・角度・方位）、コア情報のうち地層・色調・観察記事・標準貫入試験（合計の打撃回数と貫入量）・孔内水位を読む。
- ほかの要素は、名前ごとに `boring.element.unsupported` を返す。調査会社（技術者の名前と登録番号）は読まず、返さない。
- 数として読めない値は、`boring.value.invalid`（要素の名前と値）を返して飛ばす。

### op

- 新しい op `boring`（小版 57）を、図面のモジュールに置く。要求は入力の名前だけで、結果はボーリング 1 本である。成果品の中の複数の BED を照らすのは、`delivery_check` のプロファイルの規則で足す。

## 影響

- 試験の試料は、構造図の名前で合成する。実データ（KuniJiban の柱状図など）との照合は、試料を入れるときに検証の記録に残す。
- 構造図から名前を拾ったので、DTD の本体と食い違う名前があれば、実データで見つけて直す。

# 0028: DWG（R2000）の変更は、変えたオブジェクトと地図をファイルの後ろに足して書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

DWG のコーデックは R2000・R2004・R2010・R2013・R2018 を読み（[決定 0026](0026-dwg-r2004-container.md)・[決定 0027](0027-dwg-r2010-reading.md)）、書くときは元のバイトをそのまま並べる。[#64](https://github.com/zumen-jp/zumen/issues/64) は、DWG への書き戻しを求めている。

- 共有の表の変更を DWG に戻すには、オブジェクトの欄をビット列に書く仕組みと、変わった大きさのオブジェクトをファイルに置き直す仕組みが要る。
- R2000 のオブジェクトは、オブジェクトの地図が指すファイルの中の位置に並ぶ。地図の後ろには、ほかの区切りと第 2 の見出しが続き、その中身は確かめていない。
- R2004 から後は、区切りを圧縮したページに分けて置くので、置き直すには入れ物を書く仕組みが要る。

## 選択肢

1. 変えたオブジェクトをファイルの後ろに足し、地図を作り直してその後ろに置き、見出しの区切りの記録を直す。
2. オブジェクトを詰めて並べ直し、後ろの区切りをずらす。
3. 大きさが変わらない変更だけを、元の位置で書き換える。

2 は、確かめていない区切りの中の位置をすべて直さなければならない。3 は、ほとんどの変更で大きさが変わるので使い道が狭い。

## 決定

選択肢 1 を採る。

- ファイルモデルの変更は、`DwgTxn::set_data` でオブジェクトのデータを置き換える。表の変更からデータを作る書き戻しは、この上に後で足す。
- 確定すると、変えたオブジェクトをファイルの後ろに足し、ハンドルの順の地図をその後ろに置く。見出しの区切りの記録の地図の位置と大きさと、見出しの CRC を直す。ほかのバイトは元のまま残す。
- R2000 だけを扱い、ほかの版は `dwg.edit.unsupported` を返す。
- 変えるたびにファイルは大きくなる。使わなくなったバイトは詰めない。

## 影響

- `zumen-acad` に `DwgTxn` と、診断の符号 `dwg.edit.unsupported`・`dwg.object.missing`・`dwg.data.invalid` が加わる。
- R2000 の図面のすべてのオブジェクトを置き換えて書き、読み直した表が元の表と同じになることを確かめた。
- 変えた DWG を AutoCAD が読むかは、まだ確かめていない。

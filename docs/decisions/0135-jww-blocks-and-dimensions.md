# 0135: JWW のブロックの定義は用紙の mm の空間を持つ記号の定義にし、寸法は線形の寸法にして図面モデルへ移す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

#172 で、[決定 0134](0134-jww-lift-to-drawing.md) が報告だけにしていたブロックと寸法を図面モデルへ移す。JWW のブロックの定義（CDataList）は番号・名前・参照の数と中の図形を持ち、中の図形は用紙の mm の座標を持つ。ブロックの参照（CDataBlock）は、置く点・横と縦の倍率・回転（ラジアン）と定義の番号を持つ。寸法（CDataSunpou）は寸法線と文字を持ち、版 420 からは SXF の形（モード・2 本の引出線・端点と基準点）を持つ。

## 選択肢

1. ブロックの参照を、定義の中の図形を展開して置く。
2. ブロックの定義を記号の定義にし、参照を記号の挿入にする。定義の中の座標は用紙の mm のまま持ち、挿入の尺度にグループの縮尺を掛ける。
3. 定義の中の座標を、参照するグループの縮尺で実寸にしてから記号の定義にする。

## 決定

選択肢 2 を採る。1 は定義の共有と名前を失う。3 は、縮尺の違うグループから同じ定義を参照すると、定義が 1 つに決まらない。

- **ブロックの定義。** 定義ごとに名前空間 `jww.block`、定義の番号を名前にしたキーの記号の定義を作る。中の図形は、ID を 16 + 定義の順番にした空間に、縮尺 1 の用紙の mm で置き、基点を原点とする。名前と参照の数は、図面の拡張 `jww.block` の欄 `name`・`referenced` に持つ。
- **ブロックの参照。** 記号の挿入にし、置く点はグループの実寸の座標、尺度は横と縦の倍率にグループの縮尺の分母を掛けたもの、回転は度とする。色と線種は、参照の図形を置いたブロックから受け継ぐ。
- **寸法。** 線形の寸法にする。版 420 からで SXF のモードが 0 でなければ基準点を、ほかは寸法線の両端を測る 2 点とする（推定）。寸法線の向きを寸法の向き、寸法線の始点を寸法線の位置とし、表示する値は文字の中身で上書きする。文字は始点を左下に置き、文字の角度で回す。寸法線・引出線・端点などの元の値は、要素を対象にした拡張 `jww.dimension` に持つ。
- **読めないもの。** 中身の読めない定義・参照・寸法は `jww.lift.invalid` で落とす。

## 影響

- 画像・編集の状態・文字の大きさの意味と、境界（`open`・`drawing`）へのつなぎは、#172 の続きで行う。

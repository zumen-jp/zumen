# 0183: 点の要素を書き戻し、形式が表せない点は断る

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0160](0160-drawing-points.md) で、DXF・DWG の POINT、JWW の点、SXF の点マーカーを、図面モデルの点（`Shape::Point`）として読むようにした。ただし、apply は点の置き換え・変換・追加をすべて `change.edit.unsupported` で断っていた（#334）。点の見え方は形式ごとに違う。DXF・DWG は文書の点の表し方（`$PDMODE`・`$PDSIZE`）に従い、JWW は記号の点だけが番号・角度・倍率を持ち、SXF は既定義の印を持つ。境界の幾何（`geometry`）にも点の形がなかった。

## 選択肢

1. 点の書き戻しを断ったままにする。
2. 形式ごとに、そのまま表せる点だけを書き、表せない点（ほかの形式の印、作図の補助の点など）は `change.edit.unsupported` で断る。
3. 表せない点を、近い形（文書の点の表し方に従う点など）に寄せて書く。

## 決定

選択肢 2 を採る。3 は、利用者が渡した見え方を黙って変える。新しい診断は作らない。

- **DXF・DWG。** 文書の点の表し方に従う、作図の補助でない点だけを POINT として書く。置き換えは位置（10・20）と角度（50）を書き直し、変換は相似で写す。追加は POINT に `AcDbPoint`・位置・0 でない角度を書く。DWG は角度をラジアンで持つので、読み戻した角度は最後の桁が変わりうる。
- **JWW。** 記号の点（線種 100）とほかの点は図形の大きさが違うので、置き換えで入れ替えない。記号でない点は角度を持たないので、角度 0 だけを受け、回す変換では角度を 0 のままにする。記号の点は名前空間 `jww.point` の印だけを受け、番号・角度・倍率を書く。スタイルは色とレイヤだけを変え、線種・線幅の変更は断る。追加は、記号の点を線種 100、ほかの点を線種 1、線幅 0 で書く。
- **SXF。** SFC は、名前空間 `sxf.marker` の作図の補助でない印だけを `point_marker_feature` として書く。レイヤと色（引数の 0〜1）と、位置・コード・回転・尺度を書き直す。マーカーは線種・線幅を持たないので、その変更は断る。鏡映は印の向きを表せないので断る（決定 0160 の変換と同じ）。P21 は、記号の実体（`SYMBOL_TARGET` など）を組み直す書き方をまだ持たないので、点マーカーのスタイル・形の変更と追加を断る。
- **文書の点の表し方。** `$PDMODE`・`$PDSIZE` の変更は受け付けない。変更の種類（置き換え・変換・追加・除去・スタイル）は要素を対象とし、文書の設定を変える種類がないため。点の書き戻しは、今の文書の点の表し方のまま行う。
- **境界。** `geometry` に点の形 `point_geometry`（位置・角度・印・作図の補助か）と、印 `point_marker`（名前空間・コード・倍率）を足し、小版を 35 に上げる。印の名前空間は `sxf.marker` と `jww.point` だけを受け、置き換えで文書の点と印の点を入れ替える指定は、その場所を指して断る。

## 影響

- 文書の点の表し方が向きを持つ印（`$PDMODE` の縦線など）のとき、鏡映した点の印は、元の印を鏡に映した形と一致しない。角度は写すが、印の形そのものは映さない。
- JWW で足した点の線種 1 は、Jw_cad の既定の点からの推定である。
- 書き戻した点は、AutoCAD・Jw_cad・SXF のビューアーでまだ開いて確かめていない。
- 文書の設定を変える変更の種類ができれば、`$PDMODE`・`$PDSIZE` の書き戻しをあらためて決める。

# 0038: DWG（R2000）への書き戻しは、POLYLINE と VERTEX の欄を型ごとに符号化し、DXF の決まった値は変更を受け付けない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0037](0037-dwg-write-back-hatch.md) までで、HATCH までの型ごとの欄を R2000 の DWG に書き戻せるようにした。R2000 の POLYLINE と VERTEX は、表ではどちらも 1 つの種類だが、DWG では 2D・3D・多面・網の型で欄が分かれる。読む側は、DXF に合わせて次のように表へ置く。

- POLYLINE には、頂点が続く印（66）を 1 として置く。2D 以外の点（10〜30）と 2D の 10・20 は 0 とする。多面の POLYLINE の 70 は 64 とする。
- 3D の POLYLINE は、DWG の 2 つの印から 70 と曲線の種類（75）を作る。
- 2D の VERTEX は、始まりの幅が負なら、終わりの幅を書かず、始まりと同じ絶対値とする。
- 多面の面の VERTEX は、点を 0、70 を 128 とする。

## 選択肢

1. 元のデータの型で欄を選び、DXF に合わせて決めた値は、その値のままのものだけを受け付ける。
2. 表の値から型を選び直す。

2 は、型を変えると、続く頂点の型やハンドルの流れも変わるので、1 つの図形の欄だけでは書き戻せない。

## 決定

選択肢 1 を採る。

- 型は元のデータの型（BS）から選ぶ。
- 66 が 1 でないもの、DXF に合わせて 0・64・128 とした値が違うものは、`dwg.change.unsupported` を返す。
- 3D の POLYLINE は、70 に 3D の印（8）があり、曲線の印（4）が 75 と合うものだけを受け付ける。DWG の 2 つの印は、読む値が変わらなければ元のバイトを写し、変われば読まれるビットだけを書き換える。
- 2D の VERTEX は、始まりと終わりの幅が同じで 0 でなければ、負の始まりの幅だけを書く。どちらかの幅が負のものは受け付けない。接線の向き（50）は、度からラジアンに直す。

## 影響

- 手で組んだ R2000 の 2D・3D・多面・網の POLYLINE と VERTEX で、幅と頂点を動かし、3D の POLYLINE を開いて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の VERTEX も、多面の面を除いて点を動かして書き戻す。
- 型を変える変更と、頂点を足す・外す変更は、まだ書き戻せない。
- DIMENSION などの型ごとの欄の変更は、まだ書き戻せない。

# 0091: R2010 から後の DWG から除いた図形は、R2004 と同じく、ブロックのレコードが持つ図形の並びから除いて書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 の DWG では、表から除いた図形を、ブロックのレコードが持つ図形の数（BL）とハンドルの並びから除いて書き戻せる（[決定 0077](0077-dwg-r2004-write-back-entity-removal.md)）。R2010 から後も、図形は前後の図形のハンドルを持たず、ブロックのレコードが持つ図形を並べる。オブジェクトのデータは、ハンドルのストリームの大きさ（MC）から始まり、名前などの文字列を文字列のストリームに持ち、外部参照の番号（BS）を持たない。R2013 からは、オブジェクトの共通のフィールドに DS のデータを持つかの B が足される。オブジェクトの削除自体は、[決定 0083](0083-dwg-r2010-object-edit.md) で書ける。

## 選択肢

1. R2004 と同じく、ブロックのレコードの持つ図形の数とハンドルの並びを直し、文字列のストリームは元のまま写して、MC を付け直す。
2. 除いた図形を残し、表からだけ除いたことにする。
3. 図形の削除は、まだ書き戻さない。

## 決定

選択肢 1 を採る。

- ブロックのレコードは、持つ図形の数（BL）を減らし、ハンドルのストリームから除いた図形のハンドルを除く。主のデータの長さだけが変わり、文字列のストリームと、その大きさ（RS）と有無のフラグは元のまま写す。
- 除ける図形は R2004 と同じく、図形を持たず、リアクターと拡張辞書を持たない種類に限る。
- 同じブロックのレコードのフィールドも変えたときは、書き直したデータの MC を読み、ハンドルのストリームの始まりを求めてから直す。
- 図形の追加は、まだ受け付けない。

## 影響

- サンプルの R2010・R2013・R2018 の図面で、LINE・CIRCLE・ARC・TEXT・INSERT から選んで除いて書き、読み直した表が除いた表と同じになった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

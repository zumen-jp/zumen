# 0053: DWG（R2000）への書き戻しで足す TEXT・ATTDEF・INSERT は、指す文字の体裁とブロックを名前で探してハンドルを書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0052](0052-dwg-write-back-entity-addition.md) で、表の終わりに足した単純な図形を R2000 の DWG に書き戻せるようにした。型ごとのハンドルを持つ図形は、まだ足せない。

TEXT と ATTDEF は文字の体裁を、INSERT はブロックのレコードを、ハンドルの流れの線種の後ろで指す。表では、これらを名前（7・2）で持つ。読むときは、文字の体裁が Standard なら 7 を置かない。INSERT は、属性を持つと、属性と SEQEND のハンドルも持つ。

## 選択肢

1. 指す表のレコードを名前で探してハンドルを書く。7 がなければ Standard を指す。属性を持たない INSERT だけを足せるようにする。
2. 表に、指すレコードのハンドルを別に持たせる。
3. 属性を持つ INSERT も、属性と SEQEND をまとめて足せるようにする。

2 は、DXF から読んだ表とも、DWG から読んだ表とも形が変わる。3 は、図形を持つ図形の並びを一から組むことになり、図形を持つ図形の削除（[決定 0051](0051-dwg-write-back-entity-removal.md)）と同じく、まだ扱わない。

## 決定

選択肢 1 を採る。

- TEXT・ATTDEF・INSERT を足せるようにする。TEXT と ATTDEF の型ごとの欄は、値を変えたときと同じ書き方で、元のデータなしで書く。
- TEXT と ATTDEF は、文字の体裁（7）を表の STYLE から名前（大文字と小文字は区別しない）で探す。7 がなければ Standard を探す。
- INSERT は、ブロック（2）を表の BLOCK_RECORD から名前で探す。`*Model_Space` と `*Paper_Space` で始まる空間のブロックと、足す図形の所有者のブロックそのものは指せない。属性を持つ印（66）は受け付けない。MINSERT の欄（70・71・44・45）も受け付けない。
- 指すレコードのハンドルは、ハンドルの流れの、線種の後ろに書く。見つからなければ受け付けない。

## 影響

- 文字の体裁 Standard・Mono と図形のないブロックを持つ手組みのファイルに、TEXT（7 のあるものとないもの）・ATTDEF・INSERT を足して書き戻し、読み直した表が足した表と同じになることを確かめた。表にない文字の体裁とブロック、所有者のブロックそのもの、66 を持つ INSERT は受け付けない。
- 試料の R2000 の図面のモデル空間に TEXT を、名前のあるブロックを持つ図面には INSERT も足して書き戻し、読み直した表が同じになることを確かめた。
- 属性を持つ INSERT、MINSERT、MTEXT など元のデータから欄を写す図形、図形でないオブジェクトの追加は、まだ書き戻せない。

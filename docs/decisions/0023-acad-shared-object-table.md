# 0023: AutoCAD の系統は、DXF と DWG が共有するオブジェクトの表を持ち、元のバイトは符号化ごとに持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[0008](0008-model-layers-and-codecs.md) は、形式の系統ごとに 1 つの L1 のモデルを持ち、DXF と DWG はその別々のコーデックとした。ところが [#3](https://github.com/zumen-jp/zumen/issues/3) の試作で作った `DxfFile` は、DXF のタグとレコードの並びを元のバイトとともに持つもので、DWG とは共有できない。

- DXF はテキストのタグの並びで、値はグループ・コードで名付けられる。DWG はビットで詰めたオブジェクトの並びで、同じデータベースを別の方法で符号化している。
- DXF の往復で元のバイトを保つ仕組み（決定 0008 の変えていないレコードの扱い）は、符号化に強く結び付いている。
- 型付きの見方と図面モデルへの変換（決定 0022）は、符号化によらずに書ければ、DWG を足したときに作り直さずに済む。

DWG のコーデックを書く前に、何を系統で共有し、何を符号化ごとに持つかを決める。

## 選択肢

1. 系統で共有するオブジェクトの表を置く。オブジェクトは種類と、DXF のグループ・コードで名付けた値を持つ。元のバイトは、符号化ごとのファイルモデルが持ち、表のオブジェクトはその場所を指す。
2. 先に DWG のコーデックを書き、2 つの符号化が揃ってから共有する所を決める。
3. 符号化ごとに別のモデルを持ち、図面モデル（L2）で初めて合流させる。

2 は、共有の形を決めないまま DWG の読み手を書くことになり、`DxfFile` と同じ作り直しが DWG でも起きる。3 は、型付きの見方と変換を符号化ごとに 2 度書くことになり、0008 の系統ごとのモデルに反する。

## 決定

選択肢 1 を採る。

- `zumen-acad` に、系統で共有するオブジェクトの表 `AcadDb` を置く。ハンドルでオブジェクトを引ける。
- オブジェクトは、種類（DXF の名前）、属する所（クラス・表・ブロック・図形・オブジェクトなど）、値の並び、元の場所を持つ。
- 値は、DXF のグループ・コードで名付ける。型は、DXF Reference の「Group Code Value Types」の範囲で決める（文字列・整数・実数・真偽・ハンドル・バイナリ）。仕様にない範囲は文字列とする。同じグループ・コードが何度も現れてよく、並びの順を保つ。
- DWG のコーデックも、読んだ欄を同じグループ・コードの名前で表に置く。DWG にしかない欄の名付け方は、DWG を試作するときに決める。
- 型どおりに読めない値は、捨てずに元のバイト列のまま文字列として置き、診断を返す。
- 元のバイトは、符号化ごとのファイルモデルが持つ。DXF は今の `DxfFile` のまま、タグとレコードとそのバイト範囲を持つ。DWG は、オブジェクトごとのビットの範囲を持つ。表のオブジェクトは、元のレコードを指す。
- 型付きの見方と図面モデルへの変換は、後で表の上に移す。移すまでは、`DxfFile` の上のものを使う。
- 表への変更と、変更を符号化に戻す方法は、まだ決めない。試作で表を読む経路が揃ってから決める（[0024](0024-acad-table-write-back.md) で決めた）。

最初の試作は、DXF を表として見る `DxfFile::objects` とする。

## 影響

- `zumen-acad` に `db`（表）と、DXF から表を作る経路が加わる。新しい診断の符号 `dxf.value.invalid` を足す。
- 次の試作で、DWG（R2000）の一部を読んで同じ表に置き、2 つの符号化で同じ表になることを確かめる。DWG の読み手は、公開の仕様だけから書き、GPL の実装は読まない。
- DWG（R2000）の試作で、見出し・オブジェクトの地図・LINE を読み、同じ表に置いた（[DWG の扱い](../formats/dwg.md)）。DWG にしかない表の名前と、既定の値の欄を置かない扱いは、その文書に推定として記した。
- `lift` を表の上に移し、DXF からの変換の結果が変わらないことを試験で確かめた。DWG も同じ `lift` で図面モデルにし、同じ図面の DXF と同じ結果になることを確かめた。型付きの見方（`Line`）も表の上に移し、DXF と DWG のどちらの表でも同じ値になることを試験で確かめた。

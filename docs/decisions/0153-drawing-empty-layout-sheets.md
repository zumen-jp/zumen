# 0153: 図形のない DXF・DWG のレイアウトも、中身のない用紙にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

[決定 0145](0145-drawing-sheets-per-layout.md) は、DXF・DWG のレイアウトごとに用紙を作り、用紙に元の名前を持たせた。ただし、図形のない空のレイアウトは用紙を作らず、名前も移さなかった。ABI の図面の要約（`SheetSummary`）も、用紙の名前を渡さなかった（#174）。

手元の試料では、空のレイアウトを持つ図面が多い。

- AutoCAD の試料（`arc_2000.dwg` など）と、日本の公開の図面（`jp-yokosuka-minami-survey-plan` など）は、モデルのタブだけに図形を描き、図形のない Layout1・Layout2 を持つ。横須賀市の図面は、モデルのタブを開いた状態（`$TILEMODE` が 1）で保存され、2 つのレイアウトは用紙を設定していない（0145）。
- `features-r2018.dxf` は、図形のない Layout1 と、図形のある A3-PLAN を持つ。この図面も、モデルのタブを開いた状態で保存されている。

空のレイアウトを落とすと、使い手は、図面がどんなレイアウトを持つかを知れない。用紙を選ぶ画面や、AI が図面の構成を説明するときに、元の図面とずれる。

この決定の最初の案は、中身のない用紙の ID を、中身のある用紙の後から振った。用紙の並びと ID の順が合わず、空のレイアウトに図形を足すと ID が変わる。0145 は、用紙の ID を LAYOUT のハンドルにした（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）。

## 選択肢

1. 空のレイアウトも中身のない用紙にし、ID・名前・大きさ・並びは、中身のある用紙と同じ規則（0145）で決める。
2. 空のレイアウトも中身のない用紙にし、ID は中身のある用紙の後から振る（この決定の最初の案）。
3. 空のレイアウトの名前を、図面全体の形式固有の情報として持つ。
4. これまでどおり移さず、文書にだけ書く。

2 は、上のとおり ID が変わる。3 では、レイアウトの並びと名前を、使い手が形式ごとに読み分けることになる。4 では、レイアウトの構成が失われる。

## 決定

選択肢 1 を提案する。

- **作る条件。** ペーパー空間のブロックのレコードを指す LAYOUT があれば、図形がなくても用紙を作る。用紙は、もともと要素とビューのない状態を表せる。LAYOUT を持たない版（R14 まで）は、ペーパー空間の図形があるときだけ用紙を作る。
- **ID・名前・大きさ・並び。** 中身のある用紙と同じく、0145 の規則で決める。ID は LAYOUT のハンドル（`sheet/h1E` など）、並びはタブの順（71）とし、名前と大きさは LAYOUT から読む。用紙を設定していないレイアウト（44 か 45 が 0）は、大きさを持たない。中身があるかどうかで、ID の振り方を変えない。
- **今のレイアウト。** 今のレイアウトの図形は ENTITIES にあり、そのペーパー空間のブロックは中身を持たない。今のレイアウトは、ペーパー空間の図形の所有者を指す LAYOUT とする。図形がなければ、今のペーパー空間のブロックのレコード（DXF は名前が `*Paper_Space` のもの、DWG は見出しが指すもの）を指す LAYOUT とする。今のレイアウトの用紙は、図形があってもなくても 1 枚だけ作る。
- **ABI。** 図面の要約（`SheetSummary`）は、用紙の名前（`name`）を渡す。名前がなければ持たない。用紙の ID は、0156 の文字列（`id`）で渡す。どちらもスキーマに欄を足すだけなので、これまでの読み手はそのまま読める。

## 影響

- モデルのタブだけに図形を描いた図面も、レイアウトの数だけ用紙を持つ。用紙の有無で、用紙を表示するかを決めていた使い手は、要素とビューがあるかも見る必要がある。開いたときに見せる用紙は、0145 の今の用紙（`current_sheet`）で決める。
- 用紙の ID は LAYOUT のハンドルなので、レイアウトに図形を足しても、ほかのレイアウトを足しても変わらない。
- 今の main は、中身のない用紙の ID を中身のある用紙の後から振り、今のレイアウトに図形がなければ、今のレイアウトを見分けない。この決定と 0145 を採ったら、LAYOUT のハンドルの ID に移す。
- 試料では、`arc_2000.dwg`・`line_2000.dwg`・`jp-yokosuka-minami-survey-plan` の DWG と DXF が、Layout1・Layout2 の中身のない 2 枚の用紙になる（main で確かめた）。横須賀市の図面の 2 枚は、大きさを持たない。`features-r2018.dxf` は、タブの順に、中身のない Layout1（`sheet/h1E`）と、図形のある A3-PLAN（`sheet/hF5`）を持ち、どちらも 420 × 297 mm になる。今の用紙は持たない。

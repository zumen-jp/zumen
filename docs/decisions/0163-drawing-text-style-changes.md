# 0163: 図面モデルの変更で文字スタイルの名前と定義を変え、文字スタイルを足し、除く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0158](0158-drawing-text-styles.md) で、図面モデルは文字スタイルの表を持ち、境界の `tables` は文字スタイルを ID・フォントつきで返す。しかし、文字スタイルそのもの（名前・フォント・高さ・幅・傾き・向き）は変えられず、新しい文字スタイルも作れない。[決定 0162](0162-drawing-layer-changes.md) はレイヤの表の変更だけを足した。図面を整える人と AI は、文字スタイルの名前を規則に合わせ、フォントを日本語の書体に揃え、注記のための文字スタイルを作る。

AutoCAD の系統の文字スタイル（STYLE の表のレコード、DXF Reference「STYLE」）は、名前（2）・印（70。形のファイル 1・縦書き 4）・固定の高さ（40。0 なら決めない）・幅の倍率（41）・傾き（50、度）・文字の作り方（71。逆向き 2・上下逆 4）・主のフォントのファイル（3）・大きいフォントのファイル（4）を持つ。TrueType の書体は、XDATA（ACAD の 1000・1071）で書体の名前と属性を持つこともある。DXF の図形・表の書式・寸法スタイルは文字スタイルを名前（7）かハンドルで指し、今の文字スタイル（`$TEXTSTYLE`）も名前で指す。DWG の図形は、文字スタイルをハンドルで指す。

AutoCAD では、Standard の名前は変えられず、Standard は除けない。傾きは ±85 度までを受け付ける（推定）。

## 選択肢

1. `Edit` に、文字スタイルを置き換える変更・足す変更・除く変更を加える（0162 のレイヤと同じ形）。
2. 文字スタイルの変更を、要素の変更とは別の一覧にする。

2 は、0162 で選ばなかった理由と同じく、文字スタイルを変える流れと要素の変更を 1 つの文書のハッシュの前提で当てることを分けてしまう。

## 決定

選択肢 1 を採る。

- **変更。** `Edit::ReplaceTextStyle { target, style }` は、指した文字スタイルの名前と定義を、渡した文字スタイルのもので置き換える。`Edit::AddTextStyle { style }` は文字スタイルを足し、`Edit::RemoveTextStyle { target }` は除く。指し方はレイヤと同じく ID（`id::text_style`）と読んだときのハッシュ（`Hash::text_style`）とする。渡す文字スタイルは定義を持つ。出所は使わない。
- **結果。** apply は、置き換えた文字スタイルの ID と、足した文字スタイルのハンドルで作る ID（`text-style/h40`）と、書き戻した後のハッシュを返す。除いたものは ID もハッシュも持たない。文字スタイルのハッシュは表の並びの番号を含まないので、除いてもほかの文字スタイルのハッシュは変わらない。
- **書けるフォント。** 主のフォントは、形のファイル（`kind: shape`、TrueType のファイルの名前でないもの）か、属性（太字・斜体・文字集合・ピッチ）を持たない TrueType のファイル（`.ttf`・`.ttc`・`.otf`）だけを 3 に書く。フォントがなければ空にする。大きいフォントは形のファイルだけを 4 に書く。XDATA の書体の名前で指すフォントは、XDATA を書き直さないので変えられない（名前と定義のほかの欄は変えられる）。
- **決まり。** 次の変更は `change.edit.unsupported` にして、一覧全体を当てない。
  - 名前が空か、使えない文字か前後の空白を持つか、ほかの文字スタイル（足したもの・名前を変えたもの、表にない名前を図形が指すものと、形のファイルのレコードを含む）と重なる。
  - Standard と、外部参照に依る文字スタイルの名前を変える。
  - 書けないフォント（上のとおり）。高さが負。幅の倍率が 0 以下。傾きの大きさが 85 度を超える。
  - 同じ文字スタイルを 1 つの一覧で 2 度変える。定義のない文字スタイル（文字が名前で指すだけのもの）を変える。
  - 表にない名前を図形が指しているときに、文字スタイルを足す。定義のない項目は表の後ろに並ぶため、足すとその ID が変わる。
  - 形式の版が持てない値を書く。2007 より前の DXF の ASCII でない名前など。
- **DXF。** 置き換えは、元のレコードの 2・70 の 4・40・41・50・71 の 2 と 4・3・4 だけを書き直し、ほかの値は写す。名前を変えたら、図形の 7 と、ヘッダーの変数の 7（`$TEXTSTYLE` など）も新しい名前にする。図形でないオブジェクト（表の書式など）が文字スタイルを名前（7）で指していれば、書き直せないので当てない。足すときは、Standard のレコードを写し、ハンドル・拡張辞書と反応子の組・拡張データを除いてから同じ欄を書き、新しいハンドルで文字スタイルの表の ENDTAB の前に置く。
- **DWG。** 図形は文字スタイルをハンドルで指すので、名前を変えてもレコードの名前だけを書き直す。同じ一覧で足した図形の文字スタイルの名前は、新しい名前にする。R2010 から後のレコードの名前は、0162 のレイヤと同じく文字列の流れの初めに書く。足すレコードは、[決定 0094](0094-dwg-r2010-write-back-table-record-addition.md) の書き方で書く。除くときは、レコードを除き、文字スタイルの表のオブジェクト（STYLE_CONTROL）の項目の並びから、そのハンドルを除く。
- **除去。** 次の文字スタイルは除けず、`change.edit.unsupported` にする。
  - Standard と、外部参照に依る文字スタイル。拡張辞書か反応子（102・360）を持つもの。ハンドルのないもの。後ろにハンドルのない文字スタイル（表にない名前を文字が指すものも含む）があるもの。その ID は並びの番号なので、除くと変わる。
  - ほかのオブジェクトが指すもの。すべてのオブジェクトの値のうち、文字スタイルのハンドルを指すもの、名前（7、大文字と小文字を区別しない）を持つものを探す。図形・ブロック・寸法スタイル・表の書式などを含む。ヘッダーの変数も同じく探す。
  - 同じ一覧で足した要素が指すもの。
- **同じ一覧の要素。** 足す要素は、同じ一覧で足した文字スタイルを指せない。足した文字スタイルで文字を足すには、apply を 2 回に分ける。
- **境界。** 新しい小版で、`apply` に変更の種類 `text_style`（書いた欄だけを変える）・`add_text_style`（書かない欄は Standard と同じ）・`remove_text_style` を足す。高さは 0 で「決めない」を表す。フォントの名前が空なら、フォントを持たない。形のファイルに属性を書けば `call.value.invalid` にする。

## 影響

- 人と AI が、文字スタイルの名前と定義を変え、文字スタイルを足し、除いて、元の DXF・DWG に書き戻せる。
- 線種と寸法スタイルの表の変更は、まだない。SXF・JWW の文字スタイル（文字フォントの表）の書き戻しも、まだない。
- 図面モデルの文字と寸法の型は、まだ文字スタイルを名前で指す（0158）。
- XDATA の書体の名前の書き直しと、属性を持つ TrueType の書体は、のちに足す。
- 傾きの範囲と、DWG の名前を書き直したレコードを AutoCAD が開けるかは、AutoCAD を持つ環境で確かめる。

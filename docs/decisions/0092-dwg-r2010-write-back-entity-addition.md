# 0092: R2010 から後の DWG に足した図形は、文字列の流れの形が R2000 と同じ種類だけを、ブロックのレコードの持つ図形に加えて書き戻す

| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 の DWG には、足した単純な図形と属性を持つ INSERT を書き戻せる（[決定 0079](0079-dwg-r2004-write-back-entity-addition.md)・[0080](0080-dwg-r2004-write-back-attributed-insert-addition.md)）。R2010 から後は、図形の変更と除きを書き戻せる（[決定 0085](0085-dwg-r2010-write-back.md)〜[0091](0091-dwg-r2010-write-back-entity-removal.md)）。R2010 から後の図形のデータは、ハンドルの流れの大きさ（MC）と型（BOT）から始まり、共通の欄に材質の印（BB）・影の印（RC）・表示スタイルを持つかの 3 つの B を持ち、文字列を文字列の流れに持つ。R2013 からは、DS のデータを持つかの B が足される。

## 選択肢

1. 型ごとの欄を R2000 と同じに符号化できる種類だけを、R2010 の共通の欄と文字列の流れで書き、ブロックのレコードの持つ図形に加える。
2. R2004 で足せるすべての種類を、版ごとの欄を読み分けて一度に足せるようにする。
3. 図形の足しは、まだ書き戻さない。

## 決定

選択肢 1 を採る。

- 足せるのは、モデル空間か用紙空間の LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE・TEXT・LWPOLYLINE と、属性と列と行と回転（50）を持たない INSERT。回した INSERT は、変更でも元と同じに符号化できることを確かめられていない。
- 共通の欄は、拡張辞書を持たず、材質は画層のもの（0）、影の印は 0、表示スタイルを持たない。試料の R2010・R2013・R2018 の図形は、どれも材質の印と影の印が 0 だった。
- 足した図形は、R2004 と同じく、所有者のブロックのレコードの持つ図形の数（BL）を増やし、ハンドルの流れの終わりに固い所有で加える。文字列の流れは元のまま写し、MC を付け直す。
- MTEXT・SPLINE・属性を持つ INSERT・MINSERT・表のレコード・ブロックの足しは、まだ受け付けない。

## 影響

- 試料の R2010・R2013・R2018 の図面に LINE・CIRCLE・TEXT・LWPOLYLINE・INSERT を足して書き、読み直したものが足したものと合い、HANDSEED も進んだ。
- 書いた図面を AutoCAD で開いて確かめてはいない。

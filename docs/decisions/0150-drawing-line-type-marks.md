# 0150: 線種の列の要素に添える形と文字を、線種の定義に持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

AutoCAD の系統の線種（LTYPE）は、線と間の長さの列の要素ごとに、形のファイルの形か文字を添えられる（複合線種）。ガス管の線の途中に「GAS」と書く線種や、線路の枕木を形で描く線種がそれに当たる。[決定 0106](0106-drawing-color-line-type-weight.md) は、形と文字を移さずに `dxf.line-type-element.dropped` を返すとした（#174 の「線種の形と文字」）。形と文字を移さなければ、表示する使い手は、ガス管と水道管を同じ破線で描いてしまう。

手元の試料の `sample_AC10*` の図面（R12 の AC1009 を除く）は、どの版の DWG と DXF も、文字を添える GAS_LINE と、形を添える TRACKS・ZIGZAG を持つ。DXF の要素は、印（74）・形の番号（75）・文字スタイル（340）・倍率（46）・回転（50、度）・ずれ（44・45）・文字列（9）を持つ。印の 2 は文字、4 は形、1 は回転を文書の x 軸から測ることを表す。R2013 からの DXF は、文字に 8 の印を付ける。AutoCAD の線種の定義のファイルの、文字が逆さに見えないように回す指定（U）に当たると推定する。形は、形のファイル（`ltypeshp.shx`）を持つ文字スタイルを指す。ほかの試料の図面（横須賀の測量図）は、形の番号が 0 で、文字スタイルを指さない形の印（74 の 4）を持つ。形がないので、線と間だけの線種と同じに描かれると推定する。

## 選択肢

1. 線種の定義に、列の要素の番号で添える形と文字の並びを足す。形はフォントと番号、文字は文字列と文字スタイルの名前で持つ。
2. 形式固有の情報（拡張）にして、図面モデルの値にはしない。
3. 形と文字を、線種を使う要素ごとの図形に展開する。

## 決定

選択肢 1 を採る。

- 拡張（選択肢 2）では、表示する使い手が DXF の符号を知る必要がある。形と文字は見た目を決めるので、図面モデルの値にする。
- 展開（選択肢 3）は、線の長さと線種の倍率ごとに図形が増え、線種の定義と要素の区別がなくなる。線と間の長さの列も展開していない。
- 文字は、ほかの文字の要素と同じく、文字スタイルを名前で指す。形のファイルは、書式つきの文字のフォントと同じ `Font`（`FontKind::Shape`）で持つ。字形の取得と評価は、どちらも図面モデルの外に置く。

内容は次のとおり。

- `LineTypeDefinition.marks` は、列の要素に添える `LineTypeMark` の並びである。線と間だけの線種（SXF・JWW の線種を含む）は空にする。
- `LineTypeMark` は、添える要素の番号（`pattern` の添字）・中身・倍率・回転（度）・回転の基準・ずれを持つ。ずれは、線の向きを x とする、列と同じ空間の長さとする。
- 中身（`MarkContent`）は、形（フォントと形の番号）か、文字（文字列と文字スタイルの名前）である。元の形式が指す文字スタイルがなければ、フォントと文字スタイルは `None` にする。
- 回転の基準（`MarkRotation`）は、線の向きから測る（`Relative`）、文書の x 軸から測る（`Absolute`）、線の向きから測り、文字が逆さに見えるなら半回転する（`Upright`）のどれかである。
- DXF・DWG では、74 の 1 を `Absolute`、8 を `Upright` とする。形の番号が 0 の形は、形がないとみなして添えない（推定）。形と文字を兼ねる印、範囲の外の形の番号、知らない印、有限でない値の要素は読めないとして添えず、`dxf.line-type-element.dropped` を返す。線と間の長さは移す。
- DWG の読み手は、要素ごとの文字スタイルのハンドル（340）を、DXF と同じく形の番号（75）の後に置く。

## 影響

- 表示する使い手は、要素の始まりに、線の向きとずれで形か文字を置く。形の字形は、形のファイルを持つ使い手が評価する。
- 文字の倍率は、文字スタイルの高さへの倍率である。高さが 0 の文字スタイルなら、倍率を高さとして使う（AutoCAD の線種の定義のファイルの、S の指定に当たる。推定）。図面モデルは、文字スタイルの高さを持たない。
- 形と文字の変更の書き戻しは、まだ扱わない。DWG の書き戻しは、今までどおり 340 を欄として書かず、ハンドルの流れを写す。
- 図面モデルの `LineTypeDefinition` に欄が増えるので、`LineTypeDefinition` を作る使い手は欄を足す必要がある。

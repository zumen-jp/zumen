# 0065: DWG（R2000）への書き戻しで足す寸法の体裁は、表にない欄を既定の値で書き、表のオブジェクトの項目の終わりに加える

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md)〜[0064](0064-dwg-write-back-appid-addition.md) で、表の終わりに足した画層・文字の体裁・線種・アプリケーションの名前を、R2000 の DWG に書き戻せるようにした。寸法の体裁（DIMSTYLE）の追加は、まだ拒んでいた。

R2000 の DIMSTYLE のレコード（型 0x45）は、名前から外部参照に依る印までの欄がほかの表のレコードと同じで、その後に寸法の変数の欄が続く。読むときは、既定の値の欄を表に置かない（[決定 0046](0046-dwg-write-back-dimstyle.md)）。ハンドルの流れは、所有者の表のオブジェクト（型 0x44）・拡張辞書・外部参照のブロックの後に、文字の体裁と、引出線・矢印・1 つめと 2 つめの矢印のブロックを指す。試料の図面では、この 5 つの参照の型はみな 5 だった。

試料の図面の DIMSTYLE の表のオブジェクトは、ほかの表と違い、項目の数の後に RC を持ち、項目のハンドルの後にその数だけ参照の型 5 のハンドルが続いた。試料ではどれも RC が 1 だった。

## 選択肢

1. 画層などと同じく一から符号化し、表にない欄を既定の値で書く。表のオブジェクトでは、項目の数を 1 増やして RC を残し、足すハンドルを項目の終わり（余分なハンドルの前）に置く。
2. DIMSTYLE の追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。

- 足した寸法の体裁は、画層と同じく、ハンドル（DXF と同じく 105）が HANDSEED より小さくなく、名前（2）が表のほかの DIMSTYLE と同じでないものだけを受け付ける。
- 印（70）は 0 でなければならない。寸法の変数の欄は、[決定 0046](0046-dwg-write-back-dimstyle.md) と同じ型でなければならず、表にない欄は既定の値で書く。
- 文字の体裁とブロックのハンドル（340〜344）は、図面にあるものを指さなければならない。表にないものは 0 と書く。参照の型は、試料の図面と同じく 5 とする。

## 影響

- 手組みのファイルで、接尾辞・矢印の大きさなどを持つ寸法の体裁を足して書き戻した。読み直した表は、足した表と同じになった。表にある名前・外部参照に依る印・図面にないハンドル・型の違う欄を持つものは拒んだ。
- 試料の R2000 の図面にも、画層・文字の体裁・線種・アプリケーションの名前と並べて、足した文字の体裁を使う寸法の体裁を足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。DIMSTYLE の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増え、余分なハンドルは残った。
- 足した寸法の体裁を、AutoCAD で開いて確かめてはいない。
- ほかの表のレコード（ブロック・ビュー・UCS・ビューポート）の追加は、まだ書き戻せない。

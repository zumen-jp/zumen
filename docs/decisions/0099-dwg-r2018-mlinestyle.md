# 0099: R2018 から後の DWG の MLINESTYLE は、線ごとの線種の番号を読まずに書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

MLINESTYLE は、線ごとに位置（BD）・色（CMC）・線種の番号（BS）を持つ。R2018 からは、線種を番号でなくハンドルで指し、線ごとの欄に BS がない。読む側はこれを読み分けていたが、書き戻す側は BS を読もうとして欄がずれるので、R2018 からの MLINESTYLE の変更を受け付けていなかった（[決定 0090](0090-dwg-r2010-write-back-objects.md)）。

## 選択肢

1. R2018 からは線ごとの BS を読まず、線種のハンドルはハンドルの流れから元のまま写す。
2. R2018 からの MLINESTYLE は、まだ書き戻さない。

## 決定

選択肢 1 を採る。線の数は、これまでどおり変えられない。線種のハンドルは値に置いていないので、元のまま写す。

## 影響

- 試料の R2018 の図面の MLINESTYLE の線の位置と色を変えて書き、読み直したものが変えたものと合った。
- 書いた図面を AutoCAD で開いて確かめてはいない。

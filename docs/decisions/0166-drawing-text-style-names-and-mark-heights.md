# 0166: 図面モデルの要素は文字スタイルを名前で指し、線種に添える文字の高さを図面モデルで決める

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0158](0158-drawing-text-styles.md)（提案）は、図面モデルに文字スタイルの表を置き、文字の要素は文字スタイルを ID で指すとした。今の実装は次のとおりである。

- 表（`Drawing2D::text_styles`）がある。ID は、`id::text_style` が出所のハンドルか並びの順で作る文字列である。
- 境界の要素（`entities`・`add`・`replace`）は、文字スタイルを ID（`style_id`）で指せる。
- 図面モデルの要素の型（文字・書式つきの文字・寸法の文字）は、まだ文字スタイルを名前（`style`）で指す。0158 は、`TextStyleId` で指す型に変えることを、要素の型を変える PR に残した。

0158 は、線種に添える文字の高さ（[決定 0150](0150-drawing-line-type-marks.md)）を決めることも残した。0150 は、文字の倍率は文字スタイルの高さへの倍率で、高さが 0 なら倍率を高さとして使う（推定）とした。そのときの図面モデルは文字スタイルの高さを持たなかったが、0158 の表が高さを持つようになった。境界の `tables` は、線種が形か文字を添えるかどうか（`marked`）だけを返し、添える形と文字そのものは返さない。表示する使い手と AI は、ガス管の線種の「GAS」の文字を、境界から描けない。

## 選択肢

1. 図面モデルの要素は、文字スタイルを名前で指したままにする。ID は境界で、名前から引く。
2. 図面モデルの要素の型を、レイヤ・線種と同じく、番号の ID（`TextStyleId`）で指す型に変える。

## 決定

選択肢 1 を採る。0158 のうち、要素の型を `TextStyleId` で指す型に変える部分は、この決定で置き換える。

- **名前を変えない理由。**
  - 元の形式が、文字スタイルを名前で指す。DXF の要素は名前（7）で指し、名前は大文字と小文字を区別せずに比べる。DWG はハンドルで指すが、読むときに名前にする。図面モデルの照合（`Drawing2D::text_style`）も同じ比べ方をする。
  - 番号の ID にすると、要素のハッシュが表の順に依る。文字スタイルを除くと、後ろの文字スタイルを指す要素のハッシュが変わる。レイヤと線種には、この不便がある（決定 0162・0164）。名前なら、ほかの文字スタイルを除いても変わらない。
  - 境界は、すでに ID で指せる（0158 の続く PR）。型を変えても、人と AI ができることは増えない。一方で、要素を作るすべての使い手が型を直す必要がある。
  - 寸法スタイルも、同じく名前で指したままにする（大文字と小文字を区別する）。
- **線種に添える文字の高さ。**
  - `Drawing2D::mark_text_height` が決める。文字の指す文字スタイルが決まった高さ（正の数）を持てば、その高さに倍率を掛けた値にする。持たないか、文字スタイルが表にないか、指さなければ、倍率を高さとする。形は高さを持たない。
  - 単位は、線種の列と同じ空間の長さとする。
  - 高さが有限の数で表せないときは、高さを返さず、線種の名前と場所を持つ `drawing.mark-height.dropped` を返す。
- **境界。** 新しい小版で、`tables` の線種の項目に、添える形と文字（`marks`）を足す。
  - 項目は、添える列の要素の番号・種類・倍率・回転・回転の基準・ずれを持つ。
  - 形なら、形のファイルと形の番号を持つ。
  - 文字なら、文字列・文字スタイルの名前・名前で引いた文字スタイルの ID（`style_id`）・上の高さを持つ。

## 影響

- 図面モデルの要素の型は変わらない。要素を作る使い手は、今までどおり文字スタイルを名前で指す。0158 の「`TextStyle` は ID（`TextStyleId`）を持つ」は、`id::text_style` の文字列の ID として作った。`TextStyle` に ID の欄は足さない。
- 表示する使い手と AI は、`tables` から線種に添える形と文字を引き、文字を高さつきで描ける。形の字形は、形のファイルを持つ使い手が評価する。
- 文字スタイルの高さが 0 のときに倍率を高さとする規則は、0150 と同じく推定である。AutoCAD で描いて確かめる必要がある。
- 添える形と文字の変更の書き戻しは、まだない（[決定 0164](0164-drawing-line-type-changes.md)）。

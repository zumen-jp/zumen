# 0190: P21 の点マーカーを記号の実体を足して書き戻し、文書の点の表し方を変える変更を足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0183](0183-drawing-apply-points.md) で点の書き戻しを足したが、2 つを残した（#341）。

- P21 の点マーカーは、記号の実体（`SYMBOL_TARGET`・`DEFINED_SYMBOL`）とマーカーの名前で表す。これを組み直す書き方がなかったので、スタイル・形の変更と追加を `change.edit.unsupported` で断っていた。
- 変更の種類は要素か表の項目を指し、文書の設定を変える種類がなかった。そのため、DXF・DWG の `$PDMODE`・`$PDSIZE`（文書の点の表し方）を変えられなかった。

## 選択肢

P21 の点マーカーは、次のどちらかにする。

1. 断ったままにする。
2. P21 の書き方（[決定 0169](0169-sxf-p21-apply.md)）と同じく、新しい実体を足して表記の実体の参照を指し替える。元の実体は書き換えない。

文書の点の表し方は、次のどれかにする。

1. 断ったままにする。
2. 文書の設定を変える変更の種類 `SetPointStyle` を足す。要素を指さないので、前提は変更の一覧の文書のハッシュで確かめる。
3. 表の項目と同じく、文書を指す ID とハッシュ（`Target::Document`・`Basis::Document` に当たるもの）を持たせる。

## 決定

P21 は選択肢 2 を、文書の点の表し方も選択肢 2 を採る。3 は、文書のハッシュ（`apply` の `hash`）と役目が重なる。形式固有の情報（拡張）の `Target::Document`・`Basis::Document` も、文書全体には共通の欄のハッシュを持たせていない。

- **P21 の点マーカー。** 形の変更（置き換え・変換）は、点・向き（`DIRECTION`）・配置・`SYMBOL_TARGET`（尺度を X と Y に書く）・マーカーの名前の `PRE_DEFINED_POINT_MARKER_SYMBOL`・`DEFINED_SYMBOL` を足し、表記の実体の対象を指し替える。色の変更は、`SYMBOL_COLOUR`・`SYMBOL_STYLE`・見え方の割り当てを足し、元の記号の見え方の割り当てと置き換える（なければ並びの終わりへ足す）。追加は、これらと `ANNOTATION_SYMBOL_OCCURRENCE` を足し、用紙とレイヤの並びへ加える。マーカーの名前は、読むときに使う名前の表（コード 1〜7）から引く。新しい仕様の表は写さない。指されなくなった記号の実体は、ほかの幾何と同じく除く。線種・線幅の変更と鏡映は、SFC と同じく断る。
- **回転の比べ方。** 回転は向きの成分で書いて角度で読むので、最後の桁が違いうる。読み直した点は、円弧の角度と同じ許容差で比べる。
- **文書の点の表し方。** 図面モデルの変更に `Edit::SetPointStyle { style: PointStyle }`（名前 `point_style`）を足す。1 つの変更の一覧で 1 度だけ変えられ、結果（`Applied`）は ID とハッシュを持たない。
  - **DXF。** `$PDMODE`（70）に形 0〜4 と、円で囲むなら 32、四角で囲むなら 64 を足した値を、`$PDSIZE`（40）に長さなら正、画面の高さに対する百分率なら負の値を書く。読んで同じ意味になる変数は書き直さず、変数がなければ足す。大きさが正で有限でなければ断る。
  - **DWG。** 同じ値を、見出しの変数の区切りの中でその場で書き直す（[決定 0069](0069-dwg-write-back-header-variables.md)・[決定 0084](0084-dwg-r2010-header-variables.md)）。BS・BD で書いたときのビットの数が元と同じ値だけを受け付け、ほかは `dwg.change.unsupported` で断る。
  - **JWW・SXF。** 文書の点の表し方に当たるものを持たない（JWW の点は記号の番号、SXF の点は既定義の印で描く）。`change.edit.unsupported`（種類 `point_style`）で断る。新しい診断は作らない。
- **境界。** `apply` の変更に `point_style_edit`（形 `mark`・囲み `circle`・`square`・大きさ `size`・大きさの意味 `size_kind`）と、列挙 `point_mark`・`point_size_kind` を足し、小版を 38 に上げる。大きさが 0 より大きい有限の数でなければ `call.value.invalid` にする。

## 影響

- DWG の `$PDMODE` は、0（小さな点）とほかの値の間で変えられない。`$PDSIZE` も、0・1 とほかの値の間で変えられない。既定の図面（`$PDMODE` 0・`$PDSIZE` 0）の形は、まだ変えられない。区切りの長さを変える書き方は、試料で確かめてから決める。
- P21 の点マーカーの色の見え方の割り当てがほかの見え方を合わせて持つときは、色の変更を断る。
- 書き戻した点マーカーと点の表し方は、SXF のビューアーと AutoCAD でまだ開いて確かめていない。
- 境界には、今の文書の点の表し方を読む欄がまだない（シーンの `point_style` の区画だけが返す）。

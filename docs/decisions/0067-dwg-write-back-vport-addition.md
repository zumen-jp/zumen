# 0067: DWG（R2000）への書き戻しで足すビューポートの設定は、型ごとの欄をみな持ち、使い道の分からないビットを偽として表のオブジェクトの項目の終わりに加える

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md)〜[0066](0066-dwg-write-back-view-addition.md) で、表の終わりに足した画層・文字の体裁・線種・アプリケーションの名前・寸法の体裁・ビューを、R2000 の DWG に書き戻せるようにした。ビューポートの設定（VPORT）の追加は、まだ拒んでいた。

R2000 の VPORT のレコード（型 0x41）は、名前から外部参照に依る印までの欄がほかの表のレコードと同じで、その後に [決定 0045](0045-dwg-write-back-view-ucs-vport.md) で書き直す型ごとの欄が続く。その中に使い道の分からないビットが 1 つあり、変更の書き戻しでは元のまま写している。試料の図面の VPORT では、このビットはどれも偽で、欄の終わりがハンドルの流れの始まりと一致した。ハンドルの流れは、所有者の表のオブジェクト（型 0x40）・拡張辞書・外部参照のブロックの後に、名前の UCS と基準の UCS を指す。試料の図面では、この 2 つの参照の型はどれも 5 だった。

## 選択肢

1. 画層などと同じく一から符号化し、型ごとの欄は決定 0045 と同じく書く。使い道の分からないビットは試料と同じく偽とし、所有者の表のオブジェクトの項目の終わりに足す。
2. VPORT の追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。

- 足したビューポートの設定は、画層と同じく、ハンドルが HANDSEED より小さくなく、名前（2）が表のほかの VPORT と同じでないものだけを受け付ける。名前の同じ VPORT を並べるもの（タイルのビューポートの分割）は受け付けない。
- 印（70）は 0 でなければならない。型ごとの欄は、読む側が置くものをみな持たなければならない。幅は、高さ（40）と比（41）の積で書く。
- 名前の UCS（345）と基準の UCS（346）は、図面にある UCS を指さなければならない。表にないものは 0 と書く。参照の型は、試料の図面と同じく 5 とする。

## 影響

- 手組みのファイルで、ビューポートの設定を足して書き戻した。読み直した表は、足した表と同じになった。外部参照に依る印・分からない見え方の印・分からない UCS のアイコン・UCS でないものを指すものは拒んだ。
- 試料の R2000 の図面にも、今のビューポートの設定を写して名前を変えたものを、ほかの表のレコードと並べて足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。VPORT の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増えた。
- 試料の図面には UCS のレコードがないので、UCS を指すビューポートの設定は確かめていない。
- 足したビューポートの設定を、AutoCAD で開いて確かめてはいない。
- ほかの表のレコード（ブロック・UCS）の追加は、まだ書き戻せない。

# 0155: 図面モデルで足した要素は、モデル空間か用紙の新しい図形として書き戻し、出所は読み直して決める

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

[決定 0139](0139-drawing-apply.md) は、図面モデルの変更を DXF・DWG へ書き戻すとし、`Edit::Replace` と `Edit::Remove` を置いた。要素を足すことは、新しい出所の決め方と合わせて次に決めるとした。

共有の表は、表に足したオブジェクト（`Origin::New`）を DXF にも DWG にも書ける（[決定 0025](0025-acad-object-add-remove-write-back.md)、[決定 0079](0079-dwg-r2004-write-back-entity-addition.md)、[決定 0092](0092-dwg-r2010-write-back-entity-addition.md)）。DWG に足す図形は、色（62）・線種（6）・線種の倍率（48）を書けるが、線の太さは ByLayer とし、RGB の色はまだ書けない。

図面モデルの要素の出所（`Ref`）は、元の形式のレコードを指す。DXF ではレコードの番号、DWG ではオブジェクトのバイトの範囲で、書き戻したファイルの中で初めて決まる。

## 選択肢

1. `Edit::Add` は、要素の出所を使わない。書き戻したファイルを読み直したときに、新しいレコードの出所を持つ。
2. `Edit::Add` に、使い手が決める仮の識別子を持たせ、`apply` が仮の識別子と新しい出所の対応を返す。
3. 足すことを `apply` で扱わず、図面モデルから新しいファイルを作るとき（lower）だけで扱う。

## 決定

選択肢 1 を提案する。

- **変更の型。** `Edit::Add(Box<Element<ModelPoint>>)` と `Edit::AddOnSheet(Box<Element<PaperPoint>>)` を置く。`Add` の要素は実寸の空間（モデル空間、`SpaceId(0)`）のもの、`AddOnSheet` の要素は、点が指す用紙のものとする。どちらも出所は使わない。記号の定義の中の要素は、まだ足さない。
- **書き方。** `Add` の要素は、表のモデル空間の新しい図形（ENTITIES の所）として書き、所有者（330）を `*Model_Space` のブロックのレコードとする。`AddOnSheet` の要素は、その用紙のほかの図形と同じ所と所有者に書く。今のレイアウトの用紙は ENTITIES の所でペーパー空間の印（67 = 1）を付け、ほかのレイアウトの用紙は BLOCKS の所のペーパー空間のブロックに置く（DXF では ENDBLK の前、DWG では表の終わりに置き、書き戻しがブロックの図形の列につなぐ）。点と長さは、置き換えと同じく、用紙の mm を図面の単位に戻して用紙の原点を足す。図形を持たない用紙（LAYOUT だけを持つ用紙）には、その LAYOUT のブロックのレコードを所有者として足す。今のレイアウト（`*Paper_Space`）なら ENTITIES の所でペーパー空間の印を付け、原点を `$PLIMMIN` とする。ほかのレイアウトなら、そのペーパー空間のブロックに置き、原点を LAYOUT の範囲の始まり（なければ 0）とする。どちらも読む側の原点と同じで、図面の単位が分からない図面の用紙には足さない。足した用紙は要素を持つ用紙になり、読み直すと ID が変わる（中身のない用紙の ID は、中身のある用紙の後から付く）。ハンドルは、表のどのハンドルよりも大きく、HANDSEED（DXF は表の `$HANDSEED`、DWG は見出しの HANDSEED）より小さくない値から、変更の順に付ける。R13 以降の DXF には、最初の図形でも DXF Reference の並びで区切り（100）を書く。ハンドルか次の HANDSEED を増やせなければ、追加をすべて拒否する。続く ATTRIB と SEQEND もハンドルの予約に含める。
- **足せる形。** 線分（LINE）・円（CIRCLE）・円弧（ARC、時計回りは始まりと終わりを入れ替える）・楕円（ELLIPSE）・軽量の折れ線（LWPOLYLINE）・文字（TEXT）・書式つきの文字（MTEXT）・記号（INSERT）。文字は、高さの意味が TEXT の高さ（`dxf.TEXT.40`）のものに限り、位置合わせが左の基準線でなければ、置く点を 11 と 10 の両方に書く。書式つきの文字は、高さの意味が MTEXT の高さ（`dxf.MTEXT.40`）で、背景を持たず、行送りの倍率が 0.25〜4 で、区間が内容を解釈し直した区間と合うものに限る。向きは、DXF では元の形（50 のラジアンか 11・21 の向き）で、DWG では 11・21 の向きで書く。DWG に足す MTEXT は 50 を持てないので、0 でない角度の MTEXT は DWG に足さない（DWG から読む MTEXT は、どれも向きを持つ）。R2010 からの DWG には、枠の高さ（46）を、なければ 0 として書く。版が分かる DXF では、楕円と書式つきの文字は R13 以降、軽量の折れ線は R14 以降に限る。記号は、名前のあるブロック（`dxf.block`）を置くもので、切り抜きを持たないものに限る。格子を持つ記号は、列と行の数（70・71）と間隔（44・45）を書く（DWG では MINSERT として足す。R2004 から後の DWG には、MINSERT をまだ足せない）。属性を持つ記号は、属性が続く印（66 = 1）を書き、属性ごとの ATTRIB と、記号のレイヤの SEQEND を、所有者を INSERT として続ける。属性は、高さの意味が属性の高さ（`dxf.ATTRIB.40`）で、複数行の値を持たないものに限る。DWG の ATTRIB と SEQEND は、ペーパー空間の印を持たず、R2010 からの ATTRIB は属性の版と位置を固定するか（2 つの 280）を 0 として持つ。
- **名前で指す定義。** レイヤ・線種・文字の体裁・ブロックは、大文字と小文字を区別せずに表の定義を引き、定義の名前で書く。定義がなければ足さない。DXF で、その表そのものを持たない図面だけは、名前だけで指す。ただし、ブロックは BLOCK_RECORD の表がなくても、BLOCKS に実在する定義を確かめる。2007 より前の版には、ASCII の文字だけを書く。
- **色・線種・線幅。** レイヤと部品からの継承は、欄を省くか ByBlock で書く。色は ACI の 1〜255 を 62 に、RGB を 420 に書く。RGB は、DXF の R2004 からだけ書く。線幅（370）は、DXF の R2000 からだけ書く。DWG には、線幅と RGB の色を持つ要素をまだ足さない。
- **作業量。** 追加するレコード・折れ線の頂点・文字と属性の内容とタグのバイト数を、複製前に数える。DXF の BLOCKS への挿入では、終端の検索と索引の作り直しに必要な表の数も、変更前にまとめて数える。
- **足せないとき。** ほかの空間や用紙の点、ない用紙や図面の単位が分からない用紙、0 の半径、改行を持つ文字、扱わない形などは、`change.edit.unsupported`（変更の種類・要素の種類・形式）を、要素が持つ出所の場所で返し、変更をすべて反映しない。
- **理由。** 選択肢 2 は、`Apply` の戻り値を変え、どの形式でも仮の識別子を対応づける仕組みが要る。新しい出所は、書き戻したファイルを読み直せば決まり、図面モデルの要素は読み直した図面モデルから指せばよい。選択肢 3 は、元のファイルの表・ブロック・XDATA を残したまま図形を足す使い方を扱えない。

## 影響

- 使い手は、足した要素を、書き戻したファイルを読み直した図面モデルで指す。足した要素は、モデル空間の要素の終わりに並ぶ（描く順の表がなければ）。
- 背景を持つ MTEXT、寸法・ハッチングなどほかの形、複数行の属性、記号の定義の中の要素の追加は、のちに広げる。DWG の線幅と RGB の色は、DWG の足しが書けるようになってから足す。
- 図面モデルから新しいファイルを作ること（lower）は、この足し方を土台に、別に決める。
- [決定 0139](0139-drawing-apply.md) の書き直した案（提案）は、`Add` の足す先を空間か用紙の ID で指し、足した要素の ID を読み直さずに返す。書き方と足せる形は、この決定のまま使う。用紙の ID を LAYOUT のハンドルにする案（[決定 0153](0153-drawing-empty-layout-sheets.md)・[決定 0156](0156-drawing-stable-ids-and-preconditions.md)、提案）では、図形を持たない用紙に足しても、用紙の ID は変わらない。

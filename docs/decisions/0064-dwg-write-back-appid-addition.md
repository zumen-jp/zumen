# 0064: DWG（R2000）への書き戻しで足すアプリケーションの名前は、使い道の分からない RC を 0 として表のオブジェクトの項目の終わりに加える

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md)〜[0063](0063-dwg-write-back-ltype-addition.md) で、表の終わりに足した画層・文字の体裁・線種を、R2000 の DWG に書き戻せるようにした。アプリケーションの名前（APPID）の追加は、まだ拒んでいた。

拡張データを付けるアプリケーションは、その名前を APPID の表に持つ。R2000 の APPID のレコード（型 0x43）は、名前から外部参照に依る印までの欄がほかの表のレコードと同じで、その後に使い道の分からない RC が 1 つ続く。ハンドルの流れは、所有者の表のオブジェクト（型 0x42）・拡張辞書・外部参照のブロックを指す。試料の図面の APPID の RC は、どの版でもみな 0 だった。

## 選択肢

1. 画層などと同じく一から符号化し、RC を試料と同じく 0 として、所有者の表のオブジェクトの項目の終わりに足す。
2. APPID の追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。

- 足したアプリケーションの名前は、画層と同じく、ハンドルが HANDSEED より小さくなく、名前（2）が表のほかの APPID と同じでないものだけを受け付ける。
- 印（70）は 0 でなければならない。使い道の分からない RC は 0 と書く。

## 影響

- 手組みのファイルで、2 つのアプリケーションの名前を足して書き戻した。読み直した表は、足した表と同じになった。表にある名前と、外部参照に依る印を持つものは拒んだ。
- 試料の R2000 の図面にも、画層・文字の体裁・線種・それらを使う図形と並べて APPID を足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。APPID の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増えた。
- 足したアプリケーションの名前を、AutoCAD で開いて確かめてはいない。
- ほかの表のレコード（ブロック・寸法の体裁・ビューなど）の追加は、まだ書き戻せない。

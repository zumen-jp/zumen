# 0161: R2004 から後の DWG の MINSERT は、持つオブジェクトの数を列と行の欄の前に読み書きし、変更と足しを書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

ODS 5.4.1 によれば、R2004 から後の MINSERT は、属性を持つとき、持つオブジェクトの数（BL）を属性が続く印の後、列と行の数の前に持つ（INSERT では、型ごとの欄の終わりに持つ）。読む側はこの数を読まず、属性を持つ MINSERT の列と行の欄を、ずれた位置から読んでいた。書く側は、属性を持つ INSERT と同じく数を欄の終わりに書くので、R2004 から後の DWG では、MINSERT の変更と足しを `dwg.change.unsupported` にしていた（[決定 0073](0073-dwg-r2004-write-back-kinds.md)・[決定 0080](0080-dwg-r2004-write-back-attributed-insert-addition.md)・[決定 0101](0101-dwg-rotated-insert.md)）。そのため、図面モデルの格子を持つ記号は、R2004 から後の DWG に足せず、変換もできなかった（[決定 0139](0139-drawing-apply.md)・[決定 0155](0155-drawing-apply-additions.md)）。

## 選択肢

1. R2004 から後の MINSERT は、属性を持つとき、持つオブジェクトの数を列と行の欄の前に読み、書く。変更は、元のビットが元の値から書いたものと合うときだけ、数を元のビットのまま写して書き戻す。
2. 試料に MINSERT がないので、これまでどおり受け付けない。

## 決定

選択肢 1 を採る。

- 読む側は、R2004 から後の、属性を持つ MINSERT の持つオブジェクトの数を、列と行の欄の前で読み飛ばす。
- 足す MINSERT は、属性を持てば、属性が続く印の後に ATTRIB の数を書き、続けて列と行の数と間隔を書く。R2010 から後も同じ形で書く。
- 変える MINSERT は、置く点・尺度・回転・属性が続く印の欄と、列と行の欄が、元の値から書いたものと元のビットで合うときだけ書き戻す。持つオブジェクトの数と、列と行の欄より後ろは、元のビットを写す。属性の有無は変えない。

## 影響

- 図面モデルの格子を持つ記号を、R2004 から後の DWG に足し、変換できる。
- 試料の R2004・R2010・R2013・R2018 の DWG に、属性を 1 つ持つ MINSERT を足して書き、読み直したものが足したものと合った。足した MINSERT の基点と列の数と間隔を変えて書き戻し、読み直したものが変えたものと合った。
- 試料の DWG に、格子を持つ記号を足し、回して動かし、鏡映して書き戻し、読み直した形が変換した形と合った。
- 試料の図面は、AutoCAD で作った MINSERT を持たない。そのため、AutoCAD が書いた MINSERT を読めるか、書いた図面を AutoCAD が開けるかは、確かめていない。AutoCAD で作った、属性を持つ MINSERT の試料が要る。

# 0075: R2004 の DWG への表のレコードの書き戻しは、色を CMC の形で書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 の DWG へは、図形の共通の欄と型ごとの欄を書き戻す（[決定 0072](0072-dwg-r2004-write-back.md)〜[0074](0074-dwg-r2004-write-back-hatch.md)）。表のレコード（LAYER・STYLE・LTYPE・VIEW・UCS・VPORT・DIMSTYLE）は、R2000 では書き戻す（[決定 0043](0043-dwg-write-back-layer-style.md)〜[0046](0046-dwg-write-back-dimstyle.md)）が、R2004 ではまだ受け付けていなかった。R2004 では、図形でないオブジェクトの反応子の数の後に、拡張辞書を持たない印（B）が続く。また、LAYER の色と DIMSTYLE の色の欄は CMC で、番号（BS）の後に、色の決め方と番号の BL と、名前の印（RC）が続く（ODS 5.4.1 の 2.11）。ほかの欄の形は R2000 と同じになる。

## 選択肢

1. 色が変わらない欄は元のビットを写し、変わった欄は番号の形の CMC で書く。
2. 色の欄が変わったレコードは受け付けない。

## 決定

選択肢 1 を採る。表は色を番号（62・176〜178）で持つので、番号の形の CMC で書けば表の値を失わない。

- 図形でないオブジェクトの型ごとの欄の始まりは、R2004 では反応子の数の後の B を読み飛ばした位置とする。
- 色が変わらない CMC は、色の名前を含めて元のビットを写す。
- 変わった色は、番号の BS の後に、ByLayer（256）は 0xC0000000、ByBlock（0）は 0xC1000000、ほかの番号は 0xC3000000 に番号を足した BL と、名前を持たない印（RC の 0）を書く。
- 真の色（420）を持つ画層は、これまでどおり書き戻さない。
- R2004 の図形でないオブジェクト（GROUP・DICTIONARY など）は、まだ書き戻さない。

## 影響

- 試料の R2004 の 2 つの図面で、画層の色、文字スタイルの幅の係数、線種の要素の長さ、ビューとビューポートの高さ、UCS の原点、寸法の尺度と色を変えて書き戻し、読み直した表が変えた表と同じになった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0059: DWG（R2000）への書き戻しで足す SPLINE は、重みを持てば有理の印を立て、当てはめる点を持てば場合を 2 にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0057](0057-dwg-write-back-spline-addition.md) では、足した SPLINE のうち、節点と制御点を持ち重みを持たないものだけを書き戻せるようにした。重み（41）を持つものと、当てはめる点（11・21・31）を持つものは、試料に同じ形がないので拒んだ。

DWG の SPLINE は、場合（scenario）が 1 なら節点と制御点の欄を、2 なら当てはめる点の欄を持つ。場合が 1 のときだけ、有理・閉じている・周期的の 3 つの印と、重みがあるかの印を持つ。値を変えたときの書き方（[決定 0036](0036-dwg-write-back-spline.md)）は、どちらの場合も書ける。

## 選択肢

1. 当てはめる点を持つものは場合を 2 にし、重みを持つものは有理の印を立てて書く。
2. 決定 0057 のまま、重みを持つものと当てはめる点を持つものは拒む。

有理の印は、重みを持つ SPLINE であることを示す。読む側は、この印を読み飛ばし、重みがあるかの印から重みを読む。

## 決定

選択肢 1 を採る。

- 足した SPLINE が当てはめる点（11）を持てば場合を 2、持たなければ 1 にする。
- 場合が 1 のとき、有理の印は重みを持つかに合わせる。閉じている・周期的の印は 0 にする。
- 一部の制御点だけが重みを持つものと、場合に合わない欄（場合が 2 での制御点や節点など）を持つものは受け付けない。

## 影響

- 手組みのファイルで、重みを持つ SPLINE と、始まりの接線と当てはめる点 2 つを持つ SPLINE を足して書き戻した。読み直した表は、足した表と同じになった。
- 一部の制御点だけが重みを持つものと、制御点と当てはめる点の両方を持つものは、拒むことを確かめた。
- 試料の R2000 の図面のモデル空間にも、同じ 2 つの SPLINE を足して書き戻した。読み直した表は同じになり、CRC の診断も出なかった。
- 有理の印と場合が 2 の形は、試料になく、AutoCAD で開いて確かめてはいない。
- 属性を持つ MINSERT と、図形でないオブジェクトの追加は、まだ書き戻せない。

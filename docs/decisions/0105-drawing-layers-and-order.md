# 0105: 図面モデルのレイヤを ID で引く一覧にし、描く順を入力の順と分けて持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0022](0022-drawing2d-semantics-and-format-mapping.md) は、レイヤを名前と定義の ID で持ち、表示・印刷・編集の可否とビューごとの表示条件を分けること、要素とビューの描く順を明示的な一覧で持ち、確定できなければ入力の順を保って診断することを決めた。#3 の最小のモデル（`crates/zumen-drawing`）は、要素がレイヤの名前の文字列を持ち、要素の一覧の順を描く順としていた。用紙の要素とビューは別の一覧なので、その間の順は失っていた。点どうしの計測やビューでの配置にも、空間の ID を確かめる操作がなかった。

## 選択肢

1. レイヤを図面の一覧に置き、要素は ID で指す。描く順は、要素の一覧（入力の順）とは別の添字の一覧で持つ。
2. 要素がレイヤの名前と状態を持ち、要素の一覧を描く順に並べ替える。
3. レイヤは 1 と同じにし、用紙の要素とビューを 1 つの一覧にまとめて、その順を描く順とする。

## 決定

選択肢 1 を採る。同じ名前で定義の違うレイヤを区別でき、入力の順と描く順の両方を保てるため。添字が入力の順を指すので、出所や診断の位置とも食い違わない。

- `Drawing2D::layers` に `Layer`（ID・元の名前・状態・出所）を置き、`Element::layer` は `LayerId` で指す。状態（`LayerState`）は表示・印刷・編集の可否で、ファイルに定義がないレイヤは `None` とする。既定の値で埋めない。
- `View` は、置く先の用紙（`sheet`）と、そのビューで表示しないレイヤ（`hidden_layers`）を持つ。
- `ModelSpace::order` は `elements` の添字を、`Sheet::order` は要素とビュー（`SheetItem`）を、先に描くものから並べる。要素とビューの一覧は入力の順のままにする。
- 点の距離（`ModelPoint::distance`・`PaperPoint::distance`）とビューでの配置（`View::place`・`View::paper_length`）は、空間か用紙の ID が合わなければ `None` を返す。`View::paper_length` は実寸の向きを受け取り、非等方の変換で向きごとに長さを換算する。1 つの平均の縮尺は使わない。
- DXF・DWG からは、LAYER のレコードを状態にし、凍結と非表示はどちらも「表示しない」とする。凍結と非表示の違い、新しいビューポートでの凍結は、形式固有の情報の置き場（#28）ができるまで移さない。後に[決定 0141](0141-drawing-layer-frozen.md) で、凍結を表示しないことと分けて持つことにした。描く順は SORTENTSTABLE で決め、表が壊れているか、ハンドルのない図形があれば入力の順のままにして診断する。

## 影響

- 要素の一覧を順に描いていた使い手は、`order` に従って描く。境界の `drawing` の op は要素の数と範囲しか返さないので、応答は変わらない。
- DWG の読み手は、ビューポートで凍結した画層と SORTENTSTABLE をまだ表に置かない。DWG の図面モデルでは、ビューで表示しないレイヤを持たず、描く順は入力の順になる（[DWG の扱い](../formats/dwg.md)）。
- 線種・色・線幅の解決と、レイヤからの継承は、この決定に含めない。#28 で扱う。

# 0033: DWG（R2000）への書き戻しは、ATTRIB・ATTDEF の型ごとのフィールドを、TEXT と同じフィールドに続けて符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0032](0032-dwg-write-back-text-insert.md) で、TEXT の型ごとのフィールドを R2000 の DWG に書き戻せるようにした。ATTRIB・ATTDEF の型ごとのフィールドは、TEXT と同じフィールドに、タグ（2）・フィールドの長さ（73）・フラグ（70）が続き、ATTDEF は問い（3）も続く。表では、TEXT の縦の合わせを 74 に置き、73 をフィールドの長さに使う。

## 選択肢

1. TEXT の符号化を、縦の合わせのグループ・コードを変えて使い、続くフィールドを書き足す。
2. ATTRIB・ATTDEF のために、TEXT と別の符号化を書く。

2 は、同じフィールドの符号化が 2 つになる。

## 決定

選択肢 1 を採る。

- TEXT のフィールドは、縦の合わせを 74 から読んで符号化する（決定 0032 と同じく、フラグは表の値から選ぶ）。
- タグと問いは、TEXT の文字列と同じく `^` の書き方を戻し、終わりの NUL を付けて書く。
- フィールドの長さは、なければ 0 を書く。フラグは RC に収まらなければ `dwg.change.unsupported` を返す。

## 影響

- 手で組んだ R2000 の ATTRIB・ATTDEF の文字列・タグ・問い・フラグ・合わせを変えて書き戻し、読み直した表が変えた表と同じになることを確かめた。サンプルの図面の ATTRIB・ATTDEF も点を動かして書き戻す。
- MTEXT などの型ごとのフィールドの変更は、まだ書き戻せない。

# 0071: R2004 の DWG の変更は、オブジェクトの区切りの後ろに足し、地図の区切りを作り直して、入れ物の区切りを置き換える

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2000 の DWG は、変えたオブジェクトをファイルの後ろに足し、オブジェクトの地図を作り直して書く（[決定 0028](0028-dwg-object-data-edit.md)）。R2004 から後は、オブジェクトと地図がそれぞれ入れ物の区切り（`AcDb:AcDbObjects`・`AcDb:Handles`）にあり、地図の位置は区切りの初めから数える。入れ物は、置き換えた区切りから組み直して書ける（[決定 0070](0070-dwg-r2004-container-write.md)）。

R2004 のオブジェクトは、大きさ（MS）・データ・CRC の並びが R2000 と同じで、地図の区切りの形も同じだった。R2010 から後は、大きさの後にハンドルの流れの大きさ（MC）が加わる。見出しの変数は、R2004 で変数が増えて並びが違う。

## 選択肢

1. 展開した `AcDb:AcDbObjects` の後ろに変えたオブジェクトと足したオブジェクトを足し、`AcDb:Handles` を作り直して、2 つの区切りを置き換える。
2. `AcDb:AcDbObjects` を、地図の順にオブジェクトを並べ直して作り直す。
3. 変えたオブジェクトを元の位置で書き換え、大きさが変わるときだけ後ろに足す。

## 決定

選択肢 1 を採る。R2000 と同じ考え方で、元のオブジェクトのバイトを動かさない。選択肢 2 は、地図が指さないバイト（区切りの初めの RL など）の扱いを決める必要がある。選択肢 3 は、大きさで扱いが分かれる。

- `DwgTxn` のオブジェクトの置き換え・除き・足しを、R2000 と R2004 で受け付ける。R2010 から後は、これまでどおり `dwg.edit.unsupported` を返す。
- R2004 は、展開した `AcDb:AcDbObjects` の後ろに、R2000 と同じ形（MS・データ・CRC）でオブジェクトを足す。地図は、区切りの初めからの位置で、R2000 と同じ形で作り直す。
- 地図の区切りは、変更があれば必ず置き換える。オブジェクトの区切りは、置き換えか足しがあるときだけ置き換える。除くだけなら、元のバイトが残る。
- 見出しの変数の変更（HANDSEED・INSUNITS・PLIMMIN・PLIMMAX）と、共有の表からの書き戻しは、R2000 だけで受け付ける。
- 変えた後のオブジェクトのデータを渡せるよう、`DwgFile::object_data` で、オブジェクトのデータ（MS の後から CRC の前まで）を返す。

## 影響

- 合成の R2004 の入れ物で、置き換え・除き・足しを確定して書き、読み直したオブジェクトと表が確定の後と同じになった。
- 試料の R2004 の 2 つの図面で、すべてのオブジェクトを同じデータで置き換え、最後のオブジェクトを除いて書き、読み直した表が、除いたものを除いて元と同じになった。
- `AcDb:ObjFreeSpace` の区切り（オブジェクトの数や地図の位置を持つ）は直さない。書いた図面を AutoCAD で開いて確かめてはいない。
- R2004 の図形の型ごとの欄の符号化（共有の表からの書き戻し）と、R2010 から後のオブジェクトの変更は、後の作業に残る。

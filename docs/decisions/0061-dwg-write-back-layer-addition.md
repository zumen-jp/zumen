# 0061: DWG（R2000）への書き戻しで足す画層は、一から符号化して画層の表のオブジェクトの項目の終わりに加える

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0052](0052-dwg-write-back-entity-addition.md) から [決定 0060](0060-dwg-write-back-minsert-addition.md) までで、表の終わりに足した図形を、R2000 の DWG に書き戻せるようにした。図形でないオブジェクトの追加は、まだ拒んでいた。

図形でないもののうち、図面を作るときによく足すのは画層である。R2000 の画層のレコード（型 0x33）の欄は、名前（TV）・参照される印（B）・外部参照の番号（BS）・外部参照に依る印（B）・印（BS）・色（BS）で、ハンドルの流れは、所有者の画層の表のオブジェクト・拡張辞書・外部参照のブロック・印刷スタイル・線種を指す。画層の表のオブジェクト（型 0x32）は、項目の数（BL）を持ち、ハンドルの流れの所有者・反応子・拡張辞書の後に、項目のハンドルを並べる。試料の図面で、これを確かめた。印と色の書き方は、値を変えたときの書き方（[決定 0043](0043-dwg-write-back-layer-style.md)）がすでにある。

## 選択肢

1. 足した画層のレコードを一から符号化し、所有者（330）の画層の表のオブジェクトの項目の数を 1 増やして、項目のハンドルの終わりに新しいハンドルを足す。
2. 画層の表のオブジェクトは直さず、レコードだけを加える。
3. 図形でないオブジェクトの追加は、これまでどおり拒む。

2 は、表から画層を探す読み手が、足した画層を見つけられない。

## 決定

選択肢 1 を採る。

- 足した画層は、図形と同じく、ハンドルが HANDSEED より小さくなく、表の順に大きいものだけを受け付ける。図形の並びへは繋がない。
- 名前（2）が表のほかの画層と同じもの（大文字と小文字は区別しない）は受け付けない。
- 印（70）・色（62）・線の太さ（370）は要る。印刷しない印（290）はなくてよい。凍結・新しいビューポートで凍結・ロック・表示しない（負の色）・印刷・線の太さを、決定 0043 と同じく DWG の印に書く。外部参照に依る印（70 の 16）と、真の色（420）は受け付けない。参照される印は立て、外部参照の番号と外部参照のブロックは 0 にする。
- 線種（6）は、表の線種を名前で探してハンドルを書く。印刷スタイル（390）は、表にあるオブジェクトを指さなければならない。なければ画層 0 と同じものにする。
- 画層の表のオブジェクトのハンドルの流れは、読んだハンドルを書き直し、新しい項目を足す。その後の埋めるビットは写さない。

## 影響

- 手組みのファイルで、2 つの画層と、その画層の LINE を足して書き戻した。読み直した表は、足した表と同じになった。表にある名前・画層の表でない所有者・真の色・外部参照に依る印を持つ画層は拒んだ。
- 試料の R2000 の図面にも、画層とその画層の LINE を足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。画層の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増えた。
- 足した画層を、AutoCAD で開いて確かめてはいない。
- 画層のほかの、図形でないオブジェクトの追加は、まだ書き戻せない。

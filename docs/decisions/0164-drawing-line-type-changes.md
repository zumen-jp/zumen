# 0164: 図面モデルの変更で線種の名前と定義を変え、線種を足し、除く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

図面モデルは線種の表を持ち（[決定 0106](0106-drawing-color-line-type-weight.md)）、境界の `tables` は線種を ID・名前・ハッシュで返す（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）。レイヤの表は [決定 0162](0162-drawing-layer-changes.md) で、文字スタイルの表は [決定 0163](0163-drawing-text-style-changes.md) で変えられるようになった。しかし、線種そのもの（名前・説明・線と間の長さの列）は変えられず、新しい線種も作れない。図面を整える人と AI は、線種の名前を社内や発注者の規則に合わせ、破線の長さを縮尺に合わせ、規則にない線種を足す。

AutoCAD の系統の線種（LTYPE の表のレコード、DXF Reference「LTYPE」）は、名前（2）・印（70）・説明（3）・揃え（72。65 の `A`）・要素の数（73）・全体の長さ（40）と、要素ごとの長さ（49）を持つ。R13 からは、要素ごとに形と文字の印（74）を持ち、形か文字を添える要素は、形の番号（75）・文字スタイルのハンドル（340）・倍率（46）・回転（50）・ずれ（44・45）・文字（9）も持つ。DXF の図形と画層のレコードは線種を名前（6）で指し、今の線種（`$CELTYPE`）も名前で指す。多重線のスタイル（MLINESTYLE）も線種を名前で指す。DWG の図形と画層は、線種をハンドルで指す。

AutoCAD では、ByLayer・ByBlock・Continuous の名前は変えられず、除けない。

## 選択肢

1. `Edit` に、線種を置き換える変更・足す変更・除く変更を加える（0162・0163 と同じ形）。
2. 線種の変更を、要素の変更とは別の一覧にする。

2 は、0162 で選ばなかった理由と同じく、線種を変える流れと要素の変更を 1 つの文書のハッシュの前提で当てることを分けてしまう。

## 決定

選択肢 1 を採る。

- **変更。** `Edit::ReplaceLineType { target, line_type }` は、指した線種の名前と定義を、渡した線種のもので置き換える。`Edit::AddLineType { line_type }` は線種を足し、`Edit::RemoveLineType { target }` は除く。指し方はレイヤと同じく ID（`id::line_type`）と読んだときのハッシュ（`Hash::line_type`）とする。渡す線種は定義を持つ。ID と出所は使わない。
- **結果。** apply は、置き換えた線種の ID と、足した線種のハンドルで作る ID（`line-type/h40`）と、書き戻した後のハッシュを返す。除いたものは ID もハッシュも持たない。線種の ID はハンドルか並びの番号で、除いてもほかの線種の ID は変わらない。要素とレイヤのハッシュは線種の並びの番号を含むので、除いた線種より後ろの線種を指す要素とレイヤのハッシュは変わる（0162 のレイヤと同じ）。
- **書ける定義。** 列の長さは要素の空間の長さ（`PatternBasis::Element`）で、有限の数だけを書く。添える形と文字（決定 0150 の `marks`）は変えられない。足す線種は形も文字も添えない。形か文字を添える線種は、列の要素の数を変えずに、長さだけを順に書き直す。
- **決まり。** 次の変更は `change.edit.unsupported` にして、一覧全体を当てない。
  - 名前が空か、使えない文字か前後の空白を持つか、ほかの線種（足したもの・名前を変えたものと、表にない名前を図形が指すものを含む）と重なる（大文字と小文字を区別しない）。
  - ByLayer・ByBlock・Continuous と、外部参照に依る線種の名前を変える。
  - 用紙の mm の列、有限でない長さ、添える形と文字の変更、形か文字を添える線種の要素の数の変更。DWG の今ある線種の要素の数の変更。
  - 同じ線種を 1 つの一覧で 2 度変える。定義のない線種（要素が名前で指すだけのもの）を変える。
  - 表にない名前を図形が指しているときに、線種を足す。定義のない項目は表の後ろに並ぶため、足すとその ID が変わる。
  - 形式の版が持てない値を書く。2007 より前の DXF の ASCII でない名前など。
- **DXF。** 置き換えは、元のレコードの 2・3・73・40 と要素の値だけを書き直し、ほかの値は写す。形も文字も添えない線種は、要素の値（49 と、74 から 9 まで）を除いてから、要素ごとに 49 を書く。区切り（100）か 74 を持つレコードは、要素ごとに 74 を 0 で書く。全体の長さ（40）は、長さの大きさの和にする。名前を変えたら、図形と画層のレコードの 6 と、ヘッダーの変数の 6（`$CELTYPE`）も新しい名前にする。図形と画層のレコードでないオブジェクト（多重線のスタイルなど）が線種を名前（6）で指していれば、書き直せないので当てない。足すときは、Continuous のレコードを写し、ハンドル・拡張辞書と反応子の組・拡張データ・要素の値を除いてから同じ欄を書き、新しいハンドルで線種の表の ENDTAB の前に置く。
- **DWG。** 図形と画層は線種をハンドルで指すので、名前を変えてもレコードの名前だけを書き直す。同じ一覧で足した図形と画層の線種の名前は、新しい名前にする。今あるレコードは、要素の数を変えずに、要素の長さだけを書き直す（形と文字の印と、要素ごとの値の並びは変えない）。R2010 から後のレコードの名前は、0162 のレイヤと同じく文字列の流れの初めに書く。足すレコードは、[決定 0094](0094-dwg-r2010-write-back-table-record-addition.md) の書き方で、形も文字も添えない要素だけを書く。除くときは、レコードを除き、線種の表のオブジェクト（LTYPE_CONTROL）の項目の並びから、そのハンドルを除く。
- **除去。** 次の線種は除けず、`change.edit.unsupported` にする。
  - ByLayer・ByBlock・Continuous と、外部参照に依る線種。拡張辞書か反応子（102・360）を持つもの。ハンドルのないもの。後ろにハンドルのない線種（表にない名前を要素が指すものも含む）があるもの。その ID は並びの番号なので、除くと変わる。
  - ほかのオブジェクトが指すもの。すべてのオブジェクトの値のうち、線種のハンドルを指すもの、名前（6、大文字と小文字を区別しない）を持つものを探す。図形・ブロック・画層・寸法スタイル・多重線のスタイルなどを含む。ヘッダーの変数も同じく探す。
  - 同じ一覧で足す・変える要素とレイヤが指すもの。
- **同じ一覧の要素とレイヤ。** 足す要素とレイヤは、同じ一覧で足した線種を指せない。足した線種で要素を足すには、apply を 2 回に分ける。
- **境界。** 新しい小版で、`apply` に変更の種類 `line_type`（書いた欄だけを変える）・`add_line_type`（書かない欄は Continuous と同じ）・`remove_line_type` を足す。`tables` の線種の項目は、定義（説明・列・列の長さが用紙の mm か・形か文字を添えるか）も返す。列は文書の単位で書く。

## 影響

- 人と AI が、線種の名前・説明・線と間の長さを変え、線種を足し、除いて、元の DXF・DWG に書き戻せる。
- 形か文字を添える線種（複合線種）は作れず、添える形と文字も変えられない。
- 寸法スタイルの表の変更は、まだない。SXF・JWW の線種の表の書き戻しも、まだない。
- 多重線のスタイルなどが名前で指す線種の名前は、変えられない。
- DWG の名前と長さを書き直したレコードを AutoCAD が開けるかは、AutoCAD を持つ環境で確かめる。

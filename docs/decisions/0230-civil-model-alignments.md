## 背景

段階 3（[#304](https://github.com/zumen-jp/zumen/issues/304)）は、J-LandXML と IFC4.3 の道路・鉄道を読み、線形の平面図・縦断図・横断図と、設計の TIN と点群の差（出来形）を扱う。2 つの形式の線形を同じモデル（L2、[決定 0008](0008-model-layers-and-codecs.md)）で受けるために、その中身を決める（#366）。

2 つの形式は、線形を次のように書く。

- J-LandXML（台帳の `jlandxml_1_8`）: `Alignment` の `CoordGeom` に、直線（`Line`）・円弧（`Curve`）・緩和曲線（`Spiral`。`spiType` で種類を書く）を並べる。縦断は `Profile` の `ProfAlign` に、縦断の変化点（`PVI`）と縦断曲線（`ParaCurve`・`CircCurve`）の長さで書く。片勾配は `Superelevation`、横断は `CrossSects`、地表面は `Surfaces` の点と三角形で書く。測点の不連続は `StaEquation` で書く。
- IFC4.3（台帳の `ifc_4_3_2`）: `IfcAlignment` の下に、平面（`IfcAlignmentHorizontal`）・縦断（`IfcAlignmentVertical`）・片勾配（`IfcAlignmentCant`）の区間を、区間の初めの点・向き・半径・長さで並べる。地表面は `IfcTriangulatedIrregularNetwork`、測点は `IfcReferent`、地図の座標は `IfcMapConversion` で書く。

どちらも、区間を「初めの点・初めの向き・初めと終わりの半径・長さ」で書く。図面モデルのクロソイド（[決定 0123](0123-drawing-clothoid-edge.md)）は、原点・パラメーター・原点からの長さの形で持つ。

## 選択肢

### 線形の持ち方

1. 区間の並び（初めの点・向き・半径・長さ）で持ち、曲線は種類のまま持つ。
2. 図面モデルの形（直線・円弧・原点の形のクロソイド）に直して持つ。
3. 決めた間隔の点の列に直して持つ。

2 は、ほかの緩和曲線（3 次放物線など）を持てない。原点の形に直すと、区間の初めの値が計算の結果になり、書き戻すと元の値と合わなくなる。3 は、元の定義に戻せず、許容差が表示の事情に縛られる（[決定 0018](0018-geometry-layers-and-tolerances.md)）。

### 縦断の持ち方

1. 区間の並び（初めの追加距離・高さ・勾配と長さ）で持つ。
2. 縦断の変化点と縦断曲線の長さで持つ。

2 は J-LandXML の書き方だが、IFC4.3 は区間で書く。1 にすると、平面と縦断を同じ形でたどれる。

## 決定

線形・縦断・片勾配は、どれも選択肢 1 を採る。

### crate と依存

- 土木の領域モデルは `zumen-civil` に置く。依存は `zumen-base`・`zumen-geom2d`・`zumen-crs` だけにし、形式の crate（`zumen-ifc` と J-LandXML の crate）が `zumen-civil` に lift する。
- 曲線の位置・接線・距離の計算は `zumen-geom2d` に置き、図面モデルと共有する。数の関数は libm を使う（決定 0018）。

### 線形

- **線形。** 線形は、ID・名前・平面線形・縦断線形（なくてもよい）・片勾配（なくてもよい）・測点の定め・横断の並びを持つ。道路・鉄道などの用途は、元の形式の値を文字で持つ。
- **平面線形。** 区間を並べて持つ。区間は、初めの点（地図の点、`northing`・`easting`）・初めの方向角・長さ・種類を持つ。方向角は、平面直角座標系の習わしに合わせ、北（`northing` の正の向き）から時計回りの角度とし、ラジアンで持つ。
- **区間の種類。** 直線・円弧・緩和曲線の 3 つにする。円弧は半径を持ち、曲がる向きは符号で表す（右へ曲がるものを正）。緩和曲線は、初めと終わりの半径（直線の側は無限大にせず「なし」）と、曲線の種類を持つ。種類は、クロソイド・3 次放物線・サイン半波長逓減曲線・コサイン曲線・ブロス曲線・ヘルマート曲線・ウィーン曲線とし、ほかは元の名前のまま持つ。
- **形の値の扱い。** 区間の初めの点と向きは、元の形式の値をそのまま持つ。前の区間の終わりから計算した点と合わないときは、両方を持ち、差が許容差（決定 0018）を超えれば診断を返す。黙って直さない。
- **計算できない曲線。** 種類が分からない緩和曲線は、区間の値を保ち、その区間の位置を求める操作で診断を返す。
- **図面のクロソイドとの関係。** 線形のクロソイドの区間は、原点の形（決定 0123）に直せる。直すのは、線形を図面モデルに出すとき（#369）だけにし、線形のモデルには区間の形を持つ。区間の形から原点の形への換算と、その逆は `zumen-geom2d` に置く。

### 縦断と片勾配

- **縦断線形。** 区間を並べて持つ。区間は、初めの追加距離・初めの高さ・初めの勾配・長さ・種類を持つ。種類は、一定の勾配・2 次放物線・円弧・クロソイドとする。日本の道路の縦断曲線は 2 次放物線で書くことが多い。
- **J-LandXML の縦断。** 縦断の変化点と縦断曲線の長さから、区間を並べた形に直して持つ。元の変化点の値は、出所から引けるようにする。
- **片勾配。** 区間を並べて持ち、初めの追加距離・長さ・初めと終わりの左右の横断勾配（%）を持つ。鉄道のカント（高さの差、mm）は、片勾配と別の種類にし、軌間を添えて持つ。勾配の変わり方（直線・3 次など）は、種類として持つ。

### 測点

- **追加距離。** 線形の上の位置は、線形の初めからの平面の距離（メートル）で持つ。これを追加距離と呼ぶ。
- **測点の値。** 測点の値は、線形の初めの測点の値に追加距離を足したものにする。測点の不連続（ブレーキ）は、追加距離と、そこでの戻りと進みの測点の値の組で持つ。測点の値から追加距離を引くときは、不連続ごとに区間を分けて引き、同じ値が 2 つの所にあれば、どちらかを選ぶ引数を取り、なければ診断を返す。
- **表記。** `No.12+5.000` の形の表記は、測点の間隔（道路では 20 m が多い）と、小数の桁数で決める。間隔と桁数はプロファイル（[決定 0138](0138-profiles-as-versioned-data.md)）から取り、決まっていなければ 20 m と 3 桁にする。鉄道のキロ程（`12k345m`）も、同じ仕組みで表記の種類として持つ。表記の文字は、境界で文字として返し、モデルには値だけを持つ。

### 横断

- **横断。** 横断は、追加距離と、名前を付けた横断の線の並びを持つ。横断の線は、線形の中心からの離れ（右を正とするメートル）と高さの点の列にする。地盤の線と計画の線は、線の役割で分ける。
- **IFC4.3 の横断。** `IfcOpenCrossProfileDef` の横断は、同じ形に直す。断面の形で書いたもの（`IfcSectionedSolidHorizontal` の閉じた断面など）は、#375 で扱い、それまでは種類と出所だけを持ち、診断を返す。

### 地表面

- **TIN。** 地表面は、名前・役割（現況・計画など）・点（地図の点と標高）の列・三角形（点の番号の 3 つ組）の列で持つ。境界線とブレーク線は、点の番号の列で持つ。
- **点群との差。** 出来形の計算（#372）は、この TIN と点群を、同じ地図の空間と同じ高さの成果で比べる。

### 座標と高さ

- **空間。** 線形・横断・TIN の点は、地図の空間（[決定 0019](0019-coordinate-systems-and-gsi-data.md)、`northing`・`easting`、メートル）に置き、モデルに平面直角座標系の CRS を 1 つ持つ。高さは、高さの基準と成果（決定 0019 の「標高」）を持つ。
- **CRS が分からないとき。** 座標系を書いていない J-LandXML と、`IfcMapConversion` のない IFC は、地図の空間の点として読み、CRS を「不明」にして診断を返す。CRS の違う 2 つのモデルの点を、黙って比べない。
- **IFC の座標。** IFC4.3 のプロジェクトの空間の点は、`IfcMapConversion` で地図の空間に直す（#375）。

### ID と出所

- **ID。** 線形・横断・TIN の ID は、[#1](https://github.com/zumen-jp/zumen/issues/1) の規則に従い、J-LandXML では要素の名前（`name`）、IFC では `GlobalId` から作る。名前のない要素と、同じ名前が重なる要素は、親の ID と順の番号で作り、同じ入力なら同じ ID にする。
- **出所。** 区間・測点の不連続・横断・三角形は、元の要素（J-LandXML の要素、IFC のインスタンス）までたどれるようにする。

### 境界

- **op。** 境界の op（[決定 0012](0012-boundary-functions-and-messages.md)・[決定 0015](0015-add-only-boundary-and-version-floors.md)）は、`civil` の名前で、要約・線形の区間・追加距離での位置（点・方向角・高さ・片勾配）・決めた間隔での点の列・測点の値と表記の換算・TIN を返すものにする。名前と引数は、#367 で `schema/` に足すときに決める。
- **シーン。** 土木のための新しいシーンの区画は作らない。平面図・縦断図・横断図は図面モデルに出し（#369）、2D のシーン（[決定 0172](0172-scene-sections-and-op.md)）で表示する。TIN と点群の 3D の表示は、3D のシーン（#417）の区画を使う。

### J-LandXML と IFC4.3 の要素の対応

| 土木の領域モデル | J-LandXML | IFC4.3 |
| --- | --- | --- |
| 線形 | `Alignment` | `IfcAlignment` |
| 平面線形の区間（直線・円弧・緩和曲線） | `CoordGeom` の `Line`・`Curve`・`Spiral` | `IfcAlignmentHorizontalSegment`（`LINE`・`CIRCULARARC`・`CLOTHOID` など） |
| 縦断線形の区間 | `ProfAlign` の `PVI`・`ParaCurve`・`CircCurve` | `IfcAlignmentVerticalSegment`（`CONSTANTGRADIENT`・`PARABOLICARC`・`CIRCULARARC`・`CLOTHOID`） |
| 片勾配・カント | `Superelevation` | `IfcAlignmentCantSegment` |
| 測点の不連続 | `StaEquation` | `IfcReferent`（`STATION`）と測点の属性 |
| 横断 | `CrossSects` の `CrossSect` | `IfcOpenCrossProfileDef`（ほかは #375） |
| TIN | `Surface` の `Pnts`・`Faces` | `IfcTriangulatedIrregularNetwork` |
| 地図の座標 | `CoordinateSystem` | `IfcMapConversion`・`IfcProjectedCRS` |

要素の名前と属性の細かな対応は、#368 と #375 で形式の文書（`docs/formats/`）に書く。

### 用語

- 道路・鉄道の中心の線を「線形」と呼ぶ。図面モデルの寸法とスプラインの "linear" は、「線形の寸法」「線形のスプライン」と後ろに名詞を付けて書き、土木の文書では「線形」の 1 語で寸法やスプラインを指さない。用語集（`docs/style.md`）に書く。

## 影響

- #367 は、この決定の型と計算を `zumen-civil` と `zumen-geom2d` に作る。#368 と #375 は、形式ごとの lift と対応の細目を書く。#369 は、区間の形から図面モデルの形に直して図を出す。
- 線形を区間の形で持つので、J-LandXML と IFC4.3 の間で線形の値を写しても、初めの点と向きは元の値のまま残る。
- 縦断の変化点の値は、モデルに直接は持たないので、J-LandXML に書き戻すときは区間から計算し直す。書き戻しは、この決定の範囲の外にする。

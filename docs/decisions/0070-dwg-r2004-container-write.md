# 0070: R2004 のコンテナーは、置き換えたセクションだけを圧縮し直し、ページを並べ直してマップとヘッダーを作り直して書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 から後の DWG は、コンテナーのセクションを展開して読む（[決定 0026](0026-dwg-r2004-container.md)・[決定 0027](0027-dwg-r2010-reading.md)）。書くときは元のバイト列をそのまま写すだけで、セクションを変えたファイルは書けなかった。R2004 から後のオブジェクトの書き換えには、展開したセクションからコンテナーを組み直す書き手が要る。

サンプルの R2004・R2010・R2013・R2018 の図面では、次のようになっていた。

- ページは `0x100` から隙間なく並ぶ。データのページの大きさは、ヘッダーとデータを `0x20` の倍数に切り上げたもので、ヘッダーの 4 つめのフィールドと同じ。マップのページも `0x20` の倍数に切り上げる。
- ファイルの終わりは、ページのマップのページ、空のページのヘッダー（`0x14` バイト）、2 つめのヘッダーの順で、2 つめのヘッダーは暗号化したヘッダーと同じバイト列だった。
- 暗号化したヘッダーは、最後のページの番号、ページのマップの番号と位置、セクションのマップの番号、2 つめのヘッダーの位置、ページの数を持つ。
- データのページのヘッダーは位置を含まず、位置との排他的論理和で隠すだけだった。
- ファイルのヘッダーの `0x0D` と `0x20` は、プレビューと要約のセクションのページのデータの位置を指していた。
- `AcDb:FileDepList` は暗号化のフィールドが 2 で、読む側は読まない。

## 選択肢

1. 置き換えたセクションだけを圧縮し直し、ほかのページは元のバイト列を写す。ページの番号を振り直し、2 つのマップとヘッダーを作り直す。
2. すべてのセクションを、展開したバイト列から圧縮し直す。
3. 置き換えたセクションのページを、ファイルの終わりに足す。

## 決定

選択肢 1 を採る。選択肢 2 は、読まない暗号化したセクションを書けない。選択肢 3 は、古いページが残り、ページのマップに空いたページの項目が要る。

- ページは元の位置の順に並べ、番号を 1 から振り直す。置き換えたセクションのページは、そのセクションの元の初めのページの所に置く。セクションのマップとページのマップは、その後に、この順で置く。
- 置き換えていないセクションのページは、ヘッダーを新しい位置で隠し直して写す。後ろは 0 で埋める。
- 置き換えたセクションは、ページの最大の大きさごとに分け、0 で埋めてから、圧縮するセクションは ODS の 4 の圧縮で縮める。圧縮は、距離 `0x4000` までの一致を 3 バイトのハッシュの鎖で探す。
- ページのマップの自分の大きさは、ヘッダーと続く空のページのヘッダーを含めて `0x20` の倍数に切り上げる。サンプルの図面では、この大きさと合わないものもあった。
- 暗号化したヘッダーは、読んだものの番号・位置・数のフィールドを書き直し、CRC を計算し直す。2 つめのヘッダーにも同じバイト列を置く。
- ファイルのヘッダーの `0x0D` と `0x20` が元のページのデータを指していれば、動いた先に合わせる。
- セクションを置き換えていなければ、これまでどおり元のバイト列を写す。

## 影響

- 手組みのコンテナーで、セクションを置き換えて書き、読み直したセクションが置き換えたセクションと同じになった。圧縮は、乱れたバイト・繰り返し・0 の並びを、展開して元に戻ることを確かめた。
- サンプルの R2004・R2010・R2013・R2018 の 7 つの図面で、そのまま組み直したものと、読めたセクションをすべて置き換えたものを読み直し、セクションが元と同じで、診断も出なかった。セクションをすべて置き換えると、ファイルは元より少し小さくなった。
- 書いた図面を、AutoCAD で開いて確かめてはいない。ページのマップの自分の大きさの決め方と、データのページの後ろの埋め方（サンプルには乱数の列で埋めたものもある）は、仕様の文からは決まらない。
- セクションを置き換える口は、まだ R2004 から後のオブジェクトの書き換えにつないでいない。

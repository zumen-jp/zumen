# 0104: R2010 から後の DWG に足した VIEW は、表示スタイルの 2dWireframe を指す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG の VIEW は、外部参照のブロックの後に、背景・表示スタイル・太陽を指すハンドルを持つ。これまで、足した VIEW はどれも持たない（0）ものとしていた（[決定 0095](0095-dwg-r2010-write-back-more-record-addition.md)）。試料の R2010・R2013・R2018 の図面のビューは、名前のオブジェクトの辞書の ACAD_VISUALSTYLE が指す辞書の、2dWireframe の VISUALSTYLE を表示スタイルとして指し、背景と太陽は指していなかった。

## 選択肢

1. ACAD_VISUALSTYLE の辞書の 2dWireframe を指す。見つからなければ、これまでと同じく持たない。
2. 表の 348 があれば、その VISUALSTYLE を指し、なければ 1 と同じく 2dWireframe を指す。
3. これまでと同じく持たない。

## 決定

選択肢 1 を採る。試料の図面と同じ値になり、表の欄を増やさずに済むため。

- 表示スタイルは、ACAD_VISUALSTYLE の辞書の項目のうち、名前が 2dWireframe のもの（大文字と小文字は区別しない）を、参照の型 5 で指す。辞書や項目が見つからなければ、0 を書く。
- 背景と太陽は、これまでと同じく持たない（0）。

## 影響

- 試料の R2010・R2013・R2018 の図面に VIEW を足して書き、読み直したとき、足したビューが 2dWireframe の VISUALSTYLE を指していた（読む側は表示スタイルのハンドルを置かないので、一時的に置いて確かめた）。試料の図面のビューと同じハンドルだった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

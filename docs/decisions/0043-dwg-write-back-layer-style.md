# 0043: DWG（R2000）への書き戻しは、LAYER と STYLE の表のレコードの欄を符号化し直し、名前とハンドルは変えない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0042](0042-dwg-write-back-shape.md) までで、表に型ごとの欄を置く図形は、どれも R2000 の DWG に書き戻せるようにした。表（TABLES）のレコードの欄は、まだ書き戻せない。

読む側は、LAYER の DWG の印（BS）から、DXF の 70（凍結 1・新しいビューポートで凍結 2・ロック 4・外部参照に依る 16）と、色（62）の負の符号（表示しない）と、印刷しない印（290）と、線の太さ（370）を作る。STYLE は、形のファイルと縦書きの印を 70 にまとめ、高さ（40）・幅の係数（41）・傾き（50）・文字の生成の印（71）・前に使った高さ（42）・フォント（3）・ビッグフォント（4）を置く。名前（2）と、ハンドルの流れから引く 390・6 は、共通の欄やハンドルの流れにある。

## 選択肢

1. LAYER と STYLE の型ごとの欄だけを符号化し直し、名前とハンドルの流れは元のまま写す。
2. 名前も含めて、表のレコードのどの欄も符号化し直す。

2 は、名前を変えると、そのレコードを名前で指す DXF の値（図形の 8 など）とハンドルの対応が崩れる。名前の変更は、指す側も含めて扱う別の決定にする。

## 決定

選択肢 1 を採る。

- 名前（2）と、ハンドルから作る値（390・6）が変わったものは受け付けない。
- LAYER の印は、元の印の 10 ビットより上を写し、DXF の 70・62・290・370 から下の 10 ビットを作る。290 がなければ印刷する。線の太さは、読む側の太さの表の番号に直し、表にない太さは受け付けない。色は、62 の絶対値を書く。
- STYLE の 70 は 1 と 4 だけを受け付ける。傾き（50）は度からラジアンに直す。フォントとビッグフォントは、変わらなければ元のビットを写す。
- 外部参照に依る印（70 の 16）は共通の欄にあり、元のものと同じでなければ受け付けない。

## 影響

- 手で組んだ R2000 の LAYER と STYLE で、印・色・印刷しない印・線の太さ・縦書き・高さ・フォントを変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の画層の色と、文字スタイルの幅の係数も変えて書き戻す。
- LTYPE・DIMSTYLE などのほかの表のレコードと、OBJECTS のオブジェクトの欄の変更は、まだ書き戻せない。

# 0037: DWG（R2000）への書き戻しは、HATCH の欄を表の順に読み直して符号化し、境界の図形の数の変更は受け付けない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0036](0036-dwg-write-back-spline.md) までで、SPLINE までの型ごとの欄を R2000 の DWG に書き戻せるようにした。R2000 の HATCH の型ごとの欄は、境界の道ごとに、辺（線・円弧・楕円弧・SPLINE）か多角形の頂点が続き、塗りつぶしでなければ模様の線が続く。読む側は、これらを決まった順に表へ置き、境界の図形の数（97）だけを表に置いて、そのハンドルはハンドルの流れに残す。

表の中で、境界の点・辺の点・種の点は、どれも 10・20 を使う。そのため、符号で欄を探すことはできない。

## 選択肢

1. 表の値を、読む側が置いた順に初めから読み直し、同じ順に符号化する。
2. 符号ごとに値を集め、欄に割り当てる。

2 は、同じ符号が境界・辺・種の点に出るので、どの点がどの欄かを決められない。

## 決定

選択肢 1 を採る。

- HATCH の欄の符号の値を、表の順に読み直す。道の数（91）・辺や頂点の数（93）・模様の線の数（79）などの数で、続く値の数を決める。読み終えて値が残るもの、足りないものは受け付けない。
- 初めの 10・20 は 0 だけを受け付ける。押し出しの向き（210〜230）がなければ (0, 0, 1) を書く。模様の名前は、DXF の `^` の書き方を元に戻して書く。角度（50・51・52・53）は、度からラジアンに直して書く。
- 多角形の道の膨らみの印は、表に 42 があるかから選ぶ。画素の大きさ（47）は、どれかの道の印に 4 があるときに書く。
- 道ごとの境界の図形の数（97）が元と違うものは、`dwg.change.unsupported` を返す。境界の図形のハンドルは、ハンドルの流れとして元のまま写す。

## 影響

- 手で組んだ R2000 の HATCH で、線の辺の終わりと、多角形の頂点の膨らみと、模様の尺度を変えて書き戻し、読み直した値が同じになることを確かめた。初めの 10 を 0 以外にしたもの、97 を変えたものは受け付けない。試料の図面の HATCH も、境界と種の点を動かして書き戻す。
- 境界の図形を足す・外す変更は、まだ書き戻せない。
- POLYLINE・VERTEX・DIMENSION などの型ごとの欄の変更は、まだ書き戻せない。

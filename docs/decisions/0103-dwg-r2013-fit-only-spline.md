# 0103: R2013 から後の DWG のフィット点だけを持つ SPLINE の変更は、Bézier の形の値だけをフィット点に戻して書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2013 から後の DWG の SPLINE は、場合が 1 でもスプラインのフラグの 1 が立てば、制御点を持たず、フィット点と始まりと終わりの接線だけを持つ。読む側は、DXF と同じく、3 次でフィット点が 2 つのものを、両端の点と接線から Bézier の制御点に直して置く（ノットは 0 と 1 の 4 つずつ、制御点は 4 つ、ノットと制御点の許容差は 1e-9 と 1e-10）。ほかの次数と点の数のものは、フィット点のフィールドとして置く。これまでは、このスプラインの変更を受け付けていなかった（[決定 0097](0097-dwg-r2013-spline.md)）。サンプルの R2013・R2018 の図面には、3 次でフィット点が 2 つのものが 1 つずつある。

## 選択肢

1. 値が読む側の置く Bézier の形のままなら、両端の制御点をフィット点に、両端の制御点との差の 3 倍を接線に戻して、フィット点の形で書く。ほかは受け付けない。
2. 制御点が変われば、フラグを 0 にした制御点のスプラインに直して書く。
3. このスプラインの変更は、まだ受け付けない。

## 決定

選択肢 1 を採る。AutoCAD でフィット点を編集できる定義を保つため。

- 値が、3 次・ノットの数 8・制御点の数 4・フィット点の数 0・ノットの許容差 1e-9・制御点の許容差 1e-10、ノットが 0 と 1 の 4 つずつ、重みのない 4 つの制御点の形のときだけ受け付ける。ノットや重みを変えた値、フィット点のフィールドとして置いた値（サンプルの図面にない）は受け付けない。
- 始まりのフィット点は初めの制御点、終わりは最後の制御点とする。始まりの接線は 2 つ目と初めの制御点の差の 3 倍、終わりの接線は最後と 3 つ目の制御点の差の 3 倍とする。
- 端の制御点とその隣の制御点が、元のフィット点と接線から読む側が求めた値と同じなら、元の接線のビットを写す。フラグ・ノットの取り方・当てはめる許容差は、元のビットを写す。

## 影響

- サンプルの R2013・R2018 の図面の、フィット点だけを持つ SPLINE の制御点を動かして書き、読み直したものが動かしたものと合った。接線を求め直すので、読み直した内側の制御点は、最後のビットが異なることがある。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0103: R2013 から後の DWG の当てはめる点だけを持つ SPLINE の変更は、Bézier の形の値だけを当てはめる点に戻して書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2013 から後の DWG の SPLINE は、場合が 1 でもスプラインの印の 1 が立てば、制御点を持たず、当てはめる点と始まりと終わりの接線だけを持つ。読む側は、DXF と同じく、3 次で当てはめる点が 2 つのものを、両端の点と接線から Bézier の制御点に直して置く（節点は 0 と 1 の 4 つずつ、制御点は 4 つ、節点と制御点の許容差は 1e-9 と 1e-10）。ほかの次数と点の数のものは、当てはめる点の欄として置く。これまでは、このスプラインの変更を受け付けていなかった（[決定 0097](0097-dwg-r2013-spline.md)）。試料の R2013・R2018 の図面には、3 次で当てはめる点が 2 つのものが 1 つずつある。

## 選択肢

1. 値が読む側の置く Bézier の形のままなら、両端の制御点を当てはめる点に、両端の制御点との差の 3 倍を接線に戻して、当てはめる点の形で書く。ほかは受け付けない。
2. 制御点が変われば、印を 0 にした制御点のスプラインに直して書く。
3. このスプラインの変更は、まだ受け付けない。

## 決定

選択肢 1 を採る。AutoCAD で当てはめる点を編集できる定義を保つため。

- 値が、3 次・節点の数 8・制御点の数 4・当てはめる点の数 0・節点の許容差 1e-9・制御点の許容差 1e-10、節点が 0 と 1 の 4 つずつ、重みのない 4 つの制御点の形のときだけ受け付ける。節点や重みを変えた値、当てはめる点の欄として置いた値（試料の図面にない）は受け付けない。
- 始まりの当てはめる点は初めの制御点、終わりは最後の制御点とする。始まりの接線は 2 つ目と初めの制御点の差の 3 倍、終わりの接線は最後と 3 つ目の制御点の差の 3 倍とする。
- 端の制御点とその隣の制御点が、元の当てはめる点と接線から読む側が求めた値と同じなら、元の接線のビットを写す。印・節点の取り方・当てはめる許容差は、元のビットを写す。

## 影響

- 試料の R2013・R2018 の図面の、当てはめる点だけを持つ SPLINE の制御点を動かして書き、読み直したものが動かしたものと合った。接線を求め直すので、読み直した内側の制御点は、最後のビットが異なることがある。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0204: プロファイルに、用紙の大きさごとの線幅とファイルの名前の照合を足し、mlit-cad に表の値を足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

- `mlit-cad` の 2025-12 版（[0138](0138-profiles-as-versioned-data.md)）は、線幅の語彙を 1 つの列で持ち、用紙の大きさごとの線の太さ（本編の表 1-7）、延長サイズ（解説表 1-1）、輪郭と表題欄の寸法（表 1-2・表 1-3）、CAD データの名前（図 1-5）を持たなかった（#220）。
- AGENTS.md は「仕様の本文・図・表を写さない」としていた。利用者の判断で、この規則を除いた。プロファイルには、値と、出典の文書・節・表の番号を書く（`profiles/README.md`）。
- 照合（[0173](0173-profile-checks.md)・[0179](0179-profile-check-details.md)）は、ファイルの名前を受け取らない。文書は入力の名前で開くが、入力の名前は呼び出し側が付けるもので、ファイルの名前とは限らない。

## 選択肢

### 用紙の大きさごとの線幅

1. 線幅の語彙を用紙の大きさごとに分け、新しい照合の種類で、起点の用紙の大きさに合う行の線幅と比べる。
2. 今の `line-width` の語彙（選べる線幅の一覧）だけで比べる。

### ファイルの名前

1. `check` の要求に `file_name` を足し、規則が決める部分の並びで比べる。
2. 入力の名前を比べる。
3. 照合しない。

## 決定

どちらも選択肢 1 を採る。

- **`line-width-by-sheet`。** 語彙の値は、`sheet`（用紙の語彙の名前）と、残りの欄の線幅（`mlit-cad` では細線・太線・極太線・寸法線と引出線・輪郭線）を持つ。規則の `sheets` で用紙の語彙を指し、名前から大きさを引く。用紙を通してたどった線を描く要素の線幅を、起点の用紙の大きさ（向きを問わない）に合う行の線幅と、`tolerance` の内で比べる。用紙を通さない要素と、表にない大きさの用紙は比べない。線幅が決まらなければ照合できない指摘にする。行の用紙の名前が用紙の語彙にない規則は使えない（`profile.rule.unsupported`）。
- **`file-name`。** `check` の要求の `file_name`（拡張子を含み、フォルダーを含まない。小版 40 から）を比べる。規則は、決まった部分の並び（`parts`。文字の数 `length` と範囲 `characters`（`0-9A-Z` の形）か、符号の語彙 `vocabulary`）、利用者が決める部分（`user-part` の `prefix` と、始めの文字列を含めた文字の数の上限 `max-length`。半角の文字は英大文字と数字に限る）、拡張子（`extensions`。大文字と小文字を区別する）、全体の文字の数の上限（`max-length`）を持つ。文字は Unicode の文字で数える。合わなければ理由（`length`・`extension`・`part`・`user-length`・`user-characters`）を持つ指摘にする。`file_name` がなければ照合できない指摘にする。
- **`mlit-cad`（revision 2）。**
  - 用紙の語彙に、解説表 1-1 の延長サイズ（第 2 類・第 3 類）を足す。類（`class`）と、なるべく使わない大きさ（`avoid`）を持つ。`sheet-size` は延長サイズも受け付ける。
  - 表 1-7 を `line-width-by-sheet` の語彙と規則（重要度 info。表は標準で、図面に応じて変えられる）にする。
  - 表 1-2（輪郭線の太さと余白）と表 1-3（表題欄の寸法）を語彙にする。図枠と表題欄の要素を見分ける方法が決まっていないので、照合の規則はまだ足さない。
  - 図 1-5 を `file-name` の規則にする。ライフサイクルは責任主体の語彙（S・D・C・M）を使う。SAF ファイルの名前（図 1-7）は、SAF を読み書きしないので足さない。

## 影響

- メッセージのスキーマの小版を 40 に上げた。`check` の要求に `file_name` が増えた。
- 診断の code に `profile.line-width-by-sheet.invalid`・`profile.line-width-by-sheet.unsupported`・`profile.file-name.invalid`・`profile.file-name.unsupported` を足した。
- `mlit-cad` で照合すると、`file_name` を渡さない呼び出しには、`file-name` の照合できない指摘が 1 つ増える。

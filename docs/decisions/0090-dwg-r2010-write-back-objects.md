# 0090: R2010 から後の DWG の図形でないオブジェクトは、R2004 と同じ欄の符号化で、文字列を文字列の流れに書いて書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG は、図形と表のレコードの変更を書き戻せる（[決定 0085](0085-dwg-r2010-write-back.md)〜[0089](0089-dwg-r2010-write-back-records.md)）。図形でないオブジェクトは、R2000 と R2004 では GROUP・DICTIONARYVAR・DICTIONARY・ACDBDICTIONARYWDFLT・MLINESTYLE・LAYOUT・XRECORD の欄を書き戻せる（[決定 0047](0047-dwg-write-back-group-dictionaryvar.md)〜[0050](0050-dwg-write-back-xrecord.md)・[0076](0076-dwg-r2004-write-back-objects.md)）。R2010 から後のオブジェクトは、文字列を文字列の流れに持つ。表のレコードと違い、名前を流れの初めに置くことはない。

## 選択肢

1. R2000 と R2004 の欄の符号化を、欄を書く先を受け取る形にして使い、文字列は文字列の流れに書く。
2. R2010 から後のオブジェクトの符号化を、種類ごとに別に作る。
3. 図形でないオブジェクトは、まだ書き戻さない。

## 決定

選択肢 1 を採る。表のレコードと同じく、元の値を符号化した主のデータの長さと文字列の流れが元と同じときだけ、新しい値で書き直す。

- MLINESTYLE の名前は、R2010 からは文字列の流れに書き直す（名前の変更は、これまでどおり受け付けない）。
- R2018 からの MLINESTYLE は、線ごとの欄の形が異なり、元の値を符号化しても主のデータの長さが合わないので、まだ受け付けない。
- XRECORD の文字列の値は、R2007 からは形が変わるはずだが、試料の図面になく確かめていないので、文字列の値を持つ XRECORD の変更は受け付けない。

## 影響

- 試料の R2010・R2013・R2018 の図面で、グループの説明・辞書の変数の値・辞書の複製の扱い・レイアウトの設定・XRECORD の実数と、R2010・R2013 の多重線の体裁の線の位置と色を変えて書き、読み直した表が変えた表と同じになった。
- R2004 の試料にはなかった GROUP も、R2010 から後の試料で確かめた。
- 書いた図面を AutoCAD で開いて確かめてはいない。

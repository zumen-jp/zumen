# 0089: R2010 から後の DWG の表のレコードは、名前の文字列を写し、版ごとの欄を読み分けて書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG は、図形の変更を文字列の流れと一緒に書き戻せる（[決定 0085](0085-dwg-r2010-write-back.md)〜[0088](0088-dwg-r2010-write-back-more-entities.md)）。表のレコードは、R2000 と R2004 では LAYER・STYLE・LTYPE・VIEW・UCS・VPORT・DIMSTYLE の欄を書き戻せる（[決定 0043](0043-dwg-write-back-layer-style.md)〜[0046](0046-dwg-write-back-dimstyle.md)・[0075](0075-dwg-r2004-write-back-records.md)）。R2010 から後のレコードは、名前を文字列の流れの初めに置き、外部参照の番号（BS）を持たない。R2013 からは、オブジェクトの共通の欄に DS のデータを持つかの B が足される。

## 選択肢

1. R2000 と R2004 の欄の符号化を版を受け取る形にして使い、名前の文字列は元の TU を写し、R2010 で増えた欄は元のビットを写すか読み分ける。
2. R2010 から後のレコードの符号化を、種類ごとに別に作る。
3. 表のレコードは、まだ書き戻さない。

## 決定

選択肢 1 を採る。図形と同じく、元の値を符号化した主のデータの長さと文字列の流れが元と同じときだけ、新しい値で書き直す。

- 文字列の流れは、初めの名前の TU を写し、STYLE のフォントの名前・LTYPE の説明・DIMSTYLE の文字列を続けて書く。
- VIEW は、描画の種類（281）の後の照明の欄（B・RC・2 つの BD・CMC）を元のビットから写す。
- LTYPE は、文字の要素があるときだけ 512 バイトの領域を持つ。R2010 から後の文字の要素の文字列（UTF-16LE）の変更は、まだ受け付けない。R2013 からは、DXF の 74 の文字の要素の印（8）も書く。
- DIMSTYLE は、読む側と同じ欄の並び（R2010 で増えた欄を含む）で書く。
- UCS のレコードは、試料の図面になく確かめていないので、まだ受け付けない。

## 影響

- 試料の R2010・R2013・R2018 の図面で、画層の色・文字の体裁の幅とフォントの名前・線種の長さと説明・ビューとビューポートの設定の高さ・寸法の体裁の尺度と色を変えて書き、読み直した表が変えた表と同じになった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

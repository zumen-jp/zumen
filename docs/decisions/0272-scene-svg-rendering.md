# 0272: SVG はシーンの列から書き、文字は字形の輪郭にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-06 |
| 状態 | 採用 |

## 背景

サーバーで図面の画像を作るときも、シーンで解いた配置・線種・文字・ID を使う。ブラウザーのフォントや画面の状態に依存せず、同じ入力・設定から同じ出力と診断を返す必要がある。

## 選択肢

- SVG をシーンの列から直接書くか、外部の描画エンジンを介するか。直接書けば、外部のフォント・画像の探索を含まず、SVG のバイト列と予算を管理できる。
- 文字を字形の輪郭にするか、フォント名つきの `text` にするか。後者は閲覧側のフォントと配置に依存する。決定 0188 のシーンにある輪郭を使えば形を固定できる。
- SVG と PNG を同時に作るか、SVG の部品・API 接続・PNG を順に分けるか。PNG はラスタライズの依存と wasm の大きさを別に測る必要がある。

## 決定

`zumen-render` を L3 の描画部品にし、ZMSC のバイト列と明示的な設定・`Cx` から SVG 1.1 を作る。L1 の形式や L2 の継承を再解釈せず、生成したシーンの配置を読む。内部の依存は `zumen-scene` の生成した配置と `zumen-base`、三角関数は既存の `libm` 0.2.16（MIT、wasm に対応）にする。新しい外部の描画エンジンは入れない。

- 表示範囲はシーンの起点における `[xmin, ymin, xmax, ymax]`、出力は正の幅・高さ（ピクセル）を渡す。範囲を縦横同率で中央に収め、その範囲の外を切る。縦横比の違いによる余白にも背景を塗る。単位を mm と推測しない。線幅の用紙 mm だけを、明示した DPI でピクセルへ直す。線幅 0 は 1 ピクセルとする。
- 背景と前景は RGBA で渡す。ACI 7 の前景指定は設定を使う。未解決の色も前景にし、診断を返す。解決済みの色と透明度は保つ。
- 塊の順、塊の中の描く単位の順を保つ。同じ単位では線・面・文字・点・画像の順、同じ単位・種類では元の列の順にする。色の再使用や領域による絞り込みで、列の unit が昇順でないシーンも受け付ける。シーンの列・ID は変えず、塊ごとの順序索引を作る。輪は面が evenodd、字形が nonzero。切り抜きは多角形の共通部分とし、反転の指定も保つ。
- 文字は字形の輪郭だけを書く。字形のない空でない文字、外部画像、名前で指定された点記号は診断して描かない。空白の字形が輪を持たないことは未描画の診断にしない。決定 0188・0267 の表示側での代替文字は変えず、サーバーの SVG では OS のフォントを使わない。
- ID を作り直さない。診断は元の要素 ID に加え、シーンの描く単位の番号を値で持つ。同じ定義の別の配置は、その番号から元の `unit_entities`・`entity_paths`・`step_cells` をたどる。L1 のレコード番号としては扱わない。
- 受け取ったシーンの範囲・列の長さ・参照・数値を検査する。入力を `input_bytes`、検査・索引の作成・並べ替え・描画の繰り返しを `work`、描くものを `elements`、座標の出力を `segments`、切り抜きの入れ子を `depth` で数える。索引は塊ごとの要素数を先に `elements`、1 要素につき 12 バイトを `decoded_bytes` で数えてから確保する。出力の容量と診断へ写す ID も、確保前に `decoded_bytes` で数える。予算超過・中断・不正な入力では途中の SVG を返さない。
- SVG は固定のタグ・属性と数値だけで書く。入力の文字列や参照名を XML・URL・スタイルとして埋め込まない。外部資源・スクリプト・文書型宣言を含めない。

## 影響

文字を検索・編集できる SVG は作らない。シーンへフォントを明示して字形を作ったときに形が決まる。未描画を含む結果は、呼び出す側が診断を見て扱う。SVG のバイト列の決定性と、閲覧側のアンチエイリアスによる画素の違いは区別する。

SVG の部品は #602、領域の API と適合テストへの接続は #603、PNG の依存の選択と API は #604 で追跡する。#603 は #533 と #602 の完了後に始める。#534 は対象の API の条件がそろうまで閉じない。

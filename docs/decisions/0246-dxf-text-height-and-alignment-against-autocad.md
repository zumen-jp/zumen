# 0246: DXF の TEXT の高さは A の字形の上に当て、外形の中央は横を送りの半分にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

1 行の文字の配置（[決定 0176](0176-text-layout-with-glyph-metrics.md)）は、位置合わせの規則を推定で決め、DXF の TEXT の高さ（40）がフォントのどの寸法に当たるかを決めていなかった。シーン（[決定 0188](0188-scene-fonts-and-glyph-outlines.md)）は、決めていない宣言値を大文字の高さとみなし、`scene.text-height.assumed` を返していた。AutoCAD 2027（体験版の accoreconsole）で TEXT を置き、表示の計算の結果と比べて決める（#329）。Jw_cad は手元にないので比べていない。

## 確かめたこと

高さ 10 の TEXT を entmake で置き、AutoCAD が位置合わせから計算し直す置く点（10）・高さ（40）・幅の倍率（41）と、`textbox` の外形を読んだ。フォントの寸法は、同じフォントのファイルの `head`・`hhea`・`OS/2`・`glyf` から読んで比べた。

- **高さ。** TrueType では、高さ 10 は `A` の字形の外形の上に当たる。Arial は 1466（sCapHeight 1467、もっとも高い大文字は O・Q の 1492）、Times New Roman は 1387（sCapHeight 1356、H は 1356 で `textbox` の上が 9.7765）、Georgia は 1439（sCapHeight 1419）、MS ゴシック・MS 明朝・Segoe UI・Verdana・游ゴシックも `A` の上に合う。sCapHeight・`H` の上・もっとも高い大文字・em・アセンダーのどれでもない。SHX（txt.shx・simplex.shx）では、`H` の上が高さに当たる。
- **位置合わせ。** 左・中央・右は送りの合計の 0・半分・全部。外形の中央（72 = 4）は、横が送りの合計の半分（外形の中央ではない）、縦が字形の外形の中央。下はディセンダーの線で、`hhea` のディセンダー（試したフォントはどれも USE_TYPO_METRICS が立たない）に合う。中央と上は、高さの半分と高さ。2 点の間は、Fit が幅の倍率を、Aligned が高さを、送りの合計が 2 点の距離になる比で変える。斜体は置く点を変えない。左右と上下の反転は、置く点のまわりで当てる。回転は置く点のまわりで当てる。
- **ずれ。** 外形の下が基準線より上にある字形（MS ゴシックの `H` の下 2 など）は、AutoCAD が外形をその分だけ下げて測るので、外形の中央の縦が字形の単位で最大その分ずれる（MS ゴシックの `Hxg` で、高さ 10 に対し 0.05）。

## 選択肢

1. TEXT の高さを sCapHeight（大文字の高さ）に当てたままにする。
2. 高さの意味に `A` の字形の上を足し、TEXT の高さの既定にする。
3. 高さを当てる字形を、呼び出し側がキーごとに選べるようにする。

## 決定

選択肢 2 を採る。

- **高さの意味。** `layout::Reference::CapitalA`（境界の `height_reference` の `capital_a`、小版 59 から）を足す。`A` の字形の外形の上に当て、フォントに `A` がないか外形を持たなければ、大文字の高さにする。この意味では、上と中央の位置合わせも `A` の上で決める。
- **既定。** シーンの `heights` で決めなければ、`dxf.TEXT.40` は `capital_a` とし、`scene.text-height.assumed` を返さない。線種の文字の高さ（同じキーを使う）も同じにする。ほかのキー（MTEXT・ATTRIB・Jw_cad など）はまだ比べていないので、大文字の高さとみなして診断を返すままにする。
- **外形の中央。** 横を送りの合計の半分にする。縦は字形の外形の中央のまま。
- **ずれ。** 外形の下が基準線より上にある字形の測り方は、`textbox` と外形の中央でしか見えず、描く字形も下げているかを確かめられないので、まねない。

## 影響

- Arial・MS ゴシック・Times New Roman の `Hxg` で、9 点・基準線・外形の中央・Fit・Aligned・斜体・反転・回転の 18 通りの置く点を、AutoCAD の値と比べた。54 のうち 53 が 0.002 以内で合い、残る 1 つは上のずれ（0.05）である。Aligned の高さも合う（Arial 24.15・MS ゴシック 30.78・Times New Roman 23.60）。
- 比べたフォントと図面は手元の検証だけに使い、リポジトリに置かない。試験は合成のフォントで、`A` の上が大文字の高さと違うときの倍率と位置合わせを確かめる。
- USE_TYPO_METRICS が立つフォントのディセンダー（[決定 0180](0180-read-truetype-metrics-without-dependency.md)）・MTEXT の行送り（[決定 0181](0181-formatted-text-layout.md)）・CFF のカーニング・縦書きと重ねた文字（[決定 0187](0187-vertical-text-stacks-and-kinsoku.md)）は、まだ表示と比べていない。SHX は読まないので、SHX の高さの規則は記録だけにする。

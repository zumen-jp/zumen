# 0126: SFC のスプラインは節点を 3 重にした B スプラインに、点マーカーは既定義の記号のキーにする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

[決定 0121](0121-sxf-sfc-lift-to-drawing.md) は、SFC のスプラインと点マーカーをまだ移さなかった。SFC のスプライン（`spline_feature`）は、3 次のベジェ曲線をつないだもので、制御点を 3n + 1 個持つ（旧版の推定）。点マーカー（`point_marker_feature`）は、レイヤと色のコード・点・マーカーのコード・回転・尺度を持ち、マーカーの形は既定義の表で決まり、ファイルは形を持たない（#171）。

## 選択肢

1. スプラインを、内側の節点を 3 重にした 3 次の B スプラインにする。点マーカーを、既定義の記号のキーで指す配置にする。
2. スプラインを点の列に近似する。点マーカーを、既定義の形の線に展開する。

## 決定

選択肢 1 を採る。節点を 3 重にした B スプラインは、ベジェ曲線をつないだものと同じ形で、近似にならない（[決定 0111](0111-drawing-curves.md)）。点マーカーを線に展開すると、マーカーという意味と元のコードが分からなくなる（[決定 0108](0108-drawing-symbols-hatches-arrowheads.md)）。

- スプラインは、次数 3、節点 0 を 4 つ・1 から n − 1 を 3 つずつ・n を 4 つ、制御点をそのまま持つ。開閉のフラグは 0 を閉じているとする（推定）。制御点が 3n + 1 個でないものは `sxf.lift.invalid` で落とす。
- 点マーカーは、名前空間 `sxf.marker` の、マーカーのコードを名前にした記号のキーで指す配置にする。尺度は X と Y に同じ値を入れる。既定義の形は、記号の定義として持たない（既定義の線種を名前だけで持つのと同じ）。線種はレイヤに従う。後に[決定 0160](0160-drawing-points.md) で、点マーカーを、既定義の印で描く点の形にすることにした。

## 影響

- 既定義のマーカーの形を描くには、表示側がコードから形を引く。
- 作図部品（区分 4 の複合図形）の配置は、記号の定義と一緒に移す。

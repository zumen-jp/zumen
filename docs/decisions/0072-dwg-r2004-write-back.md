# 0072: 共有の表の変更は、R2004 の DWG には図形の共通の欄と単純な種類の型ごとの欄から書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

共有の表の変更は、R2000 の DWG のオブジェクトを符号化し直して書き戻す（[決定 0029](0029-dwg-table-write-back.md)〜[決定 0069](0069-dwg-write-back-header-variables.md)）。R2004 の DWG は、オブジェクトの置き換え・除き・足しを書ける（[決定 0071](0071-dwg-r2004-object-edit.md)）が、表から書き戻せなかった。

R2004 の図形は、R2000 と次が違う（ODS 5.4.1 の 2.12・20.4.1 と、各オブジェクトの R2004 の欄）。

- 共通の欄で、反応子の数の後に拡張辞書がないことを表す B があり、前後の図形のハンドルはない。
- 色（ENC）の BS の上のビットが印で、0x8000 は RGB の値（BL）、0x2000 は透明度（BL）が続くこと、0x4000 は色を DBCOLOR のハンドルで指すことを表す。
- MTEXT・HATCH・INSERT など、いくつかの種類の型ごとの欄が増えている。表のレコードの色（CMC）も、RGB の値と名前を持つ。

試料の R2004 の図面には、透明度を持つ色と、DBCOLOR を指す色があった。共有の表は、DBCOLOR のハンドルを値に置かない。

## 選択肢

1. 図形の値の変更のうち、共通の欄（色・線種の尺度・非表示）と、型ごとの欄が R2000 と同じ種類だけを、R2004 の欄の位置で符号化し直す。ほかの変更は `dwg.change.unsupported` を返す。
2. R2000 で書き戻せるものを、すべて R2004 の欄に合わせてから受け付ける。

## 決定

選択肢 1 を採る。選択肢 2 は、種類ごとに R2004 の欄を確かめる必要があり、1 つの変更にまとまらない。後の作業で、種類を足していく。

- 型ごとの欄を書き直す種類は、LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE・TEXT とする。
- 共通の欄は、R2004 の位置で読み、変わった欄だけを書き直す。色を変えないときは、元の ENC のビットを写す。
- 色を変えるときは、番号を BS の下の 12 ビットに書く。透明度の印と BL は元のまま写す。RGB の値か DBCOLOR を持つ色の変更と、12 ビットに収まらない番号は受け付けない。
- 表のレコードと図形でないオブジェクトの変更、図形の削除と追加、見出しの変数の変更は、R2004 ではまだ受け付けず、`dwg.change.unsupported` を返す。R2010 から後は、これまでどおり `dwg.edit.unsupported` を返す。

## 影響

- 試料の R2004 の 2 つの図面で、単純な種類の図形の点と線種の尺度を変えて書き戻し、読み直した表が変えた表と同じになった。色は、図面ごとに 40 個まで 1 つずつ変え、書き戻せたものは読み直した表が同じになり、書き戻せないもの（DBCOLOR を指す色）は `dwg.change.unsupported` を返した。
- 書いた図面を AutoCAD で開いて確かめてはいない。
- 残る種類（INSERT・MTEXT・HATCH など）、表のレコード、図形でないオブジェクト、削除と追加、見出しの変数、RGB の値と DBCOLOR の色の変更は、後の作業に残る。

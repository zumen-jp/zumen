# 0087: R2010 から後の DWG の MTEXT と VERTEX は、R2010 で増えた欄を表と元のビットから書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG は、文字列を持つ図形の型ごとの欄を、文字列の流れと一緒に書き直せる（[決定 0086](0086-dwg-r2010-write-back-strings.md)）。MTEXT は、R2010 から幅（41）の後に枠の高さ（46）を持ち、R2004 の形の符号化では長さが合わなかった。2D の VERTEX は、R2010 から膨らみの後に頂点の番号（BL、DXF の 91）を持つ。読む側はこの番号を読まずに、接線の向きとして読んでいた。

## 選択肢

1. MTEXT は枠の高さを表の 46 から書き、範囲の大きさと文字列の後の欄（背景の欄など）は元のビットを写す。2D の VERTEX は、読む側で番号を読み飛ばし、書く側で番号の元のビットを写す。
2. 頂点の番号を表に 91 として置き、表から書く。
3. MTEXT と VERTEX は、まだ書き戻さない。

## 決定

選択肢 1 を採る。頂点の番号は、DXF に書くかどうかと合わせて扱いを決める必要があり、書き戻しには元のビットで足りるので、選択肢 2 は採らない。

- MTEXT の文字列は、文字列の流れに書く。範囲の大きさ（2 つの BD）と、文字列の後の印から主のデータの終わりまでは元のビットを写す。
- 2D の VERTEX は、R2004 の形で符号化した欄の接線の向きの前に、元の頂点の番号を写す。
- R2010 から後の 2D の VERTEX を読むときは、頂点の番号を読み飛ばしてから接線の向きを読む。

## 影響

- 試料の R2010・R2013・R2018 の図面で、MTEXT の文字列に日本語を足し、MTEXT と VERTEX の点を動かして書き、読み直した表が変えた表と同じになった。
- 番号を読み飛ばす前は、2D の VERTEX の接線の向きを、番号の位置から読んでいた。
- DIMENSION・HATCH・TOLERANCE・VIEWPORT・SHAPE は、R2010 で増えた欄の形を確かめていないので、まだ受け付けない。
- 書いた図面を AutoCAD で開いて確かめてはいない。

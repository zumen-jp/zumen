# 0031: DWG（R2000）への書き戻しは、図形の共通の欄の色・線種の尺度・非表示を、どの種類の図形でも符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0029](0029-dwg-table-write-back.md)・[決定 0030](0030-dwg-write-back-more-entities.md) で、いくつかの種類の図形の型ごとの欄を R2000 の DWG に書き戻せるようにした。共通の欄の色（62）・線種の尺度（48）・非表示（60）は、まだ書き戻せない。

- 共通の欄は、どの種類の図形でも同じ形で、型ごとの欄の前にある。
- 型ごとの欄を符号化できない種類（TEXT・INSERT など）も多い。

## 選択肢

1. 共通の欄を符号化し直し、型ごとの欄は、変わっていなければ元のビットのまま写す。どの種類の図形でも、共通の欄を書き戻せる。
2. 型ごとの欄を符号化できる種類だけ、共通の欄も書き戻す。

2 は、色を変えた TEXT や INSERT を書き戻せない。

## 決定

選択肢 1 を採る。

- 図形の共通の欄の、色（BS）・線種の尺度（BD）・非表示（BS）を符号化し直す。線種と印刷スタイルの印と、線の太さは元のまま写す。
- 値がなければ、色は ByLayer（256）、線種の尺度は 1、非表示は 0 を書く。
- 型ごとの欄が変わっていなければ、元のビットのまま写す。変わっていて、その種類の型ごとの欄を符号化できなければ `dwg.change.unsupported` を返す。
- 真の色（420）は R2000 で表せないので、足せば `dwg.change.unsupported` を返す。

## 影響

- 試料の R2000 の図面のすべての図形の色と線種の尺度を変えて書き戻し、読み直した表が変えた表と同じになることを確かめた。
- 線種・印刷スタイル・線の太さと、型ごとの欄を符号化できない種類の、型ごとの欄の変更は、まだ書き戻せない。

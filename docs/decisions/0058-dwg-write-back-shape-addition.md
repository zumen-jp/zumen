# 0058: DWG（R2000）への書き戻しでは、足した SHAPE を受け付けない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0057](0057-dwg-write-back-spline-addition.md) までで、表の終わりに足した図形のうち、型ごとの欄を元のデータなしで符号化できるものを R2000 の DWG に書き戻せるようにした。SHAPE の型ごとの欄には、形の番号（BS）がある。ハンドルの流れには、形のファイル（文字の体裁のレコード）を指すハンドルがある。DXF は、この 2 つを形の名前（2）で書く。名前は形のファイルの中にあり、読む側は名前を表に置いていない（[決定 0042](0042-dwg-write-back-shape.md)）。

試料の R2000 の図面で SHAPE を持つのは 1 つで、SHAPE も 1 つだけだった。形のファイルの体裁は名前が空で、ファイル名（3）だけを持つ。

## 選択肢

1. 足した SHAPE は受け付けず、`dwg.change.unsupported` を返す。
2. 形の番号を 0 とし、図面にある最初の形のファイルを指す。
3. 形の名前（2）を受け取り、形のファイルを読んで番号を引く。

2 は、利用者が示していない形を描く図面を作る。3 は、図面の外にある形のファイルを読む必要がある。また、読む側も名前を置いていないので、読み直した表と合わない。

## 決定

選択肢 1 を採る。SHAPE は、表に足せる種類に入れない。足した SHAPE を書き戻そうとすると、何も反映せず、種類（`kind`）を SHAPE とした `dwg.change.unsupported` を返す。

## 影響

- 手で組んだ R2000 の図面に SHAPE を足して書き戻すと、`dwg.change.unsupported` を返すことを確かめた。
- 元からある SHAPE の欄の変更は、これまでどおり書き戻せる（決定 0042）。
- 形のファイルから名前を読めるようになったら、名前（2）で形を示して足せるようにするかを決め直す。
- 重みを持つ SPLINE と合わせ点の SPLINE、属性を持つ MINSERT、図形でないオブジェクトの追加は、まだ書き戻せない。

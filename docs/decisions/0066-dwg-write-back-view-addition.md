# 0066: DWG（R2000）への書き戻しで足すビューは、型ごとの欄をみな持ち、UCS を伴うなら UCS を指すものを表のオブジェクトの項目の終わりに加える

| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md)〜[0065](0065-dwg-write-back-dimstyle-addition.md) で、表の終わりに足した画層・文字の体裁・線種・アプリケーションの名前・寸法の体裁を、R2000 の DWG に書き戻せるようにした。ビュー（VIEW）の追加は、まだ拒んでいた。

R2000 の VIEW のレコード（型 0x3D）は、名前から外部参照に依る印までの欄がほかの表のレコードと同じで、その後に [決定 0045](0045-dwg-write-back-view-ucs-vport.md) で書き直す型ごとの欄が続く。UCS を伴う印（72）が立つときだけ、UCS の原点と軸・高さ・正投影の種類が続く。試料の図面の VIEW では、欄の終わりがハンドルの流れの始まりと一致した。ハンドルの流れは、所有者の表のオブジェクト（型 0x3C）・拡張辞書・外部参照のブロックの後に、UCS を伴うときだけ基準の UCS と名前の UCS を指す。試料の図面では、この 2 つの参照の型は 5 だった。

## 選択肢

1. 画層などと同じく一から符号化し、型ごとの欄は決定 0045 と同じく書く。所有者の表のオブジェクトの項目の終わりに足す。
2. VIEW の追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。

- 足したビューは、画層と同じく、ハンドルが HANDSEED より小さくなく、名前（2）が表のほかの VIEW と同じでないものだけを受け付ける。
- 印（70）は、紙空間の 1 だけを持てる。型ごとの欄は、読む側が置くものをみな持たなければならない。UCS を伴わないビューは、UCS の欄を持てない。
- UCS を伴うビューの基準の UCS（346）と名前の UCS（345）は、図面にある UCS を指さなければならない。表にないものは 0 と書く。参照の型は、試料の図面と同じく 5 とする。

## 影響

- 手組みのファイルで、UCS を伴わないビューと、紙空間の UCS を伴うビューを足して書き戻した。読み直した表は、足した表と同じになった。外部参照に依る印・分からない見え方の印・UCS を伴わないのに UCS の欄を持つもの・UCS でないものを指すものは拒んだ。
- 試料の R2000 の図面にも、ほかの表のレコードと並べて UCS を伴うビューを足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。VIEW の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増えた。
- 試料の図面には UCS のレコードがないので、UCS を指すビューは手組みのファイルでも試料でも確かめていない。
- 足したビューを、AutoCAD で開いて確かめてはいない。
- ほかの表のレコード（ブロック・UCS・ビューポート）の追加は、まだ書き戻せない。

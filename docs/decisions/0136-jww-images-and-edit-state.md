# 0136: JWW の画像は角で置く下敷きにし、編集状態と未解釈の制御文字は拡張にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

#172 で、[決定 0134](0134-jww-lift-to-drawing.md) と [決定 0135](0135-jww-blocks-and-dimensions.md) の残りを図面モデルへ移す。JWW の画像は、`^@BM` で始まる文字が `ファイル,幅,高さ,…` の形で置き方を持ち、版 700 からは同梱画像を図形の後ろに持つ。同梱画像は `%temp%` に続く名前で指す。見出しは書き込むグループとレイヤ・グループとレイヤの保護・グループの名前を、図形は曲線属性の番号と属性のフラグを、文字は文字種と字の間隔を持つ。図面モデルは、下敷き（[決定 0114](0114-drawing-underlays.md)）と、形式の拡張（[決定 0115](0115-drawing-format-extensions.md)）を持つ。

## 選択肢

1. 画像を指す文字を、文字のまま移す。
2. 画像を指す文字を下敷きにし、画素の数を持たないので角の平行四辺形（`Corners`）で置く。
3. 画像の画素の数を同梱画像から読み、画素の格子で置く。

## 決定

選択肢 2 を採る。1 は画像を指す文字を通常の文字として描いてしまう。3 は画像を開いて中身を読むことになり、参照名のファイルは開かないとした決定 0114 に反する。SXF の画像（[決定 0125](0125-sxf-raster-underlays.md)）と同じ形になる。

- **画像。** 幅と高さは用紙の mm とし、文字の始点を左下の角にして文字の角度で回す（推定）。角は、図形を置いた空間の座標に移す。資源の参照名は、ファイルの名前をそのまま持つ。`%temp%` で同梱画像を指し、その名前か `.gz` を付けた名前の同梱画像があれば、そのレコードを資源の定義にし、ほかは文字のレコードを定義にする。高さと幅の後ろの値（切り抜きと透過色と推定）は、要素の拡張 `jww.image` の欄 `extra` に元のまま持つ。ファイルの名前が空か、幅と高さが正の有限の数でなければ `jww.lift.invalid` とする。
- **未解釈の制御文字。** `^@BM` のほかの `^@` で始まる文字は描かず、文字をそのまま名前にした図面の拡張 `jww.control` に、位置（用紙の mm）を持つ。
- **編集状態。** 見出しを読めたら、図面の拡張 `jww.edit` に書き込むグループを、グループごとの拡張 `jww.group` に名前・書き込むレイヤ・保護を持つ。保護したレイヤは、拡張 `jww.layer` に保護を持つ。
- **図形の属性。** 曲線属性の番号か属性のフラグが 0 でなければ、要素の拡張 `jww.entity` に両方を持つ。
- **文字。** 高さは決定 0134 のとおり縦の大きさを形式の宣言値（`jww.moji.size_y`）として持ち、字形の大きさへは換算しない（[決定 0022](0022-drawing2d-semantics-and-format-mapping.md)）。文字種か字の間隔が 0 でなければ、要素の拡張 `jww.moji` に元の値を持つ。文字種の太字と斜体の加算値は、仕様の説明と例が食い違うので解釈しない。

## 影響

- 境界（`open`・`drawing`）へのつなぎと適合試験は、#172 の続きで行う。
- 同梱画像の中身（gzip）は L1 のまま持ち、ホストが資源を渡す op を作るときに展開を決める。

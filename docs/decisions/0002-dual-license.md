# 0002: ライセンスを MIT OR Apache-2.0 にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-24 |
| 状態 | 採用 |

## 背景

- 旧版のライセンスは MIT。
- 利用者には、建設会社・ソフトウェアの会社・発注者が多く、特許の扱いを気にする組織がある。
- Rust の生態系では「MIT OR Apache-2.0」が一般的で、依存する crate の多くも同じライセンス。

## 選択肢

1. **MIT のまま。** 短く分かりやすい。ただし特許の許諾を明示しない。
2. **Apache-2.0 だけ。** 特許の許諾と、その終了の条項がある。ただし GPL-2.0 のソフトと組み合わせられない。
3. **MIT OR Apache-2.0。** 利用者がどちらかを選べる。

## 決定

3 を選ぶ。

- `LICENSE-MIT` と `LICENSE-APACHE` を置く。
- 明示しない限り、寄稿は Apache-2.0 の定める「寄稿」として、追加の条件なしに 2 つのライセンスで提供されたものとする。

## 影響

- 依存の許可リストは変わらない。寛容なライセンスに限る（AGENTS.md）。
- 基準のデータ（プロファイル）と同梱のフォントは、別のライセンスにできる。データは CC BY 4.0、フォントは OFL の予定で、それぞれのフォルダーにライセンスを置く。
- 旧版のコードを移すときは、旧版の著作者が MIT から二重ライセンスに付け替える。ほかの人の寄稿を含む部分は、その人の同意を確かめる。

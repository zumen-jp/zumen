# 0179: 照合する要素の種類、指摘の形、使えない規則の扱いを決める

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-30 |
| 状態 | 採用 |

## 背景

[決定 0173](0173-profile-checks.md) は、照合の置き場所（`zumen-profile`）・`check` の op・`extends` の解き方・照合の種類ごとに比べる値を決めた。実装（#220）で、次のことが決まっていなかった。

- 色・線種・線幅・文字の高さ・文字を、どの種類の要素で比べるか
- 線種の語彙の、比べる列の名前と、名前の比べ方
- 指摘の値の名前と場所、`describe` に渡す形
- 知らない種類の規則や、語彙のない規則の扱い
- 縮尺の仮数と、レイヤの名前の部分の比べ方の細部

`extends` の解き方は 0173 のとおりにし、ここでは決め直さない。

## 選択肢

1. 使えない規則があれば、照合を始めずに失敗にする。
2. 使えない規則だけを照合せず、診断で返して、ほかの規則を照合する。

1 は、新しい小版のプロファイル（知らない種類の規則を持つもの）を、古いコアで照合できなくなる。0138 の「知らない欄は読み飛ばす」に近いのは 2 である。

## 決定

選択肢 2 を採る。あわせて、次のとおりにする。

### 比べる要素

| 照合 | 比べる要素 |
| --- | --- |
| `color` | 記号の配置と下敷きを除く、すべての要素と属性 |
| `line-type`・`line-width` | 線を描く要素（線分・円・曲線・折れ線・引出線・寸法・引出線つきの注記・表） |
| `text-height` | 文字・書式つきの文字・属性。高さに、要素から起点への変換の尺度（ビューと記号の配置の尺度）を掛ける |
| `characters` | 文字・書式つきの文字・属性（書式つきの値を含む）・表のセル・寸法の文字・引出線つきの注記の文字 |

- 同じ要素を、2 つのビューや 2 つの用紙を通してたどれば、たどるごとに比べる。
- `sheet-size` と `orientation` は起点の用紙を、`scale` は起点の用紙のすべてのビュー（`view` を書けばそのビューだけ）を比べる。実寸の空間を起点にすれば、どれも比べない。
- `check` の op に、`scene` と同じ `view`（用紙のビューの番号）を足す。

### 線種の名前

- 語彙の、比べる列の名前は、図面の形式の系統（`capabilities` の `family`: `acad`・`sxf`・`jww`）にする。
- 名前は、ASCII の大文字と小文字を区別せずに比べる。DXF・DWG の線種の名前は、大文字で書かれることが多い。

### 指摘

- 指摘は、規則の id（`rule`）と、診断と同じ形の値（`diagnostic`）の組にする。`diagnostic` をそのまま `describe` に渡せる。`severity` は規則の `level`（照合できない値は `info`）、`count` は 1 にする。
- 場所は、要素の ID・実効のレイヤの ID・起点の用紙の ID の順にする。レイヤの名前の指摘はレイヤの ID、用紙とビューの指摘は用紙の ID にし、ビューの番号は値（`view`）で持つ。
- どの指摘も、値 `rule` に規則の id を持つ。色は、符号で比べたら `sxf:20` の形、RGB で比べたら `#rrggbb` の形にする。文字は `U+XXXX` の形にする。
- 結果に、全体の指摘の数（`total`）を持たせる（`entities` と同じ）。

### 照合を始めない場合と、照合しない規則

- 知らない種類・知らない重要度の規則と、語彙や欄が使えない規則は、`profile.rule.unsupported`（warning）の診断を返して照合せず、結果の `rules` に入れない。
- 選んだプロファイル（`profile`）が `profiles` にないときは、`call.value.invalid`（`/profile`）で失敗にする。`profiles` の入力のうち 1 つでも読めなければ、`profile.format.unsupported` で失敗にする。同じ `id` と `edition` のプロファイルが重なれば、先のものを使う。

### 比べ方の細部

- 縦横の尺度が同じとみなすのは、2 つの尺度の差と、軸の内積が、尺度の 1e-9 倍以内のとき。
- 縮尺の分母の仮数は、10 との差が 1e-6 以内なら 1 とする。仮数は、語彙の値と 1e-6 以内の差なら同じとする。
- レイヤの名前の部分の語彙の値が、ほかの部分の語彙の名前をキーにした列を持てば、その部分の符号をその列に限る（`mlit-cad` の `ORD` の `responsibility = ["C"]`）。
- 名前の幅は、ASCII と半角カナ（U+FF61〜U+FF9F）を 1、ほかを 2 と数える。

## 影響

- 境界の小版を 34 に上げ、`check` の op と結果の型を足した。
- 指摘と診断の code（`profile.*`）をカタログに足した。指摘の code の `severity` は使わない（0173）。
- `xtask` のプロファイルの検査は、照合の種類と欄の一覧と書式の大版を `zumen-profile` から引く。
- 線種を模様で比べること、ACI の列を `mlit-cad` に足すことは、0173 のとおり別に決める。

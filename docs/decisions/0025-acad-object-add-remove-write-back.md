# 0025: AutoCAD の系統の表に足したオブジェクトは、同じ所の次の残したオブジェクトの前に書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[0024](0024-acad-table-write-back.md) は、共有の表 `AcadDb` の値と見出しの変数の変更を、元のレコードと比べて DXF に書き戻すことにした。オブジェクトの追加と削除は、表に足したオブジェクトの元の場所の決め方とともに後で決めることにした。[#64](https://github.com/zumen-jp/zumen/issues/64) は、表の変更を DXF に書き戻すことを求めている。

- 表のオブジェクトは、元のレコードを `Origin` で指す。足したオブジェクトには元のレコードがない。
- DXF の図形と表は、所（セクション）の中の順に意味がある。表のオブジェクトも、符号化の中の順に並ぶ。
- `DxfTxn` は、レコードを指定したレコードの前に足し、レコードを除ける。

## 選択肢

1. 足したオブジェクトは、表の中で同じ所の後ろで最初の残したオブジェクトの前に足す。なければ、その所の ENDSEC の前に足す。
2. 足したオブジェクトは、いつもその所の ENDSEC の前に足す。
3. 足すときに、呼ぶ側が前に置くレコードの番号を渡す。

2 は、表の中の順と書いた後の順が合わない。3 は、表を変える経路が DXF のレコードの番号を知らなければならず、DWG の表にも同じ仕組みが要る。

## 決定

選択肢 1 を採る。

- `Origin` に、元のレコードがないことを表す `Origin::New` を足す。表には `AcadDb::insert`・`AcadDb::remove` で足し、除く。
- `DxfFile::write_back` は、今のファイルから作り直した表にあって、表にない元のレコードを除く。
- `Origin::New` のオブジェクトは、表の中で同じ所の後ろにある最初の残したオブジェクトのレコードの前に足す。なければ、その所の最初の ENDSEC の前に足す。その所がファイルになければ、`dxf.object.unsupported` を返す。
- 足すレコードは、グループ・コード 0 の種類の後に、値を表の順に書く。値の書き方は 0024 と同じ。
- 同じ元のレコードを指すオブジェクトが 2 つ以上あれば、2 つ目からは `dxf.object.unsupported` を返す。種類か所が元のレコードと違うものも、同じように返す。
- 足したオブジェクトのハンドルと所有者は、呼ぶ側が決める。`$HANDSEED` などのほかに直すものは、後の PR で扱う。

## 影響

- `zumen-acad` に `Origin::New`、`AcadDb::insert`・`AcadDb::remove` が加わる。`Origin` を網羅して照合する呼び出し側は、`Origin::New` を扱う。
- 書き戻した後のファイルから作った表が、元の場所のほかは書き戻した表と同じになることを試験で確かめた。

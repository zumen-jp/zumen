# 0168: 図面モデルの変更を JWW の図形の一覧に書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0139](0139-drawing-apply.md) の apply は、図面モデルの変更を DXF と DWG に、[決定 0167](0167-sxf-sfc-apply.md) は SXF の SFC に書き戻す。JWW は読めるが、境界の `apply` は `change.format.unsupported` で断り、`capabilities` も書けないと返す。Jw_cad で描いた図面を直したい使い手と AI は、DXF に移してから直すしかなく、移すときの情報の損失を避けられない。

JWW は、見出しの欄と、MFC の CArchive で書いた図形の一覧・ブロックの定義の一覧と、版 700 からは画像の一覧を持つ（[決定 0133](0133-jww-l1-records.md)）。

- 図形は、共通の欄（曲線属性・線種・色・線幅・レイヤ・レイヤグループ・フラグ）と、形の値を持つ。線と円弧の形の値は、決まった大きさの実数である。
- オブジェクトの前の印は、初めてのクラスなら名前を、2 度目からはクラスの番号を書く。クラスとオブジェクトの番号は、ファイルの全体で 1 から数える。1 つのオブジェクトを除くか足すと、後ろの印の番号が変わる。
- 一覧は、前に件数を持つ。
- 要素は鍵を持たない。要素の ID は、レコードの番号で作る（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）。

実寸の空間の座標は、用紙の値にレイヤグループの縮尺の分母を掛けて読む（[決定 0134](0134-jww-lift-to-drawing.md)）。円弧の角度はラジアンで持ち、読むときに度にする。

## 選択肢

1. JWW のファイルモデルを図面モデルから書き直す。
2. スタイルと形の変更は、共通の欄と形の値のバイトを同じ大きさのまま書き直す。除くか足すときは、図形の一覧とブロックの定義の一覧を書き直し、件数と印の番号を数え直す。見出しと画像の一覧は写す。当てた後に読み直して確かめる。
3. 除くときは、印を空のオブジェクト（`00 00`）にして、番号をずらさない。

1 は、見出しと、図面モデルに移さない欄（曲線属性・ソリッドの色・寸法の SXF の欄など）を保てない。3 は、Jw_cad が図形の一覧の空のオブジェクトを読めるか確かめられない。

## 決定

選択肢 2 を採る。

- **当てる変更。** どれも要素を ID と読んだときのハッシュで指す（決定 0156）。
  - スタイルの変更（`Restyle`）。線（`CDataSen`）と円・円弧・楕円・楕円弧（`CDataEnko`）の、レイヤ・色・線種・線幅のうち、変わったものを共通の欄に書く。
  - 置き換え（`Replace`）と移動（`Transform`）。線は線分に、`CDataEnko` は円か円弧にする。クラスは変えない。置き換えは、変わったレイヤとスタイルも書く。
  - 除去（`Remove`）。どの図形（線・円弧・点・文字・ソリッド・ブロックの参照・寸法）も除ける。ブロックの定義の中の図形も除ける。
  - 追加（`Add`）。レイヤグループの空間（`space/0`〜`space/15`。図形を持つグループ）に、線分・円・円弧を足す。図形の一覧の終わりに置く。
- **値の書き方。**
  - 座標と長さは、縮尺の分母で割って用紙の値にする。ブロックの定義の中は、割らない。
  - 円は、傾き 0・扁平率 1・全周の印で書く。円弧は、傾き 0・扁平率 1 で、始まりの角度と開き角をラジアンにして書く。時計回りは、開き角を負にする。
  - レイヤは、グループ × 16 + レイヤ + 1 の番号を、レイヤとグループの欄に戻す。グループは空間と縮尺を決めるので、ブロックの定義の外では変えない。
  - 色は、JWW のペンの番号（`ColorSystem::Jww`。0〜9 と、版 420 からの SXF の拡張色 100〜356）にする。RGB だけなら、同じ RGB のペン（1〜9、100〜356 の順）にする。
  - 線種は、番号（1〜9、11〜19、版 420 からの 30〜62）にする。
  - 線幅は、見出しの単位（1/100 mm か、印刷の解像度のドット）で書き、読み直すと同じ太さになるものだけを書く。版 351 より前は、図形が線幅を持たないので書けない。追加で線幅を書かなければ 0 とし、ペンの印刷の幅に従う。
  - レイヤに従う値、ブロックに従う値、1 でない線種の倍率は、JWW の図形が持たないので書けない。
- **書き直し方。**
  - スタイルと形の変更だけなら、ほかのバイトを写す。
  - 除くか足すときは、見出しまでを写し、図形の一覧とブロックの定義の一覧を書き直す。印は、初めてのクラスなら名前を、2 度目からは番号を書く（MFC の CArchive と同じ。番号が `7FFF` 以上なら 4 バイトの形）。件数は 2 バイト、`FFFF` 以上なら `FF FF` と 4 バイトで書く。足すクラスが初めてなら、ファイルの最初のクラスのスキーマで書く。画像の一覧と、読めなかった残りは写す。
- **断るもの。** `change.edit.unsupported` で断り、何も変えない。
  - 線と `CDataEnko` のほかの図形のスタイルと形の変更（点・文字・ソリッド・ブロックの参照・寸法）。
  - 楕円と楕円弧にする置き換えと移動（扁平率の書き戻しは、まだない）。
  - 1 つのレコードから複数の要素ができたものと、同じ要素を 2 度指す変更。
  - 表（レイヤ・文字スタイル・線種・寸法スタイル）の変更。
  - 用紙と、ブロックの定義の空間への追加。
- **確かめ方。** 書き直したバイト列を読み直して図面モデルに変換し、次を確かめる。合わなければ断る。
  - 変えた要素と足した要素が、求めたレイヤとスタイルになり、形が求めた値に近い（相対誤差 1e-9。角度は 1 周の違いを除く）。実寸の値は用紙の値に縮尺の分母を掛けて読み、角度はラジアンを度にして読むので、最後の桁が違いうる。
  - 除いた要素がなくなり、ほかに要素が増えない。
  - ほかの要素は、値が変わらない。
- **ID のずれ。** 前の図形を除くか足すと、後ろの要素の ID（レコードの番号）がずれる。apply は、変えていない要素の ID がずれたときに、そのことを返す（決定 0156 の `ids_shifted`）。
- **境界。** 新しい小版で、次を足す。
  - `capabilities` は JWW を書けると返す。
  - 色の変更（`color_change`）に、JWW のペンの番号（`jww`）を足す。`aci`・`sxf`・`jww` は 1 つだけ書く。
  - `apply` の結果に `ids_shifted` を足す。ずれたときだけ `true` を持つ。

## 影響

- 使い手と AI は、JWW の図面を JWW のまま直せる。見出し・画像・変えない図形のバイトは残る。
- 書き戻した線と円弧の座標は、求めた値と最後の桁が違いうる。apply が返すハッシュは、読み直した値のものである。
- 書き戻した円弧は、傾きを 0 にして角度に足す。元の傾きは残らない。
- 除くか足した後は、使い手が持つ ID が別の要素を指しうる。`ids_shifted` を見て、`entities` で読み直す。ハッシュの前提条件は、値の違う要素への変更を防ぐ。
- Jw_cad が書き戻したファイルを開けるかは、Jw_cad を使える環境で確かめる必要がある。
- 点・文字・ソリッド・ブロックの参照・寸法の形とスタイル、楕円と楕円弧、表の変更、ブロックの定義への追加は、まだ書き戻さない。

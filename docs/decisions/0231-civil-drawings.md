# 0231: 線形の平面図・縦断図・横断図は、新しい crate で図面モデルに出し、縦断図の文字は用紙に置く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-01 |
| 状態 | 採用 |

## 背景

土木の領域モデル（[決定 0230](0230-civil-model-alignments.md)）から、平面図・縦断図・横断図を図面モデル（Drawing2D）に出す（#369）。縦断図は、縦の尺度を横より大きくして描く。図面モデルのビューは任意の 1 次変換を持てるので、縦横で尺度の違うビューも持てる。ただし、次の制約がある。

- DXF・DWG のビューポートは等方の尺度しか持たないので、縦横で尺度の違うビューは書かない（[決定 0139](0139-drawing-apply.md)）。
- 新しい DXF への変換（`convert`）は、ビューを書かない（[決定 0206](0206-convert-to-new-dxf.md)）。縦横で尺度の違うビューは、のちに焼き込んで書くことにした（[決定 0238](0238-bake-anisotropic-views.md)）。
- プロファイルの照合は、縦横で尺度の違うビューで、文字の高さと尺度を照合できない（[決定 0173](0173-profile-checks.md)）。

## 選択肢

1. 土木の領域モデルの crate（`zumen-civil`）に、図面モデルへの変換を足す。
2. 新しい crate（`zumen-civil-drawing`）を作り、土木の領域モデルと図面モデルの両方に依る。
3. 縦断図を、縦の値を先に拡大した等方の空間にして出す。

## 決定

選択肢 2 にする。`zumen-civil` は図面モデルに依らないまま（決定 0230）にする。

### 図の組み立て

- 平面図は、1 つ目の空間（メートル、x を東、y を北）に置き、用紙「平面図」に等方のビューで置く。
  - 線形の区間は、直線を線、円弧を弧、クロソイドを原点の形のクロソイド（[決定 0123](0123-drawing-clothoid-edge.md)）にする。区間の形から原点の形への変換は `zumen-geom2d` の `clothoid_origin` で行う（決定 0230）。
  - 図面モデルの形のないほかの緩和曲線（ブロス曲線・サイン半波長逓減曲線など）は、許容差の内の折れ線にし、`civil.curve.approximated` で知らせる。計算できない曲線（両端に半径のある 3 次放物線など）は除き、`civil.curve.unsupported` で知らせる（[決定 0236](0236-civil-curve-positions.md)）。
  - 測点は、測点の間隔ごとに線形に直交する短い線と、表記（`No.12`）の文字を置く。
  - TIN は、三角形を閉じた折れ線にする。
- 縦断図は、2 つ目の空間（x を追加距離、y を標高、メートル）に計画線と地盤線を置き、用紙「縦断図」に縦横で尺度の違うビューで置く。
  - 計画線は、一定の勾配の区間を線に、縦断曲線を許容差の内の折れ線にする。
  - 地盤線は、横断の現況の線の、中心（離れ 0）の高さを結ぶ。
  - 測点・計画高・地盤高の文字と、それらの欄の線は、用紙の要素として置く。文字が縦横の尺度で歪まず、文字の高さを照合できる。
- 横断図は、横断ごとに空間と用紙を作り、等方のビューで置く。
- 尺度・文字の高さ・測点の間隔は、変換の引数（`Options`）で渡す。既定は、平面図 1/1000、縦断図の横 1/1000 と縦 1/100、横断図 1/100、文字の高さ 2.5 mm、測点の間隔 20 m とする。プロファイルから読むことは、[決定 0239](0239-civil-drawing-op.md) で決めた。

### 書き出しと照合

- DXF・DWG に書き出すときは、縦横で尺度の違うビューを、ビューの変換で写した用紙の要素に直してから書く。弧とクロソイドは、写すと形が変わるので、許容差の内の折れ線にする。この変換は [決定 0238](0238-bake-anisotropic-views.md) で決めた。
- 照合では、縦断図の文字は用紙の要素なので、文字の高さを照合できる。縦断図のビューの尺度は、これまでどおり `profile.scale.unsupported` で知らせる。

## 影響

- 縦断図の計画線と地盤線の線分は、縦の尺度で傾きが大きく見えるので、曲線の許容差は、縦の尺度で用紙に写したときの値で決める。縦断の円弧とクロソイドの区間は、位置の計算と同じ式（[決定 0236](0236-civil-curve-positions.md)）で高さを求め、同じ許容差の折れ線にする（#479）。
- 片勾配図・土工の数量の図は、まだ出さない。

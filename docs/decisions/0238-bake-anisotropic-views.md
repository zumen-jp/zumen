# 0238: 横と縦の尺度の違うビューは、DXF に書くとき用紙の要素に焼き込む

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

[決定 0231](0231-civil-drawings.md) の縦断図は、縦の尺度を横より大きくしたビューで、実寸の空間を用紙に置く。DXF・DWG のビューポートは相似の変換しか表せない。新しい DXF への変換（[決定 0206](0206-convert-to-new-dxf.md)）は、これまでビューを書かずに落としていた（#469）。

決めることは、次のとおり。

- どのビューを焼き込むか。
- 要素ごとの写し方と、曲線の許容差。
- 書き戻し（apply）で同じことをするか。

## 選択肢

1. **変換のときに、ビューの要素を用紙の要素に写して書く。** 図面モデルは変えず、書き出しの段だけで直す。
2. **図面モデルを作る側（土木の図面）で、初めから用紙の要素にする。** 実寸の空間とビューが残らず、照合と描画でビューを使えなくなる。

## 決定

1 にする。

- 焼き込むのは、相似でなく、向きを潰さず（行列式が 0 でない）、切り抜きを持たないビュー。相似のビューと、切り抜きを持つビューは、これまでどおり落として `convert.element.unsupported`（種類 `view`）で知らせる。
- 用紙の要素とビューは、用紙の描く順（`Sheet::order`）に書く。ビューの空間の要素は、空間の描く順に書く。ビューで表示しないレイヤの要素は書かない。
- 線分と、膨らみのない折れ線は、頂点を写す。
- 円・円弧・楕円弧・スプライン・クロソイドと、膨らみを持つ折れ線は、写すと元の種類で表せないので、`zumen-geom2d` で折れ線にしてから頂点を写す。用紙の上で 0.02 mm に収まるよう、実寸の空間の許容差を、変換がいちばん引き延ばす向きの倍率（最大の特異値）で割る。幅を持つ折れ線は書かない。
- 文字は基点を写す。字の枠の横の向きと、傾きを含む縦の向きを写し、写した横の向きを回転、横に直交する縦の成分を高さ、横に沿う縦の成分を傾き、横と高さの比を幅の比にする。1 行の文字なら、写した字の形は元の字の形と同じになる。鏡映になる変換は、文字の向きを表せないので書かない。
- ほかの種類（書式つきの文字・寸法・記号・ハッチングなど）は焼き込まず、種類ごとに `convert.element.unsupported` で知らせる。
- 焼き込んだビューごとに `convert.view.approximated` で知らせる。
- 書き戻し（apply）は、元の DXF・DWG のビューポートを持ったまま要素を足すので、ビューは相似のものしかなく、焼き込まない。

## 結果

- 縦断図を DXF に書き、読み直すと、用紙に同じ形の計画線と地盤線と文字がある（`zumen-abi` の試験）。
- 書いた DXF では、縦断図は実寸の空間とのつながりを持たない。読み直した図面モデルでは、縦断図の線は用紙の要素になる。

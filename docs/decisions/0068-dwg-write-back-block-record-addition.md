# 0068: DWG（R2000）への書き戻しで足すブロックは、レコードと BLOCK・ENDBLK と図形を揃えて加え、レコードを表のオブジェクトの項目の終わりに足す

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md)〜[0067](0067-dwg-write-back-vport-addition.md) で、表の終わりに足した画層・文字の体裁・線種・アプリケーションの名前・寸法の体裁・ビュー・ビューポートの設定を、R2000 の DWG に書き戻せるようにした。ブロックのレコード（BLOCK_RECORD）の追加は、まだ拒んでいた。

ブロックは、レコードだけでは成り立たない。レコードは、始まりの BLOCK と終わりの ENDBLK、持つ図形の並びの始めと終わり、それを挿す INSERT を指す。試料の R2000 の図面では、レコード（型 0x31）は、名前から外部参照に依る印までの欄がほかの表のレコードと同じで、その後に名前のない・属性を持つ・外部参照・重ねた外部参照・読み込んだの 5 つのビット、基点、外部参照のパス、INSERT ごとの RC 1 と終わりの RC 0、説明、プレビューの大きさが続いた。ハンドルの流れは、所有者の表のオブジェクト（型 0x30）・拡張辞書・外部参照のブロックの後に、BLOCK・始めの図形・終わりの図形・ENDBLK・INSERT ごとのハンドル・レイアウトを指した。ブロックの表のオブジェクトは、項目の後にモデル空間と紙空間のレコードを指す 2 つのハンドルを持った。BLOCK（型 4）は名前だけを、ENDBLK（型 5）は何も、型ごとの欄に持った。読む側は、BLOCK の名前と基点を値に置かない。

## 選択肢

1. 足したレコードと、それが持つ足した BLOCK・図形・ENDBLK を揃えてから一から符号化する。基点は BLOCK の 10・20・30 から取る。レコードは、ブロックの表のオブジェクトの項目の終わり（2 つの空間のハンドルの前）に足す。
2. ブロックのレコードの追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。

- 足したブロックのレコードは、画層と同じく、ハンドルが HANDSEED より小さくなく、名前（2）が表のほかのレコードと大文字と小文字を区別せずに同じでないものだけを受け付ける。名前が `*` で始まるもの（名前のないブロックと空間）は受け付けない。
- 足したレコードは、それが持つ足した BLOCK と ENDBLK を 1 つずつ持たなければならない。BLOCK の名前（2）はレコードと同じでなければならず、基点（10・20・30）はみな持つか、みな持たない（原点）かでなければならない。BLOCK と ENDBLK を持てるのは、足したレコードだけとする。
- BLOCK と ENDBLK は、並びをたどるハンドルを持たない。ほかの図形は、足した順にブロックの並びへ繋ぐ。ATTDEF を持つブロックは、属性を持つビットを立てる。ほかのビットは偽、外部参照のパスと説明は空、プレビューは持たないと書く。
- 足した INSERT のうち、足したブロックを挿すものは、レコードの INSERT の並びへ加える。図面にあったブロックを挿す INSERT は、これまでどおりそのレコードを直さない（[決定 0053](0053-dwg-write-back-pointing-entity-addition.md)）。
- ブロックの表のオブジェクトは、項目の後の 2 つのハンドルを残す。

## 影響

- 手組みのファイルで、線を 2 本持つブロックと、それを挿す INSERT を足して書き戻した。読み直した表は、BLOCK の名前と基点を除いて足した表と同じになった。足したブロックの線は、書き戻した図面から除くこともできた。名前が `*` で始まるもの・表にある名前・名前の違う BLOCK・一部だけの基点・ENDBLK のないもの・足したブロックでないものが持つ BLOCK は拒んだ。
- 試料の R2000 の図面にも、線を 1 本持つブロックと、それをモデル空間に挿す INSERT を、ほかの表のレコードと並べて足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。
- 足したブロックを、AutoCAD で開いて確かめてはいない。
- UCS のレコードの追加は、まだ書き戻せない。

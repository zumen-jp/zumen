# 0160: 点は図面モデルの点の形にし、文書の点の表し方と、点ごとの既定義の印で描く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

図面モデル（Drawing2D）には、点の形がない。3 つの形式の点は、それぞれ定義を持たない記号にしている。

- DXF・DWG の POINT は、名前空間 `dxf.point` の記号で、`$PDMODE` の番号を名前にする（[決定 0140](0140-dxf-solids-and-points.md)）。点の大きさ `$PDSIZE` は、移していない。
- SFC の点マーカーは、名前空間 `sxf.marker` の記号で、マーカーのコードを名前にする（[決定 0126](0126-sxf-splines-and-point-markers.md)）。
- JWW の点は、名前空間 `jww.point` の記号で、記号の点は記号の番号を、ほかは `point` を名前にする。仮点は移さない（[決定 0134](0134-jww-lift-to-drawing.md)）。

AutoCAD の系統の POINT の見え方は、図面全体の変数が決める（DXF Reference「HEADER Section Group Codes」）。

- `$PDMODE` は形である。0 は小さな点、1 はなし、2 は十字、3 はバツ、4 は上向きの短い線で、32 を足すと円、64 を足すと四角で囲む。
- `$PDSIZE` は大きさである。正なら長さ、負なら画面の高さに対する百分率、0 なら画面の高さの 5% とする。

点を記号にしたままだと、次の問題がある。

- 点を探す分析（測量図の基準点など）と、点を描く側が、3 つの名前空間とその名前の意味を知る必要がある。
- 記号は定義を描くものだが、どの点の記号も定義を持たない。
- 画面の高さに対する百分率の大きさを、記号の尺度で表せない。

## 選択肢

1. 図面モデルに点の形を足す。描き方は、文書の点の表し方か、点ごとの既定義の印で持つ。
2. 今のまま記号にし、`$PDSIZE` を形式固有の情報に足す。
3. 点を、印の形の線分と円に展開する。

2 は、点を描く側が形式ごとの名前空間を知る今の形のままで、表示を変える値を形式固有の情報に置く（[決定 0157](0157-drawing-model-fields-and-extensions.md) に反する）。3 は、点という意味と元のコードが分からなくなり、画面に対する大きさも表せない。

## 決定

選択肢 1 を提案する。

- **形。** `Shape::Point` を足す。点（`Point`）は、位置・回転（度）・描き方・作図の補助の印を持つ。
- **描き方。** 次のどちらかである。
  - 文書の点の表し方に従う（AutoCAD の系統の POINT）。
  - 既定義の印。印の表のキー（名前空間とコード）と尺度で指す。SFC の点マーカーは名前空間 `sxf.marker` とマーカーのコード、JWW の記号の点は `jww.point` と記号の番号にする。印の形は、表示する側がキーから引く。
- **文書の点の表し方。** `Drawing2D::point_style` は、形と大きさを持つ。持たない形式では `None` にし、表示する側は小さな点として描く。
  - 形は、基本の形（小さな点・なし・十字・バツ・上向きの短い線）と、円と四角で囲むかを持つ。
  - 大きさは、点のある空間の長さか、画面の高さに対する百分率である。
  - DXF・DWG は `$PDMODE` と `$PDSIZE` から作る。知らない番号は、`dxf.lift.invalid` を返し、小さな点とする。
- **作図の補助の点。** JWW の仮点は、作図の補助の印を立てた点として移す。表示する側が描くかを決め、印刷はしない（[決定 0159](0159-drawing-walk-placements.md) の印刷の可否）。
- **JWW のほかの点。** 記号の点でない点は、文書の点の表し方に従う点にする。
- **記号の名前空間。** `dxf.point`・`jww.point`・`sxf.marker` の記号は作らない。

## 影響

- 決定 0126・0134・0140 の点の扱いが変わる。0140 は、この決定に合わせた。採用するときに、0126 と 0134 からこの決定へリンクする。
- `entities` の op の `kind` に `point` が増え、点の要素の `kind` は `symbol` から `point` に変わる。
- 画面の高さに対する大きさの点は、表示する側が、表示する範囲の高さから大きさを決める。範囲（`bbox`）は、位置だけで決める。
- 点の書き戻しは、[決定 0139](0139-drawing-apply.md) の範囲を広げるときに扱う。

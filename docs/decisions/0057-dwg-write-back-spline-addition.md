# 0057: DWG（R2000）への書き戻しで足す SPLINE は、節点と制御点を持ち重みを持たないものだけを、表にない印を 0 にして書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0052](0052-dwg-write-back-entity-addition.md) からの決定で、表の終わりに足したいくつかの種類の図形を、R2000 の DWG に書き戻せるようにした。SPLINE は、値を変えたとき、場合（scenario）と、有理・閉じている・周期的の 3 つの印を元のデータから写す（[決定 0036](0036-dwg-write-back-spline.md)）。足した SPLINE には、写す元のデータがない。

試料の R2000 の図面にある SPLINE 6 個を調べた。

- 場合は、どれも 1（節点と制御点）だった。
- 3 つの印は、どれも 0 だった。
- 重みを持つものはなかった。

## 選択肢

1. 場合を 1 とし、重み（41）を持たないものだけを受け付けて、3 つの印を 0 にする。
2. 当てはめる点だけのものは場合を 2 にし、重みを持つものは有理の印を立てる。
3. 足した SPLINE は、まだ受け付けない。

2 の形は試料になく、読める形か確かめられない。1 は試料と同じ形になる。

## 決定

選択肢 1 を採る。

- SPLINE（型 0x24）を足せるようにする。値は、値を変えたときと同じ書き方で書く。
- 場合を 1 にし、有理・閉じている・周期的の印を 0 にする。
- 重みを持つものと、当てはめる点（11・21・31）を持つものは受け付けない。

## 影響

- 手組みのファイルで、3 次の SPLINE（節点 8 つ・制御点 4 つ）を足して書き戻した。読み直した表は、足した表と同じになった。
- 重みを持つものと、当てはめる点だけを持つものは、拒むことを確かめた。
- 試料の R2000 の図面のモデル空間にも、同じ SPLINE を足して書き戻した。読み直した表は同じになり、CRC の診断も出なかった。
- 閉じた SPLINE も、印は 0 のまま書く。印は形を描く側のものと見なし、AutoCAD で開いて確かめてはいない。
- まだ書き戻せない追加がある。
  - 重みを持つ SPLINE と、当てはめる点を持つ SPLINE
  - SHAPE など、表にない欄を元のデータから写すほかの図形
  - 属性を持つ MINSERT
  - 図形でないオブジェクト

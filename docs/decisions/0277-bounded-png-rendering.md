# 0277: PNG を予算で止まる走査と固定した符号化で描く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-06 |
| 状態 | 採用 |

## 背景

`render` は図面からシーンを作って SVG を返す。サーバーで PNG を作る場合にも、同じ座標・線幅・色・描画順・ID・資源の診断を使う。ネイティブと wasm でバイト列が一致し、依存の内部処理も予算と中断の対象にする必要がある。

## 選択肢

| 方法 | ライセンスと wasm | 決定性・予算 | 大きさ |
| --- | --- | --- | --- |
| tiny-skia 0.12.0 | BSD-3-Clause。Rust の CPU 描画。既定の std・SIMD・png-format を外して no-std-float を選べる | libm を選べるが、fill_path の辺の確保・並べ替え・走査には Cx を渡せない。描けない座標をログだけで落とす経路もある | README は約 200 KiB とする。成果物ごとの差は別途測る必要がある |
| resvg 0.45.1 | MIT OR Apache-2.0。Rust。既定のシステムフォント・画像読み取りを無効にする必要がある | SVG の直列化と再解析が入り、usvg と tiny-skia の内部の確保・処理も制御する必要がある | 文字・画像機能と SVG の木の分が増える |
| シーンの列から固定したサンプル位置で走査する | 既存の libm だけを使う。Rust と wasm の共通の演算 | 各辺・並べ替え・画素・出力の繰り返しで Cx を確認し、確保前に容量を数えられる | 外部の描画・圧縮の依存を追加しない |

候補の wasm の大きさは同じ機能で実測していない。tiny-skia と resvg は、内部処理の予算と中断を管理できない点で除外する。採用する実装の wasm は製品の build で測り、ネイティブと出力全体を照らす。

PNG の符号化も、png crate 0.18.0（MIT OR Apache-2.0、Rust）と比較した。行や圧縮の内部バッファーと圧縮の途中の中断を管理する必要があるため、今回は圧縮しない DEFLATE ブロックを直接書く。

## 決定

シーンの列から走査する方法を選ぶ。`zumen-render` に PNG を加え、API は既存の `render` の `format` に `png` を加える。SVG のバイト列・予算の数え方とシーン・ID の規則は変えない。サイズ・範囲・DPI・色・フォントの指定と blob の生存期間は SVG と同じにする。

アンチエイリアスは画素ごとに 4×4 の固定したサンプル位置を使う。面は evenodd、字形は nonzero、線は butt・miter（上限 4）にする。クリップはサンプルのマスクを交差させ、同じサンプルが通った分だけ sRGB の色と alpha を source-over で合成する。描く単位内の各パスについて通ったサンプルの数を coverage にし、元の alpha に掛けて画素へ合成する。各パスの最後に最も近い 8 bit の整数へ丸める。走査の交点は f64 の四則演算、平方根と三角関数は libm を使う。合成と PNG の符号化は整数で行う。SIMD・スレッド・OS のフォント・外部画像・ネットワーク・時計は使わない。

出力座標と半径は絶対値 2^31 ピクセル以内とする。変換の非有限値と範囲外は診断して全体を失敗にする。画像は最大 16,777,216 画素（RGBA 64 MiB）にする。出力と画素が同時に存在するため、予算を無制限にしても単一画像の確保を制限する。各バッファーは wasm32 と共通の i32 の容量上限を持ち、幅・高さ・行の積を u64 で検査する。確保前に DecodedBytes、辺の生成に Segments、走査・並べ替え・画素・符号化に Work を数える。行と辺の途中にも中断を確認する。失敗では一部の PNG を返さない。

## 影響

PNG は RGBA 8 bit、非インターレース、固定のフィルターとチャンク順で書く。圧縮しないため出力は概ね幅×高さ×4 バイトになる。圧縮率より、予測できる確保量・処理量・中断とビット単位の一致を優先する。圧縮方法を追加する場合も出力の変更と予算を記録し、ネイティブと wasm を照らす。

SVG の閲覧側と画素単位で同じアンチエイリアスになることは保証しない。自分たちのサンプル位置と合成を契約テストにし、外部の PNG デコーダーで寸法・RGBA を照らす。文字の輪郭がない場合、画像と名前付き点記号は SVG と同じ診断で落とす。

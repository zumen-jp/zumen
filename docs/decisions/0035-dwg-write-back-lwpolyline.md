# 0035: DWG（R2000）への書き戻しは、LWPOLYLINE の続く欄の印を、値があるかから選んで符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0034](0034-dwg-write-back-mtext.md) までで、MTEXT までの型ごとの欄を R2000 の DWG に書き戻せるようにした。LWPOLYLINE の型ごとの欄は、初めの印（BS）が、続く欄（一定の幅・標高・厚さ・押し出しの向き・膨らみ・頂点ごとの幅）があるかを表す。読む側は、印のうち閉じていることだけを 70 に置き、ほかの欄は値があるときだけ表に置く。

- 頂点ごとの幅があると、一定の幅（43）は表に置かない。
- 膨らみ（42）は、0 でないものだけ表に置く。

## 選択肢

1. 続く欄の印は、表に値があるかから選ぶ。表にない一定の幅と、続く欄を表さない印のビットは、元のデータから写す。
2. 元の印をそのまま使い、表の値の有無が印と合わなければ受け付けない。

2 は、標高を足すといった変更を書き戻せない。

## 決定

選択肢 1 を採る。

- 標高（38）・厚さ（39）・押し出しの向き（210〜230）・頂点ごとの幅（40・41）は、表に値があれば印を立てて書く。一定の幅は、0 でなければ印を立てて書く。
- 膨らみは、1 つでも表にあれば、すべての頂点の分を書く（ないものは 0）。
- 頂点ごとの幅は、初めの頂点から続けて置かれたものだけを受け付ける。頂点ごとの幅と 43 が両方あるもの、頂点の数が 90 と合わないもの、0 と 1 でない 70 は `dwg.change.unsupported` を返す。
- 頂点ごとの幅があるときは、元のデータの一定の幅を写す。続く欄と閉じていることを表さない印のビットも写す。
- 頂点は、初めを RD で、続きを前の頂点を既定の値とする DD で書く。

## 影響

- 手で組んだ R2000 の LWPOLYLINE の頂点・頂点ごとの幅を変え、標高を足して書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の LWPOLYLINE も頂点を動かして書き戻す。
- ハンドルの流れの後ろの埋めのビットも写すので、データが 1 バイト延びることがある。読み直した値は変わらない。
- 膨らみが 0 の頂点だけの元のデータも、膨らみの欄なしで書き直すことがある。読み直した値は変わらない。
- SPLINE・HATCH などの型ごとの欄の変更は、まだ書き戻せない。

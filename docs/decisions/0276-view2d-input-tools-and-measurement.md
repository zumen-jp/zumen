# 0276: 表示部品の入力は明示して接続し、ツールの有効期間を中断で終え、計測はシーンの距離と実寸を分ける

| 日付 | 2026-11-06 |
| 状態 | 採用 |

## 背景

#586 で、[決定 0267](0267-view2d-on-scene-columns.md) の表示部品に操作・吸着・計測・重ね描きを足す。[決定 0274](0274-view2d-selection-and-state.md) により、選択は要素 ID と配置の道筋で区別し、状態の同期通知中には変更しない。既存のカメラのメソッドと OffscreenCanvas の描画は、DOM のイベントを使わずに動く。

タッチやホイールを常に取り込むと、埋め込み先のスクロールを妨げる。独自ツールの購読を表示部品と同じ寿命にすると、ツールを変更した後も古い操作が残る。また、シーンの列には、配置前の精密な幾何や、実寸へ戻す尺度を判断する情報がない。

## 選択肢

- **入力を自動で登録するか、明示して接続するか。** 自動登録は小さい例を短くするが、利用側の操作と衝突し、OffscreenCanvas に別の初期化が要る。DOM の接続を独立させ、正規化した入力を共通の入口へ渡す形を採る。
- **独自ツールが個別にイベントを登録するか、共通の入力を受けるか。** 個別登録は捕捉・無効化・中断をそれぞれで実装する必要がある。組み込みと独自ツールを同じ入口に置き、有効期間に作った購読と重ね描きをまとめて解除する。
- **シーン上の長さを常に実寸とするか、実寸の可否を別に返すか。** 用紙の複数の表示枠、異なる尺度や非一様な尺度の配置、単位不明で誤った値になる。シーン上の距離は常にその単位と起点を添え、実寸を判断できない理由を別に返す。

## 決定

### 入力の接続と状態

- `attachInput` は指定した DOM 要素に入力を接続し、解除する関数を返す。接続は最大 1 つとし、付け替えで前のイベントを解除する。コンストラクターでは登録しない。`handleInput` は DOM に依らず、CSS px に正規化した入力を受ける。
- `pointer`（マウスとペン）・`touch`・`drag`・`pinch`・`wheel`・`keyboard`・`doubleClick` を個別に止められる。ホイールは既定で Ctrl または Command と一緒のときだけ使い、未処理の入力の既定の動作は止めない。DOM のホイールは単位を読んで CSS px に直し、行を 16 CSS px、ページを Canvas の高さとする。
- 組み込みは選択・移動・距離の 3 つとし、`setTool` で切り替える。ピンチ・ホイール・キーボード・ダブルクリックのカメラ操作は共通にする。独自ツールが処理した入力はカメラ操作へ重ねて渡さない。2 つまでのポインターを扱う。
- `touch-action`・フォーカス・`tabindex`・アクセシブルな名前・操作の説明は利用側に置く。CSS を自動で変更しない。DOM の座標変換は border・padding と軸に沿う正の拡縮を扱う。CSS の回転・傾斜・反転では利用側が座標を直して `handleInput` へ渡す。
- 状態に `tool`・`input`・`gesture`・`measurement` を足す。入力を処理するときは、進行中の操作を選択・計測・カメラの同期通知より先に更新する。通知から再び状態を変えられない契約は保つ。

### 独自ツールと重ね描き

- `addTool` は名前と `onActivate`・`onInput`・`onCancel` を受け、解除する関数を返す。独自ツールは選ばれた後の最初の入力で有効にし、`onInput` の `true` を消費済みとする。関数は同期で呼び、同じ入力処理へ再入させない。
- 有効期間の context に表示部品と AbortSignal を渡す。context を通じて登録した購読と重ね描き、`onActivate` が返した後始末は、有効期間の終わりにまとめて解除する。signal の中断、`onCancel`、後始末の順に実行し、例外があっても残りを実行してから最初の例外を返す。
- ツール・入力設定・接続の変更、明示した中断、Escape、捕捉の喪失、pointercancel、フォーカスの喪失、ページの非表示、成功したシーンの差し替え、破棄で、ポインター・進行中の操作・計測・独自ツールの有効期間を終える。入力の関数か同期通知が失敗したときも片づける。
- シーンの差し替えではツールの定義・名前・DOM の接続を保ち、次の入力で新しい期間を始める。表示部品の購読は決定 0274 の寿命を保つ。破棄ではツールの定義と DOM のイベントも解除する。
- 独自ツールの関数では選択・カメラ・計測を更新できる。ツールや入力の構成、シーン、破棄は関数を抜けてから変更する。`addOverlay` は描画する関数と `scene` または `viewer` の寿命を受け、既定を `scene` にする。CSS px のコンテキストと現在の状態を渡し、前後で描画状態を保存・復元する。描画する関数からの変更と再描画は拒否する。
- 部品の標準の重ね描きは計測線と選択範囲に限る。数値・単位・不明な理由のラベル、独自の形と色は利用側で指定する。

### 吸着と距離

- `snapAt` はシーンの線・面の頂点と点の中心を候補とし、可視の候補からもっとも近いものを CSS px で選ぶ。同距離なら描画の逆順を優先する。描画と当たり判定の幾何・切り抜き・実効の色・非表示レイヤ・未描画の扱いを共有する。輪郭だけを描いた点の空白の中心、文字、画像、列にない交点や曲線の中心は候補にしない。
- 位置は原点と相対座標に分け、吸着した位置は現在のシーンの ID と配置の道筋も保つ。`positionAt` は自由な位置を同じ形で返し、`toScreen` もこの形を受ける。原点を先に足して丸めない。
- `setMeasurement` は両端を受け、シーン上の差と距離、応答の起点・ビュー・単位・許容差を返す。精密な L2 の幾何を再構成しない。許容差は曲線の展開条件であり、計測の誤差保証にはしない。
- 実寸を `real` で区別する。空間を起点とし、ビューがなく、単位が既知で、両端に配置の道筋が空の要素参照がある場合だけ `known` にする。その他は `unknown` にし、用紙またはビュー、定義、単位不明、配置の尺度、要素に結ばない自由な位置の順に理由を返す。配置が一様・等倍に見えても列から尺度を推測しない。
- 吸着の候補の走査と可視性の検査に、1 つの問い合わせの作業量上限を使う。超過時は途中の結果を返さない。状態の参照、購読、独自ツールと重ね描きの数も制限する。利用側の関数の実行量は利用側で制限する。実行時の依存は足さない。

## 影響

既存の描画とカメラの利用側は、変更せずに使える。入力を使う側は接続とフォーカス・CSS を明示する。独自ツールは context の購読と中断の合図を使い、シーンを越えて非同期の結果を反映しない。精密な距離と配置前の実寸は L2 の API で求める。React の #588 は、ここで定めた状態と解除関数を使う。

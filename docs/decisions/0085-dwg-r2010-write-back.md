# 0085: R2010 から後の DWG への書き戻しは、文字列を持たない単純な図形の共通の欄と型ごとの欄から始める

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG は、オブジェクトのデータをハンドルの流れの大きさ（MC）から受け渡して置き換えられる（[決定 0083](0083-dwg-r2010-object-edit.md)）。図形の共通の欄は、R2004 の欄の後、非表示の前に、材質（BB）・影（RC）・表示の体裁の 3 つの印を持つ。主のデータの後に文字列の流れとハンドルの流れが続くので、主のデータのビットの数が変わると、ハンドルの流れの始まり（MC）を直す必要がある。文字列の流れを持つ図形（TEXT など）は、主のデータと文字列の流れの両方を組み直す必要がある。

## 選択肢

1. 文字列を持たない単純な図形（LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE）の共通の欄と型ごとの欄から書き戻し、主のデータの終わりから後ろはそのまま写して MC を直す。
2. 文字列を持つ図形・表のレコード・図形でないオブジェクトまで一度に書き戻す。
3. R2010 から後は、まだ書き戻さない。

## 決定

選択肢 1 を採る。文字列の流れを組み直す形は、種類ごとに試料で確かめてから広げる。

- 共通の欄は、R2004 と同じく色・線種の尺度・非表示を書き換え、R2010 で足された材質・影・表示の体裁の欄はそのまま写す。
- 型ごとの欄は、変わらなければ元のビットを写す。変わったときは、元の値から作った欄の長さが元の欄の長さと同じことを確かめてから、新しい値で作り直す。
- 主のデータの後ろ（文字列の流れの印とハンドルの流れ）はそのまま写し、MC を新しいバイトの数に合わせて書き直す。
- ほかの種類の図形・表のレコード・図形でないオブジェクトの変更と、図形の除き・足しは、`dwg.change.unsupported` で受け付けない。

## 影響

- 試料の R2010・R2013・R2018 の図面で、単純な図形の座標・線種の尺度・色を変えて書き、読み直した表が変えた表と同じになった。TEXT と LAYER の変更は受け付けなかった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0094: R2010 から後の DWG に足した表のレコードは、LAYER・STYLE・LTYPE・APPID だけを、名前を文字列の流れに書いて書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 までの DWG には、足した表のレコードを書き戻せる（[決定 0061](0061-dwg-write-back-layer-addition.md)〜[0064](0064-dwg-write-back-appid-addition.md) など）。R2010 から後の表のレコードは、名前を文字列の流れに持ち、外部参照の番号（BS）を持たない（[決定 0089](0089-dwg-r2010-write-back-records.md)）。R2013 からは、拡張辞書の印の後に DS のデータを持つかの B が続く。試料の R2010 から後の画層は、印刷スタイルと線種のハンドルの間に、材質のハンドルを持っていた。読み手はこれを線種と取り違え、画層の値に 6 を置けていなかった。

## 選択肢

1. 試料の図面と同じ形に書けることを確かめた LAYER・STYLE・LTYPE・APPID だけを、R2010 から後でも足せるようにする。
2. 寸法の体裁・ビュー・ビューポートの設定・ブロックのレコードも、R2004 の形から推し量って足せるようにする。
3. 表のレコードの足しは、まだ書き戻さない。

## 決定

選択肢 1 を採る。

- 足したレコードは、名前を文字列の流れに書き、外部参照の番号を書かない。R2013 からは、DS のデータを持たない印を書く。
- LTYPE は、文字の要素がなければ文字の領域を持たない（決定 0089）。足せるのは、R2004 と同じく形も文字もない要素だけ。
- LAYER は、印刷スタイルの次に材質のハンドル（347）を持つ。値が材質を持たなければ、画層 0 と同じ材質を指す。読み手も、R2010 から後の画層のハンドルを、印刷スタイル・材質・線種の順に読む。
- レコードを持つ表のオブジェクトは、項目の数を 1 増やし、項目のハンドルの終わりに足したレコードを加え、ハンドルの流れの大きさ（MC）を直す。
- 寸法の体裁・ビュー・ビューポートの設定・ブロックのレコード・UCS のレコードの足しは、まだ受け付けない。

## 影響

- 試料の図面の、拡張データを持たないレコードを、読んだ値から足したものとして書いて元のデータと比べた。R2013 の APPID の一部と R2018 の STYLE と R2010 の要素のない LTYPE は同じになり、ほかの APPID と R2018 の LTYPE は、終わりの埋めるビットだけが異なった。R2013 の要素を持つ LTYPE は、形も文字もない要素の、DXF に出ない欄が試料と異なった。画層は、試料がどれも真の色を持つので比べられなかった。
- 試料の図面に画層・文字の体裁・線種・アプリケーションの名前と、それらを使う LINE・TEXT を足して書き、読み直したものが足したものと合った。書き戻した図面にもう一度足しても合った。
- 書いた図面を AutoCAD で開いて確かめてはいない。

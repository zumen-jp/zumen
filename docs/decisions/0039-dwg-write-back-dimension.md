# 0039: DWG（R2000）への書き戻しは、DIMENSION の表にない欄と印のビットを元のまま写す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0038](0038-dwg-write-back-polyline.md) までで、POLYLINE と VERTEX までの型ごとの欄を R2000 の DWG に書き戻せるようにした。R2000 の DIMENSION は、どの型にもある欄に、型（座標・長さ・平行・3 点の角度・2 線の角度・半径・直径）ごとの点が続く。読む側は、DXF に合わせて次のように表へ置く。

- ブロックの挿入の尺度と回転は、DXF の 41・42 が別の欄に使われるので置かない。
- 70 は、型で決まる寸法の種類に、DWG の印から 128・32 を、座標の寸法の印から 64 を足す。印のほかのビットは置かない。
- 標高を 31 に置き、12 の点の Z と、2 線の角度の寸法の 36 にも同じ値を置く。

## 選択肢

1. 表にない欄と印のほかのビットは、元のデータから写す。
2. 表にない欄と印のほかのビットは、既定の値を書く。

2 は、値を変えていない挿入の尺度や印のビットまで変わる。

## 決定

選択肢 1 を採る。

- 型は元のデータの型から選ぶ。型に合わない欄（直径の寸法の 50 など）があるもの、70 の種類が型と合わないものは、`dwg.change.unsupported` を返す。
- ブロックの挿入の尺度と回転は、元のビットを写す。DWG の印と座標の寸法の印は、70 から読まれるビットだけを書き換える。
- 標高（31）と違う 12 の点の Z や 36 は受け付けない。12 の点がなければ (0, 0) を書く。
- 利用者の文字（1）が変わらなければ、元のビットを写す。変われば、DXF の `^` の書き方を元に戻して書く。
- 角度（50・51・52・53）は、度からラジアンに直して書く。

## 影響

- 手で組んだ R2000 の長さ・直径・座標の DIMENSION で、文字の中点・利用者の文字・回転・直径・印を変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の DIMENSION も、点を動かして書き戻す。
- 型を変える変更は、まだ書き戻せない。
- TOLERANCE・LEADER・MLINE・VIEWPORT などの型ごとの欄の変更は、まだ書き戻せない。

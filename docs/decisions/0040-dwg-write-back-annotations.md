# 0040: DWG（R2000）への書き戻しは、TOLERANCE・LEADER・MLINE の表にない欄を元のまま写し、MLINE の数は表の値に合わせる

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0039](0039-dwg-write-back-dimension.md) までで、DIMENSION までの型ごとの欄を R2000 の DWG に書き戻せるようにした。読む側は、TOLERANCE・LEADER・MLINE を次のように表へ置く。

- TOLERANCE は、挿入点（10）と文字（1）を置き、X 軸の向き（11）と押し出しの向き（210）は既定の値でなければ置く。
- LEADER は、注釈の種類（73）・経路の種類（72、0 でなければ）・注釈の高さと幅（40・41）・鉤の線の向き（74）を置き、押し出しの向き（210）と X 軸の向き（211）は既定の値でなければ置く。鉤の線の点と、点や注釈への差の欄は置かない。
- MLINE は、尺度・合わせ・開閉の印・頂点の数・線の数・基点・押し出しの向きを置き、頂点ごとに点と向きと、線ごとの区切りの値を置く。表の並びは DWG の並びと違う。

## 選択肢

1. 表にない欄（LEADER の点と差の欄、読む側が読まない後ろの欄）は元のデータから写す。MLINE は、表の値をすべて表の並びで読んで書き直す。
2. LEADER も、表にない欄に既定の値を書く。

2 は、DXF に出ない点を失う。

## 決定

選択肢 1 を採る。

- TOLERANCE と LEADER の、表にない既定の値の欄（11・210・211）は、既定の値を書く。72 がなければ 0 を書く。
- TOLERANCE の文字（1）が変わらなければ、元のビットを写す。変われば、DXF の `^` の書き方を元に戻して書く。
- LEADER の鉤の線の向き（74）は、0 か 1 だけを受け付ける。
- MLINE の頂点の数（72）と線の数（73）、区切りの数（74・75）は、表に続く値の数と合わなければ `dwg.change.unsupported` を返す。値が余っても受け付けない。

## 影響

- 手で組んだ R2000 の TOLERANCE・LEADER・MLINE で、公差の挿入点と文字、引出線の高さと鉤の線の向き、多重線の尺度と頂点を変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の TOLERANCE と MLINE も、点を動かして書き戻す。
- LEADER の点は、表に置かないので、まだ変えられない。
- VIEWPORT などの型ごとの欄の変更は、まだ書き戻せない。

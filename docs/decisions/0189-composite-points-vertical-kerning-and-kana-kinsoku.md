# 0189: 点の番号で合わせる部品と縦書きのカーニングを読み、欧文を倒し、小書きの仮名を禁則に足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0188](0188-scene-fonts-and-glyph-outlines.md) は、`glyf` の複合の字形のうち、部品を点の番号で合わせるものを読めない字形とし、SCALED_COMPONENT_OFFSET の旗を読まなかった（#347）。[決定 0187](0187-vertical-text-stacks-and-kinsoku.md) は、縦書きで `vkrn` と `VORG` を読まず、欧文を倒さず、上下に重ねた文字を置かず、禁則で小書きの仮名と長音の記号を扱わず、ぶら下げと追い込みをしなかった（#346）。それぞれの扱いを決める。

## 選択肢

小書きの仮名と長音の記号の選び方は次から選ぶ。

1. JIS X 4051 の文字の分類（行頭禁則和字など）を写す。
2. Unicode の文字の名前と符号位置の並び、互換分解から、規則で選ぶ。
3. 扱わない。

縦書きの欧文は次から選ぶ。

1. Unicode の Vertical_Orientation（UAX #50）の表を写す。
2. 全角の文字（決定 0181 の `wide`）と半角形を立て、それ以外を倒す。
3. 倒さない。

行の終わりの調整は次から選ぶ。

1. ぶら下げ（句読点を枠の外に出す）と追い込み（字間を詰めて行の始まりに置かない文字を前の行に入れる）の両方を行う。
2. ぶら下げだけを行う。
3. どちらも行わない。

## 決定

小書きの仮名は選択肢 2、縦書きの欧文は選択肢 2、行の終わりは選択肢 2 を採る。小書きの仮名の 1 は、仕様の表を写さない規則（AGENTS.md）に反する。欧文の 1 は表が大きく、`wide` と別の範囲を持つことになる。追い込みは、字間を詰める両端揃えをしていない（AutoCAD の MTEXT も両端揃えをしない）ので、詰める字間がない。

- **点の番号で合わせる部品。** ARGS_ARE_XY_VALUES が立たない部品の引数を、符号なしの点の番号（ARG_1_AND_2_ARE_WORDS なら 16 ビット、なければ 8 ビット）として読む。部品を位置のずれなしで写した後、親の点（同じ複合の字形の、前の部品までの点）の番号 1 と、部品の点の番号 2 が重なるように動かす（OpenType の仕様の glyf の節）。点は輪郭の点（曲線の外の点を含み、補った中点と phantom point は含まない）を、入れ子の部品を含めて番号の順に数える。親の点が前の部品までにないか、部品の点が部品の外にあれば、字形を読めないものとする。入れ子と作業量の上限は決定 0188 のままにする。
- **SCALED_COMPONENT_OFFSET。** この旗だけが立てば、位置のずれを部品の変換（尺度か 2×2 の行列）で写してから足す。どちらも立たないか、UNSCALED_COMPONENT_OFFSET が立てば（両方が立つ場合を含む）、写さない。旗のない既定を写さない側にするのは、Microsoft の実装と OpenType の仕様の既定に合わせるためである。
- **縦書きのカーニング。** `GPOS` の `vkrn` の機能の pair adjustment（決定 0186 と同じ形式・extension・上限）の、最初の字形の YAdvance を読み、なければ `kern` の表の、横書きの旗（ビット 0）が立たない形式 0 の副表を読む。字形の組は `GSUB` で縦書き用に置き換えた後の字形で引く。YAdvance は字形の座標では上が正だが、OpenType の実装の慣行どおり、値をそのまま縦の送りに足す（負なら詰める）。`Glyphs` に `vertical_kerning` を既定値 0 で足す。
- **縦の原点。** CFF・CFF2 のフォントでは、`VORG`（版 1 で、記録が表に収まるもの）があれば、その字形の vertOriginY（記録がなければ defaultVertOriginY）を縦の原点の高さにする。`glyf` のフォントでは `VORG` を使わない（仕様が CFF の外形のフォントのための表とするため）。壊れた `VORG` は使わず、決定 0187 の外形と上の余白から求める。
- **縦書きの欧文（推定）。** 全角の文字（決定 0181 の `wide`。漢字・仮名・全角形など）と半角形（U+FF61〜U+FFEF。半角の片仮名など）は立てて置き、それ以外（欧文・数字・半角の記号・空白など）は時計回りに 90 度倒す。倒した字形は横書きの字形のまま（`GSUB` で置き換えない）、横の送りで列の下へ進め、アセンダーとディセンダーの中央を列の中心線に合わせる。倒した文字の間は横書きのカーニングで、立てた文字の間は縦書きのカーニングで詰め、倒した文字と立てた文字の間は詰めない。数字を立てて横に並べる縦中横は、指定する符号がないので行わない。
- **縦書きの上下に重ねた文字（推定）。** 横書きと同じ形（決定 0187）で、立てたまま置く。段の幅の中央を列の中心線に、上の段の上を送りの始まりに合わせ、上の段の上から下の段の下までを縦の送りにする。斜線と横線も同じく立てたまま引く。
- **小書きの仮名と長音の記号。** 行の始まりに置かない文字に、小書きの仮名と、長音の記号（U+30FC KATAKANA-HIRAGANA PROLONGED SOUND MARK と、その半角形 U+FF70）を足す。小書きの仮名は、Unicode の名前に SMALL を持つ平仮名・片仮名で、次の規則で選ぶ。
  - 平仮名（U+3041〜U+3096）では、すぐ後ろの符号位置に同じ音の普通の仮名がある文字（U+3041 の「ぁ」の後に U+3042 の「あ」）が小書きで、「ぁぃぅぇぉっゃゅょゎ」の 10 字になる。区画の終わりに後から足された「ゕ」「ゖ」（U+3095・U+3096）も小書き。
  - 片仮名（U+30A1〜U+30F6）は、平仮名と同じ並びで 0x60 後ろにあるので、平仮名に戻して同じ規則で選ぶ。
  - 片仮名の拡張（U+31F0〜U+31FF）は、すべての文字の名前が KATAKANA LETTER SMALL で始まる。半角形の小書きの片仮名（U+FF67〜U+FF6F）は、互換分解（<narrow>）の先が小書きの片仮名。小書きの仮名の拡張（U+1B132・U+1B150〜U+1B152・U+1B155・U+1B164〜U+1B167）は、名前が SMALL を持つ文字。
  - 中点・繰り返し記号（ゝゞヽヾ々）・波ダッシュは、#346 の範囲の外なので足さない。
- **ぶら下げ。** 読点・句点（U+3001・U+3002 と、互換分解の先がそれになる半角形）と、全角のコンマ・ピリオド（U+FF0C・U+FF0E）は、前の文字までが枠に収まれば、枠を超えても行の終わりに置く。ぶら下げるのは 1 文字までにする。ぶら下げた文字は、空白と同じく行の長さ（揃えと `LineBox::width`）に数えない。縦書きでも同じく列の下にぶら下げる。
- **追い込み。** 行わない。行の始まりに置かない文字は、今までどおり前の文字と一緒に次の行へ送る（追い出し）。

## 影響

- `glyf` の合成のフォントで、点の番号（8 ビット・16 ビット）、尺度を掛けた部品の点、入れ子の中の点の番号、範囲の外の番号、SCALED と UNSCALED の旗を試験した。合成のフォントで `vkrn`（置き換えた字形の組を含む）、`kern` の縦の向きの副表、`VORG`（壊れた表、`glyf` のフォント）を試験し、バイト列を切り詰めたり 1 バイトずつ変えたりしてパニックしないことを確かめた。配置は、縦書きのカーニング・倒した欧文・回した枠・縦書きの重ねた文字・小書きの仮名・ぶら下げを合成のフォントで試験した。
- 縦書きの上下に重ねた文字を置くので、シーンはその文字を字形で返し、`scene.text-layout.unsupported` を返さなくなる。縦書きの欧文を倒すので、縦書きの字形の変換が変わる。適合試験の応答は変わらなかった。
- 欧文を倒す範囲、重ねた文字の位置、ぶら下げる文字は推定で、表示との照合で直しうる。

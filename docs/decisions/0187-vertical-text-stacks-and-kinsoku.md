# 0187: 縦書きの文字を vmtx と GSUB の vert で置き、上下に重ねた文字と禁則を推定の規則で置く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0181](0181-formatted-text-layout.md) は、書式つきの文字を置いたが、縦書きは `Unplaced::Vertical` で断り、上下に重ねた文字（分数・公差）は置かずに区間の位置を返し、禁則は使わなかった。縦書きを断った理由は、`Glyphs` が縦書きの送りと字形の置き換えを受け取らないことだった。カーニングの表は[決定 0186](0186-read-cff-outlines-and-kerning.md) で読んだ。残りの縦書き（#339）と、上下に重ねた文字・禁則（#340）の扱いを決める。

## 選択肢

縦書きは次から選ぶ。

1. フォントの `vhea`・`vmtx`（縦の送りと上の余白）と `GSUB` の `vert`・`vrt2`（縦書き用の字形への置き換え）を読み、`Glyphs` に縦書きの口を既定値つきで足す。
2. 送りを em とみなし、字形を置き換えずに置く（決定 0181 の選択肢 2）。
3. SHX の縦書き（#338）を待ち、TrueType でも置かない。

禁則は次から選ぶ。

1. JIS X 4051 の文字の分類を写して使う。
2. Unicode の文字の性質（一般カテゴリと互換分解）から、少数の規則で行頭・行末に置かない文字を決める。
3. 禁則を使わない。

## 決定

縦書きは選択肢 1、禁則は選択肢 2 を採る。縦書きの 2 は句読点と括弧の向きが合わず、3 は TrueType のフォントで置けるものまで断る。禁則の 1 は、仕様の表を写さない規則（AGENTS.md）に反する。

- **縦書きの口。** `Glyphs` に `vertical`（文字の縦書きの字形）と `vertical_fallback`（フォントにない文字の縦書きの字形）を足す。返す `VerticalGlyph` は、置き換えた後の字形の横の送りと外形、縦の送り、縦の原点の高さ、置き換えたかを持つ。既定は横書きの字形を、縦の送りをアセンダーとディセンダーの和、縦の原点をアセンダーの高さにして置き換えずに置く（推定）。既存の実装は変わらない。
- **縦の寸法。** `font` は、`vhea` の numOfLongVerMetrics と `vmtx` の advanceHeight・topSideBearing を読む。縦の原点は、横の送りの半分と、外形の上に上の余白を足した高さにする（OpenType の仕様の vmtx の節）。外形のない字形は既定の高さにする。`vmtx` が字形の数だけの記録を持たないか、どちらかの表がなければ、表全体を使わず既定の値にする。`VORG` は読まない（CFF の外形は決定 0186 で正確に求めるので、外形と上の余白から同じ原点が求まる）。
- **字形の置き換え。** `GSUB` の `vrt2` の機能があればその lookup を、なければ `vert` の機能の lookup を使う。`vrt2` は `vert` を含めて作られるので、両方は当てない。読むのは single substitution（lookup type 1 の形式 1・2。extension の type 7 を通したものを含む）だけで、lookup の番号の順に当て、前の lookup の結果を次に渡す。lookup の中では最初に当たる副表を使う。用字系と言語は分からないので、どの用字系の機能も使う。置き換えた先の字形が読めなければ置き換えない。`PlacedGlyph::substituted` で、置き換えたことを描く側に返す。
- **上限。** カーニング（決定 0186）と同じく、機能から読む lookup の番号は 65536、副表は 1024 までにし、超える `GSUB` は読まない（置き換えない）。lookup の番号が lookup の数を超える表も読まない。1 文字の置き換えの作業は副表の数と二分探索で抑える。縦書きの表はどれも任意の表なので、壊れていてもフォントは断らない。
- **縦書きの配置。** 書き進める向きが縦書きなら、文字を上から下へ縦の送りで並べ、列を右から左へ並べる。字形の縦の原点を、列の中心線の上の送りの位置に合わせる。列の太さは、列でいちばん幅の広い em にし、1 列目の中心線は内容の右から太さの半分、次の列は行送り（決定 0181 と同じ規則）だけ左に置く。枠の幅（`width`）は列の長さに当てて折り返す（推定）。基点は、左・中央・右を内容の幅に、上・中央・下を枠の長さに当て、列は上・中央・下に揃える（推定）。縦書きでは詰めず（`vkrn` を読まない）、ラテン文字も横に倒さない。上下に重ねた文字は、向きの規則を決めていないので置かずに区間の位置を返す。`Unplaced::Vertical` は返さなくなるが、名前と意味は変えずに残す。
- **上下に重ねた文字（推定）。** 横書きで置き、区間のフォント・書式を当てる。上下の段は区間の大きさの 0.7 倍にする（AutoCAD のヘルプの重ねた文字の既定の大きさ 70% から）。横線と公差は、区間の大文字の高さの半分の線から、大文字の高さの 0.1 倍だけ離して上下の段を置く。横線は短い段を中央に揃え、長い段の幅の線を引く。公差は左に揃え、線を引かない。斜線は、上の段の上を大文字の高さに、下の段を基準線に置き、間に横幅が大文字の高さの 0.5 倍の斜線を引く。重ねた文字は 1 文字として折り返し、上の段の上と下の段の下で行の高さを広げる。線の両端は `LaidFormatted::stacks` で返す。AutoCAD の表示とはまだ比べていない。
- **禁則。** 行の始まりに、閉じ括弧（Unicode の一般カテゴリ Pe）と句読点・感嘆符・疑問符・コロン・セミコロンを置かず、行の終わりに開き括弧（Ps）を置かない。文字は、ASCII の記号、読点・句点、CJK の括弧（U+3008〜U+3011・U+3014〜U+301B は開きと閉じが交互に並ぶ）、全角形・半角形（互換分解の先の文字に従う）から決める。Rust の `char` は一般カテゴリを返さないので、これらの範囲だけを規則で書き、JIS X 4051 の分類は写さない。小書きの仮名・長音符・中点などは扱わない。守ると折り返す所がなくなるときは、決定 0181 と同じく文字の間で切り、ぶら下げや追い込みはしない。

## 影響

- 縦書きの書式つきの文字を、TrueType・OpenType のフォントで置けるようになる。合成のフォントで、縦の寸法・`vrt2` と `vert` の選び方・extension を通した置き換え・連なる lookup・上限・壊れた表を試験し、縦書きの表のあるフォントでもバイト列を切り詰めたり 1 バイトずつ変えたりしてパニックしないことを確かめた。
- 1 行の文字（`Text`）は書き進める向きを持たず、AutoCAD の縦書きは SHX の文字スタイルだけが持つので、SHX の縦書きは #338 の判断の後に扱う。
- 縦書きの基点と枠の当て方、上下に重ねた文字の大きさと位置、禁則の範囲は推定で、表示との照合で直しうる。
- 縦書きのカーニングと `VORG`、欧文を倒すこと、縦書きの上下に重ねた文字、小書きの仮名と長音の記号の禁則、ぶら下げと追い込みは見送った（後に[決定 0189](0189-composite-points-vertical-kerning-and-kana-kinsoku.md) で扱った）。

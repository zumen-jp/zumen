# 0237: 日本測地系と JGD2000 の座標は、利用者が渡す TKY2JGD・PatchJGD の格子で経緯度を直して JGD2011 にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

[決定 0233](0233-geo-model-features.md) で、旧測地系（日本測地系）と JGD2000 の座標系を名前として受け、JGD2011 への変換は拡張 DM の旧測地系のデータを読むときに作るとした（#471）。変換のパラメーターは、国土地理院が TKY2JGD（日本測地系から JGD2000）と PatchJGD（JGD2000 から JGD2011、地殻変動のあった地域）として配る。どちらも、3 次メッシュの格子点ごとに緯度と経度の補正量（秒）を並べた形である。

決めることは、次のとおり。

- 座標系の名前の持ち方。
- パラメーターの持ち方と、補間の仕方。
- パラメーターがないときと、点がその範囲の外にあるときの返し方。

## 選択肢

1. **格子を利用者が渡し、`zumen-crs` で補間する。** ジオイドの格子（[決定 0019](0019-coordinate-systems-and-gsi-data.md)）と同じ扱いにする。
2. **jgdtrans（MIT OR Apache-2.0）を使う。** 形の読み取りと補間を持つが、std の `hypot` と `HashMap` を使い、どの環境でも同じ値になること（決定 0007）を確かめにくい（決定 0019 の表）。

## 決定

1 にする。

- **座標系。** `Crs` に、JGD2000 の平面直角座標系（EPSG:2443〜2461）と日本測地系の平面直角座標系（EPSG:30161〜30179）を足す。EPSG の名前（`JGD2000 / Japan Plane Rectangular CS IX`・`Tokyo / Japan Plane Rectangular CS IX`）も受ける。経緯度の座標系（EPSG:4612・4301）は、まだ受けない。
- **楕円体。** 日本測地系の平面直角座標は、JGD2011 と同じ計算式を、ベッセル楕円体（長半径 6 377 397.155 m、逆扁平率 299.152 813）で解いて経緯度に直す。
- **格子。** TKY2JGD・PatchJGD の形の、3 次メッシュのコードと緯度・経度の補正量の行を読む。初めの数字の行の前は見出しとして飛ばし、その後の読めない行は `crs.datum-grid.invalid` を返して読まない。高さの補正量の列は読まない。格子は同梱しない。
- **補間。** 点を囲む四隅の格子点（緯度 30 秒・経度 45 秒の間隔）の補正量を双一次に補間し、経緯度に足す。
- **順。** 日本測地系は TKY2JGD で JGD2000 にし、PatchJGD で JGD2011 にする。JGD2000 は PatchJGD で JGD2011 にする。系はそのままにする。
- **範囲。** PatchJGD の格子は地殻変動のあった地域だけを持つので、点を囲む格子点が 1 つもなければ、補正量を 0 とする。TKY2JGD の格子の外の点と、囲む格子点が欠けている点は、`crs.datum-shift.missing` を返して直さない。
- **ないとき。** 要る格子が渡されていなければ、`crs.datum-grid.missing` を返して直さない。呼ぶ側は、直せなかった点を座標系の違う点として扱い、JGD2011 の点と比べない。

## 影響

- 拡張 DM（#378）の旧測地系のデータは、この変換で JGD2011 にする。境界で格子を渡す方法は、拡張 DM を読むときに決める。
- 試験は、合成の格子で行う。国土地理院の計算の結果と比べる試験は、格子を入手して手元で確かめる。

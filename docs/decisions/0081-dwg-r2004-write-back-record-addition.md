# 0081: R2004 の DWG に足す表のレコードは、R2004 の共通の欄と CMC の色で符号化し、ブロックのレコードは持つ図形をみな指す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 の DWG へは、図形と属性を持つ INSERT を足せる（[決定 0079](0079-dwg-r2004-write-back-entity-addition.md)・[決定 0080](0080-dwg-r2004-write-back-attributed-insert-addition.md)）。R2000 では、画層・文字の体裁・線種・アプリケーションの名前・寸法の体裁・ビュー・ビューポートの設定・ブロックのレコードを一から符号化し、表のオブジェクトの項目に加える（[決定 0061](0061-dwg-write-back-layer-addition.md)〜[決定 0068](0068-dwg-write-back-block-record-addition.md)）。R2004 のオブジェクトは、反応子の数の後に拡張辞書を持たない印（B）を持ち、色は CMC で書く（[決定 0075](0075-dwg-r2004-write-back-records.md)）。ブロックのレコードは、最初と最後の図形の代わりに、持つ図形の数とそのハンドルを持つ（[決定 0077](0077-dwg-r2004-write-back-entity-removal.md)）。

## 選択肢

1. R2000 と同じ表のレコードを、R2004 の共通の欄と CMC の色で符号化し、ブロックのレコードは持つ図形の数とすべてのハンドルを持つ形で書く。
2. R2004 には、まだ表のレコードを足さない。

## 決定

選択肢 1 を採る。足すレコードと、項目を加える表のオブジェクトは次の形で書く。

- レコードは、反応子の数の後に、拡張辞書を持たない印を立てる。ハンドルの流れに拡張辞書のハンドルを置かない。
- 画層の色と、寸法の体裁の色は、CMC で書く。
- ブロックのレコードは、読み込まれた印の後に持つ図形の数（BL）を置き、ハンドルの流れの BLOCK の後に、持つ図形のハンドルをみな固い所有（符号 3）で並べる。足したブロックの BLOCK・ENDBLK と図形は、R2004 の共通の欄で書く。
- 表のオブジェクトは、拡張辞書を持たない印を読み、拡張辞書を持たなければ、そのハンドルを飛ばして項目を数える。

## 影響

- 試料の R2004 の 2 つの図面に、画層・文字の体裁・線種・アプリケーションの名前・寸法の体裁・ビュー・ビューポートの設定・ブロックと、それらを使う図形を足して書き戻し、読み直した表が足した表と同じになった。書き戻した図面にもう一度足しても同じになった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0152: 画層と線種の拡張辞書の XRECORD を、画層と線種に付く形式固有の情報にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0148](0148-drawing-extension-dictionary-xrecords.md) は、図形の拡張辞書の XRECORD を形式固有の情報にし、図形でないオブジェクトの拡張辞書は「まだ移さない」とした（#174 の「拡張辞書」）。形式固有の情報の付く先（`Target`）は、図面全体と、空間と用紙の要素だけだった。

手元の試料の `sample_AC10*` の図面では、次の図形でないオブジェクトが拡張辞書を持つ。

- 画層: 注釈の尺度の画層（`0 @ 1` など）の `ASDK_XREC_ANNO_SCALE_INFO`。R2000 の DWG では、真の色と色見本帳の色を持つ画層の、版の往復のための `ACAD_XREC_ROUNDTRIP` も持つ。
- 線種: R2010 までの DXF の、文字を添える線種（GAS_LINE）の `ACAD_XREC_ROUNDTRIP`。
- ブロックのレコード: SORTENTSTABLE・動的ブロックの辞書など、XRECORD でない項目だけ。
- 図面モデルに移さないオブジェクト（ビュー・材質・表示スタイル・表のスタイル・レイアウトなど）。

DWG の読み手は、図形でないオブジェクトの拡張辞書のハンドルを読み捨てていた。

## 選択肢

1. 付く先に画層と線種を足し、その拡張辞書の XRECORD を、図形と同じ形の形式固有の情報にする。
2. 図面全体（`Target::Document`）に付け、名前で画層と線種を指す。
3. 移さないまま、文書にだけ書く。

## 決定

選択肢 1 を採る。

- 図面全体に付けると（選択肢 2）、画層の名前や定義を変えても失効しない。付く先と読んだときの値で失効を決める、決定 0115 の仕組みが使えない。
- 移さない（選択肢 3）と、XRECORD に入った値を使い手が読めない。

内容は次のとおり。

- `Target` に、レイヤ（`Target::Layer`）と線種（`Target::LineType`）を足す。読んだときの値（`Basis::Layer`・`Basis::LineType`）は、レイヤと線種の名前・状態・定義・出所を持ち、変われば失効する。
- 画層（LAYER）と線種（LTYPE）の表のレコードの拡張辞書の項目を、[決定 0148](0148-drawing-extension-dictionary-xrecords.md) と同じく、名前空間 `dxf.xrecord` の形式固有の情報にする。XRECORD でない項目は移さず、`dxf.extension-dictionary.dropped` を返す。
- DWG の読み手は、図形でないオブジェクトの拡張辞書のハンドルも、DXF と同じく所有者の前に `102 {ACAD_XDICTIONARY`・360・`102 }` の組で置く。型ごとのハンドルを持たないオブジェクトで、ハンドルの流れが反応子と拡張辞書を読み切れなければ、拡張辞書を持たないとする。

## 影響

- 試料では、注釈の尺度の画層の XRECORD が、同じ版の DWG と DXF で同じ値になる。版の往復のための XRECORD は形式ごとに違う（DXF は線種、R2000 の DWG は画層に持つ）。
- ブロックのレコード・寸法スタイル・文字スタイルと、図面モデルに移さないオブジェクトの拡張辞書と、図面全体の名前付きの辞書の中身は、まだ移さない。ブロックのレコードの項目は、試料では XRECORD でないものだけである。
- 画層と線種の XDATA は、まだ移さない。
- 書き戻しは、図形の形式固有の情報と同じく、まだない。
- DWG の書き戻しは、図形でないオブジェクトの拡張辞書の組を、読んだままのときだけ受け付ける。拡張辞書を足す・除く・差し替える変更は `dwg.change.unsupported` を返す。足すレコードは、拡張辞書を持てない。
- 図面モデルの `Target` と `Basis` に場合が増えるので、それらを網羅して分ける使い手は場合を足す必要がある。

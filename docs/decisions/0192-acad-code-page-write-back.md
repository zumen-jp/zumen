# 0192: 2007 より前の版に書き戻す文字は、読むときの表を逆に引いて符号化し、表せない文字は断る

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0175](0175-acad-code-page-shift-jis.md) で、2007 より前の版の DXF・DWG の文字を、見出しの `$DWGCODEPAGE` が `ANSI_932` なら Shift_JIS として読むようになった。書き戻しの符号化は、その決定に含めなかった。

図面モデルの変更の書き戻し（[決定 0139](0139-drawing-apply.md)）は、2007 より前の版には ASCII の文字だけを書き、ASCII でない文字を持つ変更を `change.edit.unsupported` で断っていた。そのため、日本の図面で読んだ文字や画層の名前を、日本語のまま直せなかった。

また、名前を大文字と小文字を区別せずに比べるとき、表のバイト列の ASCII の範囲をすべて小文字にしていた。Shift_JIS の 2 バイトの文字は 2 バイト目が ASCII の範囲（0x40〜0x7E）にありうるので、「ア」（0x83 0x41）と「ヂ」（0x83 0x61）を同じ名前として扱い、別の画層を指す図形の名前を書き換えうる。

## 選択肢

符号化の選択肢は次のとおり。

1. 読むときと同じ `encoding_rs` の Shift_JIS の表を、逆に引いて符号化する。
2. 符号化の表を自前で持つ。

表せない文字の扱いの選択肢は次のとおり。

1. 変更を断り、表せない文字を診断で返す。
2. AutoCAD の `\U+XXXX` の符号に直して書く。
3. 置き換えの文字（`?` など）にして書く。

## 決定

符号化は選択肢 1、表せない文字は選択肢 1 を採る。

- **符号化。** 2007 より前の版で、`$DWGCODEPAGE` が `ANSI_932` なら、文字の値と名前（画層・文字スタイル・線種・寸法スタイル・ブロックなどを指す名前を含む）を `encoding_rs::SHIFT_JIS` で符号化する。読む側と書く側は、同じ型（`Charset`）の `decode` と `encode` を使う。ほかのコード・ページと、`$DWGCODEPAGE` がないものは、今までどおり ASCII の文字だけを書く。DWG（R2000〜R2004）は、表の文字列をコード・ページのバイトのまま持つので、同じ符号化で表に置き、そのまま書く。
- **戻らない文字。** 符号化した値を読む側と同じ表で戻し、元と同じ文字列になるものだけを書く。WHATWG の Shift_JIS の符号化は ¥（U+00A5）を 0x5C に、‾（U+203E）を 0x7E に、−（U+2212）を 0x817C にするが、読むと `\`・`~`・－（U+FF0D）に戻る。`\` は MTEXT の書式の符号でもあるので、書かない。
- **表せない文字。** 変更の一覧のどれかに表せない文字があれば、ほかの変更と同じく、どの変更も反映しない。その変更の `change.edit.unsupported` に加えて、最初の表せない文字を `change.character.unsupported`（`character` は `U+XXXX`）で返す。`\U+XXXX` の符号は、MTEXT の内容では読む側が戻すが、TEXT の内容と名前では戻さないので、読み直すと元の文字にならない。置き換えの文字は、黙って文字を変え、名前を別の名前と同じにしうる。
- **MTEXT の区切り。** 内容を 250 バイトごとに区切る（3）ときは、符号化したバイトで数え、2 バイトの文字の途中で切らない。`^` の対を数えるときは、2 バイト目の 0x5E を数えない。
- **名前の比べ方。** 名前を大文字と小文字を区別せずに比べるときは、Shift_JIS の 1 バイト目（0x81〜0x9F・0xE0〜0xFC）の次のバイトを小文字にしない。読む側が、戻した文字列の ASCII の文字だけを小文字にして比べるのと同じ結果になる。

## 影響

- ANSI_932 の DXF・DWG で、文字・MTEXT・引出線の注記の内容と、画層・文字スタイル・線種・寸法スタイルの名前を、日本語で書き戻せる。名前を変えると、図形などが指す名前も Shift_JIS で書き直す。
- 診断の code `change.character.unsupported` を足す。境界の関数・op・欄は変わらない。
- ANSI_932 でないコード・ページの文字は、読む側と同じく、試料が得られたときに表を足す。

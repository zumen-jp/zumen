# 0240: 相似のビューは DXF のビューポートで書き、モデル空間には書く用紙が焼き込まずに見せる空間だけを書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

新しい DXF への変換（[決定 0206](0206-convert-to-new-dxf.md)）は、横と縦の尺度の違うビューを用紙に焼き込む（[決定 0238](0238-bake-anisotropic-views.md)）。相似のビューは落としていたので、civil_drawing（[決定 0239](0239-civil-drawing-op.md)）で平面図を選ぶと、用紙に線形が出なかった（#480）。

DXF のモデル空間は 1 つしかない。図面モデルの空間がいくつもあると、ビューポートで見せる空間と、焼き込んだ空間の要素が、同じモデル空間に重なる。

決めることは、次のとおり。

- どのビューをビューポートで書くか。
- モデル空間にどの空間を書くか。

## 選択肢

1. **読む側（`zumen-acad`）が扱う形のビューだけを VIEWPORT で書き、焼き込んだだけの空間はモデル空間に書かない。** 書いた DXF を読み直すと、同じ変換のビューに戻る。
2. **空間ごとにモデル空間の中で位置をずらして書く。** 座標が元の値と変わり、ずらす量を決める根拠がない。

## 決定

1 にする。

- VIEWPORT で書くのは、回転と鏡映のない相似で、表示しないレイヤを持たないビュー。枠は、切り抜きが軸に沿った長方形ならそれ、切り抜きがなければ用紙の全体にする。ほかのビューは、これまでどおり焼き込むか、落として `convert.element.unsupported`（種類 `view`）で知らせる。
- ビューポートは、用紙の中心と幅・高さを図面の単位で、映す実寸の中心と高さを実寸の単位で書く。用紙そのものを表すビューポート（69 = 1）も書く。
- モデル空間には、どの用紙のビューにも置かれない空間と、書く用紙（1 枚目）が焼き込まないビューで置く空間を書く。焼き込むビューだけが置く空間は書かない。
- civil_drawing は、選んだ用紙が置く空間だけを残してから書く。

## 結果

- 平面図を選んだ civil_drawing の文書は、scene に線形の線が出る。
- 相似のビューを書いた DXF を読み直すと、同じ変換のビューになる（`zumen-abi` の試験）。
- 回転したビューと、表示しないレイヤを持つビューは、まだ落とす。読む側がねじれ（51）と凍結のレイヤ（341）を扱うのに合わせて、書く側を広げる。

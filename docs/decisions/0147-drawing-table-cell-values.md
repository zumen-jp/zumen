# 0147: 表のセルの型のある値を、単位と元の表示の書式とともに持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

[決定 0113](0113-drawing-tables-and-title-blocks.md) は、表のセルの内容を、表示する文字か記号で持つと決めた。#174 は、セルの値の種類と表示の書式を残件とした。DXF・DWG の表のセルは、2007 からの版で型のある値を持つ。値は、型（整数・実数・文字列・日時・点など）・単位の種類（長さ・角度・面積・体積・通貨・百分率）・表示の書式（`%lu2%pr2` など）・書式を当てた後の文字を持つ。手元の試料の表には、実数・角度・点・日時・整数・百分率・通貨の値がある。表示する文字だけでは、数量表を集計するときに `$100.00` や `35.00%` を文字から読み直す必要がある。角度は、表示（60）と値（ラジアン）の単位も違う。

セルの文字の高さ・回転・寄せ方・色と、枠の線は、表を描いたブロック（`Table.drawn`）が見た目として持つ。

## 選択肢

1. セルに、型のある値・単位の種類・元の表示の書式を足す。表示する文字は、今の内容のまま持つ。
2. 値を形式固有の情報（`Extension`）に置く。
3. 表示する文字だけを持ち、値は使い手が文字から読む。

## 決定

選択肢 1 を採る。

- 値の型と単位は、表を集計するための図面モデルの語である。形式固有の情報（選択肢 2）に置くと、使い手が形式ごとに読む必要がある。
- 文字から読む（選択肢 3）と、書式の当て方（桁区切り・通貨の記号・角度の単位）を使い手が知る必要がある。
- 表示の書式は、形式の書き方（DXF の `%lu2` など）を翻訳せずに持つ。書式の言語を図面モデルの語に直すのは、使い手が要るときに決める。

内容は次のとおり。

- `Cell.value` は、型のある値（`CellValue`）である。元の形式が値を持たなければ `None`。
- `CellValue` は、値（`CellData`）・単位の種類（`ValueUnit`）・元の表示の書式（`format`）を持つ。
- `CellData` は、文字列・整数・実数・日時（`DateTime`）・点を分ける。
  - 実数の長さ・面積・体積は、図面の単位のまま持つ。
  - 角度は、元の形式の単位のまま持つ（DXF・DWG はラジアン）。
  - 2 次元の点は、Z を 0 とする。
- `DateTime` は、年・月・日・時・分・秒・ミリ秒を持ち、時差を持たない。
- DXF・DWG は、セルの 2007 からの値を読む（docs/formats/dxf.md・dwg.md）。日時は SYSTEMTIME の 16 バイトとする（推定。試料の表示と曜日で確かめた）。
- オブジェクトの参照・バイト列・結果の並び・一般の値の型は、図面モデルに対応する語がないので移さず、`dxf.cell-value.dropped` で示す。表示する文字は内容に移す。

## 影響

- 図面モデルの `Cell` に欄が増える。`Cell` を作る使い手は、欄を足す必要がある。
- セルの書式と枠、表のスタイルの中身は、まだ移さない。表を描いたブロックが見た目を持つので、表示は失われない。
  - [決定 0151](0151-drawing-table-cell-formats.md) が、セルの書式と枠と、表のスタイルの行の書式を移す。

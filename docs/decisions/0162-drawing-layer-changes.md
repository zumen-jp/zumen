# 0162: 図面モデルの変更でレイヤの名前・状態・スタイルを変え、レイヤを足し、除く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

[決定 0139](0139-drawing-apply.md) の変更（`Edit`）は、要素を変えるものだけを持つ。要素のレイヤは `Restyle` で変えられるが、レイヤそのもの（名前・表示・印刷・編集・凍結・色・線種・線幅）は変えられず、新しいレイヤも作れない。図面を整理する人と AI は、レイヤの名前を規則に合わせて付け直し、表示や色を揃え、新しい要素のためのレイヤを作る。境界の `tables` も、レイヤの ID・名前・ハッシュだけを返し、状態とスタイルを返さない。

AutoCAD の系統の画層（LAYER の表のレコード、DXF Reference「LAYER」）は、名前（2）・印（70。凍結 1・ロック 4）・色（62。負なら表示しない）・真の色（420）・線種（6）・印刷の印（290）・線幅（370）を持つ。DXF の図形は画層を名前（8）で指し、XDATA も画層を名前（1003）で指す。今の画層（`$CLAYER`）も名前で指す。DWG の図形と XDATA は、画層をハンドルで指す。

AutoCAD では、画層 0 と Defpoints の名前は変えられない。名前は大文字と小文字を区別せずに比べ、`< > / \ " : ; ? * | = `` ` `` を使えない（AutoCAD の名前の決まり、推定）。

## 選択肢

1. `Edit` に、レイヤを置き換える変更と足す変更を加える。
2. レイヤの変更を、要素の変更とは別の一覧にする。
3. レイヤの名前の変更を、そのレイヤの要素すべての `Restyle` と、新しいレイヤの追加で表す。

2 は、レイヤを足してから要素を変える流れや、名前と要素の変更を 1 つの文書のハッシュの前提で当てることを分けてしまう。3 は、DWG で今ある図形のレイヤを書き戻せず（0139）、元のレイヤの XDATA・ビューポートの凍結・今の画層を写せない。

## 決定

選択肢 1 を提案する。

- **変更。** `Edit::ReplaceLayer { target, layer }` は、指したレイヤの名前・状態・スタイルを、渡したレイヤのもので置き換える。指し方は要素と同じく ID（`id::layer`）と読んだときのハッシュ（`Hash::layer`）とする。`Edit::AddLayer { layer }` は、レイヤを足す。どちらも、レイヤの ID・出所・`follows_placement` は使わない。状態とスタイルは要る。
- **結果。** apply は、置き換えたレイヤの ID と、足したレイヤのハンドルで作る ID（`layer/h40`）と、書き戻した後のレイヤのハッシュを返す。
- **決まり。** 次の変更は `change.edit.unsupported` にして、一覧全体を当てない。
  - 名前が空か、使えない文字か前後の空白を持つか、ほかのレイヤ（足したレイヤと名前を変えたレイヤを含む）と重なる。
  - 画層 0 と Defpoints と、外部参照に依る画層の名前を変える。0 か Defpoints という名前にする。
  - 凍結して表示する。番号の色を持たない色にする。
  - 同じレイヤを 1 つの一覧で 2 度変える。定義のないレイヤ（要素が名前で指すだけのもの）を変える。
  - 形式の版が持てない値を書く。2007 より前の DXF の ASCII でない名前、R2000 より前の DXF の線幅と印刷しない印、R2004 より前の DXF の真の色。
- **DXF。** 置き換えは、元のレコードの 2・70・62・420・6・290・370 だけを書き直し、ほかの値は写す。表示しない画層は、色の番号を負にする。凍結した画層の色の番号は負にしない（読むときは、凍結した画層を表示しない）。名前を変えたら、図形の 8 と、XDATA の 1003 と、`$CLAYER` も新しい名前にする。OBJECTS のオブジェクト（画層の状態の XRECORD など）が画層を名前（8）で指していれば、書き直せないので当てない。足すときは、画層 0 のレコードを写し、ハンドル・拡張辞書と反応子の組・拡張データ・真の色を除いてから同じ欄を書き、新しいハンドルで画層の表の終わり（ENDTAB）の前に置く。
- **DWG。** 図形は画層をハンドルで指すので、名前を変えてもレコードの名前だけを書き直す。同じ一覧で足した図形の画層の名前は、新しい名前にする。R2010 から後のレコードの名前は、文字列の流れの初めに UTF-16 で書き、流れの長さとハンドルの流れの位置を直す（[決定 0089](0089-dwg-r2010-write-back-records.md) の書き方）。今あるレコードの線種（ハンドル）と真の色は、変えられない。足すレコードは、[決定 0094](0094-dwg-r2010-write-back-table-record-addition.md) の書き方で書く。
- **境界。** 新しい小版で、`apply` に変更の種類 `layer`（書いた欄だけを変える）と `add_layer`（書かない欄は、状態なら表示・印刷・編集でき凍結せず、色・線種・線幅なら画層 0 と同じ）を足す。`tables` のレイヤの項目は、定義があれば状態・色・線種の ID・線幅を返す。凍結するだけなら表示もしない。表示するだけか凍結を解くだけなら、凍結を解いて表示する。
- **除去。** `Edit::RemoveLayer { target }` は、指したレイヤを除く。指し方は置き換えと同じ。結果は ID もハッシュも持たない。次のレイヤは除けず、`change.edit.unsupported` にして一覧全体を当てない。
  - 画層 0 と Defpoints と、外部参照に依る画層。拡張辞書か反応子（102・360）を持つ画層。ハンドルのない画層。後ろにハンドルのないレイヤがある画層（定義のないレイヤも含む）。
  - ほかのオブジェクトが指す画層。すべてのオブジェクトの値のうち、画層のハンドルを指すもの、DXF の 8 と 1003 で画層の名前（大文字と小文字を区別しない）を持つものを探す。図形・ブロック・OBJECTS（画層の状態の XRECORD・画層のフィルターなど）を含む。ヘッダーの変数（`$CLAYER` など）も同じく探す。
  - 同じ一覧の要素の変更（足す要素と `Restyle`）が指す画層。同じ画層を 2 度除く変更。
- **除去と ID・ハッシュ。** 除去によって、ほかのレイヤと要素の ID は変わらない。レイヤと要素のハッシュは、図面モデルの中のレイヤの番号（`LayerId`、表の並びの順）を含むので、除いたレイヤより後ろのレイヤと、その上の要素のハッシュは変わる。続けて変えるときは、`tables` と `entities` を読み直す。ハッシュの版を上げて番号を含めないようにすることは、要素の型を変えるときにまとめて決める。
- **DWG の除去。** 画層のレコードを除き、画層の表のオブジェクト（LAYER_CONTROL）の項目の並びから、そのハンドルを 1 つだけ除いて書き戻す。R2010 から後も、ハンドルの流れの項目を除く。
- **同じ一覧の要素。** 要素の変更は、同じ一覧で足したレイヤを指せない。足したレイヤに要素を置くには、apply を 2 回に分ける。名前を変えたレイヤに同じ一覧で足した要素は、新しい名前のレイヤに置く。

## 影響

- 人と AI が、レイヤの名前・状態・スタイルを変え、レイヤを足して、元の DXF・DWG に書き戻せる。
- 線種・文字スタイル・寸法スタイルの表の変更は、まだない。
- AutoCAD の名前の決まりと、DWG の名前を書き直したレコードを AutoCAD が開けるかは、AutoCAD を持つ環境で確かめる。
- 最初の PR で、DXF と R2010 より前の DWG の置き換えと追加、R2010 から後の DWG の名前を変えない置き換えと追加、境界の `layer`・`add_layer` と `tables` のレイヤの定義（小版 22）を作った。
- 続く PR で、レイヤの除去と境界の `remove_layer`（小版 24）を作った。試料の DXF と、R2010 の前と後の DWG で、どこからも指されない画層を除いて書き戻し、読み直して、ほかの画層の ID・名前・状態・スタイルと、要素ごとの画層の名前が変わらないことを確かめた。試料の多くの画層は、拡張辞書か反応子を持つか、ほかのオブジェクトが指すので除けなかった。
- 続く PR で、R2010 から後の DWG のレイヤの名前の変更を作った。試料の R2010 から後の DWG で、レイヤを日本語の名前に変えて書き戻し、読み直して一致した。

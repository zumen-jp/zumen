# 0287: エージェントは公開の資料を読み、同意して手に入れた資料は条件が AI を禁じていなければ読む

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-09 |
| 状態 | 採用 |

## 背景

- エージェントは、仕様・販売のページ・公開の実装を読んで形式を実装し、形式の台帳（[0017](0017-format-rights-ledger-and-plugin-sdk.md)）に書誌の事実と権利の根拠を書く。何を読んでよいかの決まりはなく、AI での利用を禁じる注記には、そのつど当たってきた。台帳の `e57` は、ASTM の販売のページが規格を AI で扱うことを禁じるので、本文を読まないとした。
- 2026-11-09、`express` を台帳に足す PR（#666）の確かめる側が、ISO のサイトの注記を見つけた（#669）。作った側は、ページの本文だけを読んで見落とし、台帳に「AI で扱うことについての記述はない」と書いていた。注記は、ページの下の折りたたまれた部分（`<details>` の「© All Rights Reserved」）の中にあり、ページの本文を読むツールでは出てこない。
- 2026-11-09 に確かめた ISO の条件は、次のとおり。
  - **サイトの注記**（www.iso.org と committee.iso.org のページの下）。ISO の出版物と資料は著作権で守られ、複製を含む使用には書面の許諾が要るとする。ISO Open data のものを除き、ISO の内容を機械学習・AI に使うことを禁じ、例として、大規模言語モデルの学習と、AI のツールに応答を作らせることを挙げる。
  - **利用許諾**（[Licence Agreement](https://www.iso.org/terms-conditions-licence-agreement.html)、2026-05-29 の改定）。出版物の使用は、End Customer Licence Agreement に従う。その 7(b) は、ISO・ISO の会員団体・認められた配布者が別に許諾しなければ、出版物を AI・機械学習のために読み・使い・処理することを禁じる。禁じる使い方には、AI に出版物を取り込ませ、要約・言い換え・生成させるための入力や問い合わせが入る。EU の指令 2019/790 の 4 条にあるテキスト・データマイニングの例外も、使えないとする。6(b) は、出版物をソフトウェア・データモデル・AI のツールなどに組み込むことに、別の許諾を求める。
  - **PDF Association が配る ISO 32000-2 の無償版。** 0 ドルの手続きで受け取る。配る頁に、利用の条件は書かれていない（#674）。
- 利用者は 2026-11-09 に、会話で「知識は消せないし、あなたは私の代わりとしてふるまうのだから全部読んでよい。権利上問題が起きることがなければよい。理想のツールを作るために柔軟なルールを設計したい」と答え、下の方針を示されて「この方針で進めて」と答えた（#669）。

## 選択肢

1. **AI での利用を禁じる持ち主のページと資料は、開かない。** 持ち主の意向にいちばん沿う。ただ、書誌の事実を得るのにも利用者の手が要り、持ち主ごとに禁止を足していくことになる。
2. **書誌の事実を読むためだけなら、ページを開いてよい。本文は読まない。** ページを読むこと自体が、注記の「AI のツールに応答を作らせる」に当たるので、注記の読み方としては弱い。
3. **何を読めるかは、同意した条件だけで決める。** 誰でも見られる公開のページと資料は、注記によらず読む。購入・登録・会員・NDA などで、条件に同意して手に入れた資料は、その条件が AI での利用を禁じていなければ読む。何を書けるかは、著作権と今の決まりで縛る。

## 決定

3 を選ぶ。権利の問題が実際に起きるのは、同意した条件に反すること、書くものに仕様の本文や寛容でないライセンスのコードが混ざること、受け取った図面や秘密を出すことの 3 つである。決まりはこの 3 つを避けることに絞る。新しい資料に当たったら、手に入れるときに条件に同意したかと、その条件が AI での利用を禁じているかの 2 つを確かめる。

- **読む**
  - 誰でも見られる公開のページと資料（ログインも、条件への同意も要らないもの）は、読んでよい。サイトの注記が AI での利用を禁じていても、事実を得るために読む。注記の中身は台帳に書く。
  - 自動の取得を拒む公開のページは、利用者のブラウザー（ブラウザーの拡張）で開いてよい。ログイン・CAPTCHA・支払いは越えない。
  - 購入・登録・会員・NDA などで、条件に同意して手に入れた資料は、その条件が AI での利用を禁じていなければ読む。禁じているか、確かめていなければ読まない。条件の文はエージェントが読んでまとめてよいが、読むと決めるのは利用者にする（利用規約の読みで採否が決まる権利の判断。[0254](0254-parallel-agents-and-cross-review.md)）。読まないと決めるのは、エージェントでよい。
  - 学習済みの知識は使ってよい。
- **書く**（今の決まりのまま）
  - 仕様の本文・表・図は写さない。節の番号・名前・値などの事実は書いてよい。
  - GPL などのソースは読まない。読むこと自体ではなく、書くコードに混ざることを防ぐためである。
- **記録する**
  - 台帳の仕様の項の `note` に、入手に条件への同意が要るかと、その条件が AI での利用を禁じるかを書く。確かめていなければ、そう書く。項目は足さない。当てはまる仕様が少なく、文で足りるため。
  - 注記と条件は、ページの本文だけでなく、折りたたまれた部分とページの下まで読む。

エージェントは利用者の代わりに読むので、公開のページを読むことは、利用者が読むことと同じに扱う。同意した条件が AI を名指しで禁じる資料は、エージェントが読めば、同意した利用者が条件に反するので、分けて扱う。

今の仕様には、次のように当てる。

| 仕様 | 扱い |
| --- | --- |
| `iso_10303_11_2004`（EXPRESS） | 本文は ISO から買い、利用許諾が AI での利用を禁じるので読まない。買ってもいない。学習済みの知識・公開された EXPRESS のスキーマ・寛容なライセンスの実装で読む |
| `iso_32000_2_2020`（PDF 2.0） | 無償版を受け取るときの条件を確かめていないので、利用者が確かめるまで読まない（#674）。それまでは、学習済みの知識・Arlington PDF Model（Apache-2.0）・pdf-issues（CC BY 4.0）・寛容なライセンスの実装で進める |
| `e57_astm_e2807`（E57） | 本文は買うもので、販売のページが AI で扱うことを禁じるので読まない（今のまま） |

## 影響

- エージェントは、ISO・ASTM などのサイトのページを、ほかの公開のページと同じく読める。#669 で決めるまで ISO のページを開かないとした扱いは終わる。確かめる側も、同じ決まりで読む。
- サイトの注記を知ったうえでページを使い続けると、注記の条件に同意したと見られる余地は残る。読むのは事実だけにし、本文・表・図を写さないので、持ち主に損害は生じない。
- 本文を読めない仕様は、学習済みの知識・公開の資料・寛容なライセンスの実装と、テストで確かめた結果で実装する。台帳の実装の根拠（`basis`）は、今の決まりのとおりに書く。
- ISO の利用許諾の 6(b) は、出版物を手に入れた者（licensee）が、出版物をソフトウェアなどに組み込むことに別の許諾を求める。このリポジトリは、ISO の出版物を同梱せず、本文・表・図を写さない。仕様に従って形式を読み書きするコードは、出版物を組み込むことに当たらないと読む。
- 入手に同意が要るかは、`access` だけでは分からない。`iso_32000_2_2020` は `public`（無償）だが、手続きで受け取る。そのため `note` に書く。

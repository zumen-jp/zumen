# 0128: SFC の引出線とバルーンは、引出線つきの注記にし、矢印をコードのキーで指す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

SFC の引出線（`label_feature`）は、レイヤ・色・線種・線幅のコード・頂点の列・矢印のコードと倍率・文字（有無と、文字のフィーチャと同じ値）を持つ。バルーン（`balloon_feature`）は、これに円の中心と半径を足したもの。頂点は矢印の側から並び、矢印のコード 0 は矢印を描かない（旧版の推定）。矢印の形は既定義の表で決まり、ファイルは形を持たない。図面モデルには、経路と注記を 1 つに持つ引出線つきの注記（`Callout`）があり、バルーンも含むとしている（#171）。

## 選択肢

1. 引出線とバルーンを `Callout` にし、矢印を名前空間 `sxf.arrow` の、矢印のコードを名前にした記号のキーで指す。バルーンの円は拡張に残す。
2. 引出線（`Leader`）と、別の要素の文字・円に分ける。
3. 線と文字と円の要素に分ける。

## 決定

選択肢 1 を採る。注記を別の要素にすると、出所が同じ要素を引き当てる規則が要る。線と文字に分けると、引出線という意味が分からなくなる（[決定 0022](0022-drawing2d-semantics-and-format-mapping.md)）。矢印をコードのキーにするのは、点マーカー（[決定 0126](0126-sxf-splines-and-point-markers.md)）と同じ扱い。

- 頂点の列を 1 本の枝の線にする。集まる点と折れ曲がりは持たない。線の引き方は折れ線にする。
- 矢印は、コード 0 も含めてキーにする。0 が矢印を描かないことは、表示側がコードの表から引く。倍率は `scale` に入れ、`arrow_size` は要素の空間の 1 にする（推定。矢印の大きさもコードの表で決まる）。
- 文字があれば、文字のフィーチャと同じく書式つきの文字にし、文字範囲の幅と字の間隔を `sxf.callout` の拡張に残す。なければ注記を持たない。
- バルーンの円の中心（`center`）と半径（`radius`）を、`sxf.callout` の拡張に、要素と同じ座標で残す。
- 頂点の数が 2 未満か、X と Y で違う、文字の有無が 0 と 1 でない、半径が正でないなどは、`sxf.lift.invalid` で落とす。診断の code は足さない。

## 影響

- 既定義の矢印の形と、バルーンの円を描くのは、表示側の作業にする。
- 境界（`drawing` の op）の要約は、決定 0107 のとおり引出線つきの注記を数えない。
- 寸法の矢印（[決定 0127](0127-sxf-dimensions.md)）は、拡張にコードのまま残している。寸法スタイルの端部記号に移すかは、寸法スタイルを SXF から作るときに決める。

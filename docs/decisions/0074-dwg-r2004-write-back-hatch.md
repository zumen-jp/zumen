# 0074: R2004 の DWG への HATCH の書き戻しは、初めのグラデーションのフィールドを元のビットのまま写す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 の DWG へは、R2000 と同じ形の種類と、後ろにフィールドが増えた INSERT・MTEXT の型ごとのフィールドを書き戻す（[決定 0073](0073-dwg-r2004-write-back-kinds.md)）。HATCH は、R2004 から型ごとのフィールドの初めにグラデーションのフィールド（ODS 5.4.1 の 20.4.75）があり、その後ろのフィールドの順は R2000 と同じになる。表は、グラデーションの値を 450〜470 に置く。

## 選択肢

1. グラデーションのフィールドは元のビットを写し、その後ろを R2000 と同じに符号化する。グラデーションの値の変更は受け付けない。
2. グラデーションのフィールドも、表の値から符号化する。

## 決定

選択肢 1 を採る。グラデーションのフィールドには、表に置かない値（色の BS と RC、色の数だけの並び）があり、表の値からは書けない。

- R2004 の HATCH は、型ごとのフィールドの初めのグラデーションのフィールドを読み飛ばし、そこまでの元のビットを写してから、R2000 の形で符号化したフィールドを続ける。
- 450〜470 の値が変わったものは、これまでどおり書き戻さない。

## 影響

- サンプルの R2004 の図面の 8 つの HATCH（グラデーションを持つものを 2 つ含む）で、境界の点を動かして書き戻し、読み直した表が変えた表と同じになった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0178: シーンの区画を 1 つの列にし、配置を schema/scene.toml に置く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-30 |
| 状態 | 採用 |

## 背景

決定 0137 はシーンのバッファーの見出しと区画の表を、決定 0172 は描くもの（線・面・文字・点・画像）と表（単位・要素・色・切り抜き・塊・文字列）を決めた。区画の中の並びと、塊の大きさ、起点の選び方、色の表の渡し方は決めていない（#219）。

## 選択肢

1. 描くものごとに 1 つの区画を置き、行を構造体の並び（AoS）にする。
2. 値の列ごとに 1 つの区画を置き（SoA）、区画の番号を定義の順にする。
3. 区画の中に自前の小さな表を持たせる。

## 決定

選択肢 2 を採る。

- **区画は 1 つの列。** 区画は型（`u8`・`u32`・`f32`・`f64`）と幅（1〜4）を持つ型付きの配列で、行の数は区画の長さ ÷（型のバイト数 × 幅）。区画の番号は `schema/scene.toml` に並べた順で、`cargo xtask codegen` で `crates/zumen-scene/src/layout.rs` の定数を作る。区画は後ろに足すだけにし（決定 0015 と同じ考え）、足すたびに配置の小版を上げる。
- **配置の版。** 見出しの大版・小版は境界のスキーマの版と別に、`schema/scene.toml` の `[versions]` で持つ。今は 1.0。
- **始まりの列。** `*_vertices`・`*_rings`・`chunk_*` など「始まり」の列は、参照先の区画の行の番号を持ち、行は次の行の始まりで終わる（最後は参照先の終わり）。番号の「なし」は `u32::MAX`。文字列は `strings` 区画の（始まり, 長さ）のバイトの組で指す。
- **座標。** 描くものの座標は、塊の原点からの相対の `f32` にする。塊の原点は塊の範囲の最小の角（`f64`）。切り抜きの頂点だけは絶対の `f64` のままにする。
- **塊の大きさ（仮）。** 描くものが 4096 個に達するか、範囲の幅か高さが許容差 × 2^16 を超えたら塊を閉じる。f32 の相対座標の誤差を許容差より十分小さく保つための値で、実際の図面での計測（#219）で変える。`Chunking::PROVISIONAL` に置き、境界の要求からは変えられない。
- **起点。** `scene` の要求の `from` に空間・定義の空間・用紙の ID を渡し、用紙ならビューを `view`（番号）で選べる。空間と定義の空間の座標はその空間の単位、用紙は mm。許容差を省くと、用紙では 0.02 mm、空間では大まかな範囲の対角 ÷ 50000 にする（仮）。
- **色の表。** `palette` に入力の名前を渡す。中身はプロファイルの色の語彙と同じ形の JSON（`{"values":[{"rgb":"#rrggbb","aci"|"sxf"|"jww":番号}]}`）。表になく、ファイルにも RGB がない色は「引けない」の印を立てる。
- **文字。** 揃えは横（左・中・右・中央・両端・合わせ）と縦（基準線・下・中・上）の 2 つの `u8`、向きと書式は印の `u8`（逆向き・上下逆・縦書き・書式つき・積み上げの上下）。書式つきの文字は文字の区切りごとに 1 行にし、段落ごとに `text_lines` を進める。変換の行列の行列式が負なら上下逆の印を反転する。
- **線の種類。** 要素の基準の線種は要素の尺度 × 文書の尺度 × 変換の拡大で、用紙の基準の線種はそのままの長さで破線にする。空間を起点にしたときも用紙の基準をその空間の単位として扱う。周期が許容差以下なら実線にする。
- **幅のある折れ線。** 区間ごとに 1 つの面にする。

## 影響

- 境界の小版を 33 に上げ、`scene` の op とその結果を足した。能力と要求の応答のハッシュが変わり、適合試験に `scene` の組を足してハッシュを作り直した。
- 読む側の型は Rust の定数だけを作る。C・TypeScript などの型は作っていない。
- 残る作業は、寸法・引出線・注記・表の描画、ハッチングの模様の線、線種の記号、下敷きの切り抜き、合わせ点だけのスプラインの正確な評価、外側だけの島の正しい扱い、書式の色、塊の大きさの計測、3D のインスタンスと LOD で、それぞれ issue で追う。

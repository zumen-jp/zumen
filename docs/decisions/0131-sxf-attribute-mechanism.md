# 0131: SFC の属性付加機構の名前は、複合図形の要素ごとの拡張に残す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

SXF の属性付加機構は、複合図形の名前に、`$$` で区切った記述（`$$ATRU$$番号$$名称$$属性名$$値` や `$$ATRF$$背景色$$色$$…` など）を書いて、複合図形の要素に属性を結ぶ。附属書の共通属性セットは、背景色・表題欄・フィーチャ定義属性セットを決めている。等高線の標高や朱書きなどの運用の属性も、この記述で書く。[対応表](../formats/drawing2d-mapping.md)は、共通化できる項目と形を保持し、属性の結合・独自の役割・関連ファイルの関係を拡張に残すとしている。表題欄は [決定 0124](0124-drawing-title-blocks.md) で、画像は [決定 0125](0125-sxf-raster-underlays.md) で、共通の欄に移した（#171）。

## 選択肢

1. 名前が属性付加機構の記述の複合図形について、その要素に、名前と、`$$` で区切った値を `sxf.attribute` の拡張で付ける。要素は、ほかの複合図形と同じく移す。
2. 属性の名前ごとに、共通の欄（背景色・標高など）を図面モデルに足す。
3. 属性付加機構の記述を落とし、診断する。

## 決定

選択肢 1 を採る。附属書の属性の名前と値の組は運用ごとに増え、ファイルからは役割が決まらない。共通の欄にするのは、表題欄と画像のように、ほかの形式にも同じ役割がある項目に限る。落とすと、標高のような値と、要素との結合が失われる。

- 名前が `$$ATR` で始まる複合図形（作図グループ・部分図・作図部品）の要素に、`sxf.attribute` の拡張を付ける。値は、元の名前（`name`）と、`$$` で区切った値（`part`）を順に持つ。作図グループは置くたびに、置いた要素に付ける。部分図と作図部品は、その空間の要素に付ける。
- 名前は翻訳せず、値の形（数か、色の組か）も解かない。背景色は、図面モデルに用紙の背景の欄がないので、共通の欄にしない。
- 画像の属性（`画像`）は、決定 0125 のとおり下敷きにし、範囲の折れ線ではなく下敷きの要素に拡張を付ける。
- 属性を落とさないので、診断はしない。

## 影響

- 属性の値を使う表示や検索は、拡張の `part` を読む。
- 関連ファイル（属性ファイル）は読まない。ファイルの名前が属性の値にあれば、値として残る。
- 背景色などを共通の欄にするときは、ほかの形式の同じ役割の値と合わせて決める。

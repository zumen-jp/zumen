# 0082: R2004 の LAYOUT は、印刷するビューをハンドルで持ち、陰影の印刷のフィールドとビューポートの数を持つ形で読み書きする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2000 の LAYOUT は、印刷の設定のフィールドとレイアウトのフィールドを読み、フィールドをすべて書き直して書き戻す（[決定 0049](0049-dwg-write-back-layout.md)）。R2004 の図形でないオブジェクトは LAYOUT を除いて書き戻せるが、読む側が R2004 の LAYOUT のフィールドを R2000 の並びで読もうとして失敗し、ハンドルしか置いていなかった（[決定 0076](0076-dwg-r2004-write-back-objects.md)）。ODS 5.4.1 によれば、R2004 の LAYOUT は次の点で R2000 と違う。

- 印刷するビューの名前（TV）の代わりに、ハンドルのストリームに印刷するビューのハンドルを持つ。
- 印刷の設定の終わりに、陰影の印刷の方法・解像度・DPI（BS）を持つ。
- レイアウトのフィールドの後に、ビューポートの数を持ち、ハンドルのストリームの終わりにその数だけビューポートのハンドルを持つ。
- R2007 からは、印刷するビューの後に表示スタイルのハンドルを持つ。

## 選択肢

1. 仕様の並びで読み、印刷するビューとビューポートのハンドルは値に置かずに、書き戻すときはハンドルのストリームをそのまま写す。
2. 印刷するビューのハンドルをビューの名前（6）に直して置く。
3. R2004 の LAYOUT は、まだ読まない。

## 決定

選択肢 1 を採る。陰影の印刷のフィールドは、DXF と同じく 76・77・78 に置く。印刷するビューは、サンプルの図面ではどれも 0 で、名前に直す形を確かめられないので、値に置かない。ビューポートのハンドルも DXF の LAYOUT にないので置かない。

ビューポートの数を、ODS は RL とするが、サンプルの R2004 の図面では、レイアウトのフィールドの終わりからハンドルのストリームの始まりまでが 2 か 10 ビットで、BL として読むと合う。BL として読む。

書き戻しは、R2000 と同じくフィールドをすべて書き直し、フィールドの後のビューポートの数からハンドルのストリームの前までと、ハンドルのストリームを写す。

## 影響

- サンプルの R2004 の 2 つの図面の LAYOUT 6 つを読めるようになり、同じ図面の DXF の値と合った。R2010 の図面の LAYOUT も、表示スタイルのハンドルを飛ばして DXF と合った。
- サンプルの R2004 の図面の LAYOUT の高さ（146）と陰影の印刷の DPI（78）を変えて書き戻し、読み直した表が変えた表と同じになった。
- 印刷するビューを持つ LAYOUT は、名前を値に置かない。書いた図面を AutoCAD で開いて確かめてはいない。

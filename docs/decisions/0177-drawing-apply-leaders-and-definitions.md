# 0177: 引出線を形で置き換えて足し、記号の定義の中にも要素を足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-30 |
| 状態 | 採用 |

## 背景

境界の `replace` と `add` は、引出線と記号の定義の空間を扱わなかった（#315）。引出線の形は境界で値にならず、定義の空間の ID（`space/h…`）は足す先に使えなかった。引出線は注記の要素を指し、定義の空間に足すと、その定義を置く INSERT すべての見た目が変わる。

## 選択肢

1. 引出線と引出線の多重（MULTILEADER）を一度に扱い、注記もともに足す。
2. 引出線（LEADER）だけを形の値にし、注記は同じ所の要素の ID で返し、置き換えでは変えない。足すときは注記のない引出線にする。
3. 境界では扱わず、形式ごとの API に任せる。

定義の空間に足すことには、どの定義にも足す、名前のある定義だけに足す、の 2 つがある。

## 決定

選択肢 2 を採る。定義の空間には、名前のある定義だけに足す。境界の小版を 31 に上げる。

- **引出線の形。** `geometry` に `shape` が `leader` の値を足す。経路（2 点以上）・スプラインか・矢印の有無・注記・寸法スタイルの名前と ID を持つ。注記は、同じ所の要素の ID で返す。引けなければ省く。
- **置き換え。** 経路・スプラインか・矢印を変えられる。寸法スタイルと注記は変えられない。注記の ID を渡すなら元の注記と同じ要素を、省くなら元が注記を持たないか、引けないときに限る。
- **追加。** 注記を持つ引出線は足さない。R13 から後の DXF に、注記のない（73 = 3）LEADER を足す。寸法スタイルは表の定義を引いて書き、表がなければ Standard だけを許す。R12 の DXF には LEADER がないので足さない。
- **DWG。** R2000〜R2004 の LEADER の置き換えだけを書き戻す。矢印（71）は DWG に書かない。DWG への追加と、R2010 から後の置き換えはまだしない。
- **定義の空間に足す。** 足す先を `space/h{BLOCK のハンドル}` で指す。所有者は BLOCK の BLOCK_RECORD にし、DXF では ENDBLK の前に、DWG では書き戻しでブロックの図形の列につなぐ。名のない定義（`*D`・`*T`・`*U` など。AutoCAD が作り直す）、外部参照の定義、BLOCK_RECORD がない定義（R12 の DXF など）には足さない。定義の中に記号（INSERT）は足さない。定義の循環を確かめていないため。
- **読み直し。** `entities` の要求に `place` を足す。渡せば、その空間・用紙・定義の空間の要素だけを返し、定義の要素は `place` を渡したときにだけ返す。

## 影響

- 小版 31 で、能力と要求の応答のハッシュが変わり、適合試験のハッシュを作り直した。
- 足した LEADER は AutoCAD ではまだ開いて確かめていない。
- 残る作業は、引出線の多重（MULTILEADER）、注記をもつ引出線の追加、DWG への LEADER の追加と R2010 からの置き換え、引出線の変換（`Edit::Transform`）、定義の中への記号の追加で、それぞれ issue で追う。

# 0051: DWG（R2000）への書き戻しは、表から除いた図形をマップから除き、前後の図形とブロックのレコードの並びのハンドルを直す

| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0050](0050-dwg-write-back-xrecord.md) までで、表に型ごとのフィールドを置くオブジェクトの値の変更を、R2000 の DWG に書き戻せるようにした。表から除いたオブジェクトは、まだ書き戻せない。

R2000 の図形は、前と後ろの図形のハンドルを持つか、持たないことを表す B（nolinks）を立てる。ブロックのレコードは、最初と最後の図形のハンドルを持つ。図形をマップから除くだけでは、この並びが除いた図形を指したまま残る。サンプルの図面では、次を確かめた。

- ブロックの図形の並びは、ブロックのレコードの最初の図形から、後ろの図形のハンドルをたどると最後の図形に着く。最初の図形の前と、最後の図形の後ろは 0。BLOCK と ENDBLK は並びの外にある。
- nolinks の図形の前と後ろは、ハンドルの 1 つ前と 1 つ後ろの図形。
- ブロックのレコードのハンドルの並びは、所有者・リアクター・拡張辞書・外部参照のブロック・BLOCK・最初の図形・最後の図形・ENDBLK・配置。
- ATTRIB・VERTEX・SEQEND は、所有者の図形の後ろに続き、ブロックの並びとは別に並ぶ。

## 選択肢

1. 除いた図形をマップから除き、隣が変わった図形の前後のハンドルと、ブロックのレコードの最初と最後の図形のハンドルを直す。図形を持つ図形と、ほかのオブジェクトから指される図形は除かない。
2. 図形をマップに残し、消したフラグを立てる。

2 は、R2000 のデータに消したフラグのフィールドがなく、読む側が図形を表に置いてしまう。

## 決定

選択肢 1 を採る。

- 除けるのは、所有者がブロックのレコード（モデル空間と用紙空間も含む）の、LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE・TEXT・MTEXT・ATTDEF・LWPOLYLINE・SPLINE・INSERT・SHAPE。ほかの図形を持つ図形（ATTRIB を持つ INSERT など）と、リアクターか拡張辞書を持つ図形は除かない。図形でないオブジェクトも除かない。
- 除いた図形は、オブジェクトのマップから除く。元のバイトはファイルに残す。
- 除いた図形の所有者のブロックのレコードごとに、図形の並びをたどる。たどれないか、最後の図形に着かないか、除いた図形が並びの中にないときは受け付けない。
- 除いた後の並びで隣が変わった図形は、前後の図形のハンドルを、絶対の柔らかいポインター（符号 4）で書き直す。nolinks の図形は、B を 0 にして前後のハンドルを拡張辞書の後ろに足す。データのストリームの長さは変わらないので、ハンドルのストリームの位置（RL）は直さない。
- 最初か最後の図形が変わったブロックのレコードは、その 2 つのハンドルを書き直す。図形がなくなれば、どちらも 0 にする。

## 影響

- 手で組んだブロックの 3 つの LINE（前後のハンドルを持つものと、nolinks のもの）を、真ん中・最初・最後の順に除いて書き戻し、読み直した表が除いた表と同じになることを確かめた。前の削除で並びが崩れれば、次の削除はたどれずに受け付けられない。
- サンプルの R2000 の図面の図形を、1 つずつ足して除いて書き戻し、読み直した表が同じになることを確かめた。リアクターを持つ LINE は除かない。
- オブジェクトの追加と、図形でないオブジェクトと図形を持つ図形の削除は、まだ書き戻せない。

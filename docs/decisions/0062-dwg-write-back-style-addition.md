# 0062: DWG（R2000）への書き戻しで足す文字の体裁は、画層と同じく文字の体裁の表のオブジェクトの項目の終わりに加える

| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md) で、表の終わりに足した画層を、R2000 の DWG に書き戻せるようにした。画層のほかの表のレコードの追加は、まだ拒んでいた。

TEXT や MTEXT を足すときは、それが使う文字の体裁も足したいことが多い。R2000 の文字の体裁のレコード（型 0x35）の欄は、名前から外部参照に依る印までが画層と同じで、その後に形のファイルの印（B）・縦書きの印（B）・高さ・幅の係数・斜めの角度（BD）・生成の印（RC）・前の高さ（BD）・字体の名前と大きな字体の名前（TV）が続く。ハンドルの流れは、所有者の文字の体裁の表のオブジェクト・拡張辞書・外部参照のブロックを指す。文字の体裁の表のオブジェクト（型 0x34）は、画層の表のオブジェクトと同じく、項目の数と項目のハンドルを持つ。試料の図面で、これを確かめた。

## 選択肢

1. 画層と同じく、足した文字の体裁のレコードを一から符号化し、所有者の文字の体裁の表のオブジェクトの項目の終わりに足す。
2. 文字の体裁の追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。

- 足した文字の体裁は、画層と同じく、ハンドルが HANDSEED より小さくなく、名前（2）が表のほかの文字の体裁と同じでないものだけを受け付ける。
- 印（70）・高さ（40）・幅の係数（41）・斜めの角度（50）・生成の印（71）・前の高さ（42）・字体の名前（3）・大きな字体の名前（4）は、みな要る。印は形のファイル 1 と縦書き 4 だけを受け付け、角度は度からラジアンに直す。
- 足したレコードの名前は、ほかの文字列と同じく、終わりに NUL を付けて書く。足した画層の名前も同じにする。
- 足した TEXT などは、足した文字の体裁を名前で指せる。

## 影響

- 手組みのファイルで、縦書きの文字の体裁と、その体裁の TEXT を足して書き戻した。読み直した表は、足した表と同じになった。表にある名前・文字の体裁の表でない所有者・外部参照に依る印を持つ文字の体裁は拒んだ。
- 試料の R2000 の図面にも、画層と文字の体裁と、その LINE と TEXT を足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。文字の体裁の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増えた。
- 足した文字の体裁を、AutoCAD で開いて確かめてはいない。
- 画層と文字の体裁のほかの表のレコード（線種・ブロックなど）の追加は、まだ書き戻せない。

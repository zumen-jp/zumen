# 0236: 3 次放物線は曲線の長さを追加距離にし、縦断の円弧とクロソイドは縦断の面の曲線として位置を計算する

| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

線形の上の位置（#367）は、3 次放物線・ウィーン曲線と、縦断の円弧・クロソイドを計算せず、`civil.curve.unsupported` で知らせていた（#467）。これらの曲線は、長さの取り方と、式に入れる値が、書き方によって違う。土木の領域モデル（[決定 0230](0230-civil-model-alignments.md)）の約束に、どう合わせるかを決める。

## 選択肢

1. **モデルの約束に合わせて、曲線の式から解く。** 平面の長さは曲線に沿った長さ（追加距離）、縦断の長さは水平の距離とし、式の値をそれに合うように解く。
2. **近い式で置き換える。** 3 次放物線をクロソイドに、縦断の円弧を 2 次放物線にする。計算は易しいが、元の曲線と離れる。

## 決定

1 にする。

- **3 次放物線。** 初めの接線を x 軸として `y = x³ / 6RX`（X は終わりの点の x、R は円弧の側の半径）と書く。区間の長さは曲線に沿った長さなので、曲線の長さがそれになる X を解き、追加距離の所の x も曲線の長さから解く。円弧の側から直線へ移る区間は、同じ形を終わりからたどる。両端に半径のある区間は、式が決まらないので、これまでどおり `civil.curve.unsupported` で知らせる。
- **ウィーン曲線。** 曲率を、長さの割合 t の 7 次の式 `35t⁴ − 84t⁵ + 70t⁶ − 20t⁷` で、初めから終わりへ移す。車両の重心の高さとカントによる項は、モデルが値を持たないので入れない。
- **縦断の円弧。** 追加距離と高さの面の円にする。半径は上に凸のものを正とし、勾配の角 θ は `sin θ = sin θ₀ − u / R`、高さは `h₀ + R (cos θ − cos θ₀)` とする（u は区間の初めからの水平の距離）。円の上にない所は `civil.segment.invalid` で知らせる。
- **縦断のクロソイド。** 追加距離と高さの面で、曲率が曲線に沿った長さに比例して変わる曲線にする。区間の長さは水平の距離なので、水平の長さがそれになる曲線の長さを解く。

## 影響

- 平面線形の 3 次放物線は、図面では許容差の内の折れ線にし、`civil.curve.approximated` で知らせる（[決定 0231](0231-civil-drawings.md)）。
- IFC4.3 の縦断のクロソイドは、モデルでは計算できるが、半径の持ち方を試料で確かめるまで、移さない（[決定 0235](0235-ifc-alignments.md)）。

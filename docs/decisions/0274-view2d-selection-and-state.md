# 0274: 表示部品の選択は ID と配置の道筋で区別し、シーンの差し替えで消し、状態の購読は表示部品に結ぶ

| 日付 | 2026-11-06 |
| 状態 | 採用 |

## 背景

[決定 0267](0267-view2d-on-scene-columns.md) の表示部品に、#585 のレイヤ・選択・当たり判定を足す。シーンの同じ要素 ID が複数の配置に現れ、シーンを差し替えると、同じ文書の名前でも入力の版や起点が変わりうる。React のフックは後続の #588 で作るため、状態と購読を表示部品の契約として先に定める。

## 選択肢

- **選択を表示部品の外だけで持つか、表示部品が持つか。** 外だけで持つと、強調表示・非表示レイヤ・差し替えのたびに、利用側と表示部品の状態を合わせる必要がある。表示部品が持ち、利用側がその状態を購読する形にする。
- **シーンの差し替えで選択を推測して移すか、消すか。** 同じ ID でも文書の版や配置の意味が同じとは限らない。まず消し、移したい利用側が文書の同一性を確認して選び直す形にする。
- **状態の購読をシーンに結ぶか、表示部品に結ぶか。** シーンに結ぶと、React などがシーンの差し替えを知るために、購読し直す必要がある。表示部品の購読は解除か破棄まで保ち、シーンに結ぶ外部の処理は差し替えの通知を受けて片づける。

## 決定

- 選択は、シーンの `entity_ids` と、`step_ids`・`step_cells` の道筋全体で区別する。格子の列・行を省かず、永続 ID を作らない。利用側へ返す参照は凍結し、選択・hover・名前付き強調には現在のシーンにある参照だけを受ける。
- `select` は置き換え・追加・除去・切り替え、`setHovered` は 1 つの参照か null、`setHighlight` は名前・参照の一覧・色を受ける。名前付き強調は後に設定したものを優先し、その上に選択、その上に hover の色を使う。表示しないレイヤは、強調されていても描かず、当たり判定にも含めない。非表示にするだけでは選択を消さない。
- レイヤは `layer_ids` と `unit_layers` の実効の ID で扱う。`setHiddenLayers` は非表示の集合を置き換え、`setLayersVisible` は指定した ID の表示だけを切り替える。参照のないレイヤを推測して足さない。
- `getState` は、シーンの組・カメラ・サイズ・非表示レイヤ・選択・hover・名前付き強調の凍結した状態を返す。状態が変わるまでは同じ参照を返す。列の所有権は従来どおり利用側に残り、保持中には変更しない。
- `subscribe` は状態の変化、`on` は種類を選んだ変化を通知し、どちらも解除する関数を返す。登録だけでは通知しない。通知は描画と状態の更新後に同期で行う。通知の中から状態を変更することは断り、再帰する更新を作らない。通知する関数が例外を投げても残りへ通知し、最後に最初の例外を返す。この場合も、状態の更新は済んでいる。
- 成功した `setScene` は、同じ組の再設定を含め、レイヤの非表示・選択・hover・名前付き強調を消す。カメラと表示部品の購読は保つ。検査に失敗した差し替えは、以前の画面と状態を保つ。破棄では購読も消す。[決定 0267](0267-view2d-on-scene-columns.md) の購読の寿命は、この区別で具体化する。
- 点と範囲の問い合わせは CSS px で受け、描く順の逆順に、同じ ID と道筋の重複を除いて返す。描画と同じ線幅・塗り規則・字形・点の形・切り抜きと、非表示レイヤ・未描画の扱いを使う。点の許容円か範囲の四角と、可視の形が一部でも交われば返し、境界への接触も含む。代替文字だけはブラウザーの外形の四角で近似し、字形の穴や文字間の空白を区別しない。この違いを使用案内に書く。精密な幾何の検査には L2 の API を使う。
- 当たり判定と状態の更新にも作業量と件数の上限を付ける。超過した問い合わせは途中の結果を返さず、`RangeError` にする。新しい実行時の依存は足さない。

## 影響

`setScene` の後に選択を戻す利用側は、文書のハッシュ・起点・配置を確認してから `select` する。表示部品は、別の版への対応付けをしない。出所は、選択した要素 ID で既存の `entities` を呼び、`source.record` とバイト範囲へたどる。ポインター操作・ツール・吸着は #586、React の購読は #588 で、この状態を使う。

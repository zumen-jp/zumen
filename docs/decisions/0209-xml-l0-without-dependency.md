# 0209: XML の L0 は、依存を足さずに zumen-xml で読み、ルートの要素と名前空間で形式を判定する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

IDS・BCF・J-LandXML・GML・CityGML・電子納品の管理ファイル・ST-Bridge などは、どれも XML で書く。形式の意味を知らずに要素・属性・文字・名前空間を読む L0（[決定 0008](0008-model-layers-and-codecs.md)）を作り、これらで共有する（#364）。受け取ったファイルなので、パニックせず、作業量に上限を持ち（[決定 0010](0010-budget-by-work.md)）、ネイティブと wasm32 で同じ結果を返す必要がある（[決定 0007](0007-single-rust-implementation.md)）。電子納品の管理ファイルには Shift_JIS のものがある。

## 選択肢

1. `roxmltree` を足す。
2. `quick-xml` を足す。
3. `xmlparser` を足し、木は自前で組む。
4. 依存を足さずに書く。文字コードは、ほかの crate がすでに使う `encoding_rs` で戻す。

選択肢 1 は UTF-8 の文字列しか受け取らず、Shift_JIS の文書は先に全体を変換することになり、元のバイトの範囲を失う。DTD の内部サブセットの実体を展開するので、展開しないようにはできない。

選択肢 2 は名前と文字を UTF-8 として確かめる所があり、Shift_JIS のまま読むことに合わない。入れ子の深さと要素の数を数える場所を差し込めず、外で数えることになる。

選択肢 3 は 2023 年から更新がない。

要るのは、元のバイトの範囲、Shift_JIS のままの読み取り、予算を数える場所、DTD を処理しないことである。どれも、既製の読み手に後から足すより、初めから作るほうが小さい。前例として、[決定 0180](0180-read-truetype-metrics-without-dependency.md) も依存を足さずに書いた。

## 決定

選択肢 4 を採り、`crates/zumen-xml` に置く。

- **読むもの。** XML 1.0 と名前空間 1.0 の、要素・属性・文字・CDATA と、元のバイトの範囲を読む。注記と処理命令は飛ばす。要素は開始タグを書いた順の番号で引き、親と子の番号を持つ。文字と属性の値は範囲のまま持ち、文字にするのは呼び出し側が求めたときに行う。そのとき改行を `\n` にそろえ、定義済みの実体と文字の参照を戻し、属性の値の空白の文字を空白にする。
- **文字コード。** XML 宣言がないか `UTF-8` なら UTF-8、`encoding_rs` の名前の対応で Shift_JIS になるもの（`Shift_JIS`・`windows-31j` など）なら Shift_JIS として、元のバイトのまま読む。Shift_JIS の 2 バイト目は 0x40 以上なので、マークアップの文字と取り違えない。UTF-16 とそのほかの文字コードは、読まずに `xml.encoding.unsupported` を返す。
- **DTD。** 文書型宣言は範囲だけを持ち、処理しない。外部の DTD と外部の実体を解決せず、内部サブセットの実体も展開しない。文書型宣言があれば `xml.dtd.dropped` を報告し、DTD で宣言する実体の参照は、そのまま残して実体の名前ごとに `xml.entity.unsupported` を報告する。これで、実体を入れ子にして膨らませる文書（いわゆる billion laughs）と、外部の実体でファイルを読ませる文書の両方を避ける。
- **名前空間。** 宣言を要素の入れ子に沿って引き継ぎ、名前ごとに名前空間を決める。宣言されていない接頭辞は `xml.namespace.missing` を報告し、名前空間のない名前にする。
- **予算。** 要素を `records`、要素と属性を `work`、入れ子を `depth` で数え、入れ子は再帰でなく開いた要素の列で読む。止まったら、そのタグの範囲を示す。
- **壊れた文書。** 整形式でない文書（終了タグが合わない、ルートの要素が複数ある、属性が重なる、参照が壊れているなど）は、読まずに `xml.document.invalid` をその場所とともに返す。
- **形式の判定。** SDK の `Signature` に `XmlRoot` を足し、最初の開始タグの、接頭辞を除いた名前と名前空間で判定する。XML 宣言・注記・処理命令・文書型宣言は飛ばす。
- **書き出し。** 書き出しは、要る作業の issue で足す。

## 影響

- `encoding_rs` は zumen-acad・zumen-jww・zumen-sxf がすでに使うので、新しい依存はない。
- 試験はファイルを同梱せず、試験の中で文書を作る。切り詰めたり 1 バイトずつ変えたりしても、パニックしないことを確かめる。
- IDS（#411）・BCF（#429）と段階 3 からの XML の形式は、この L0 の上に L1 を作る。

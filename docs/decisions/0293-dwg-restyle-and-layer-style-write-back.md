# 0293: DWG の今ある図形のレイヤ・線種・線幅・RGB の色と、画層のレコードの線種と真の色を書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-10 |
| 状態 | 採用 |

## 背景

[決定 0139](0139-drawing-apply.md) の `Restyle` は、DWG では今ある図形の色（ACI）と線種の倍率だけを書き戻し、レイヤ・線種・線幅・RGB の色を変えるものは `change.edit.unsupported` にした。[決定 0162](0162-drawing-layer-changes.md) の画層の置き換えも、今ある DWG のレコードの線種（ハンドル）と真の色を変えられない。DXF では、どれも当たる。

エディター（#694。編集の流れは PR #712 で決める）は、DXF と DWG で同じ操作を出したい。DWG の図形は、画層と線種をハンドルのストリームのハンドルで指し、線種の種類（ByLayer・ByBlock・Continuous・ハンドル）を共通のデータの BB で持つ。色は、R2004 から ENC（ODS 5.4.1 の 2.11）で、真の色を持てる。線幅は、R2000 から共通のデータの RC で持つ。画層のレコードの色は CMC で、線種はハンドルのストリームの最後のハンドルで指す。

## 選択肢

1. 今のまま断る。エディターは、DWG ではスタイルの変更を出さない。
2. 図形の共通のデータとハンドルのストリームを、変えたフィールドだけ書き直す。ハンドルのストリームの長さが変わるときは、R2010 からは [決定 0089](0089-dwg-r2010-write-back-records.md) の書き方で組み直す。
3. 図形を除いて、同じ形の新しい図形として足し直す。

3 は、ハンドルが変わり、ID も変わる（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）。1 は、DXF と DWG で出せる操作が分かれる。

## 決定

選択肢 2 を採る。

- **図形の `Restyle`。** DWG の今ある図形で、レイヤ・色・線種・線種の倍率・線幅を変えられる。
  - レイヤは、画層の表から名前でレコードを引き、図形の画層のハンドルを、そのハンドルの固い参照（符号 5）で書き直す。
  - 線種は、ByLayer・ByBlock・Continuous なら共通のデータの BB（0・1・2）だけを書き、ほかは BB を 3 にして、線種のハンドルを画層のハンドルの後ろに書く。ハンドルを持っていた図形を ByLayer などに変えるときは、線種のハンドルを除く。
  - 色は、R2004 から ENC で書く。RGB の色は、フラグの 0x8000 を立てて、上位のバイトを 0xC2 にした値（BL）を続ける。透明度（0x2000）は元のまま写す。DBCOLOR を指す色（0x4000）を持つ図形の色は変えない。R2000 は番号（BS）だけで RGB の色を持てないので、RGB の色への変更は `change.edit.unsupported` にする。
  - 線幅は、共通のデータの RC に、線幅の番号で書く。
  - ほかのビットは、元のまま写す。MULTILEADER の画層と線種は、型ごとのデータにもあるので、変えない。
- **画層のレコード。** 今ある DWG の画層のレコードの線種と真の色を書き戻す。
  - 線種は、ハンドルのストリームの線種のハンドル（所有者・リアクター・拡張辞書・外部参照のブロック・印刷スタイル・材質（R2010 から）の後）を書き直す。
  - 真の色は、R2004 から CMC の方式を 0xC2 にして RGB の値を書き、番号（BS）も書く。色見本帳の色の名前は書かないので、真の色を変えたら、モデルの名前（430）も除く。名前を持つ画層の番号だけを変える置き換えは断る。読むときは、番号が 1〜255 なら 62 にも置く。AutoCAD は真の色の画層の番号を 0 にする（ODS 5.4.1 の 2.11）ので、AutoCAD が作った画層の読み方は変わらない。
- **追加は変えない。** DWG に足す図形は、[決定 0155](0155-drawing-apply-additions.md) のとおり、線幅と RGB の色をまだ持たない。足すレコードの書き方は、この決定では変えない。
- R2010 から後のデータは、ハンドルのストリームを組み直し、データの大きさ（MC）と文字列のストリームの位置を直す（決定 0089）。
- 決定 0139 と 0162 の、DWG で書き戻さないとしたスタイルのフィールドは、この決定で置き換える。

## 影響

- エディターは、DXF と DWG で同じスタイルの変更とレイヤの変更を出せる。
- 公開サンプルの DWG（R2000・R2004・R2013・R2018）で、実寸の空間の要素ごとにレイヤ・色・線種（足した線種と ByBlock）・線種の倍率・線幅を変えて書き戻した。読み直すと、変えた値が同じで、形とほかの要素は変わらなかった。R2004 からは RGB の色も確かめた。同じ組の DXF も確かめた。
- 公開サンプルの DWG の画層で、線種（足した線種）と、ACI と RGB の色（R2004 から）を、表示する・しないの両方で変えて書き戻した。読み直すと、線種・色・状態が変えたものと同じで、ほかの画層と要素は変わらなかった。
- 検証キットに、レイアウトのサンプル（DXF・DWG の R2000・R2004・R2018）で、画層を足して 2 つの図形のレイヤ・ACI の色・線種（ByBlock）・線種の倍率・線幅を変える組（`723/`）を足した。手元で、ACadSharp 3.8.0 は書き戻した DWG を入力にない通知なしに読み、変えた図形の画層と ACI の色が zumen の読みと同じだった。ezdxf 1.4.5 も、同じ組の DXF で同じだった。名前のある線種・線幅・RGB の色と、画層のレコードの線種と真の色は、キットのダンプが持たないので、外部の実装で照らしていない。
- AutoCAD で、書き戻した DWG を開く確認は、まだしていない。
- AutoCAD が作った真の色の画層（番号 0）は、読むときに表示しないかが分からない（色が負にならない）。直すのは #743 とする。

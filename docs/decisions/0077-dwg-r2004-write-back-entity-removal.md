# 0077: R2004 の DWG への図形の削除は、ブロックのレコードの持つ図形の数とハンドルを直して書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2000 の DWG へは、表から除いた図形を、前後の図形とブロックのレコードの並びをたどるハンドルを直して書き戻す（[決定 0051](0051-dwg-write-back-entity-removal.md)）。R2004 の図形は、前後の図形のハンドルを持たない。代わりに、ブロックのレコードが持つ図形の数（BL）と、その数だけの図形のハンドルを持つ。ODS 5.4.1 の BLOCK_HEADER の節は、この数とハンドルの位置を示すが、外部参照のブロックで数を持つかははっきりしない。

## 選択肢

1. 除いた図形のハンドルを、所有者のブロックのレコードの持つ図形から除き、数を減らす。外部参照のブロックは受け付けない。
2. R2004 の図形の削除は受け付けない。

## 決定

選択肢 1 を採る。サンプルの R2004 の 2 つの図面のブロックのレコードで、持つ図形の数が、所有者がそのレコードである BLOCK・ENDBLK のほかの図形の数と同じになり、ハンドルの並びが次の形であることを確かめた。

- 持つ図形の数（BL）は、外部参照に依るフラグの後の、名前のないフラグ・属性を持つフラグ・外部参照のフラグ・重ねる外部参照のフラグ・読み込まれたフラグの 5 つの B に続く。
- 持つ図形のハンドルは、ハンドルのストリームの、所有者・リアクター・拡張辞書・外部参照のブロック・BLOCK の後に、その数だけ並び、ENDBLK が続く。

除ける図形は、R2000 と同じく、ほかのオブジェクトを持たず、リアクターと拡張辞書を持たないものに限る。外部参照のフラグか重ねる外部参照のフラグを持つブロックのレコードの図形は、受け付けない。R2004 の図形の追加は、まだ受け付けない。

## 影響

- サンプルの R2004 の 2 つの図面で、LINE・CIRCLE・ARC・TEXT・INSERT を除いて書き戻し、読み直した表が除いた表と同じになった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

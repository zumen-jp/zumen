# 0079: R2004 の DWG への図形の足しは、R2004 の共通の欄で符号化し、ブロックのレコードの持つ図形に加える

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2000 の DWG へは、表の終わりに足した図形を一から符号化し、ブロックの図形の並びの終わりに繋いで、HANDSEED を進める（[決定 0052](0052-dwg-write-back-entity-addition.md)〜[0060](0060-dwg-write-back-minsert-addition.md)）。R2004 の DWG では、HANDSEED を書き換えられるようになった（[決定 0078](0078-dwg-r2004-header-variables.md)）。R2004 の図形は、反応子の数の後に拡張辞書を持たない印（B）を持ち、前後の図形のハンドルを持たない。ブロックのレコードは、持つ図形の数とハンドルを持つ（[決定 0077](0077-dwg-r2004-write-back-entity-removal.md)）。

## 選択肢

1. 型ごとの欄が R2000 と同じ形の図形と MTEXT を、R2004 の共通の欄で符号化し、所有者のブロックのレコードの持つ図形の終わりに加える。属性を持つ INSERT・MINSERT・表のレコード・ブロックの足しは、後に回す。
2. R2000 で足せるものを、すべて一度に R2004 でも足せるようにする。

## 決定

選択肢 1 を採る。属性を持つ INSERT は、R2004 では持つ ATTRIB のハンドルを並べる形になり、表のレコードとブロックのレコードも R2004 で形が変わるので、それぞれ図面で確かめてから扱う。

- 足せるのは、すでにあるブロックの LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE・TEXT・ATTDEF・MTEXT・LWPOLYLINE・SPLINE と、属性を持たない INSERT とする。
- 共通の欄は R2000 と同じ値で書き、前後の図形のハンドルを持つ印の代わりに、拡張辞書を持たない印を 1 で書く。ハンドルの流れには、拡張辞書と前後の図形のハンドルを書かない。色は、印を持たない ENC の番号で書く。
- MTEXT は、型ごとの欄の終わりに、背景を持たないことを表す BL の 0 を書く。
- 所有者のブロックのレコードの、持つ図形の数（BL）を増やし、ハンドルを持つ図形の終わり（ENDBLK の前）に固い所有（符号 3）で加える。試料の R2004 の図面では、持つ図形のハンドルはどれも符号 3 だった。

## 影響

- 試料の R2004 の 2 つの図面のモデル空間に、LINE・CIRCLE・TEXT・MTEXT・LWPOLYLINE・3 つの形の SPLINE・INSERT を足して書き戻し、読み直した表が足した表と同じになり、HANDSEED が足した数だけ進んだ。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0056: DWG（R2000）への書き戻しで足す LWPOLYLINE は、表にない印のビットと一定の幅を 0 にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0052](0052-dwg-write-back-entity-addition.md) からの決定で、表の終わりに足したいくつかの種類の図形を、R2000 の DWG に書き戻せるようにした。LWPOLYLINE は、値を変えたとき、表にない印のビットを元のデータから写す（[決定 0035](0035-dwg-write-back-lwpolyline.md)）。頂点ごとの幅を持つものは、表にない一定の幅も元のデータから写す。足した LWPOLYLINE には、写す元のデータがない。

試料の R2000 の図面にある LWPOLYLINE 72 個を調べた。

- 表に出る印（続く欄があるかと、閉じていること）のほかのビットは、どれも 0 だった。
- 頂点ごとの幅を持つものは、どれも一定の幅を持たなかった。

## 選択肢

1. 表にない印のビットを 0、頂点ごとの幅を持つときの一定の幅を 0 にする。
2. 足した LWPOLYLINE は、まだ受け付けない。

試料のどの LWPOLYLINE も 1 の形なので、1 で読める形になる。

## 決定

選択肢 1 を採る。

- LWPOLYLINE（型 0x4D）を足せるようにする。値は、値を変えたときと同じ書き方で書く。
- 表にない印のビットは 0 にする。頂点ごとの幅を持つときの一定の幅も 0 にする。

## 影響

- 手組みのファイルで、3 つの LWPOLYLINE を足して書き戻し、読み直した表が足した表と同じになることを確かめた。
  - 一定の幅を持つもの
  - 閉じていて、膨らみ・標高・厚み・押し出しの向きを持つもの
  - 頂点ごとの幅を持つもの

  頂点の数（90）が頂点と合わないものは受け付けない。
- 試料の R2000 の図面のモデル空間に LWPOLYLINE を足して書き戻し、読み直した表が同じになり、CRC の診断が出ないことを確かめた。
- AutoCAD で開いて確かめてはいない。
- 属性を持つ MINSERT はまだ足せない。SPLINE・SHAPE など、表にない欄を元のデータから写すほかの図形も、図形でないオブジェクトも、追加はまだ書き戻せない。

# 0170: 拡張辞書を持つ表のレコードを、拡張辞書ごと除く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0162](0162-drawing-layer-changes.md) から [決定 0165](0165-drawing-dimension-style-changes.md) は、レイヤ・文字スタイル・線種・寸法スタイルの表のレコードを除けるようにした。拡張辞書か反応子（102・360）を持つレコードは、除かずに `change.edit.unsupported` を返す。

試料の DXF と DWG の画層の多くは、拡張辞書を持つ。

- 中身のない拡張辞書（DICTIONARY）。
- 注釈の尺度の XRECORD（`ASDK_XREC_ANNO_SCALE_INFO`）を持つ拡張辞書。

拡張辞書は、レコードが所有する（DXF Reference「Extension Dictionary」）。拡張辞書の所有者（330）はレコードで、反応子もレコードを指す。拡張辞書が持つ XRECORD の所有者は、拡張辞書である。そのため、0162 の決まりでは、要素が使わない画層でも除けないことが多い。

## 選択肢

1. 拡張辞書を持つレコードは、これまでどおり除かない。
2. レコードだけを除き、拡張辞書は残す。
3. レコードと一緒に、拡張辞書と、拡張辞書が所有するオブジェクトを除く。ほかが指すものがあれば除かない。

1 では、使わないレイヤを AI と人が片付けられない。2 は、所有者のない拡張辞書が残り、所有者のハンドルが壊れる。

## 決定

選択肢 3 を採る。レイヤ・文字スタイル・線種・寸法スタイルの除去に当てる。

- **一緒に除くもの。** レコードの拡張辞書の組（`{ACAD_XDICTIONARY`）の 360 が指す DICTIONARY から、所有をたどる。
  - たどるのは、辞書の項目（350・360）、102 の組の外の 360、たどったオブジェクトの拡張辞書の組の 360 である。
  - たどったオブジェクトは、OBJECTS のオブジェクトで、所有者（102 の組の外の 330）がたどった元でなければならない。そうでなければ、ほかと共有しうるので除かない。
  - 同じオブジェクトに 2 度たどり着くか、指すオブジェクトがなければ除かない。
- **除かないもの。** 次のレコードは除かず、`change.edit.unsupported` にして一覧全体を当てない。
  - 拡張辞書の組のほかの 102 の組（反応子など）か、組の外の 360 を持つレコード。
  - 一緒に除くオブジェクトを、ほかのオブジェクトか見出しの変数がハンドルで指すもの。レコードと一緒に除くオブジェクトの中からの参照は、数えない。
  - レコードを指すものの探し方は、0162〜0165 と同じである。一緒に除くオブジェクトの中は探さない。
- **DXF。** レコードと、一緒に除くオブジェクトを除く。除いたオブジェクトを、ほかの辞書の項目と 102 の組が指していれば、その参照も除く（これまでの除去と同じ）。
- **DWG。** レコードを、表のオブジェクトの項目の並びから除く（0162〜0165 と同じ）。一緒に除くオブジェクトは、オブジェクトの地図から除く。所有者も除くオブジェクトだけを除ける。ほかの図形でないオブジェクトの除去は、これまでどおり書き戻せない。
- **境界。** スキーマは変えない。除けるレコードが増えるだけである。

## 影響

- 要素が使わないレイヤ・文字スタイル・線種・寸法スタイルは、空の拡張辞書や注釈の尺度の XRECORD を持っていても除ける。
- 拡張辞書の XRECORD は、レイヤと線種の形式固有の情報（`dxf.xrecord`、[決定 0152](0152-drawing-layer-line-type-xrecords.md)）として見えるので、除く前に何がなくなるかを確かめられる。
- 反応子を持つレコードは、まだ除かない。何がそのレコードの変化を受け取るかは種類ごとに違い、試料にも見当たらないので、試料を得てから決める。
- 書き戻した DXF と DWG を AutoCAD が開けるかは、AutoCAD を持つ環境で確かめる。
- 最初の PR で、DXF と DWG の 4 つの表の除去に当てた。試料の DXF の拡張辞書を持つ画層はどれも要素が使うので、先に要素を除いて書き戻してから画層を除き、読み直して確かめた。

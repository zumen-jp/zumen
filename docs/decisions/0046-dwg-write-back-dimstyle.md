# 0046: DWG（R2000）への書き戻しは、DIMSTYLE のフィールドを DWG の並びで書き、表にないフィールドは既定の値で書く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0045](0045-dwg-write-back-view-ucs-vport.md) までで、LAYER・STYLE・LTYPE・VIEW・UCS・VPORT の表のレコードのフィールドを R2000 の DWG に書き戻せるようにした。DIMSTYLE は、まだ書き戻せない。

読む側は、DIMSTYLE の 59 のフィールドのうち、既定の値と違うものだけを DWG の並びで表に置く。フィールドは文字列・実数・ビット・短い整数・色の 5 つの形を持つ。R2000 の色は、色の番号（BS）で持つ。340〜344 のフィールドは、ハンドルのストリームから作る。

## 選択肢

1. フィールドごとに、値が変わらなければ元のビットを写し、変わったフィールドは書き直す。表にないフィールドは、読む側と同じ既定の値で書く。
2. すべてのフィールドを表の値から書き直す。

2 は、値が変わらないフィールドでも、元のビットと違う書き方になることがある（実数の書き方など）。

## 決定

選択肢 1 を採る。

- 59 のフィールドを DWG の並びで読み進め、表の値（同じ番号の値の並び）が元と同じフィールドは、元のビットを写す。
- 変わったフィールドは、その形で書く。表にないフィールドは、既定の値で書く。1 つのフィールドに 2 つ以上の値があるときは受け付けない。
- ビットのフィールドは 0 と 1 だけを受け付ける。色は、R2000 の色の番号として書く。
- 70 は、外部参照に依るフラグだけを受け付ける。外部参照に依るフラグは、元のものと同じでなければ受け付けない。
- ハンドルのストリームから作るフィールド（340〜344）の変更は受け付けない。

## 影響

- 手で組んだ R2000 の DIMSTYLE で、文字列・実数・ビット・短い整数・色のフィールドを変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。フィールドを除くと既定の値に戻ることも確かめた。サンプルの図面の寸法の尺度（40）も変えて書き戻す。
- APPID・BLOCK_RECORD の表のレコードと、OBJECTS のオブジェクトのフィールドの変更は、まだ書き戻せない。

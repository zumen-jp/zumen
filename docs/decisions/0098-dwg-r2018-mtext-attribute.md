# 0098: R2018 から後の DWG に MTEXT を足し、1 行の属性の変更と追加を書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2018 から後の DWG の MTEXT は、行の間隔の後に、背景のフィールドに続けて、注釈的でないフラグ（B）・バージョン（BS）・既定のフラグ（B）・揃え（BL）・X 軸と挿入点（3BD）・枠の幅と高さ・範囲の幅と高さ（BD）・段の種類（BS）を持ち、ハンドルのストリームの終わりにアプリケーションの名前を指すハンドルを持つ。ATTRIB・ATTDEF は、属性のバージョンの後に属性の種類（RC）を持つ。1 は 1 行の属性で、ほかは埋め込みの MTEXT のフィールドが続く複数行の属性になる。これまでは、R2018 からの MTEXT と属性の追加と、属性の変更を受け付けていなかった（[決定 0093](0093-dwg-r2010-write-back-more-entity-addition.md)）。

サンプルの R2018 の図面の MTEXT を読むと、増えたフィールドはどれも、注釈的でないフラグが真、バージョンが 4、既定のフラグが真だった。揃え・X 軸・挿入点・枠の幅と高さは型ごとのフィールドと同じ値で、範囲の幅と高さは型ごとの範囲の高さと幅を入れ替えた値だった。段の種類はほとんどが 0 で、アプリケーションの名前のハンドルはどれも 0 だった。

## 選択肢

1. MTEXT を足すときは、サンプルの図面と同じ値で増えたフィールドを書く。範囲の幅と高さは 0 とする。属性は 1 行のものだけを書き戻し、種類を 1 と書く。
2. 範囲の幅と高さも、文字の大きさから求めて書く。
3. R2018 からの MTEXT と属性は、まだ書き戻さない。

## 決定

選択肢 1 を採る。

- MTEXT を足すときは、増えたフィールドを、注釈的でない・バージョン 4・既定のフラグは真・段なしとし、揃え・X 軸・挿入点・枠の幅と高さは型ごとのフィールドと同じ値で書く。型ごとの範囲と同じく、範囲の幅と高さは 0 とする。アプリケーションの名前のハンドルは 0 とする。変更では、これまでどおり増えたフィールドを元のビットから写す。
- ATTRIB・ATTDEF は、バージョンの後に種類 1 を書く。複数行の属性（DXF の 71 を持つもの）は、埋め込みの MTEXT のフィールドを値に置かないので、変更も足しも受け付けない。

## 影響

- サンプルの R2018 の図面に MTEXT と属性を持つ INSERT を足して書き、読み直したものが足したものと合った。
- サンプルの R2018 の図面の 1 行の属性を変えて書き、読み直したものが変えたものと合った。
- 書いた図面を AutoCAD で開いて確かめてはいない。範囲の幅と高さを 0 とした MTEXT を AutoCAD が求め直すかは確かめていない。

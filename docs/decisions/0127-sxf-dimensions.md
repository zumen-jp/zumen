# 0127: SFC の寸法は定義点と文字を図面モデルの寸法に、描いた形を拡張に移し、弧長の寸法の種類を足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

[決定 0107](0107-drawing-dimensions-and-leaders.md) は、寸法を種類ごとの定義点・保存された測定値・寸法値の文字・文字の位置で持つと決めた。SFC の寸法（直線・弧長・角度・半径・直径の 5 つのフィーチャ）は、寸法線（弧長と角度は中心・半径・始めと終わりの角度）・2 本の補助線（有無・基点・始点・終点）・矢印（コード・向き・位置・倍率）・寸法値の文字（有無と、文字のフィーチャと同じ値）を、描いた形のまま持つ。測定値は持たない。図面モデルの寸法の種類には弧長がなく、[対応表](../formats/drawing2d-mapping.md)は、弧長を角度に変えて同等としないとしている（#171）。

## 選択肢

1. 定義点と寸法値の文字を図面モデルの寸法に移し、寸法線と補助線の端・矢印・文字範囲の幅と字の間隔・書く向きを `sxf.dimension` の拡張に残す。弧長の種類（`DimensionKind::ArcLength`）を足す。
2. 寸法を、線・矢印の記号・文字の要素に分けて移す。
3. 弧長を、角度の寸法として移す。

## 決定

選択肢 1 を採る。線と文字に分けると、寸法という意味が分からなくなる（[決定 0022](0022-drawing2d-semantics-and-format-mapping.md)）。弧長を角度にすると、測る量が変わる。

- 直線の寸法は `Linear` にする。補助線があれば基点を、なければ寸法線の端を定義点にし、寸法線の始点を寸法線が通る点、寸法線の向きを測る向きにする。補助線が寸法線に垂直でなければ、補助線の向き（0 度以上 180 度未満）を傾きにする。長さのない寸法線は読めない。
- 弧長の寸法は `ArcLength`、角度の寸法は `Angular` にする。中心を頂点にし、補助線があれば基点を、なければ寸法の弧の両端を定義点にする。寸法の弧は、始めの角度から反時計回りに終わりの角度までとし（推定）、その中ほどの点を弧が通る点にする。
- 半径の寸法は `Radius` にし、寸法線の、矢印に近い端を円の上の点、もう一方を中心にする。矢印がなければ終点を円の上の点にする（推定）。直径の寸法は `Diameter` にし、寸法線の始点と終点を円の上の向かい合う 2 点にする。引出線の長さは 0 にする。
- SFC は測定値を持たないので、`measurement` は `None` にする。寸法値の文字があれば、`Label::Override` に元の文字列を入れ、文字の高さ・斜体・フォントを書式に入れる。文字の基点を位置に、回転をそのまま、9 点の配置を位置合わせにする。文字がなければ `Label::Hidden` にする。
- 寸法線の端（`line_start`・`line_end`）または寸法の弧（`radius`・`start_angle`・`end_angle`）、補助線の始点と終点、矢印のコード・向き・位置・倍率、文字範囲の幅・字の間隔・書く向きを、`sxf.dimension` の拡張に、要素と同じ座標で残す。
- 有無のフラグが 0 と 1 でない、文字の 9 点の配置が 1〜9 でないなどは、`sxf.lift.invalid` で落とす。診断の code は足さない。

## 影響

- `DimensionKind` に `ArcLength` を足した。DXF の ARC_DIMENSION を移すときも、この種類を使う。
- 境界（`drawing` の op）の要約は、決定 0107 のとおり寸法を数えない。
- 描いた形を拡張から戻して表示するのは、表示側の作業にする。

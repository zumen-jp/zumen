# 0048: DWG（R2000）への書き戻しは、DICTIONARY と MLINESTYLE の欄を書き直し、項目と線の数と体裁の名前は変えない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0047](0047-dwg-write-back-group-dictionaryvar.md) までで、OBJECTS のうち GROUP と DICTIONARYVAR の欄を R2000 の DWG に書き戻せるようにした。DICTIONARY・ACDBDICTIONARYWDFLT・MLINESTYLE・XRECORD・LAYOUT は、まだ書き戻せない。

読む側は、辞書の複製の扱い（281）と、0 でない所有する印（280）と、項目の名前（3）を、ハンドルの並びの項目と組にして置く。多重線の体裁は、名前（2）・印（70）・説明（3）・色（62）・2 つの角度（51・52、度）・線の数（71）と、線ごとの位置（49）と色（62）を置く。印は、DWG と DXF でビットの並びが違うので並べ直し、DXF にない DWG のビットは置かない。線の線種は番号で記録されているので置かない。

## 選択肢

1. 値の番号の並びが元と同じときだけ受け付け、欄を書き直す。項目と線の数と、表にない DWG の値は元のまま写す。
2. 項目と線の追加と削除も受け付ける。

2 は、辞書ではハンドルの並びの書き直しが、多重線の体裁では足した線の線種の番号が要る。

## 決定

選択肢 1 を採る。

- 辞書は、複製の扱い・所有する印・項目の名前を書き直し、項目の数は元のまま写す。読む側は 0 の所有する印を置かないので、置いた印は 1〜255 だけを受け付ける。ACDBDICTIONARYWDFLT も同じに扱う。
- 多重線の体裁は、説明・印・色・角度・線ごとの位置と色を書き直す。名前は図形から名前で指されるので、変更を受け付けない。印は DXF のビットを DWG のビットに並べ直し、DXF にない DWG のビットと、線の線種の番号は元のまま写す。DXF の印にないビットは受け付けない。
- 値の番号の並びが元と違う変更（項目や線の追加と削除、所有する印を置くかの変更）は受け付けない。

## 影響

- 手で組んだ R2000 の辞書と多重線の体裁で、複製の扱い・項目の名前・説明・印・角度・線の位置を変えて書き戻し、読み直した値が、変えた値で組んだものと同じになることを確かめた。多重線の体裁は、データも組んだものと同じになる。試料の図面の辞書の複製の扱いと、多重線の体裁の線の位置も変えて書き戻す。
- XRECORD と LAYOUT の欄の変更は、まだ書き戻せない。

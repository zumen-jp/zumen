# 0142: DXF・DWG の厚さとスプラインの節点・制御点の許容差は拡張 `dxf.entity` に控え、線種の生成とスプラインの当てはめの値は図面モデルの欄にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 提案 |

## 背景

DXF・DWG から図面モデル（Drawing2D）へ移すとき、図形の厚さ（39）と、LWPOLYLINE・POLYLINE の線種の生成（70 の 128）と、SPLINE の許容差（42・43・44）は「まだ移さない」としていた（#174）。診断も出さないので、黙って落としていた。

- **厚さ**: 平面の図形を Z の向きに押し出す長さである。上から見た形は変わらないので、平面の図面モデルの形には要らない。3D の見え方や、元の形式へ戻すときには要る。
- **線種の生成**: 線種の模様を頂点ごとに切らずに、ポリライン全体で続ける印である。表示の結果を変える。日本の測量図の試料（横須賀市の 3 つの図面）では、線種の生成を立てたポリラインが合わせて 137 本あった。
- **節点と制御点の許容差**: SPLINE の 42・43 は、スプラインを作り直すときの精度である。節点と制御点で決まる形は変えない。
- **当てはめの許容差と節点の取り方**: 当てはめる点で決めるスプラインでは、当てはめの許容差（44）と節点の取り方（弦の長さ・その平方根・等間隔）が、点から作る曲線の形を決める。R2013 からの DWG は、当てはめる点で決めるスプラインの制御点を書かないことがある（試料で確かめた）。そのとき、形はこの 2 つの値と当てはめる点だけで決まる。DWG の読み手は、R2013 からの節点の取り方（BL）を読み捨てている。日本の測量図の試料の SPLINE も、3 つの許容差を持っていた。

形式固有の情報は、[決定 0115](0115-drawing-format-extensions.md) の拡張（`Extension`）に置ける。[決定 0157](0157-drawing-model-fields-and-extensions.md)（提案）は、表示を変える値をモデルの欄にし、平面の図面モデルの範囲の外の値を形式固有の情報にするとした。

## 選択肢

1. 値の働きで分ける。厚さと節点・制御点の許容差は `dxf.entity` の拡張に、線種の生成と当てはめの許容差・節点の取り方は図面モデルの欄にする。
2. すべてを `dxf.entity` の拡張に控える（この決定の最初の案）。
3. 移さず、診断を出す。

2 は、線種の生成と当てはめの値という表示を変える値を、拡張を読まない表示する側から隠す。3 では、値が失われる。

## 決定

選択肢 1 を提案する。

- **`dxf.entity`。** 名前空間は `dxf.entity`、値の型の契約の版は 1。付く先は図形の要素で、名前は空、版は `$ACADVER`。どの欄もない図形は、この拡張を持たない。
  - `thickness`（実数）: LINE・CIRCLE・ARC・TEXT・LWPOLYLINE・POLYLINE・SOLID・TRACE・POINT・SHAPE の 39。0 でなければ置く。
  - `knot_tolerance`・`control_tolerance`（実数）: SPLINE の 42・43。あれば置く。
- **線種の生成。** `Polyline` に、線種の模様を頂点で切らずに続けるかの欄を足す。DXF・DWG は、70 の 128 で立てる。SXF・JWW の折れ線の模様の続き方は、それぞれの決定で確かめる。確かめるまでは立てない。
- **当てはめの値。** `Spline` に、当てはめの許容差と節点の取り方を足す。
  - 当てはめの許容差は 44 とする。
  - 節点の取り方は、DWG の R2013 からの BL を、弦の長さ（0）・その平方根（1）・等間隔（2）とし、ほかの値は知らない取り方として値を保つ（ObjectARX の `AcGe::KnotParameterization` の並び。推定）。DXF での置き場所は、AutoCAD で作った試料で確かめる。確かめるまでは、DXF の SPLINE の節点の取り方を持たない（`None`）。
- DWG は、表の値が DXF と同じなので、同じ扱いになる。試料の DWG と DXF の組で、厚さと 3 つの許容差が一致することを確かめた。

## 影響

- 表示する側は、当てはめる点だけのスプラインを、図面モデルの値だけで描ける。点から曲線を作る処理は、図面モデルの外に置く。
- 拡張を読む使い手は、`dxf.entity` を見れば厚さと節点・制御点の許容差を得られる。要素を変えると、付く先のハッシュが合わなくなり（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）、`is_current` が偽になる。
- 今の main は、線種の生成と当てはめの許容差を `dxf.entity` に置いている。この決定を採ったら、モデルの欄に移す。
- 図面モデルから DXF・DWG への書き戻し（[決定 0139](0139-drawing-apply.md)）は、元の表の値を残すので、この拡張を読まない。
- 欄を足すときは、版を上げずに `dxf.entity` に足してよい。意味を変えるときは版を上げる。

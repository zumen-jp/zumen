# 0110: 図面モデルの引出線つきの注記を枝と注記の組で持ち、寸法値の文字を区間に分ける

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0022](0022-drawing2d-semantics-and-format-mapping.md) は、引出線とバルーンを経路・端部・注記・囲みで持ち、組の意味がファイルから分からなければ幾何の集まりのまま保持することを決めた。寸法は、測定値・保存された文字・文字の上書きを別に持つ。[決定 0107](0107-drawing-dimensions-and-leaders.md) は、LEADER を経路と注記の出所で持ち、MULTILEADER を移さなかった。寸法値の上書きの文字は、書式の符号を含む元の文字列のままだった。[決定 0109](0109-drawing-formatted-text.md) で、書式つきの文字の区間ができた。

## 選択肢

1. 引出線つきの注記を新しい要素にし、枝（線の頂点・集まる点・折れ曲がり）と注記（書式つきの文字か記号）を 1 つの要素に持つ。寸法値の上書きの文字は、元の文字列と区間を両方持つ。
2. MULTILEADER を、LEADER の要素と注記の要素に分ける。
3. 寸法値の文字は、元の文字列のままにする。

## 決定

選択肢 1 を採る。MULTILEADER は枝と注記を 1 つの図形として持ち、分けると、どの枝がどの注記を指すかを出所でつなぎ直す必要がある。注記の記号は、バルーンなどの囲みを表す。寸法値の文字は、書式の符号と測定値を書く所を区間にしないと、測定値と上書きの区別が文字列の中に埋もれる。

- `Shape::Callout` は `Callout` を持つ。枝（`Branch`）は、線ごとの頂点・線が集まる点・折れ曲がり（`Dogleg`: 向きと長さ）を持つ。線の引き方（`PathKind`: 折れ線・曲線・描かない）・端部記号と大きさ・ランディングを描くか・倍率・元のスタイルの出所も持つ。
- 注記（`CalloutContent`）は、なし・書式つきの文字・記号とその属性の値（`AttributeValue`: 属性の定義の出所と値）を分ける。
- 寸法値の文字（`Label::Override`）は、元の内容と区間を持つ。区間の中身に、測定値を書く所（`Piece::Measurement`、DXF の `<>`）と、寸法線の下の文字の始まり（`Piece::Below`、DXF の `\X`）を足す。書式つきの文字では、どちらも解釈しない。
- DXF の MULTILEADER を移す。公差の注記と段組みの文字は、まだ移さない。
- 境界（`drawing` の op）の要約は、引出線つきの注記を数えず、範囲にも入れない。要約の欄は、要素の一覧の op（#66）と合わせて決める。

## 影響

- DWG の読み手は MULTILEADER を表に置かないので、DWG の引出線つきの注記は、まだ移らない。
- 線ごとの端部記号、線と注記の色・線種・線幅、注記の寄せ方の欄、属性の番号と幅は、まだ移さない。線と注記の色・線種・線幅は、後に[決定 0146](0146-drawing-callout-line-style.md) で移すことにした。
- 元の形式の色の値（AcCmColor）は、上の 1 バイトで RGB と色の番号を分ける。ほかの方式（ByLayer など）は読めないとする。この読み方は推定で、試料の図面で確かめていない。
- LEADER の注記の MTEXT は、LEADER とは別の書式つきの文字の要素として移り、LEADER が出所で指す。

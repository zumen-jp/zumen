# 設計の判断の記録

選択肢、選んだ理由、その影響を 1 件ずつ記録します。

- ファイル名は `NNNN-<主題>.md` にし、番号は 0001 からの連番にします。主題は英語の小文字とハイフンで書きます。
- 記録の採否は、その記録を書く PR の中で決めます。PR では状態を「採用」と書き、マージで採用とします。採らないときは、PR を閉じるか、記録を直します。
- 「提案」は、まだ採用していないことを表します。提案のまま main にある記録は、それを実装する PR か、採否だけを決める PR で決めます。
- main に入れた記録は、提案のままでも内容を書き換えません。判断を変えるときは新しい記録を書き、元の記録からリンクします。次の 2 つは例外にします。
  - 表記の基準（[docs/style.md](../style.md)）に合わせる直し。意味を変えないためです（[0021](0021-notation-and-terms.md)）。
  - 提案を採用にする PR で、記録を main の実装とこの規則に合わせる直し。
- 記録には、決めたことと、その理由・影響だけを書きます。どの PR で何を作ったかは PR に、何が残っているかは issue に（[作業の選び方](../work.md)）、形式ごとの対応の細部は [docs/formats](../formats/README.md) に書きます。
- 旧版（[zumen-jp/zumen-legacy](https://github.com/zumen-jp/zumen-legacy)）の記録は、「旧版の決定 0013」のように書いてリンクします。

```markdown
## 影響

## 参照
```

# 0093: R2010 から後の DWG に足した MTEXT・属性を持つ INSERT・SPLINE は、欄の形を確かめた版だけで書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG には、型ごとの欄が R2000 と同じ形の図形の足しを書き戻せる（[決定 0092](0092-dwg-r2010-write-back-entity-addition.md)）。MTEXT は R2010 から枠の高さ（46）を持ち、ATTRIB は属性の版（RC）と位置を固定するか（B）を持つ（[決定 0086](0086-dwg-r2010-write-back-strings.md)・[0087](0087-dwg-r2010-write-back-mtext-vertex.md)）。R2018 からは、MTEXT と属性の欄がさらに増える。SPLINE は、R2013 から欄の形が R2000 と異なり、変更もまだ書き戻せない。

## 選択肢

1. 変更の書き戻しで欄の形を確かめた版だけで、MTEXT・属性を持つ INSERT・SPLINE の足しを受け付ける。
2. R2018 の欄も推し量って、すべての版で受け付ける。
3. これらの足しは、まだ書き戻さない。

## 決定

選択肢 1 を採る。

- MTEXT は R2010・R2013 で足せる。変更と同じ欄の並びで書き、範囲の大きさは 0、背景の欄の前の B と背景の印（BL）は 0 にする。試料の R2010・R2013 の MTEXT は、どれもこの 2 つが 0 だった。値は枠の高さ（46）を持たなければならない。
- 属性を持つ INSERT と、その ATTRIB・SEQEND は R2010・R2013 で足せる。INSERT は、R2004 と同じく型ごとの欄の終わりに ATTRIB の数（BL）を持ち、すべての ATTRIB と SEQEND を固い所有で指す。ATTRIB の値は、2 つの 280 を持たなければならない。
- SPLINE は R2010 だけで足せる。
- R2018 からの MTEXT と属性、R2013 からの SPLINE、MINSERT、表のレコードとブロックの足しは、まだ受け付けない。

## 影響

- 試料の R2010・R2013 の図面に MTEXT と、属性を 2 つ持つ INSERT を、R2010 の図面に 3 種類の SPLINE を足して書き、読み直したものが足したものと合った。
- 書いた図面を AutoCAD で開いて確かめてはいない。

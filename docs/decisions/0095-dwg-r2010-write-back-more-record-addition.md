# 0095: R2010 から後の DWG に足した寸法の体裁・ビュー・ブロックは、版で増えた欄を試料の図面と同じ値で書いて書き戻す

| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG には、足した LAYER・STYLE・LTYPE・APPID を書き戻せる（[決定 0094](0094-dwg-r2010-write-back-table-record-addition.md)）。R2004 までは、寸法の体裁・ビュー・ビューポートの設定・ブロックも足せる（[決定 0065](0065-dwg-write-back-dimstyle-addition.md)〜[0068](0068-dwg-write-back-block-record-addition.md)）。試料の R2010・R2013・R2018 の図面を調べると、これらのレコードは R2004 より欄とハンドルが多かった。

- DIMSTYLE は、読む側の並びの増えた欄の後に B を 1 つ持ち、試料ではどれも偽だった。ハンドルは、文字の体裁と矢印のブロックの後に、寸法線と 2 つの補助線の線種（345〜347）が続く。
- VIEW は、描画の種類の後に照明の欄（B・RC・2 つの BD・CMC）を持つ。試料では、既定の照明を使い、種類は 1、明るさと対比は 0、環境の色は真の色の 0x333333 だった。UCS の欄の後に B を 1 つ持ち、偽だった。ハンドルは、外部参照のブロックの後に背景・表示スタイル・太陽を、最後に断面の表示を指す。
- ブロックのレコードは、絵の大きさの後に、挿す単位（BS）・分解できるか（B）・尺度を揃えるか（RC）を持つ。試料の多くは、単位なし・分解できる・揃えないだった。
- VPORT は、読む側がまだ R2010 の欄を読めない。

## 選択肢

1. 寸法の体裁・ビュー・ブロックを、増えた欄に試料の図面と同じ値を書いて足せるようにし、ビューポートの設定はまだ受け付けない。
2. ビューポートの設定も、欄の形を推し量って足せるようにする。
3. これらの足しは、まだ書き戻さない。

## 決定

選択肢 1 を採る。

- DIMSTYLE は、読む側と同じ並びで増えた欄も書き、偽の B を続け、345〜347 には線種を指すハンドルか 0 を書く。R2010 からは文字の背景の色も 70 に置かれるので、70 を 2 つ持つ値は受け付けない。
- VIEW は、照明の欄とカメラの B を試料の図面と同じ値で書く。背景・表示スタイル・太陽・断面の表示は持たない（0）ものとする。
- ブロックのレコードは、挿す単位を 0、分解できる、尺度を揃えないとして書く。足したブロックの BLOCK・ENDBLK と、ブロックの持つ図形も足せる。
- ビューポートの設定と UCS のレコードの足しは、まだ受け付けない。

## 影響

- 試料の R2010・R2013・R2018 の図面に、ビューポートの設定のほかの表のレコードと、それを使う LINE・TEXT と、線を 1 本持つブロックとそれを挿す INSERT を足して書き、読み直したものが足したものと合った。書き戻した図面にもう一度足しても合った。
- 試料の図面のビューは、表示スタイルを指していた。足したビューは表示スタイルを指さない。書いた図面を AutoCAD で開いて確かめてはいない。

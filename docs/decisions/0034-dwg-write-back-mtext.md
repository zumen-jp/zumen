# 0034: DWG（R2000）への書き戻しは、MTEXT の表にない欄を元のビットから写して符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0032](0032-dwg-write-back-text-insert.md)・[決定 0033](0033-dwg-write-back-attributes.md) で、TEXT・INSERT・ATTRIB・ATTDEF の型ごとの欄を R2000 の DWG に書き戻せるようにした。MTEXT の型ごとの欄には、表に置かない欄がある。

- 文字の範囲の大きさ（2 つの BD）は、DXF にないので表に置かない。
- 行の間隔（44）の後の B も、表に置かない。
- 文字列は、DXF と同じく 250 バイトずつの 3 と、残りの 1 に分けて表に置く。

## 選択肢

1. 表にない欄は、元のデータの型ごとの欄を読んで位置を決め、そのビットを写す。
2. 表にない欄は、既定の値（0 など）を書く。

2 は、文字の範囲の大きさを変えてしまう。

## 決定

選択肢 1 を採る。

- 元のデータの型ごとの欄を読み、文字の範囲の大きさと、行の間隔の後の B の位置を決めて、元のビットを写す。
- ほかの欄は表の値から符号化する。押し出しの向きと X 軸の向きは、なければ (0, 0, 1)・(1, 0, 0) を書く。
- 文字列は、3 の値を並びの順に、続けて 1 をつなぎ、`^` の書き方を戻して終わりの NUL を付けて書く。文字列でない 3 は `dwg.change.unsupported` を返す。

## 影響

- 手で組んだ R2000 の MTEXT の文字列・高さ・合わせ・X 軸の向き・行の間隔を変えて書き戻し、レコードのバイト列が、文字の範囲の大きさを残して組んだものと同じになることを確かめた。試料の図面の MTEXT も点を動かして書き戻す。
- 文字列の長さを変えると、読み直したときの 3 と 1 の分け方は変わる。
- LWPOLYLINE・SPLINE・HATCH などの型ごとの欄の変更は、まだ書き戻せない。

# 0088: R2010 から後の DWG の DIMENSION・HATCH・TOLERANCE・VIEWPORT・SHAPE は、版ごとの欄を読み分けて書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG は、文字列の流れと一緒に型ごとの欄を書き直せる（[決定 0086](0086-dwg-r2010-write-back-strings.md)・[0087](0087-dwg-r2010-write-back-mtext-vertex.md)）。DIMENSION・TOLERANCE・VIEWPORT・SHAPE の符号化は、写す欄の位置を R2000 の形で元のデータから読み、ハンドルの流れの位置も R2000 の形で求めていた。DIMENSION は R2010 から初めに寸法の版（RC）と、測った値の後に 3 つの B を持ち、VIEWPORT はグリッドの向きの後に主なグリッドの線の間隔（BS）を持つ。HATCH のグラデーションの名前は、文字列の流れの初めにある。

## 選択肢

1. 写す欄の位置を版の形で読み、R2010 で増えた欄は元のビットを写すか表から書き、文字列は文字列の流れに書く。
2. R2010 から後の符号化を、種類ごとに別に作る。
3. これらの種類は、まだ書き戻さない。

## 決定

選択肢 1 を採る。R2000 と R2004 の符号化を、版と主のデータの終わりを受け取る形にして使い回す。

- DIMENSION は、寸法の版と 3 つの B を元のビットから写す。
- VIEWPORT は、主なグリッドの線の間隔を表の 61 から書く。
- HATCH は、グラデーションの欄を R2010 の形で読み飛ばして写し、文字列の流れの初めのグラデーションの名前（TU）も写してから、模様の名前などを続ける。
- TOLERANCE・SHAPE は、写す欄の終わりを主のデータの終わりとする。
- LEADER は、試料の R2010 から後の図面になく確かめられないので、まだ受け付けない。

## 影響

- 試料の R2010・R2013・R2018 の図面で、これらの種類の点を動かし、文字列に日本語を足して書き、読み直した表が変えた表と同じになった。
- R2010 から後に受け付けない図形の変更は、LEADER、R2018 の ATTRIB・ATTDEF、R2013 からの SPLINE、MINSERT、回転を持つ INSERT になった。
- 書いた図面を AutoCAD で開いて確かめてはいない。

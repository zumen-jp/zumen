# 0165: 図面モデルの変更で寸法スタイルの名前と端部記号を変え、寸法スタイルを足し、除く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

図面モデルは寸法スタイルの表を持つ（[決定 0108](0108-drawing-symbols-hatches-arrowheads.md) の `DimensionStyle`）。寸法スタイルは、名前・寸法線の両端と引出線の端部記号・端部記号の大きさ・斜線の大きさ・倍率を持つ。境界の `tables` は寸法スタイルを ID・名前・ハッシュで返す（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）。レイヤ・文字スタイル・線種の表は、[決定 0162](0162-drawing-layer-changes.md)・[決定 0163](0163-drawing-text-style-changes.md)・[決定 0164](0164-drawing-line-type-changes.md) で変えられるようになった。しかし、寸法スタイルはまだ変えられず、新しい寸法スタイルも作れない。図面を整える人と AI は、寸法スタイルの名前を社内や発注者の規則に合わせ、端部記号を建築の図面で使う斜線や黒丸に変え、縮尺に合わせて大きさと倍率を変える。

AutoCAD の系統の寸法スタイル（DIMSTYLE の表のレコード、DXF Reference「DIMSTYLE」）は、名前（2）と寸法の変数の値を持つ。端部記号の大きさは 41（DIMASZ）、斜線の大きさは 142（DIMTSZ）、倍率は 40（DIMSCALE）にある。R2000 からは、端部記号をブロックのレコードのハンドルで指す。両端が同じなら 342（DIMBLK）、両端を別にするなら 173（DIMSAH）を 1 にして 343・344（DIMBLK1・DIMBLK2）、引出線は 341（DIMLDRBLK）を使う。DXF のレコードは、ハンドルを 5 でなく 105 に書く。

DXF の寸法・引出線・公差は、寸法スタイルを名前（3）で指す。今の寸法スタイル（`$DIMSTYLE`）も名前で指す。DWG の図形は、寸法スタイルをハンドルで指す。名前に `$` を持つ寸法スタイル（`Standard$0` など）は、寸法の種類ごとの子の寸法スタイルで、親の名前から決まる。AutoCAD では、Standard の名前は変えられず、除けない。

## 選択肢

1. `Edit` に、寸法スタイルを置き換える変更・足す変更・除く変更を加える（0162〜0164 と同じ形）。
2. 寸法スタイルのすべての寸法の変数を、図面モデルに足してから変えられるようにする。

2 は、図面モデルの寸法スタイルを大きく広げ、寸法の描き方（部品の作り直し）と合わせて決める必要がある。この決定では、図面モデルが今持つ欄だけを変える。

## 決定

選択肢 1 を採る。

- **変更。** `Edit::ReplaceDimensionStyle { target, style }` は、指した寸法スタイルの名前と定義を、渡した寸法スタイルのもので置き換える。`Edit::AddDimensionStyle { style }` は寸法スタイルを足し、`Edit::RemoveDimensionStyle { target }` は除く。指し方はレイヤと同じく、ID（`id::dimension_style`）と読んだときのハッシュ（`Hash::dimension_style`）とする。出所は使わない。
- **結果。** apply は、置き換えた寸法スタイルの ID と、足した寸法スタイルのハンドルで作る ID（`dimension-style/h40`）と、書き戻した後のハッシュを返す。除いたものは ID もハッシュも持たない。
- **書ける定義。**
  - 大きさ・斜線の大きさ・倍率は、有限で負でない数だけを書く。斜線を描くなら、その大きさは正の数とする。
  - 端部記号は、既定の矢印か、ブロックの名前空間（`dxf.block`）の記号で、同じ名前のブロックのレコードがあるものだけを書く。
  - 端部記号は、元と変わったときだけ書き直す。両端が同じなら、173 を 0 にして 342 を書き、343・344 を除く。両端が別なら、173 を 1 にして 343・344 を書く。
- **決まり。** 次の変更は `change.edit.unsupported` にして、一覧全体を当てない。
  - 名前が空か、使えない文字か `$` か前後の空白を持つか、ほかの寸法スタイル（足したもの・名前を変えたものを含む）と重なる（大文字と小文字を区別しない）。
  - Standard・子の寸法スタイル・子を持つ寸法スタイル・外部参照に依る寸法スタイルの名前を変える。
  - 端部記号を変える先が、R2000 より前の DXF か DWG。R2000 より前の DXF は端部記号をハンドルで持たない。DWG の書き戻しは、端部記号のハンドルを書く欄を持たない。足す寸法スタイルも、端部記号は既定の矢印だけにする。
  - 同じ寸法スタイルを 1 つの一覧で 2 度変える。形式の版が持てない値を書く。
- **DXF。**
  - 置き換えは、元のレコードの 2・40・41・142 と、端部記号が変わったときの 173・341〜344 だけを書き直し、ほかの値は写す。
  - 名前を変えたら、寸法・引出線・公差の 3 と、ヘッダーの変数の 2（`$DIMSTYLE`）も新しい名前にする。
  - 寸法・引出線・公差と寸法スタイルのレコードと辞書でないオブジェクトが、名前と同じ文字列（3）を持てば、名前で指すかどうか分からないので当てない。辞書の 3 は項目の名前で、項目はハンドルで指す。
  - 足すときは、Standard のレコードを写す。Standard がなければ、表の初めの子でない寸法スタイルを写す。ハンドル・区切り・拡張辞書と反応子の組・拡張データ・端部記号を除いてから同じ欄を書き、新しいハンドルを 105 に置いて、寸法スタイルの表の ENDTAB の前に置く。
- **DWG。**
  - 図形は寸法スタイルをハンドルで指すので、名前を変えてもレコードの名前だけを書き直す。R2010 から後のレコードの名前は、0162 のレイヤと同じく文字列の流れの初めに書く。
  - 足すレコードは、[決定 0094](0094-dwg-r2010-write-back-table-record-addition.md) の書き方で書く。
  - 除くときは、レコードを除き、寸法スタイルの表のオブジェクト（DIMSTYLE_CONTROL）の項目の並びから、そのハンドルを除く。項目の後ろのハンドルが指す寸法スタイルは、意味が分からないので除かない。
- **除去。** 次の寸法スタイルは除けず、`change.edit.unsupported` にする。
  - Standard・子の寸法スタイル・子を持つ寸法スタイル・外部参照に依る寸法スタイル。
  - 拡張辞書か反応子（102・360）を持つもの、ハンドルのないもの。後ろにハンドルのない寸法スタイルがあるもの。その ID は並びの番号なので、除くと変わる。
  - ほかのオブジェクトが指すもの。すべてのオブジェクトの値のうち、寸法スタイルのハンドルを指すものと、名前（3）を持つもの（寸法スタイルのレコードと辞書を除く）を探す。ヘッダーの変数も探す。DXF の寸法スタイルの表の 340 が指すものも含む。
- **境界。**
  - 新しい小版で、`apply` に変更の種類 `dimension_style`・`add_dimension_style`・`remove_dimension_style` を足す。`dimension_style` は書いた欄だけを変える。`add_dimension_style` の書かない欄は、Standard（なければ初めの子でない寸法スタイル）と同じにする。
  - 端部記号はブロックの名前で書き、空の名前は既定の矢印とする。斜線の大きさは、0 なら描かない。
  - `tables` の寸法スタイルの項目は、端部記号・大きさ・斜線の大きさ・倍率も返す。

## 影響

- 人と AI が、寸法スタイルの名前・端部記号・大きさ・斜線・倍率を変え、寸法スタイルを足し、除いて、元の DXF・DWG に書き戻せる。
- 寸法の部品（DIMENSION の指すブロック）は作り直さない。寸法スタイルを変えた寸法の見た目は、AutoCAD が寸法を描き直すまで元のまま。
- 図面モデルが持たない寸法の変数（文字の高さ・補助線の長さ・丸めなど）は、まだ変えられない。DWG の寸法スタイルの端部記号も変えられない。SXF・JWW の寸法スタイルの書き戻しも、まだない。
- 書き直した DWG を AutoCAD が開けるかは、AutoCAD を持つ環境で確かめる。

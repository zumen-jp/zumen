# 0036: DWG（R2000）への書き戻しは、SPLINE の場合を元のまま保ち、それに合うフィールドを符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0035](0035-dwg-write-back-lwpolyline.md) までで、LWPOLYLINE までの型ごとのフィールドを R2000 の DWG に書き戻せるようにした。R2000 の SPLINE の型ごとのフィールドは、初めの場合（scenario）で形が分かれる。

- 場合 1 は、有理・閉じている・周期的のフラグ、ノットと制御点の許容差、ノット、制御点（重みがあれば重みも）を持つ。
- 場合 2 は、フィット許容差、始まりと終わりの接線、フィット点を持つ。

読む側は、有理・閉じている・周期的のフラグを表に置かない。接線は、0 でなければ表に置く。

## 選択肢

1. 場合は元のままとし、表の値がその場合に合わなければ受け付けない。
2. 表の値から場合を選び直す。

2 は、場合 2 から 1 に変えると、表にない有理・閉じている・周期的のフラグを決められない。

## 決定

選択肢 1 を採る。

- 場合 1 は、有理・閉じている・周期的のフラグを元のビットから写し、許容差（42・43）・ノット（40）・制御点（10〜30）を表の値から書く。重みがあるかのフラグは、41 があるかから選ぶ。重みは、すべての制御点にあるか、どれにもないかのどちらかだけを受け付ける。
- 場合 2 は、許容差（44）・接線（12・13）・フィット点（11〜31）を書く。接線がなければ 0 を書く。
- 場合に合わない値（場合 1 のフィット点や 44、場合 2 のノットや制御点）があるもの、ノット・制御点・フィット点の数が 72・73・74 と合わないものは、`dwg.change.unsupported` を返す。

## 影響

- 手で組んだ R2000 の SPLINE で、場合 1 の制御点を動かして重みを外し、場合 2 のフィット点を動かして終わりの接線を足して書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。サンプルの図面の SPLINE も点を動かして書き戻す。
- 場合を変える変更は、まだ書き戻せない。
- HATCH などの型ごとのフィールドの変更は、まだ書き戻せない。

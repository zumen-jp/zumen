# 0063: DWG（R2000）への書き戻しで足す線種は、形も文字もない要素だけのものを線種の表のオブジェクトの項目の終わりに加える

## 背景

[決定 0061](0061-dwg-write-back-layer-addition.md)・[0062](0062-dwg-write-back-style-addition.md) で、表の終わりに足した画層と文字の体裁を、R2000 の DWG に書き戻せるようにした。線種の追加は、まだ拒んでいた。

R2000 の線種のレコード（型 0x39）は、名前から外部参照に依る印までの欄がほかの表のレコードと同じで、その後に説明（TV）・長さ（BD）・揃え（RC）・要素の数（RC）・要素ごとの欄・文字の要素の文字列を詰める 256 バイトの領域が続く。要素ごとの欄は、長さ（BD）・形の番号（BS）・ずれ（RD 2 つ）・尺度と回転（BD）・印（BS）で、ハンドルの流れには、外部参照のブロックの後に要素ごとの形のファイルの文字の体裁のハンドルが続く。形や文字を持つ要素は、形の番号や文字列と、それを持つ文字の体裁が要る。

試料の R2000 の図面の、形も文字もない要素は、どれも形の番号 0・ずれ 0・尺度 1・回転 0 だった。

## 選択肢

1. 形も文字もない要素だけの線種を受け付け、一から符号化して、所有者の線種の表のオブジェクトの項目の終わりに足す。形や文字を持つ要素の線種は拒む。
2. 形や文字を持つ要素の線種も受け付ける。
3. 線種の追加は、これまでどおり拒む。

## 決定

選択肢 1 を採る。破線や一点鎖線のような線種は、形も文字もない要素だけで書ける。形や文字を持つ要素は、文字の体裁のハンドルと文字列の領域の位置を決めることが要り、確かめる試料もまだ少ないので、後に回す。

- 足した線種は、画層と同じく、ハンドルが HANDSEED より小さくなく、名前（2）が表のほかの線種と同じでないものだけを受け付ける。
- 印（70）は 0、説明（3）・揃え（72）・要素の数（73）・長さ（40）が要り、要素の数だけ、長さ（49）と印 0（74）の組が続かなければならない。
- 要素の形の番号・ずれ・尺度・回転は、試料と同じく 0・0・0・1・0 とし、要素ごとの文字の体裁のハンドルは空にする。文字の領域は 0 で埋める。
- 足した図形や画層は、足した線種を名前で指せる。

## 影響

- 手組みのファイルで、線と空きの線種と、その線種の LINE を足して書き戻した。読み直した表は、足した表と同じになった。表にある名前・外部参照に依る印・数の合わない要素・文字の要素を持つ線種は拒んだ。
- 試料の R2000 の図面にも、画層と文字の体裁と線種と、それらを使う LINE と TEXT を足して書き戻し、書き戻した図面にもう一度足した。読み直した表は同じになり、CRC の診断も出なかった。線種の表のオブジェクトの項目の数は、書き戻すたびに 1 ずつ増えた。
- 足した線種を、AutoCAD で開いて確かめてはいない。
- 形や文字を持つ要素の線種と、ほかの表のレコード（ブロック・寸法の体裁など）の追加は、まだ書き戻せない。

# 0096: R2010 から後の DWG の VPORT は、照明と格子のフィールドを読み分け、変更と追加を書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2010 から後の DWG の VPORT を、読む側は R2000 と同じフィールドの並びで読んでいた。そのため値を置けず、変更も足しも書き戻せなかった（[決定 0095](0095-dwg-r2010-write-back-more-record-addition.md)）。サンプルの R2010・R2013・R2018 の図面を調べると、VPORT は VIEW と同じく描画の種類の後に照明のフィールド（B・RC・2 つの BD・CMC）を持っていた。UCS のフィールドの後には、2 つの BS（格子のフラグと主の線の間隔）が主のデータの終わりまで続いた。ハンドルは、外部参照のブロックの後に背景・表示スタイル・太陽を指し、その後に名前の UCS と基準の UCS が続いた。

## 選択肢

1. 照明と格子のフィールドを読み分け、値には置かずに、変更では元のビットを写し、足しではサンプルの図面と同じ値を書く。
2. 照明と格子のフィールドも、DXF のグループ・コード（292・282・141・142・63・60・61）で値に置く。
3. VPORT は、まだ書き戻さない。

## 決定

選択肢 1 を採る。VIEW の照明のフィールド（[決定 0089](0089-dwg-r2010-write-back-records.md)）と扱いを揃える。

- 読む側は、照明のフィールドと 3 つのハンドルを読み飛ばす。格子の 2 つの BS は、型ごとのフィールドの後に残る。
- 変更では、照明のフィールドと格子のフィールドを元のビットから写す。
- 足すときは、照明のフィールドを VIEW と同じ値で書き、格子のフラグを 3、主の線の間隔を 5 とする。サンプルの図面の VPORT の多くがこの値だった。背景・表示スタイル・太陽は持たない（0）ものとする。

## 影響

- サンプルの R2010 から後の図面の VPORT の高さを変えて書き、読み直したものが変えたものと合った。
- サンプルの図面に、今の VPORT を写して名前を変えたものを足して書き、読み直したものが足したものと合った。
- 照明と格子のフィールドは、DXF に移すと失われる。書いた図面を AutoCAD で開いて確かめてはいない。

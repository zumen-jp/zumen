# 0044: DWG（R2000）への書き戻しは、LTYPE の要素の数と形と文字の印を変えず、変わった文字列は領域に詰め直す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0043](0043-dwg-write-back-layer-style.md) で、LAYER と STYLE の表のレコードの欄を R2000 の DWG に書き戻せるようにした。LTYPE は、まだ書き戻せない。

読む側は、LTYPE の説明（3）・揃え（72）・要素の数（73）・長さ（40）と、要素ごとの長さ（49）と印（74）を置く。形か文字の要素は、形の番号（75）・尺度（46）・回転（50）・ずれ（44・45）と、文字の要素なら文字列（9）も置き、形のファイルの文字の体裁のハンドル（340）をハンドルの流れから引く。DWG の文字の要素は、形の番号の欄に、256 バイトの領域の中の文字列の位置を持つ。

## 選択肢

1. 要素の数と、要素ごとの形と文字の印を変えないものだけを受け付ける。
2. 要素の足し引きと、形か文字の要素への変更も受け付ける。

2 は、要素ごとの 340 のハンドルの数が変わるので、ハンドルの流れを作り直す必要がある。

## 決定

選択肢 1 を採る。

- 要素の数（73）と、要素ごとの形と文字の印（74 の 2・4）が元のものと違えば受け付けない。74 の 1（回転が絶対）は書き換え、7 より上の印のビットは元のまま写す。
- 形も文字もない要素の形の番号・ずれ・尺度・回転は、表にないので元のまま写す。
- 回転（50）は度からラジアンに直す。文字の要素の 75 は 0 でなければ受け付けない。
- 説明が変わらなければ元のビットを写す。文字列（9）がどれも変わらなければ、領域と文字列の位置を元のまま写す。変われば、文字列を領域の初めから順に終わりの NUL を付けて詰め直し、収まらなければ受け付けない。
- 外部参照に依る印（70 の 16）は、元のものと同じでなければ受け付けない。

## 影響

- 手で組んだ R2000 の LTYPE で、説明・長さ・要素の長さ・文字の要素の尺度・回転・文字列を変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の線種の要素の長さも変えて書き戻す。
- 要素の足し引きは、まだ書き戻せない。VIEW・UCS・VPORT・DIMSTYLE などのほかの表のレコードと、OBJECTS のオブジェクトの欄の変更も、まだ書き戻せない。

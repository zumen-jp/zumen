# 0083: R2010 から後の DWG のオブジェクトは、ハンドルの流れの大きさ（MC）から始まるデータで置き換え、除き、足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2004 の DWG は、`DwgTxn` でオブジェクトのデータを置き換え、除き、足せる（[決定 0071](0071-dwg-r2004-object-edit.md)）。R2010・R2013・R2018 は R2004 と同じ入れ物を使い（[決定 0027](0027-dwg-r2010-reading.md)）、オブジェクトは大きさ（MS）の後に、ハンドルの流れのビットの数（MC）を持ち、型を BOT で表す。MS は MC を除いたデータのバイトの数で、ハンドルの流れはデータの終わりにある。これまで `DwgFile::object_data` は MC の後のデータを返していたので、それを `DwgTxn::set_data` に渡してもハンドルの流れの位置が分からない。

## 選択肢

1. オブジェクトのデータを、R2000・R2004 と同じく「MS の後から CRC の前まで」とし、R2010 からは MC を含めて受け渡す。
2. MC の後のデータと、ハンドルの流れの位置を別に受け渡す。
3. R2010 から後は、まだ変えない。

## 決定

選択肢 1 を採る。どの版でも、`object_data` が返すものをそのまま `set_data` と `add` に渡せる。

- `object_data` は、R2010 からは MC から CRC の前までを返す。
- `set_data` と `add` は、R2010 からは MC を読み、その後の BOT で型を読む。MC を読めないデータと、ハンドルの流れが MC の後のデータより大きいデータは受け付けない。
- 確定では、R2004 と同じく展開したオブジェクトの区切りの後ろにオブジェクトを足し、地図を作り直す。MS は MC を除いたバイトの数で書き、CRC は MS からデータの終わりまでで求める。
- 見出しの変数の変更と、共有の表からの書き戻しは、これまでどおり R2004 までとする。

## 影響

- 試料の R2010・R2013・R2018 の図面で、すべてのオブジェクトを同じデータで置き換え、最後のオブジェクトを除いて書き、読み直した表が、除いたものを除いて元と同じになった。
- 合成の R2010 の入れ物に、MC と型だけのオブジェクトを足して書き、読み直したオブジェクトが同じデータを持った。
- `AcDb:ObjFreeSpace` の区切りは直さない。書いた図面を AutoCAD で開いて確かめてはいない。

# 0191: MULTILEADER の変換・文字の書き直し・DWG の値の書き戻しと、注記の反応子を足す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0185](0185-drawing-apply-leader-and-callout-write-back.md) は、引出線の書き戻しで次を残した（#344）。

- 足した注記つきの LEADER の注記の MTEXT に、反応子（330）を書かない。
- LEADER の 212・213（注記からのずれ）を、変換で写さない。
- MULTILEADER の追加・変換・注記の書き直しと、DWG の MULTILEADER の書き戻しを断る。

## 選択肢

1. 残りを断ったままにする。
2. 文書にある MLEADERSTYLE と MULTILEADER から作れるもの、読み手が読む欄だけで書けるものに限って足し、推定が要るものは断る。
3. 足りない値を推定して、すべてを書く。

## 決定

選択肢 2 を採る。

- **反応子**: 注記つきの LEADER を足すと、注記の MTEXT に `102 {ACAD_REACTORS` の組を作り（あれば続けて）、足した LEADER の handle を 330 で書く。DWG では、実体の共通の部分の反応子の数（BL）を増やし、handle の流れの持ち主の後に軟らかい参照（4）を足す。R2000・R2004 は handle の位置（RL）を、R2010 以降は大きさ（MC）を直す。全版で書く。
- **212・213**: 変換は、212・213 を線形の部分だけで写す（平行移動を含めない）。DWG でも、値が元と同じに符号化できなければ新しい値を書く。
- **MULTILEADER の変換**: 回転と平行移動（尺度 1 の相似、鏡映なし）で、注記が文字かなしのものだけを写す。枝の点・鉤の向き・注記の基点・文字の位置と向き・平面の原点と軸・文字の回転（42）を写す。尺度を変える変換は、大きさがスタイルから来るか上書きか（90 の旗）を推定することになるので断る。鏡映は文字の反転を表せないので断る。記号の注記は、変換の行列（47）の扱いを確かめていないので断る。
- **MULTILEADER の文字の書き直し**: 文字の内容だけが変わり、書式の区切りが内容から読み直したものと同じで、改行がなく 250 バイト以下なら、文脈の 304 を書き直す。注記の位置の変更は、基点・平面・着地が結びつくので断る。
- **MULTILEADER の追加**: 断る。文脈のデータの注記の基点・平面の原点・着地と付き方・上書きの旗（90）は、MLEADERSTYLE と既存の MULTILEADER からは決まらず、推定になる。
- **DWG の MULTILEADER**: R2000・R2004 で、値の数と code が変わらず実数（BD）だけが変わる変更を、読み手の読んだビットの範囲に書き直す。同じ頂点の数の枝の置き換えと変換がこれに当たる。頂点の数の変更・文字・handle の変更と、R2010 以降（文字列の流れを持つ見本がない）は `dwg.change.unsupported` で断る。

断るものは、既存の診断（`change.edit.unsupported`・`dwg.change.unsupported`）で知らせ、ファイルを変えない。

## 影響

- 足した LEADER は、AutoCAD が注記を動かすと追うことが期待できる。
- MULTILEADER の追加・尺度を変える変換・鏡映・注記の位置の変更・記号の注記の変換は残る。
- DWG の MULTILEADER の文字の書き直しと、R2010 以降の書き戻しは残る。
- 書き戻した MULTILEADER と反応子は、AutoCAD でまだ開いて確かめていない。

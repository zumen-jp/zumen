# 0047: DWG（R2000）への書き戻しは、OBJECTS のうち GROUP と DICTIONARYVAR のフィールドを書き直し、図形の数は変えない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0046](0046-dwg-write-back-dimstyle.md) までで、LAYER・STYLE・LTYPE・VIEW・UCS・VPORT・DIMSTYLE の表のレコードのフィールドを R2000 の DWG に書き戻せるようにした。APPID と BLOCK_RECORD は、名前と外部参照に依るフラグのほかに表に置くフィールドを持たないので、書き戻すフィールドはない。OBJECTS のオブジェクトのフィールドは、まだ書き戻せない。

読む側は、GROUP の説明（300）・名前のないフラグ（70）・選べるフラグ（71）と、図形の数だけのハンドルの並びの図形（340）を置く。DICTIONARYVAR は、型（280）と値（1）を置く。SCALE は R2007 からの型なので、R2000 の書き戻しには出てこない。

## 選択肢

1. GROUP と DICTIONARYVAR のフィールドを書き直し、ハンドルの並びから作る値（GROUP の図形）の変更は受け付けない。
2. GROUP の図形の追加と削除も受け付け、図形の数とハンドルの並びを作り直す。

2 は、ハンドルの並びの書き直しが要る。ハンドルの並びの変更は、まだどの書き戻しも扱わない。

## 決定

選択肢 1 を採る。

- GROUP は、説明・名前のないフラグ・選べるフラグを書き直し、図形の数は元のまま写す。フラグは 0 と 1 だけを受け付ける。
- DICTIONARYVAR は、型（RC）と値を書き直す。RC に収まらない型は受け付けない。
- 図形（340）など、ハンドルの並びから作る値の変更は受け付けない。

## 影響

- 手で組んだ R2000 の GROUP と DICTIONARYVAR で、説明・フラグ・型・値を変えて書き戻し、読み直した値が、変えた値で組んだものと同じになることを確かめた。サンプルの図面の DICTIONARYVAR の値も変えて書き戻す。
- MLINESTYLE・DICTIONARY・XRECORD・LAYOUT のフィールドの変更は、まだ書き戻せない。

# 0239: 土木の図の作図の値はプロファイルの語彙から読み、civil_drawing の op で DXF の文書にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-02 |
| 状態 | 採用 |

## 背景

[決定 0231](0231-civil-drawings.md) で、土木の図（平面図・縦断図・横断図）の尺度・文字の高さ・測点の間隔は変換の引数で渡し、既定は作図の慣習の値にした。プロファイルから読むことと、境界から図を出すことは、別の作業にした（#470）。

決めることは、次のとおり。

- 作図の値を、プロファイルのどこに書くか。
- 文字の高さの選び方。
- 境界の op の形と、作った図の渡し方。

## 選択肢

1. **作った図を新しい DXF の文書として開く。** `scene` と `check` は、文書の名前で図を受けるので、そのまま使える。DXF には用紙を 1 枚だけ書ける（[決定 0206](0206-convert-to-new-dxf.md)）ので、用紙を選ぶ。
2. **図面モデルのまま、セッションの新しい置き場に持つ。** 用紙をすべて持てるが、`scene`・`check`・`close`・名前の重なりの確かめを、置き場ごとに直すことになる。

## 決定

1 にする。

- **語彙。** プロファイルの語彙 `civil-drawing` の 1 つ目の値に、`plan`・`horizontal`・`vertical`・`cross-section`（尺度の分母）と `station-pitch`（測点の間隔、メートル）を書く。書かない欄は、既定の値のままにする。値が正の有限の数でなければ、`profile.vocabulary.invalid` で失敗にする。CAD製図基準は図ごとの尺度を決めないので、`mlit-cad` のプロファイルには、尺度の語彙の優先する仮数から作図の慣習の値（決定 0231 の既定）を `basis = "chosen"` で置く。
- **文字の高さ。** 語彙 `text-height` から選ぶ。既定の 2.5 mm が語彙にあればそれを、なければ 2.5 mm より大きいいちばん小さい値を、それもなければいちばん大きい値を使う。
- **op。** `civil_drawing` は、open で開いた J-LandXML の文書（`doc`）の線形（`id`）から図面モデルを作り、用紙（`sheet`、書かなければ平面図）を 1 枚選んで、新しい DXF の文書（`to`）として開く。縦断図は用紙の要素に焼き込む（[決定 0238](0238-bake-anisotropic-views.md)）。結果に、作った用紙の名前の列と、使った作図の値と、プロファイルの鎖を返す。プロファイルは `profiles` と `profile` を一緒に書く。
- 図面のモジュールに置き、スキーマの小版を 51 に上げる。
- DXF に書く用紙の大きさ（PLIMMAX）は、図面の単位（INSUNITS）で書く。これまで mm のまま書いていたので、メートルの図面を読み直すと、用紙の大きさが 1000 倍になっていた。

## 結果

- 適合試験の `civil_drawing` の組で、プロファイルの値で縦断図を作り、作った文書を `scene` に渡す。
- 用紙を 1 枚ずつ作るので、平面図・縦断図・横断図をすべて出すには、op を用紙ごとに呼ぶ。
- 選んだ用紙が置く空間だけをモデル空間に書き、平面図と横断図の相似のビューはビューポートで書く（[決定 0240](0240-write-similar-views-as-viewports.md)、#480）。

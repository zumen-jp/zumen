# 0052: DWG（R2000）への書き戻しは、表の終わりに足した単純な図形を一から符号化し、ブロックの並びの終わりに繋いで HANDSEED を進める

| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0051](0051-dwg-write-back-entity-removal.md) で、表から除いた図形を R2000 の DWG に書き戻せるようにした。表に足したオブジェクトは、まだ書き戻せない。

足す図形には、元のデータがない。共通の欄と型ごとの欄とハンドルの流れを、一から組まなければならない。新しいハンドルは、ほかのオブジェクトと重なってはならず、見出しの変数の HANDSEED より小さくてはならない。HANDSEED は見出しの変数の区切りの中にあり、その大きさを変えると後ろの変数のビットがずれる。

## 選択肢

1. 表の終わりに足した、型ごとのハンドルを持たない図形だけを一から符号化する。ハンドルは表の図形に付けてもらい、HANDSEED より小さくないことを確かめる。所有者のブロックのレコードの図形の並びの終わりに繋ぎ、HANDSEED を足した図形の後ろに進める。HANDSEED の大きさ（バイト）が変わるときは受け付けない。
2. ハンドルを書き戻す側で払い出す。
3. 見出しの変数の区切りを、ファイルの後ろに作り直す。

2 は、書き戻した後の表と、読み直した表のハンドルが食い違う。3 は、HANDSEED のほかの変数を読み飛ばすだけで、作り直せるほど読めていない。

## 決定

選択肢 1 を採る。

- 足せるのは、LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE。値は、ハンドル（5）・所有者（330）・画層（8）・線種（6）・用紙空間の印（67）と、共通の欄の色（62）・線種の尺度（48）・非表示（60）と、型ごとの欄のものだけ。
- 足した図形は、表の終わりに置く。ハンドルは、今の HANDSEED から表の順に大きくする。`DwgFile::handle_seed` で HANDSEED を読める。
- 所有者は、このファイルのブロックのレコード。名前が `*Model_Space` なら entmode を 2、`*Paper_Space` なら 1 にし、所有者のハンドルを書かない。ほかのブロックは entmode を 0 にして、所有者のハンドルを書く。表の所（図形かブロックか）と 67 は、所有者に合わなければ受け付けない。
- 画層と線種は、表のレコードを名前（大文字と小文字は区別しない）で探す。線種がないか ByLayer なら印を 0、ByBlock なら 1、Continuous なら 2、ほかは 3 にしてハンドルを書く。
- 反応子と拡張辞書と図形の絵は持たない。前後の図形のハンドルを持つ（nolinks を 0 にする）。印刷スタイルと線の太さは ByLayer にする。
- 所有者のブロックのレコードの並びの終わりの図形の、後ろの図形のハンドルを足した図形にし（[決定 0051](0051-dwg-write-back-entity-removal.md) と同じ書き直し）、レコードの最後の図形のハンドルを直す。図形のなかったブロックは、最初の図形のハンドルも直す。
- 足した図形は、変えたオブジェクトと同じくファイルの後ろに置き、オブジェクトの地図に加える。HANDSEED は、足した最後の図形のハンドルの次にし、見出しの変数の区切りの中でその場で書き換えて、区切りの CRC を直す。

## 影響

- 手で組んだブロックの LINE の並び（前後のハンドルを持つものと、nolinks のもの）の終わりに LINE と CIRCLE を足して書き戻し、読み直した表が足した表と同じになることを確かめた。足した図形は、また除ける。HANDSEED より小さいハンドル・足せない種類・表にない画層・表の途中に置いた図形は受け付けない。
- 試料の R2000 の図面のモデル空間に LINE と CIRCLE を足して書き戻し、読み直した表が同じになり、HANDSEED が進み、CRC の診断が出ないことを確かめた。
- 型ごとのハンドルを持つ図形（TEXT・INSERT など）と、図形を持つ図形と、図形でないオブジェクトの追加は、まだ書き戻せない。

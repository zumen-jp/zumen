# 0149: 記号の切り抜きを、定義の空間の境界で持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

AutoCAD の系統では、ブロックの配置（INSERT）を、境界の内側だけ見えるように切り抜ける（XCLIP）。切り抜きは、INSERT の拡張辞書の `ACAD_FILTER` の辞書の `SPATIAL` が指す SPATIAL_FILTER に入る。[決定 0148](0148-drawing-extension-dictionary-xrecords.md) は、これを移さずに診断するとした。切り抜きは見た目を変えるので、移さなければ、表示する使い手は切り抜く前の記号の全体を描いてしまう。

手元の試料の `sample_AC10*` の図面（R12 の AC1009 を除く）は、どの版も、`my_block` の配置を 1 つ長方形で切り抜く。SPATIAL_FILTER は、境界の点（10・20）と、挿入の逆の変換と境界の変換の 12 ずつの値（40）を持つ。境界の点は切り抜いたときの図面の座標で、挿入の逆の変換が、挿入点と尺度の逆になっている（尺度 1/25.4 の配置で 25.4 倍して挿入点を引く）。

図面モデルには、下敷きの切り抜き（`Clip`: 境界の頂点と、内側を隠す印）がある。記号には切り抜きの欄がない。

## 選択肢

1. 記号に、記号の定義の空間の座標で境界を持つ切り抜きを足す。下敷きの `Clip` を使う。
2. 記号に、図面の座標で境界を持つ切り抜きを足す。
3. 形式固有の情報にして、図面モデルの値にはしない。

## 決定

選択肢 1 を採る。

- 定義の空間の座標なら、記号を動かしたり回したりしても、境界が記号とともに動く。図面の座標（選択肢 2）では、記号を編集するたびに境界も直す必要がある。AutoCAD も、挿入の逆の変換を持ち、境界を定義の側に結びつけている。
- 切り抜きは見た目を変えるので、形式固有の情報（選択肢 3）では、形式を知らない使い手が誤って描く。
- 下敷きの切り抜きと同じ型にすれば、表示する使い手は同じ処理で切り抜ける。

内容は次のとおり。

- `Symbol::clip` は、切り抜きの境界を記号の定義の空間の座標で持つ。切り抜かなければ `None`。頂点が 2 つなら、向かい合う角の長方形とする（下敷きと同じ）。元の長方形が変換で軸に平行でなくなるときは、四隅を頂点にする。格子に並べる記号では、どの記号も同じ境界で切り抜く。
- DXF・DWG の INSERT の SPATIAL_FILTER の境界の点を、境界の変換と挿入の逆の変換（3 行 4 列を行の順）で写して頂点にする。境界の変換を先に当てる順は推定である（試料の図面の境界の変換は、どれも単位の変換）。
- 境界の向き（210〜230）が Z でないもの、境界の原点（11〜31）が 0 でないもの、点が 2 つより少ないもの、読めない値を持つものと、変換後の点が有限でないか平面の外にあるものは、切り抜かずに記号を移し、`dxf.clip.dropped`（グループ・コードごと）を返す。
- 前と後ろで切るか（72・73）は平面の形を変えないので移さない。境界を表示するか（71）も移さない。内側を隠す切り抜き（AutoCAD 2015 からの反転）は、試料の図面になく、どこに持つか確かめていないので、内側を隠さないものとする。
- DWG の読み手は、SPATIAL_FILTER の欄を、DXF と同じ並びで表に置く。
- 拡張辞書の `ACAD_FILTER` は、INSERT では記号が持つので、移さなかった項目として診断しない。
- SXF・JWW の記号は、切り抜かない。

## 影響

- 記号を作る使い手は、`clip` の欄を足す必要がある。
- 表示する使い手は、記号の定義の中身を描くときに、定義の空間の座標で境界の内側だけを描く。
- 切り抜きを書き戻すことは、まだしない。
- 境界を表示する印と、内側を隠す切り抜きは、試料の図面が手に入ったら確かめる。

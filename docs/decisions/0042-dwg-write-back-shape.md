# 0042: DWG（R2000）への書き戻しは、SHAPE の既定の値の欄を表になければ既定の値で書き、形の番号は元のまま写す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0041](0041-dwg-write-back-viewport.md) までで、SHAPE のほかの、表に型ごとの欄を置く図形を R2000 の DWG に書き戻せるようにした。読む側は、SHAPE の挿入点（10）と高さ（40）を置き、回転（50）・幅の尺度（41）・傾き（51）・厚さ（39）・押し出しの向き（210）は既定の値でなければ置く。角度は度に直す。形の番号（BS）は、DXF では形の名前（2）で書くので、表に置かない。

## 選択肢

1. 表にない既定の値の欄は既定の値を書き、形の番号は元のビットを写す。
2. 形の名前（2）から形の番号を引いて書く。

2 は、形の番号と名前の対応を形のファイルから読む必要があり、読む側も名前を置いていない。

## 決定

選択肢 1 を採る。

- 回転と傾きがなければ 0、幅の尺度がなければ 1、厚さがなければ 0、押し出しの向きがなければ (0, 0, 1) を書く。
- 角度（50・51）は、度からラジアンに直して書く。
- 形の番号と、読む側が読まない後ろの欄は、元のビットを写す。

## 影響

- 手で組んだ R2000 の SHAPE で、高さを変え、表になかった回転・幅の尺度・厚さを足して書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の SHAPE も、点を動かして書き戻す。
- 形の番号は、まだ変えられない。
- 表に型ごとの欄を置く図形は、どれも書き戻せる。表（TABLES）と OBJECTS のオブジェクトの欄の変更は、まだ書き戻せない。

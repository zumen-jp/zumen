# 0159: 図面モデルに、配置をたどって要素ごとの変換・解いたスタイル・表示と印刷の可否・切り抜きを返す関数を置く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

記号の定義（[決定 0112](0112-drawing-symbol-definitions.md)）は、配置ごとに展開しない。そのため、記号の中の要素を描くには、配置をたどって次のことを決める必要がある。

- 位置。配置の基点・尺度・回転・位置と、用紙のビューの変換を合わせる（[決定 0144](0144-drawing-block-insertion-units.md)・[決定 0105](0105-drawing-layers-and-order.md)）。
- 色・線種・線幅。配置からの継承と、配置のレイヤに従うレイヤを解く（[決定 0143](0143-drawing-inherit-through-placements.md) の `color_placed` など）。0143 の最初の案は、列の作り方を使い手に任せた。
- 表示。AutoCAD の系統では、凍結した画層の配置は記号の全体を隠し、非表示の画層の配置は、配置のレイヤに従う中の要素だけを隠す（[決定 0141](0141-drawing-layer-frozen.md)）。0141 と 0143 の最初の案は、この描き方と、レイヤの表示・印刷の可否を配置のレイヤで決めることを、表示する側の仕事として残した。
- 切り抜き。記号の切り抜き（[決定 0149](0149-drawing-symbol-clips.md)）とビューの切り抜きを重ねる。

どれも、形式の知識を図面モデルの値に移したものの組み合わせである。組み合わせ方を使い手ごとに書くと、同じ誤りを使い手ごとに作る。表示（シーン、#219）・範囲（`bbox`、[決定 0118](0118-entities-bbox-fields-region.md)）・プロファイルの照合（#220）・別の形式への変換は、どれも同じたどり方が要る。

## 選択肢

1. 図面モデルに、配置をたどって、要素ごとに解いた値を返す関数を置く。
2. 部品の関数（`color_placed` など）を残し、組み合わせ方を文書に書く。
3. 読み手が配置を展開し、解いた値で要素を写す。

2 は、使い手ごとに組み合わせを書く今の形と同じである。3 は、決定 0112 が採らなかった。配置の数だけ中身が増え、定義と配置の区別がなくなる。

## 決定

選択肢 1 を提案する。

- **起点。** 空間（実寸の空間か記号の定義の空間）・用紙・用紙のビューのどれかから、たどる。用紙からたどると、`Sheet::order` の順に、用紙の要素と、ビューを通した実寸の空間の要素を返す。空間の要素は、`ModelSpace::order` の順に返す。
- **返すもの。** 要素ごとに、次を返す。
  - 要素と、その ID（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）
  - 配置の道筋。外側から内側への、配置の要素の ID の列
  - 要素の空間から起点の座標への変換（`Affine`）
  - 継承を解いた色・線種・線幅と、実効のレイヤ
  - 表示と印刷の可否
  - 切り抜きの列。記号の切り抜きとビューの切り抜きを、起点の座標で外側から並べたもの。要素は、すべての切り抜きの内側だけを描く
- **実効のレイヤ。** 0143 の規則で決める。配置のレイヤに従うレイヤ（`Layer::follows_placement`）なら、外側の配置のレイヤへ進む。色・線種・線幅だけでなく、表示と印刷にも同じレイヤを使う。配置そのものの実効のレイヤも、同じ規則で外側から決める。
- **表示の可否。** 次のすべてを満たすときに表示する。
  - 道筋のどの配置も、実効のレイヤが凍結していない。
  - 要素の実効のレイヤが、オンで、凍結していない。
  - ビューを通すときは、道筋の配置と要素のどの実効のレイヤも、ビューで隠すレイヤ（`View::hidden_layers`）でない。
- **印刷の可否。** 表示し、要素の実効のレイヤが印刷するときに印刷する（推定。AutoCAD で作った試料で確かめる）。
- **ほかの形式。** 規則は形式によらない。JWW・SXF の配置とレイヤの表示の決まりは、それぞれの lift が、オン・凍結・配置のレイヤに従う印に写して表す。
- **外側まで解けない継承。** 起点まで配置から継承した値（DXF の BYBLOCK）は、文書の既定の値で解く。既定の値は `Drawing2D` が持つ。AutoCAD の系統では、色は 7、線種は実線、線幅は `$LWDEFAULT` とする（色と線種は推定）。
- **予算と壊れた図面。** 返す要素ごとに `work` を 1 と数え、配置の深さを `depth` の上限で止める（[決定 0010](0010-budget-by-work.md)）。道筋に同じ定義がもう一度現れる配置（循環）は、たどらずに `drawing.placement.invalid` を返す。図面モデルの診断の名前空間 `drawing` を台帳に足す。
- **部品。** 0143 の `color_placed`・`line_type_placed`・`line_weight_placed`・`layer_placed` は残し、たどる関数はそれらを使う。

## 影響

- 表示（#219 のシーン）・範囲・プロファイルの照合・別の形式への変換は、この関数を使う。配置の扱いを、それぞれに書かない。
- 0141 と 0143 も、記号の中身の表示と印刷を、この関数が実効のレイヤで決める形にした。
- 記号の中身は配置の数だけ返すので、返す数は要素の数より多くなりうる。上限は `work` で決める。
- たどった結果を返す境界の op は、#219 のシーンの op と一緒に決める。
- 図面モデルに、外側まで解けない継承の既定の値の欄が増える（今の `default_line_weight` を広げる）。

# 0100: R2010 から後の DWG の LTYPE の文字の要素の文字列は、UTF-16LE で 512 バイトの領域に詰め直して書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

LTYPE の文字の要素の文字列は、要素の欄の後の領域に、形の番号の位置から 0 で終わって置かれる。R2004 までは 256 バイトの領域で、文字列が変われば初めから順に詰め直して書き戻す（[決定 0044](0044-dwg-write-back-ltype.md)）。R2010 からは、文字の要素があるときだけ 512 バイトの領域があり、文字列は UTF-16LE で、形の番号はバイトの位置になる。これまでは、R2010 から後の文字列の変更を受け付けていなかった（[決定 0089](0089-dwg-r2010-write-back-records.md)）。試料の R2010・R2013・R2018 の図面は、文字の要素を持つ線種（GAS_LINE）を持つ。

## 選択肢

1. 文字列が変われば、R2004 までと同じく初めから順に、UTF-16LE で 0 の単位を終わりに付けて 512 バイトの領域に詰め直し、形の番号にバイトの位置を書く。
2. R2010 から後の文字列の変更は、まだ受け付けない。

## 決定

選択肢 1 を採る。詰めた文字列が 512 バイトを超えれば受け付けない。文字列が変わらなければ、これまでどおり元の領域を写す。

## 影響

- 試料の R2010・R2013・R2018 の図面の、線種の文字の要素の文字列を変えて書き、読み直したものが変えたものと合った。
- 書いた図面を AutoCAD で開いて確かめてはいない。

# 0032: DWG（R2000）への書き戻しは、TEXT・INSERT・MINSERT の型ごとの欄を、印を値から選んで符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0030](0030-dwg-write-back-more-entities.md)・[決定 0031](0031-dwg-write-back-entity-common.md) で、点と曲線の図形の型ごとの欄と、どの図形の共通の欄も R2000 の DWG に書き戻せるようにした。図面に多い TEXT と INSERT の型ごとの欄は、まだ書き戻せない。

- TEXT は、初めの印（RC）のビットで、標高・合わせの点・斜めの角度・回転・幅・生成・合わせの欄がないことを表す。文字列は、制御文字を `^` と文字で書いた DXF の書き方で表に置く。
- INSERT は、尺度の印（BB）で、尺度の書き方を選ぶ。MINSERT は、表では INSERT とし、列と行の数と間隔を足す。
- 属性が続くか（66）は、ハンドルの流れの属性の参照と組になる。

## 選択肢

1. 印を表の値から選び直して符号化する。表にない欄は、印でないことを表す。
2. 元の印を写し、印が表す欄の並びが変わる変更は受け付けない。

2 は、TEXT の回転を足すことや、INSERT の尺度を変えることを書き戻せない。

## 決定

選択肢 1 を採る。

- TEXT は、表にない欄の印のビットを立てる。標高（30）が 0 なら標高も書かない。合わせの点の Z（31）は、標高と同じでなければ `dwg.change.unsupported` を返す。
- TEXT の文字列（1）は、`^` と文字を制御文字に、`^ ` を `^` に戻し、終わりの NUL を付けて書く。読みが作らない `^` の並びは `dwg.change.unsupported` を返す。
- INSERT の尺度の印は、尺度がすべて 1、X が 1、すべて同じ、そのほかの順に選ぶ。尺度・回転・押し出しの向きは、なければ既定の値（1・0・(0, 0, 1)）を書く。
- MINSERT は型の番号で見分け、列と行の数（70・71）と間隔（44・45）を、なければ既定の値（1・1・0・0）で書く。
- 属性が続くか（66）の変更は、ハンドルの流れを変えるので `dwg.change.unsupported` を返す。

## 影響

- 試料の R2000 の図面の TEXT・INSERT の点も動かして書き戻し、読み直した表が変えた表と同じになることを確かめた。
- ATTRIB・ATTDEF・MTEXT などの型ごとの欄の変更は、まだ書き戻せない。

# 0101: DWG の INSERT の回転は、変わらなければ元のラジアンを書き、R2010 から後も回した INSERT を足せるようにする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

INSERT の回転は、DWG ではラジアン（BD）で、表には度（50）で置く。書き戻すときは度からラジアンに直すので、元のラジアンと同じビットになるとは限らない。たとえば試料の図面の回転は 90.00000000000004 度と読め、ラジアンに直すと元の値と最後のビットが異なる。R2004 から後の INSERT の変更は、元の値から作った欄が元のビットと同じになるときだけ書き戻すので、回した INSERT の変更を受け付けないことがあった。R2010 から後は、変更で確かめられていないので、回した INSERT を足すことも受け付けていなかった（[決定 0092](0092-dwg-r2010-write-back-entity-addition.md)）。

## 選択肢

1. 回転が変わらなければ、元の欄から読んだラジアンをそのまま書く。変わった回転と、足した INSERT の回転は、度から直して書く。
2. 回した INSERT は、これまでどおり受け付けないことがあるままにする。

## 決定

選択肢 1 を採る。R2010 から後も、回した INSERT を足せるようにする。MINSERT は、R2004 から後の試料の図面にないので、まだ足さない。

## 影響

- 試料の R2000・R2004・R2010・R2013・R2018 の図面の、回した INSERT を含む図形を変えて書き、読み直したものが変えたものと合った。
- 試料の図面に、90 度回した INSERT を足して書き、読み直したものが足したものと合った。30 度のように、度とラジアンの行き来で最後のビットが変わる値は、ほかの角度と同じく、読み直すと 29.999999999999996 度のようになる。
- 書いた図面を AutoCAD で開いて確かめてはいない。

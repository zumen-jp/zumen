# 0172: 2D のシーンは、配置をたどって解いた値を、線・面・文字・点・画像の区画に並べ、`scene` の op で返す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-30 |
| 状態 | 採用 |

## 背景

[決定 0137](0137-columnar-scene-transfer.md) は、2D のシーンを 1 つの ArrayBuffer に列で並べることにした。見出し・区画の表・塊の原点と相対座標という入れ物の配置は決めたが、区画の中身と、シーンを返す op は決めていない（#219）。

決めることは次のとおり。

- 区画に持つ形の種類。折れ線だけか、円弧・文字・塗り・画像も持つか。
- 円弧と文字を折れ線にするか。するなら、その許容差。
- 色・線種・線幅を解いて持つか。
- シーンを返す op と、その引数。

関わる決定は、次のとおり。

- L2 は曲線を厳密な形で持ち、折れ線にするのは L3 で、許容差を付けて行う。表示の弦の誤差の既定は用紙の 0.02 mm。作った点の数は予算の `segments` で数え、使った許容差を結果か診断に書く（[決定 0018](0018-geometry-layers-and-tolerances.md)）。
- 字形は、呼び出し側から渡されたフォントで評価する。フォントがなければ未解決のまま持ち、代わりの表示は診断する。L3 で親と構成要素を二重に描かない（[決定 0022](0022-drawing2d-semantics-and-format-mapping.md)）。
- コアは色の符号表を持たない（[決定 0106](0106-drawing-color-line-type-weight.md)）。
- 配置をたどって、要素ごとの変換・解いた色と線種と線幅・実効のレイヤ・表示と印刷の可否・切り抜きを返す関数を、図面モデルに置く（[決定 0159](0159-drawing-walk-placements.md)）。0159 は、たどった結果を返す境界の op を、シーンの op と一緒に決めるとした。
- 大きな座標は、塊ごとの f64 の原点と f32 の相対座標で持つ（[決定 0019](0019-coordinate-systems-and-gsi-data.md)・0137）。

## 選択肢

1. 曲線・線種・ハッチの模様をコアで線に展開し、線・面・文字・点・画像の 5 種類の区画に並べる。色・線幅は配置をたどって解く。文字は字形にせず、文字列と配置で持つ。
2. 図面モデルの形の種類（円弧・楕円・スプライン・クロソイドなど）を、そのまま区画に持つ。展開は表示する側が行う。
3. すべてを折れ線と三角形にする。文字も字形の輪郭にする。

2 は、表示する側が曲線の分割・線種・ハッチの模様・継承の解き方をそれぞれ書くことになり、同じ図面が表示する側ごとに違って見える。WebGL のように円弧を描けない描画もある。3 は、フォントがなければ文字を描けず（0022）、塗りの三角形分割と字形の輪郭で大きさが何倍にもなる。

## 決定

選択肢 1 を選ぶ。

### 何を描くか

- **起点。** シーンは、0159 の起点（実寸の空間・記号の定義の空間・用紙・用紙のビュー）のどれか 1 つから作る。座標は起点の座標とする。
- **たどり方。** 0159 の関数で要素をたどる。記号の中の要素は配置ごとに描き、色・線種・線幅・実効のレイヤは、たどった結果の値を使う。
- **表示と印刷。** 既定では、表示する要素だけを描く。引数で印刷を選べば、印刷する要素だけを描く。
- **二重に描かない。** 寸法・引出線・表・注記は、表示の部品（DXF の寸法のブロックなど）があれば部品を描き、なければ定義から描く。定義から描けない種類は、描かずに `scene.<種類>.dropped` を返す。

### 区画の中身

区画は、次の 5 種類の描くものと、それらが引く表に分ける。区画の番号は表の順で決め、新しい区画は後ろに足す（0137 の「知らない区画は読み飛ばす」）。

- **線。** 折れ線の頂点の列と、描く単位（下記）の番号。
  - 線分・円・円弧・楕円・スプライン・クロソイド・ふくらみのある折れ線は、弦の誤差で折れ線にする。
  - 線種は、線と間に展開する。線種に添える形と文字は、線と文字の描くものにする。
  - ハッチの模様は、境界で切った線にする。
- **面。** 外側と穴の輪の列と、描く単位の番号。偶奇の規則で塗る。三角形には分けない。
  - 塗りのハッチ・SOLID・幅のある折れ線を面にする。
  - グラデーションの塗りは、最初の色で塗り、`scene.gradient.approximated` を返す。
- **文字。** 字形にせず、文字列・基点・高さ・幅の倍率・回転・傾き・反転・縦書き・位置合わせ（9 点・基準線・2 点の間）・枠の幅・フォントの番号と、描く単位の番号を持つ。
  - 書式つきの文字は、書式の区間ごとに 1 つの文字にし、行の番号を持つ。折り返しは、枠の幅を使って表示する側が行う。
  - 字形の評価に要るフォントは、表示する側が引く。コアが字形の輪郭を返すことは、フォントを渡せるようにしてから、新しい区画として足す。（後に[決定 0188](0188-scene-fonts-and-glyph-outlines.md) で足した）
- **点。** 位置・回転・点の表し方（[決定 0160](0160-drawing-points.md)）と、描く単位の番号を持つ。画面の高さに対する大きさは、表示する側が決める。
- **画像。** 下敷きの画像と PDF の基点と 2 つの辺のベクトル・参照する名前と、描く単位の番号を持つ。コアは画像を読まない。
- **描く単位。** 描くものが引く表。要素の番号・色の番号・線幅・切り抜きの番号・実効のレイヤの番号を持つ。
  - 線幅は用紙の mm で持つ。文書の既定の線幅（`Default`）と、読まなかった線幅は、0159 の文書の既定の値で解く。0 は、いちばん細い線とする。
- **要素。** 要素の ID（[決定 0156](0156-drawing-stable-ids-and-preconditions.md)）・種類・配置の道筋を持つ。選んだ描くものから、`entities` で要素を引ける。
- **色。** 系統・符号・ファイルが持つ RGB・表示する RGBA・印を持つ。
  - 表示する RGBA は、ファイルの RGB があればそれにする。なければ、呼び出し側が渡した色の表（`palette`）から引く。表になければ、未解決の印を立て、表示する側が決める。コアは符号表を持たない（0106）。
  - 背景で色を変える色（ACI の 7）は、前景の印を立てる。
- **切り抜き。** 多角形の組。描くものは、組のすべての多角形の内側だけを描く。コアは形を切らず、表示する側が切り抜きの機能（Canvas の clip、WebGL のステンシルなど）で切る。
- **塊。** 描く順の続きを、塊に分ける。塊ごとに、f64 の原点・相対座標の範囲・描くものの種類ごとの始まりを持つ。座標は塊の原点からの f32 にする。描く順は、塊の順と、塊の中の並びで決まる。
- **文字列。** ID・文字・フォントの名前・画像の名前を、1 つの UTF-8 の区画にまとめ、始まりと長さで引く。
- **見出しの「数」。** 0137 の見出しの「数」は、塊の数とする。

### 許容差

- 用紙か用紙のビューからなら、用紙の長さで指す。既定は用紙の 0.02 mm（0018）。
- 空間からなら、空間の長さで指す。既定は、空間の範囲の対角線の 1/50000 とする（A1 の用紙に収めたときの 0.02 mm にほぼ等しい）。
- 使った許容差を、結果と `approximated` の診断に書く。作った点は `segments`、たどった要素は `work` で数える（[決定 0010](0010-budget-by-work.md)）。

### op

- `scene` の op を足す。引数は、文書（`doc`）・起点（`from`。空間・用紙・ビューの ID）・範囲（`region`。起点の座標の長方形。重なる塊だけを返す）・許容差（`tolerance`）・印刷（`print`）・色の表（`palette`。`zm_push` で渡した入力の名前）とする。
- 色の表の形は、プロファイルの色の語彙（[決定 0138](0138-profiles-as-versioned-data.md)）と同じにする。系統ごとに、符号と RGB を並べる。
- 結果の JSON は、起点・単位・使った許容差・描くものの種類ごとの数・範囲と、シーンの blob の番号を持つ。シーンは、`blobs` の `scene` で返し、`zm_take` で取り出す。
- 区画の定義は `schema/` に置き、`cargo xtask codegen` で読み手の型を作る。

### 置き場所

- 曲線の分割・線種の展開・ハッチの模様の線は、0018 が置くとした `zumen-geom2d` に置く。
- シーンを作る処理は、新しい crate `zumen-scene`（L3）に置く。図面モデルと `zumen-geom2d` に依り、境界の `zumen-abi` が呼ぶ。

## 影響

- 表示する側は、型付き配列のビューを作り、線・面・文字・点・画像を描くだけになる。曲線・線種・継承・表示の可否を書かなくてよい。
- 文字の字形と、ACI などの符号の色は、表示する側が補う。ACI の色の表を `profiles/` に置くかは、別に決める。
- 線種を展開するので、細かい模様の線が多い図面では、頂点の数が増える。上限は `segments` で決める。
- 塊の大きさ（塊ごとの描くものの数）は、実際の図面で測って決める（0137）。決定 0171 で `samples/` に入れた図面と、`ZUMEN_SAMPLES` の図面で測る。
- たどった結果を JSON で要素ごとに返す op は、要るときに `entities` の欄として足す。
- 3D のシーンは、別の種類のシーンとして、3D のシーン（#5、zumen-jp/zumen-legacy#126）で決める。
- 新しい診断の code（`scene.*`）と、`scene` の op・区画のスキーマを足すので、境界の小版を上げる。

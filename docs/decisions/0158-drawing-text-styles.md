# 0158: 図面モデルに文字スタイルの表を置き、文字のフォントと縦書きを文字スタイルから引く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

図面モデル（Drawing2D）は、レイヤ・線種・寸法スタイル・記号の定義の表を持つが、文字スタイルの表を持たない。文字（`Text`）・書式つきの文字（`FormattedText`）・表のセルの書式（`CellFormat`）・線種の文字（`MarkContent::Text`、[決定 0150](0150-drawing-line-type-marks.md)）は、文字スタイルを元の名前で指すだけである。寸法（`Dimension`）と引出線（`Leader`）も、寸法スタイルを名前で指す。

そのため、表示する側は、文字のフォントを知ることができない。AutoCAD の系統の文字のフォントは、図形ではなく文字スタイルが持つからである。線種の文字の高さも、文字スタイルの高さへの倍率なので、決まらない（0150 の影響）。

AutoCAD の系統の文字スタイル（STYLE の表のレコード）は、次の値を持つ（DXF Reference「STYLE」）。

- 名前（2）、主のフォントのファイル（3）、大きいフォント（漢字などの SHX のビッグフォント）のファイル（4）
- 決まった高さ（40。0 なら決めない）、幅の倍率（41）、傾き（50、度）
- 文字の生成の印（71。2 は裏返し、4 は上下反転）、表のレコードの印（70。1 は形のファイル、4 は縦書き）
- 最後に使った高さ（42）

TrueType のフォントの書体の名前と太字・斜体は、レコードの XDATA の ACAD（1000 と 1071）に書く（推定）。

AutoCAD では、文字スタイルのフォントと縦書きを変えると、そのスタイルの文字がすべて変わる。高さ・幅の倍率・傾きを変えても、今の文字は変わらず、新しく作る文字の既定の値になる（推定）。文字の図形（TEXT）は、高さ（40）・幅の倍率（41）・傾き（51）・生成の印（71）を自分で持つ。

## 選択肢

1. 図面モデルに文字スタイルの表を置き、文字の要素は ID で指す。
2. 名前で指すままにし、文字スタイルの値を形式固有の情報（`dxf.style`）にする。
3. 文字スタイルのフォントを、文字の要素ごとに写して持つ。

2 は、フォントという表示を変える値を形式固有の情報に置くので、[決定 0157](0157-drawing-model-fields-and-extensions.md) に反する。3 は、1 つの文字スタイルのフォントを変えるのに、すべての文字を変える必要があり、元の形式へ文字スタイルの表を書き戻せない。

## 決定

選択肢 1 を選ぶ。要素の型を `TextStyleId` で指す部分は、[決定 0166](0166-drawing-text-style-names-and-mark-heights.md) で置き換えた。

- **表。** `Drawing2D::text_styles` に `TextStyle` を並べる。`TextStyle` は、元の名前・定義・出所を持つ。ID は、[決定 0156](0156-drawing-stable-ids-and-preconditions.md) のとおり出所のハンドルで作る（`text-style/h11`。ハンドルがなければ並びの中の順で `text-style/0`）。要素が名前で指すだけで、ファイルに定義がない文字スタイルは、定義を `None` にした項目にする（レイヤと同じ）。
- **定義。** 主のフォント・大きいフォント（どちらも `Font`）・決まった高さ（決めなければ `None`）・幅の倍率・傾き（度）・裏返し・上下反転・縦書きを持つ。
- **要素との関係。** 文字・書式つきの文字・表のセルの書式・線種の文字は、文字スタイルを名前で指す（[決定 0166](0166-drawing-text-style-names-and-mark-heights.md)）。名前は、ASCII の大文字と小文字を区別せずに比べ、同じ名前があれば先の項目にする。
  - フォントと縦書きは、文字スタイルから引く。
  - 高さ・幅の倍率・傾き・裏返し・上下反転は、要素の値を使う。文字スタイルの値は、新しく作る文字の既定の値にする。
  - 書式つきの文字の書式の中のフォントの指定（`Format::font`）は、文字スタイルのフォントより優先する。
  - 線種の文字の高さは、文字スタイルの決まった高さに倍率を掛ける。決まった高さがなければ、倍率を高さとする（0150）。
- **寸法スタイル。** 寸法と引出線は、寸法スタイルを名前で指す（0166）。名前は、大文字と小文字を区別して比べる。
- **境界。** `tables` の op は、文字スタイルの ID・名前・ハッシュと定義を返す。`entities` の文字・書式つきの文字・寸法の形の値は、名前とともに、名前で引いた文字スタイルと寸法スタイルの ID（`style_id`）を返す。`add` と `replace` は、名前の代わりに `style_id` でも指せる。名前も書くなら、同じ項目を指す必要がある。寸法スタイルは、要素が名前で指すだけのものを表に足さないので、表にない名前なら ID を返さない。
- **DXF・DWG。** STYLE の表のレコードから作る。
  - 主のフォントは 3、大きいフォントは 4 とする。SHX のファイルは `FontKind::Shape` にする。TrueType のファイルは、XDATA の ACAD があれば、その書体の名前と太字・斜体で `FontKind::Named` にする。1071 は、下の 8 ビットをピッチと系統、次の 8 ビットを文字集合とし、ビット 24 を斜体、ビット 25 を太字とする（ビット 24・25 は推定。AutoCAD で作った試料で確かめる）。
  - 形のファイルのレコード（70 の 1）は、文字スタイルにしない。今のとおり、形の参照（`MarkContent::Shape` の `font`）が持つ。
  - 最後に使った高さ（42）は、編集の画面の値なので移さない（0157 の L1 だけの値）。
- **ほかの形式。** JWW の文字種と、SXF の文字のフォントの移し方は、それぞれ別に決める。

## 影響

- 表示する側は、文字のフォントを文字スタイルから引ける。字形の取得は、図面モデルの外に置く。
- 0150 の「図面モデルは、文字スタイルの高さを持たない」はなくなり、線種の文字の高さが決まる。0150 と [決定 0151](0151-drawing-table-cell-formats.md) の文字スタイルも、名前でこの表から引く。
- 文字の要素の文字スタイルを変える変更は、[決定 0139](0139-drawing-apply.md) のスタイルの変更で扱う。文字スタイルの表そのものの変更は、[決定 0163](0163-drawing-text-style-changes.md) で決めた。
- 図面モデルに文字スタイルの表が増えるので、`Drawing2D` を作る使い手は表を足す必要がある。要素は名前で指したままにする。
- 同じ名前の文字スタイルが複数ある図面では、DXF が名前で書くため、後の項目を ID で指して足せない。

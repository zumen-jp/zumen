# 0182: 記号の定義の中に記号を足し、定義の入れ子が輪になる追加は断る

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-31 |
| 状態 | 採用 |

## 背景

[決定 0177](0177-drawing-apply-leaders-and-definitions.md) で、名前のある記号の定義の空間（`space/h{BLOCK}`）に要素を足せるようにした。ただし、定義の中に記号（INSERT）は足さなかった。定義が自分を直接か間接に置くと、配置をたどる処理が終わらず、AutoCAD も開けない。その輪を確かめていなかった（#333）。

## 選択肢

1. 定義の中への記号の追加を断ったままにする。
2. 足す前に、足す記号の定義から、その中の記号をたどり、足す先の定義に着くかを確かめる。着けば断る。
3. 輪を作っても書き、読むときの `dxf.block-cycle.invalid` に任せる。

## 決定

選択肢 2 を採る。3 は、壊れたファイルを書くことになる。境界は変えない。

- **たどる入れ子。** 今の図面の、名前空間 `dxf.block` の定義ごとに、その空間に置く記号の定義の名前を集める。名前は大文字と小文字を区別しない（DXF と同じ）。同じ変更の一覧で先に足した記号も、入れ子に加える。後の変更が、先の変更と合わせて輪を作ることもあるため。
- **断る。** 足す記号の定義から入れ子をたどり、足す先の定義に着けば（自分自身を足すときを含む）、新しい診断 `change.symbol-cycle.invalid`（足す先の空間の ID と記号の名前）で断り、何も反映しない。たどった定義ごとに作業量を 1 数える。
- **書く。** 輪にならなければ、実寸の空間への INSERT と同じ書き方で、[決定 0177](0177-drawing-apply-leaders-and-definitions.md) の定義の空間の置き場所（DXF は ENDBLK の前、DWG はブロックの図形の列）に足す。名のない定義・外部参照の定義・BLOCK_RECORD のない定義には、今までどおり足さない。

## 影響

- 同じ変更の一覧で除く記号や置き換える記号は、入れ子から外さない。除く記号が輪を断つ場合も断るので、利用者は除く変更を先に当てる。置き換えでは記号の定義を変えられないので、置き換えは輪を作らない。
- 足した INSERT は、AutoCAD ではまだ開いて確かめていない。

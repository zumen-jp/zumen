# 0129: SFC のハッチングは複合曲線を輪にして移し、表示する複合曲線は曲線を置く

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

SFC の複合曲線（`composite_curve_org_feature`）は、前の定義の後に書いた曲線（線分・折線・円・円弧・楕円弧・スプライン・クロソイドなど）をまとめ、色・線種・線幅のコードと表示の有無を持つ。ハッチングの 4 つのフィーチャ（塗り・線・パターン・外部定義）は、外形と中抜きを、ファイルの中の複合曲線の順の番号（1 から）で指す。線のハッチングは、線ごとに色・線種・線幅のコード・通る点・間隔・角度を持つ。パターンのハッチングは、記号の名前・色・原点・2 つの並べる向きと長さ・尺度・回転を持つ。[決定 0121](0121-sxf-sfc-lift-to-drawing.md) は、複合曲線の曲線をまだ移さなかった（#171）。

## 選択肢

1. ハッチングを `Hatch` にし、指す複合曲線の曲線の辺を並べた輪にする。表示する複合曲線は、曲線を複合曲線の色・線種・線幅で置く。図面モデルの欄にない値は `sxf.hatch` の拡張に残す。
2. 複合曲線を 1 つの折れ線の要素にし、ハッチングはその要素を指す。
3. ハッチングを線と塗りの要素に展開する。

## 決定

選択肢 1 を採る。複合曲線は楕円弧やクロソイドを含めるので、折れ線にすると近似になる（[決定 0111](0111-drawing-curves.md)）。展開すると、ハッチングという意味と、パターンの名前が分からなくなる（[決定 0108](0108-drawing-symbols-hatches-arrowheads.md)）。

- 複合曲線は、前の定義の後に書いた曲線を持つ。前の複合曲線は持たない。複合曲線の位置（用紙・部分図・作図グループ）は、曲線ではなく複合曲線のフィーチャの位置で決める。
- 表示の有無が 1 か、値がなければ、曲線を、レイヤは曲線の、色・線種・線幅は複合曲線のコードで、複合曲線の位置に置く（推定。曲線の色は使わない）。0 なら置かない。
- ハッチングの輪は、外形を外側の輪、中抜きを内側の輪にし、輪の中の輪は中抜きにする（`Islands::Nested`）。辺は曲線の順に並べ、折線は線分に、円は 0 度から 360 度の円弧にする。輪の出所は曲線のフィーチャにする。
- 塗りは `Fill::Solid` にし、要素の色を塗りの色にする。
- 線のハッチングは、利用者の定義のパターンにし、線ごとに、角度・通る点と、間隔を線に垂直なずれにした値を持つ。線種の破線は持たず、線ごとの色・線種・線幅のコードを `sxf.hatch` の拡張に、`color`・`line_type`・`line_width` の順で線の数だけ残す。要素の色は、1 本目の線の色にする（推定）。
- パターンのハッチングは、記号の名前を名前にした既定義のパターンにし、回転と X の尺度を入れ、線は持たない。原点・2 つの並べる向きと長さ・X と Y の尺度を `sxf.hatch` の拡張に残す。
- 外部定義のハッチングは、名前（`Area_control` など）を名前にした既定義のパターンにし、線は持たない。要素の色はレイヤに従う。
- 複合曲線のない番号を指す、中抜きの数と並びの数が合わない、輪にできない曲線を含むなどは、`sxf.lift.invalid` で落とす。診断の code は足さない。

## 影響

- パターンの記号の形と、外部定義のハッチングの見え方は、表示側が名前から引く。
- 線のハッチングの破線は、線種のコードから表示側が引く。

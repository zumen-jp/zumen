# 0146: 引出線つきの注記の線と注記の色・線種・線幅を、注記の要素に従う指定として持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0110](0110-drawing-callouts-and-dimension-text.md) は、引出線つきの注記（`Callout`）を枝と注記の組で持つと決めた。しかし、線と注記の色・線種・線幅は移していなかった（#174 の「MULTILEADER の線ごとの値」）。DXF・DWG の MULTILEADER は、要素の色・線種・線幅とは別に、線の色（91）・線種（341）・線幅（171）と、文字の色（92）・記号の色（93）を持つ。既定はどれも ByBlock で、注記の要素の値に従う。手元の試料では、AutoCAD の試料の図面の注記はどれも ByBlock だった。作った試料の DXF には、線を赤・RGB・ByLayer にしたもの、線種と線幅（0.35 mm）を明示したもの、文字と記号の色を明示したものがあった。表示する使い手は、これらの値がないと、線と注記を要素の色で描いてしまう。

線ごとにも上書き（線の 93 の印と、色 92・線種 340・線幅 171・端部記号 341・大きさ 40 など）がある。ただし、手元の試料には上書きした線がない。

あわせて、記号の注記の属性の値を読むとき、図形の所有者（330）を属性の定義と取り違えていた。そのため、実際の DXF・DWG の記号の注記は移らなかった。DXF では、AcDbEntity の代わりの図形の大きさ（92）も、MULTILEADER の欄と同じ符号を使う。

## 選択肢

1. `Callout` に、線の色・線種・線幅（`Style`）と注記の色（`Inherit<Color>`）を足す。ByBlock は `Inherit::Block` とし、注記の要素を線と注記の配置とみなす。
2. 線を別の要素にし、それぞれに `Style` を持たせる。
3. 値を形式固有の情報（`Extension`）に置く。

## 決定

選択肢 1 を採る。

- 線を別の要素にする（選択肢 2）と、決定 0110 が避けた、枝と注記を出所でつなぎ直す必要が戻る。
- 形式固有の情報（選択肢 3）では、表示する使い手が形式ごとに読む必要がある。色・線種・線幅は図面モデルの語なので、図面モデルに置く。
- ByBlock を `Inherit::Block` にすれば、記号の定義の中の要素と同じ道具で解ける。注記の要素を配置として、列の外側に並べればよい（提案中の[決定 0143](0143-drawing-inherit-through-placements.md)）。

内容は次のとおり。

- `Callout.line_style` は、線（枝の線と折れ曲がり）の色・線種・線幅である。`Inherit::Block` は注記の要素の値、`Inherit::Layer` は注記の要素のレイヤの値に従う。線種の倍率は 1 とし、要素の線種の倍率と掛け合わせる。
- `Callout.content_color` は、注記の文字か記号の色である。記号のときは、記号の中の要素が配置から継承する色を、この色で解く。
- `Style::BLOCK` は、色・線種・線幅をすべて配置から継承する指定である。SXF の引出線は、線と注記を要素の値で描くので、これを使う。
- DXF・DWG は次のように読む。
  - 線の色は 91、文字の色は 92、記号の色は 93 から読む。上の 1 バイトが 0xC0 ならレイヤ、0xC1 なら配置から継承するとし、0xC2・0xC3 は決定 0110 と同じく RGB と色の番号とする（推定）。
  - 線種は、341 の指す LTYPE のレコードから読む。名前が ByLayer・ByBlock なら継承、ほかは表の線種とする。
  - 線幅は 171 から読む。-1 はレイヤ、-2 は配置から継承、-3 は文書の既定、0〜211 は 1/100 mm とする。
  - 値がなければ、配置から継承する（推定）。
  - DXF では、MULTILEADER の欄を最後の区切り（100）の後から読む。AcDbEntity の 92 は、代わりの図形の大きさのため。
- 線ごとの上書きは、まだ移さない。線の 93 が 0 でないか、線の色（92）が ByBlock でなければ、`dxf.leader-line-style.dropped` を返す。線は注記全体の指定で描く。
- 記号の注記の属性の組は、記号のブロック（344）の後から読む。前の 330 は図形の所有者である。

## 影響

- 図面モデルの `Callout` に欄が 2 つ増える。`Callout` を作る使い手は、欄を足す必要がある。
- 線ごとの上書きを移すには、`Branch` の線ごとに `Style` を持たせる必要がある。上書きした線の試料が見つかったら決める。
- 寄せ方の欄（271〜273）は、まだ移さない。

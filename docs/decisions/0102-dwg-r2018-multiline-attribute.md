# 0102: R2018 から後の DWG の複数行の属性は、埋め込みの MTEXT の値を DXF と同じく 101 の後に置き、書き戻す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

R2018 から後の DWG の ATTRIB・ATTDEF は、属性のバージョンの後に属性の種類（RC）を持つ。2（ATTRIB）と 4（ATTDEF）は複数行の属性で、意味の分からない 37 ビットの後に、埋め込みの MTEXT のフィールド（R2018 から増えたフィールドも）と、DXF の 72 にあたる BS が続く。ハンドルのストリームには、属性の文字スタイルの後に、埋め込みの MTEXT が指す所有者（0）・画層・線種・材質・文字スタイル・アプリケーションの名前（0）のハンドルが続く。これまでは、埋め込みの MTEXT の値を表に置かず、複数行の属性の変更と追加を受け付けていなかった（[決定 0098](0098-dwg-r2018-mtext-attribute.md)）。

DXF は、複数行の属性の値の後に、種類（71）・72・属性の合わせの点（11・21・31）・埋め込みのオブジェクトのマーカー（101、`Embedded Object`）を置き、その後に MTEXT の値を書く。サンプルの R2018 の図面と、同じ図面の DXF には、複数行の ATTRIB と ATTDEF が 1 つずつある。

## 選択肢

1. DXF と同じく、属性の値の後に、種類（71）・72・101 と MTEXT の値を置く。書き戻すときは、101 の後の値を MTEXT と同じく書く。
2. 埋め込みの MTEXT の値を、ほかのグループ・コードに置く。
3. 埋め込みの MTEXT の値は、まだ置かず、複数行の属性は書き戻さない。

## 決定

選択肢 1 を採る。

- 読むときは、属性の値（ATTDEF の問い（3）まで）の後に、種類（71）・72・101（`Embedded Object`）と、MTEXT と同じ形の値を置く。DXF の 2 つ目の合わせの点（11・21・31）は、属性の合わせの点と同じなので置かない。
- 書き戻すときは、101 の後の値から埋め込みの MTEXT のフィールドを書く。37 ビットと、MTEXT の背景のフィールドと R2018 から増えたフィールドは、元のビットを写す。段のある MTEXT は、まだ扱わない。
- 足すときは、37 ビットをサンプルの図面と同じ値とし、MTEXT のフィールドは、足した MTEXT と同じく書く（[決定 0098](0098-dwg-r2018-mtext-attribute.md)）。埋め込みの MTEXT のハンドルは、サンプルの図面と同じく、所有者を 0、画層と文字スタイルを属性と同じもの、線種と材質を ByLayer のもの（材質は名前のオブジェクトの辞書の ACAD_MATERIAL の項目から探す）、アプリケーションの名前を 0 とする。

## 影響

- サンプルの R2018 の図面の複数行の属性を含む図形を変えて書き、読み直したものが変えたものと合った。
- サンプルの R2018 の図面に、複数行の ATTRIB を持つ INSERT を足して書き、読み直したものが足したものと合った。足した ATTRIB のハンドルのストリームは、サンプルの図面の複数行の属性と同じならびになった。
- サンプルの DXF の複数行の属性の 101 の後の値と、DWG から読んだ値は、DXF の数の書き方の桁の違いを除いて合った。
- 37 ビットの意味は分かっていない。書いた図面を AutoCAD で開いて確かめてはいない。

# 0030: DWG（R2000）への書き戻しは、表にない値を読む側の既定の値として符号化する

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-26 |
| 状態 | 採用 |

## 背景

[決定 0029](0029-dwg-table-write-back.md) で、LINE・CIRCLE・ARC の型ごとの欄の変更を R2000 の DWG に書き戻せるようにした。ほかの図形も同じ形で書き戻したい。

- 読む側は、既定の値の欄（POINT の X 軸の角度、ELLIPSE の押し出しの向き、3DFACE の見えない辺の印など）を表に置かない。
- SOLID・TRACE は、4 つの角の Z を 1 つの標高として記録する。表は、角ごとに Z（30〜33）を持つ。

## 選択肢

1. 表にない値は、読む側の既定の値として符号化する。DWG に表せない値の組は、書き戻さない。
2. 表にない値は、元のデータの値をそのまま写す。
3. 既定の値の欄を、読む側でもいつも表に置く。

2 は、表から値を除く変更を戻せず、表と DWG の値が食い違う。3 は、DXF から読んだ表と形が変わる。

## 決定

選択肢 1 を採る。

- POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE の型ごとの欄を符号化する。
- 表にない値は、読む側の既定の値とする。POINT の X 軸の角度（50）は 0、ELLIPSE の押し出しの向きは (0, 0, 1) とする。3DFACE の見えない辺の印（70）がなければ、印がないことを書く。
- SOLID・TRACE の 4 つの角の Z が同じでなければ、`dwg.change.unsupported` を返す。
- 3DFACE は、最初の角の Z が 0 ならその Z を書かず、2 つ目からの角は前の角を既定の値とする DD で書く。

## 影響

- 読み直した表は、書き戻した表と同じになる。既定の値を明示した表（例: 50 が 0）は、読み直すとその値を表に置かない。
- 試料の R2000 の図面の、書き戻せるすべての種類の図形の点を動かして書き戻し、読み直した表が変えた表と同じになることを確かめた。
- 共通の欄（色・線種の尺度・非表示）と、ほかの種類の図形は、まだ書き戻せない。

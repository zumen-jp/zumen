# 0254: 形式の確かめた度合いは台帳と形式の文書に置き、境界の capabilities には出さない

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-11-03 |
| 状態 | 採用 |

## 背景

[決定 0253](0253-parallel-agents-and-cross-review.md) で、形式ごとに、読みと書きを確かめた度合い（`spec`・`samples`・`verified`）を示すと決めた。台帳の欄と検査は別に足すとし、境界の `capabilities` に出すかは決めていない（#502）。

`capabilities` は、コアの版と、使える op・形式を返す（[決定 0015](0015-add-only-boundary-and-version-floors.md)）。形式は、図面の 4 つと図面のモジュールが読む 8 つ、入れたプラグインの形式を、`read`・`write` の真偽で返す。IFC・BCF・IDS・電子納品の管理ファイル・工事写真・ボーリング交換用データ・表などは、この一覧に載らない。応答は、適合試験（`bindings/conformance/cases/capabilities.json`）のハッシュに入る。

確かめた度合いは、#503・#504・#505 の確かめる作業で、コアのコードを変えずに上がる。また、1 つの形式の中でも、規則ごとに確かめ方が違う。DXF・DWG の書きは、引出線を書き戻したファイルだけを AutoCAD 2027 で開いた（#345）。

## 選択肢

1. 台帳（`formats/ledger.toml`）に置き、生成する一覧（`docs/formats/README.md`）と形式の文書に出す。`capabilities` には出さない。
2. 1 に加えて、`capabilities` の形式に、読みと書きの段の欄を足す。台帳から生成した表をコアに入れる。
3. 1 に加えて、形式の文書の URL を `capabilities` で返す。

## 決定

選択肢 1 を採る。

- **台帳。** 形式ごとに `[formats.<キー>.read]`・`[formats.<キー>.write]` を置き、段・確かめた範囲・確かめた日と、根拠（公開の試料・外部の実装・ソフトと版）を書く。書き方は `formats/README.md` にある。
- **段の決め方。** 段は、根拠のうちもっとも強い種類で決める。ソフトで開いていれば `verified`、公開の試料か外部の実装と照らしていれば `samples`、どちらもなければ `spec`。その方法で確かめたのが一部の規則だけでも、その段にし、範囲を一緒に書く。生成する一覧と形式の文書にも、そう書く。出所を記録していない手元の図面と、依存の crate が読むことは、根拠に数えない。
- **検査。** `cargo xtask codegen` は、次を拒む。
  - 根拠と合わない段と、公開サンプルの台帳にない試料。
  - 実装を名乗る crate（`[package.metadata.zumen]`）の形式で、読みにも書きにも段がないもの。
  - 段を持つ形式の文書に「確かめた度合い」の節がないか、節の表の段が台帳と違うもの。

  `zumen-abi` の試験は、`capabilities` の `read`・`write` と、台帳の段のある向きを照らす。
- **capabilities には出さない。** 理由は次のとおり。
  - 段は、確かめる作業で、コアと別に上がる。境界に出すと、段を上げるたびに `capabilities` の応答と適合試験のハッシュが変わる。確かめる作業が、境界の契約の変更と絡む。
  - `capabilities` の形式は、半分ほどの形式しか載せない。出しても、残りの形式の段を返せない。
  - 段だけでは範囲が分からない。アプリケーションが段で振る舞いを変えると、一部しか確かめていない `verified` を、全部を確かめたものとして扱う。
  - 境界は、1.0 から足すだけになる（決定 0015）。今の段の意味で欄を足すと、段や範囲の表し方を後で変えにくい。
- **見直すとき。** アプリケーションが、確かめた度合いを境界から引いて利用者に示す必要が出たら、選択肢 2 を新しい記録で決める。そのときは、範囲を返す形と、段を上げたときに適合試験のハッシュの一覧を作り直す手順も決める。

## 影響

- 利用者とエージェントは、確かめた度合いを、生成する一覧と形式の文書で見る。
- 形式を足すときと、確かめた度合いを上げるときは、台帳の段と形式の文書の節を同じ PR で直す。
- 段が上がっても、境界の応答と適合試験のハッシュは変わらない。

# 0151: 表のセルの書式と枠、表のスタイルの行の書式を、表に持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 採用 |

## 背景

[決定 0147](0147-drawing-table-cell-values.md) は、表のセルの書式と枠、表のスタイルの中身を移さず、表を描いたブロック（`Table.drawn`）が見た目を持つとした（#174 の「表のセルの書式」）。描いたブロックは線と文字なので、表を編集して描き直す使い手や、セルの寄せ方と背景の色で見出しを見分ける使い手は、書式を線と文字から推し量る必要がある。

DXF の ACAD_TABLE のセルは、表のスタイルからの上書きとして、文字の回転（145）・文字スタイル（7）・高さ（140）・寄せ方（170）・文字の色（64）・背景を塗るか（283）と色（63）・上下左右の枠の色・線の太さ・表示を持つ。表のスタイル（TABLESTYLE）は、表題と見出しの行を出すか（280・281）と、データ・表題・見出しの行の書式を持つ。手元の試料の `sample_AC10*` の図面の最初の表は、結合したセルで、寄せ方・文字の色・背景の色・高さと、左と上の枠（色 63、0.40 mm）を上書きする。

## 選択肢

1. セルに、回転と書式（文字・寄せ方・色・背景・枠）を足し、表に、表のスタイルの行ごとの書式を足す。値のない欄は、上書きしない（表のスタイルに従う）とする。
2. 形式固有の情報（拡張）にする。
3. 表を描いたブロックだけで見た目を持つ（今のまま）。

## 決定

選択肢 1 を採る。

- 書式は、表を表示・編集する使い手が形式を問わず使う図面モデルの語である。拡張（選択肢 2）では、DXF の符号を知る必要がある。
- 描いたブロック（選択肢 3）は、編集すると古くなる。書式と描いたブロックの両方を持てば、使い手は描き直すか、描いたものを使うかを選べる。
- 上書きは `Option` で持ち、`None` を表のスタイルに従うとする。表のスタイルの値をセルに解いて持つと、どのセルが上書きしたかが分からなくなる。

内容は次のとおり。

- `Cell.rotation` は、文字の回転（度）である。
- `Cell.format`（`CellFormat`）は、文字スタイルの名前・文字の高さ・寄せ方（横と縦）・文字の色・背景を塗るか・背景の色・枠（`Borders`）を持つ。色は、ほかの要素と同じく、レイヤとブロックからの継承を持つ。
- `Borders` は、上・右・下・左と、表のスタイルの中の横と縦の枠（`Border`）を持つ。`Border` は、色・線の太さ・表示を持つ。
- `Table.formats`（`TableFormats`）は、表題と見出しの行を出すかと、表題・見出し・データの行の書式を持つ。表のスタイルがなければ `None`。
- DXF の表のスタイルは、7 で始まる書式の組を、データ・表題・見出しの順に持つ（試料の表を描いたブロックの文字の高さと寄せ方で確かめた）。セルの枠は、上を 69・279・289、右を 65・275・285、下を 66・276・286、左を 68・278・288 とする（試料の描いたブロックの線の色と太さで、上・右・左を確かめた。下は推定）。表のスタイルの枠の番号は、DXF Reference の並びからの推定とする。
- DWG は、R2007 までの ACAD_TABLE のセルの上書きを DXF と同じ並びで置くので、DXF と同じく読む。R2004 までの TABLESTYLE も、DXF と同じ並びで置く（行はデータ・表題・見出しの順で、色は ACAD_TABLE と同じく R2004 の形の CMC。試料の DXF と同じ値になる）。R2010 からの DWG のセルのスタイルと内容の書式（ODS 20.4.101）と TABLESTYLE は、まだ読まない。そのセルの書式は空、表の書式は `None` になる。

## 影響

- 図面モデルの `Cell` と `Table` に欄が増えるので、作る使い手は欄を足す必要がある。
- R2010 からの DWG の表は、セルの書式を持たない。表を描いたブロックがあれば、その見た目を利用できる。試料では、セルのスタイルの枠は DXF と同じ色と太さを持つが、寄せ方・色・高さの上書きは内容の書式の欄に見つからなかった。
- R2010 からの DWG の TABLESTYLE は、名前の後に表のセルのスタイルと、番号・種類・名前（`Table`・`_TITLE`・`_HEADER`・`_DATA`）を持つセルのスタイルの並びを持つ。試料では、表題と見出しの高さと位置合わせを DXF と同じ値で読めたが、`_DATA` の項目の並びが ODS と合わなかったので、読まない。
- 表全体の上書き（93 と値）と、行と列ごとの書式は、まだ移さない。
- 書式の変更の書き戻しは、まだ扱わない。

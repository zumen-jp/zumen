# 0114: 図面モデルの下敷きを、資源の参照名と置き方と切り抜きで持つ

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0022](0022-drawing2d-semantics-and-format-mapping.md) は、下敷き（`Underlay`）に、資源参照・種類・ページ・内容の範囲・配置先の空間と変換・切り抜き・可視性・透明度・描画順を持たせると決めた。資源は、入力とともに渡された内容の ID か、未解決の参照名で指す。核は外部ファイルやネットワークを開かない。画素数や dpi を推測して埋めない。下敷きを常に最背面へ移さない。対応表の E7 は、線・画像・文字の順の配置と、未解決の画像名、回転と切り抜きを持つ PDF の 2 ページ目を試す。

## 選択肢

1. 下敷きを要素（`Shape::Underlay`）にし、空間と用紙の描く順の一覧にほかの要素と並べる。資源は元の参照名と、参照を定義するレコードの出所で持つ。
2. 下敷きを要素とは別の一覧に置き、描く順を別に持つ。
3. 資源をホストが渡す内容の ID で持ち、参照名を ID に解く処理を先に作る。

## 決定

選択肢 1 を採る。元の形式は下敷きを図形として並べ、ほかの図形と同じ描く順の表で前後を決める。別の一覧にすると、その順序を表すために別の仕組みが要る。内容をホストが渡す境界の op は、まだない。参照名だけを持てば、未解決のまま残せる。

- `Underlay` は次を持つ。
  - 種類（`UnderlayKind`: 画像・PDF・DWF・DGN）。
  - 資源（`Resource`: 元の参照名と、定義のレコードの出所）。
  - ページなどの名前。
  - 置き方（`UnderlayFrame`）。
  - 切り抜き（`Clip`: 下敷きの座標の頂点と、内側を隠すか）と、表示するか。
- 置き方は 2 つに分ける。画素の格子（`Pixels`）は、元の形式が持つ画素の数と、左下・右下・左上の角を持つ。尺度（`Scaled`）は、内容の原点を置く点・内容の 1 単位の長さ・回転を持つ。角を点で持つので、用紙の空間に置いた下敷きも、ほかの要素と同じく mm に換算できる。
- DXF の IMAGE と IMAGEDEF、PDFUNDERLAY・DWFUNDERLAY・DGNUNDERLAY と、その定義を移す。定義を指さないものや、数が合わない切り抜きは `dxf.lift.invalid` を返す。参照名のファイルは開かない。
- 内容の ID で指す資源は、ホストが内容を渡す op を作るときに足す。

## 影響

- 次のものは、まだ移さない。
  - 明るさ・コントラスト・薄さ・単色・透明の印。
  - 下敷きの切り抜きの反転の印。
  - 画像の定義の既定の画素の大きさと解像度の単位。
- 切り抜きの頂点の座標は、元の形式の下敷きの座標のまま持つ。画像では画素の座標、下敷きでは内容の座標と推定する。試料の図面では確かめていない。
- DWG の読み手は IMAGE と下敷きの型ごとの欄を表に置かないので、DWG の下敷きは移らず、`dxf.lift.invalid` を返す。
- 境界（`drawing` の op）の要約は、下敷きを数えず、範囲にも入れない。

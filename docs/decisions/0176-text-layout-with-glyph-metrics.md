# 0176: 1 行の文字は、呼び出し側が渡す字形の寸法で置き、字形の座標を図面へ写す変換で返す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-30 |
| 状態 | 採用 |

## 背景

図面モデルの文字（`Text`）は、宣言された高さ・9 点と基準線の位置合わせ・2 点の間（Fit と Aligned）の配置を持つが、字形の大きさと文字の幅は持たない（[決定 0022](0022-drawing2d-semantics-and-format-mapping.md)）。字形はフォントがないと決まらず、フォントは同梱せず呼び出し側が渡す（0022、[決定 0172](0172-scene-sections-and-op.md)）。シーンの文字の区画に字形を足す前に、渡されたフォントの寸法だけで配置が決まるかを試作で確かめた（#318）。

## 選択肢

1. フォントのファイル（TrueType・SHX）を受け取り、コアで読んで置く。
2. 字形の寸法だけを trait で受け取り、置いた結果を字形の座標から図面への変換で返す。
3. 配置をコアで求めず、表示する側に任せる。

## 決定

選択肢 2 を採り、`zumen_drawing::layout` に置く。

- **フォント。** `Glyphs` で、em・アセンダー・ディセンダー・大文字の高さと、文字ごとの送りと外形を受け取る。フォントにない文字は、フォントの代わりの字形で置き、数を返す。ファイルの読み方は配置と分け、別に決める。
- **結果。** 字形の単位の座標（基準線の始まりが原点）を図面の座標へ写すアフィン変換、文字ごとの送りの始まり、送りの合計を返す。表示する側は、字形の輪郭にこの変換を当てるだけで描ける。回転・幅の倍率・斜体・反転・位置合わせは変換に含める。
- **高さ。** 意味が大文字の高さ・em・枠なら、その寸法で倍率を決める。形式の宣言値（`Declared`）は、呼び出し側が、キーごとにどの寸法に当たるかを渡す。渡さなければ置かずに理由を返す。DXF の TEXT の高さ（40）がどれに当たるかは、表示と比べるまで決めない。
- **位置合わせ（推定）。** 左・中央・右は送りの合計の 0・半分・全部、外形の中央は字形の外形の中央（縦も外形の中央）。基準線・下・中央・上は、基準線・ディセンダーの線・大文字の高さの半分・大文字の高さの線。2 点の間は、送りの合計が 2 点の距離になるように幅を変え、Aligned は高さも同じ比で変える。斜体は字形にだけ当て、位置合わせは斜体の前の寸法で決める。反転は、置く点（2 点の間は中点）のまわりで当てる。
- **置けないもの。** 高さ・幅の倍率・2 点の距離・送りの合計が 0 か有限でないもの、斜体が 90 度以上のものは、置かずに理由を返す。

## 影響

- 試作は合成のフォントで試験した。位置合わせの規則は推定だった。AutoCAD 2027 の表示と比べて、外形の中央の横を送りの合計の半分に改め、DXF の TEXT の高さを `A` の字形の上に当てた（[決定 0246](0246-dxf-text-height-and-alignment-against-autocad.md)）。Jw_cad の表示とはまだ比べていない。
- 書式つきの文字（MTEXT）・縦書き・DXF の特殊な符号（`%%d` など）・カーニングは扱わない。内容の文字を 1 つずつ並べるだけである。
- シーン（0172）の文字の区画は、文字列と配置のまま持つ。字形の輪郭を返す区画は、フォントのファイルを渡せるようにしてから足す。
- 残る作業は、フォントのファイルから寸法を読むこと、表示と比べて規則と DXF の高さの意味を決めること、書式つきの文字などへ広げることで、それぞれ issue で追う。

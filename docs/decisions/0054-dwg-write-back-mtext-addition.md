# 0054: DWG（R2000）への書き戻しで足す MTEXT は、表にない文字の範囲の大きさと行の間隔の後の B を 0 にする

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0053](0053-dwg-write-back-pointing-entity-addition.md) で、足した TEXT・ATTDEF・INSERT を R2000 の DWG に書き戻せるようにした。MTEXT は、値を変えたとき、表にない文字の範囲の大きさ（2 つの BD）と、行の間隔の後の B を元のデータから写す（[決定 0034](0034-dwg-write-back-mtext.md)）。足した MTEXT には、写す元のデータがない。

試料の R2000 の図面の MTEXT 111 個を調べると、行の間隔の後の B はどれも 0 だった。文字の範囲の大きさは、多くは文字の大きさから決まる値だが、0 のものもあった。

## 選択肢

1. 文字の範囲の大きさを 0、行の間隔の後の B を 0 にする。
2. 文字の範囲の大きさを、文字列と文字の大きさから見積もる。
3. 足した MTEXT は、まだ受け付けない。

2 は、字の形を知らないと見積もれない。試料には範囲の大きさが 0 の MTEXT があるので、1 で読める形になる。

## 決定

選択肢 1 を採る。

- MTEXT を足せるようにする。値は、値を変えたときと同じ書き方で書く。文字の範囲の大きさは 0、行の間隔の後の B は 0 にする。
- 文字の体裁（7）は、TEXT と同じく表の STYLE から名前で探し、なければ Standard を指す（[決定 0053](0053-dwg-write-back-pointing-entity-addition.md)）。

## 影響

- 手組みのファイルに MTEXT（7 のあるものとないもの）を足して書き戻し、読み直した表が足した表と同じになることを確かめた。表にない文字の体裁は受け付けない。
- 試料の R2000 の図面のモデル空間に MTEXT を足して書き戻し、読み直した表が同じになり、CRC の診断が出ないことを確かめた。
- 文字の範囲の大きさは、図面を開いた側で求め直されるものと見なす。AutoCAD で開いて確かめてはいない。
- 属性を持つ INSERT、LWPOLYLINE・SPLINE・SHAPE など表にない欄を元のデータから写すほかの図形、図形でないオブジェクトの追加は、まだ書き戻せない。

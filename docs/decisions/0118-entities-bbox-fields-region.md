# 0118: entities の範囲は形の定義から求め、欄は fields で選び、region で範囲の重なる要素に絞る

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-28 |
| 状態 | 採用 |

## 背景

[決定 0117](0117-entities-op.md) は、`entities` の範囲（`bbox`）・欄の選び方（`fields`）・場所での絞り込み（`view`・`region`）を後で足すとした。[決定 0012](0012-boundary-functions-and-messages.md) の要求の例は、`region` を 4 つの数の配列で、`fields` を欄の名前の配列で書いている。図面モデル（[決定 0022](0022-drawing2d-semantics-and-format-mapping.md)）は文字の字形や線の太さを持たず、記号の配置を展開しない（[決定 0116](0116-drawing-symbol-references.md)）。円弧の端点を求めるには三角関数が要り、std のものは環境で値が違いうる（[決定 0007](0007-single-rust-implementation.md)）。

## 選択肢

範囲の求め方は、次の 3 つを比べた。

1. 描いた見た目を囲む。文字の字形・線の太さ・記号の中身を含める。
2. 形の定義から求める。曲線は通る所を囲み、字形・太さ・記号の中身は含めない。
3. 定義の点（中心・制御点など）だけを囲む。

`fields` を書かないときは、次の 2 つを比べた。

1. 今までの欄（`id`・`kind`・`layer`・`source`）を返す。
2. `bbox` も含めて、すべての欄を返す。

## 決定

範囲は選択肢 2、`fields` は選択肢 1 を採る。見た目を囲むには、字形と記号の展開が要り、描く処理と同じものを境界に持つことになる。定義の点だけでは、円や円弧の範囲が実際の線から外れる。`fields` を書かない要求は、今までと同じ応答にする（[決定 0015](0015-add-only-boundary-and-version-floors.md)）。

- **範囲（`bbox`）。** 要素の座標（空間か用紙の座標）で、次の点を囲む長方形。囲む点がなければ持たない。
  - 線分は端点。円は中心から半径の上下左右。
  - 円弧・楕円弧・膨らみのある折れ線の区間は、端点と、たどる向きの間にある X と Y の極値。スプラインは制御点と当てはめる点。
  - 文字と書式つきの文字は基点（2 点の間に置く文字は 2 点）。字形の大きさと枠の幅は含めない。
  - 寸法は定義点と文字の位置。引出線は経路の点。引出線つきの注記は、線の点・端・内容の基点。
  - 表は、挿入点から列の幅の和と行の高さの和で作る格子の角。下敷きは、画素の格子なら 4 つの角、尺度で写すなら置く点。
  - 記号は、置く点と属性の文字の基点。定義の中身は、まだ含めない。ハッチングは境界。
  - 長さ（半径・行の高さなど）が要素と違う座標の系（実寸の空間の要素に用紙の長さ）なら、その長さは使わない。
- **計算。** 三角関数と逆正接は `libm` で求める（決定 0007）。`libm` は MIT で、std に依らず WebAssembly でも同じに動く。`default-features` を切り、環境ごとの命令を使わない。
- **`fields`。** 返す欄の名前（`id`・`kind`・`layer`・`source`・`bbox`）の配列。1 つ以上で、同じ名前を重ねない。書いたら、`id` と書いた欄だけを返す。`id` は書かなくても返す。
- **`region`。** 4 つの数 `[最小の X, 最小の Y, 最大の X, 最大の Y]`。範囲が、この長方形と重なるか接する要素だけを返す。範囲のない要素は返さない。最小が最大より大きければ、要求を読めないとする。
  - 比べる座標は、空間か用紙それぞれの座標とする。空間か用紙を選ぶ欄（`view`）は、まだ足さない。
  - `total` と `offset`・`next_offset` は、絞り込んだ後の要素で数える。ID は、絞り込む前の要素で作るので、変わらない。
- **予算。** `region` を書いたときは、範囲を比べる要素 1 つごとにも `work` を 1 と数える。

## 影響

- 文字の字形の大きさ・線の太さ・記号の中身は、範囲に入らない。見た目の範囲が要るときは、描く処理（#4）の範囲を使うか、記号を展開する欄を後で足す。
- `entity` の欄は `id` だけが必ずあるものになる。`fields` を書かない要求では、今までの欄をすべて返す。
- `drawing` の要約の範囲（線分と文字の基点だけ）は変えない。

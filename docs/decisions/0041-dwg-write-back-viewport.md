# 0041: DWG（R2000）への書き戻しは、VIEWPORT の表の値を DWG の並びで書き、凍結した画層の数は元のまま写す

| 項目 | 内容 |
| --- | --- |
| 日付 | 2026-10-27 |
| 状態 | 採用 |

## 背景

[決定 0040](0040-dwg-write-back-annotations.md) までで、TOLERANCE・LEADER・MLINE までの型ごとの欄を R2000 の DWG に書き戻せるようにした。読む側は、R2000 の VIEWPORT の欄を、DXF の並び（中心・大きさ・ビューの中心・スナップ・グリッド・ビューの向きと目標・ビュー・状態・UCS）ですべて表に置く。角度は度に直す。凍結した画層の数（BL）は表に置かない。

## 選択肢

1. 表の値を DWG の並びへ並べ直して書き、表にない凍結した画層の数と、読む側が読まない後ろの欄は元のビットを写す。
2. 凍結した画層の数を 0 として書く。

2 は、ハンドルの流れにある凍結した画層の参照の数と合わなくなる。

## 決定

選択肢 1 を採る。

- 表の値はどれも欠かせない。欠けたもの、2 度あるものは `dwg.change.unsupported` を返す。
- ねじれ（51）とスナップの角度（50）は、度からラジアンに直して書く。
- 印刷スタイルの名前（1）が変わらなければ、元のビットを写す。変われば、DXF の `^` の書き方を元に戻して書く。
- UCS の印（71・74）は 0 か 1、描き方（281）は RC に収まる値だけを受け付ける。

## 影響

- 手で組んだ R2000 の VIEWPORT で、幅・ねじれ・左下の角・円の細かさ・UCS の印を変えて書き戻し、読み直した値と、データが組んだものと同じになることを確かめた。試料の図面の VIEWPORT も、中心を動かして書き戻す。
- 凍結した画層は、表に置かないので、まだ変えられない。

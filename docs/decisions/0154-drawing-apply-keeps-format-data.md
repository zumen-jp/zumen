# 0154: 図面モデルの置き換えは、元の図形の XDATA と拡張辞書を残し、図形とともに動く XDATA を持つ図形の形は変えない

| --- | --- |
| 日付 | 2026-10-29 |
| 状態 | 提案 |

## 背景

[決定 0139](0139-drawing-apply.md) は、図面モデルの変更を、元の図形のレコードに当てて DXF・DWG へ書き戻すとした。書けない拡張の診断は、置き換えの範囲を広げるときに扱うとした。

置き換えは、元のレコードの値を写し、変わった形の欄だけを直す。そのため、図形の XDATA と拡張辞書（102 の組と 360）も、元のまま書き戻している。図面モデルでは、形を変えた要素に付く形式固有の情報（[決定 0115](0115-drawing-format-extensions.md)）は、付く先が変わったので失効する（`stale_extensions`）。対応表の E5（[対応表](../formats/drawing2d-mapping.md)）は、拡張を更新するか失効させ、元の位置を復活させないことを求める。

AutoCAD は、図形を動かしても XDATA を残す。XDATA のうち、位置（1011）・変位（1012）・向き（1013）・距離（1041）・倍率（1042）は、図形を動かし・回し・尺度を変えると、同じ変換で直す（DXF Reference「Group Codes That Apply to Extended Data」）。ほかの XDATA（文字列・整数・ハンドル・点の 1010 など）は、そのまま残す。

試料の `sample_AC1018` と `sample_AC1024` の図面には、1011〜1013・1041・1042 を持つ TEXT がある。

## 選択肢

1. XDATA と拡張辞書を残す。図形とともに動く XDATA を持つ図形の形の変更は、受け付けない。
2. XDATA と拡張辞書を残す。図形とともに動く XDATA も元の値のまま書き、診断で知らせる。
3. 形を変えた図形の XDATA と拡張辞書を除く。
4. 置き換えた形から、図形とともに動く XDATA の変換を求めて直す。

## 決定

選択肢 1 を提案する。

- **残すもの。** 置き換えた図形の XDATA と拡張辞書は、元のレコードのまま書き戻す。AutoCAD が図形を動かしたときと同じく、登録したアプリケーションの値を残す。
- **受け付けないもの。** 形を変える置き換えで、元の図形が 1011〜1013・1041・1042 の XDATA を持てば、変更をすべて反映せず、`dxf.xdata.unsupported`（種類と、最初のグループ・コード）を返す。形を変えない置き換え（形が元と同じもの）は、これまでどおり当てる。除去は、XDATA があっても当てる。
- **理由。** 選択肢 2 は、図形とともに動くはずの値を元の位置のまま残し、E5 の「元の位置を復活させない」に反する。選択肢 3 は、アプリケーションの値を落とし、AutoCAD と違う結果になる。選択肢 4 は、置き換えの前後の形から変換（移動・回転・尺度）を一意に決められない種類が多い。決められる場合を見分けてから、別に足す。

## 影響

- 図形とともに動く XDATA を持つ図形は、図面モデルから形を変えられない。使い手は、診断の出所で図形を知り、元の形式のソフトで編集する。
- 拡張辞書の XRECORD（MTEXT・表の版の往復のためのものなど）は、元の値のまま残る。AutoCAD は、読むときに図形の値から作り直す（推定）。
- 図面モデルの拡張の失効（`stale_extensions`）は、変わらない。書き戻した XDATA を読み直すと、新しい形を付く先とする拡張になる。
- 移動・回転・尺度の変換を決められる置き換えで、図形とともに動く XDATA を直すことは、のちに扱う。

# v0.3.0 のリリースノート（準備中）

まだ公開していません。通常の公開日は 2026-11-24 です。公開する日の最新 main と検査結果に合わせて、対象と記録を最終更新します（[#795](https://github.com/zumen-jp/zumen/issues/795)）。Rust の公開 enum の移行が必要なため、既存方針に従い、次の候補をマイナーバージョン 0.3.0 にします。

## 配布物

- GNU Linux の x64・arm64 の共有ライブラリと CLI を、glibc 2.28 の環境で作ります。ELF の要求バージョンと Python wheel の `manylinux_2_28` タグを、ビルドと梱包で検査します（[#793](https://github.com/zumen-jp/zumen/pull/793)）。
- 同じ環境で、梱包対象のライブラリを Python 3.9・3.14 と .NET 10 から開き、CLI とともに適合テストを流します。wheel 自体のインストールと読み込みも確認します。古いカーネルの下限で動かした結果とは区別します。
- v0.2.0 の既存の配布物は置き換えません。同バージョンの GNU Linux のライブラリと CLI は glibc 2.34 以降を要求し、Python wheel のタグは glibc 2.35 以降です。

## 移行が必要な変更

XML の L0 は、原本のバイト列と名前・要素・属性・診断の位置を保って UTF-16LE・UTF-16BE を読みます。SDK と JavaScript の形式判定、XML を使う各形式も更新しました（[#826](https://github.com/zumen-jp/zumen/pull/826)）。

Rust の `zumen_xml::Encoding` に `Utf16Le`・`Utf16Be` と `#[non_exhaustive]` を追加したため、既存の網羅的な `match` は残りの値を扱う必要があります。ASCII の構造の名前は `parsed_local_name`、復号した名前は `local_name_text` で取得します。原本の UTF-16 の名前を UTF-8 として読まないでください（[XML の規則](../formats/xml.md)）。

```rust
match document.encoding() {
    zumen_xml::Encoding::Utf8 => { /* UTF-8 の原本 */ }
    zumen_xml::Encoding::ShiftJis => { /* Shift_JIS の原本 */ }
    _ => { /* UTF-16 と今後追加する文字コード */ }
}
```

BCF では、UTF-8 以外の markup の topic を変更すると、未知の要素・属性を保って書き戻せないため、`bcf.encoding.unsupported` で止めます。未変更の topic は、Shift_JIS・UTF-16 とも原本のまま保持します。以前に Shift_JIS の変更保存を使っていた場合も、この診断を扱ってください。

ABI は 1、メッセージのスキーマは 1.65 のままです。対応下限と既存の ID の契約は変えません。

## 機能と修正

- Rust の `zumen-scene` に、レビューの図形をシーンにする `build_review` などを追加しました。境界 API の新しい op ではありません。新しいレビュー用の ID 名前空間を使い、既存の ID は変えません（[#771](https://github.com/zumen-jp/zumen/pull/771)）。
- IFC の要素から表現・共有写像・曲線を必要なときに取得し、押し出しと閉じた任意断面の外輪も型付きで取得できます。元の単位・配置・出所を保ち、配置や写像の適用、形の評価と Building の形のハッシュへの統合は行いません（[#811](https://github.com/zumen-jp/zumen/pull/811)・[#822](https://github.com/zumen-jp/zumen/pull/822)・[#825](https://github.com/zumen-jp/zumen/pull/825)）。
- IFC の形の項目に直接付く面の表示を取得し、Shading・Rendering の全属性と出所を保ちます。未対応の種類は診断で止め、部分成功を返しません。材質や写像元からの継承と優先順位は評価しません（[#830](https://github.com/zumen-jp/zumen/pull/830)）。
- J-LandXML の最大片勾配が一定の区間を、Rust の土木モデルへ移します。すりつけなど移さない要素は種類・件数・元の場所を診断します。`civil` の API で片勾配の値を返すことは、引き続き [#468](https://github.com/zumen-jp/zumen/issues/468) で扱います（[#821](https://github.com/zumen-jp/zumen/pull/821)）。
- PLY の float32 座標の読み取りを改善し、公開の PLY・非圧縮 LAS のサンプルを外部の実装と照合しました（[#805](https://github.com/zumen-jp/zumen/pull/805)・[#810](https://github.com/zumen-jp/zumen/pull/810)）。
- View2D の細い線と矩形・許容差での選択漏れを修正し、React のリサイズ通知による寸法更新を次のフレームへまとめました。初回 fit と破棄時の予約の取消を保ちます（[#808](https://github.com/zumen-jp/zumen/pull/808)・[#823](https://github.com/zumen-jp/zumen/pull/823)）。
- View2D の巨大な直線を画面近傍へ切って描き、Linux WebKit で線が消える範囲を修正しました。端・join・破線の位相・透明度を保ちます。ほかの図形と、極端な尺度での破線の隙間の選択は継続して調べます（[#829](https://github.com/zumen-jp/zumen/pull/829)）。
- VBA7 の薄いラッパーと適合テストの手順を追加しました。Windows x86/x64 の ABI と手順の契約は検査しましたが、Office の実機では未確認です（[#800](https://github.com/zumen-jp/zumen/issues/800)）。
- レビューのシーンと IFC・BCF の未公開の診断 18 件は、この版で初めて配るため、カタログの `since` を `0.3.0` にそろえます。v0.2.0 に含まれる診断の初出は変えません。

## 開発と検証

- 公開サイトに図面ビューアーと導入先を案内し、通常ページと 404 応答で解析スクリプトの実行を拒否します。サイトが使う公開済みのコアのバージョンは、サイトの画面に別に表示します（[#782](https://github.com/zumen-jp/zumen/pull/782)・[#786](https://github.com/zumen-jp/zumen/pull/786)・[#790](https://github.com/zumen-jp/zumen/pull/790)）。
- React/View2D の private パッケージの peer 範囲は、公開済みの 0.2.0 と候補の 0.3.0 を受け付けます。サイトの公開コアの固定版と、playground のローカルの候補を分けて検査します。
- BCF 2.1 を Autodesk Build で確認するための、オフラインの検証キットと比較器を追加しました。実製品での確認は未実施です（[#792](https://github.com/zumen-jp/zumen/pull/792)）。
- IFC4・IFC2X3 を編集し、BIM ソフトで値・形・警告を確認するための検証キットを追加しました。実機確認は未実施で、IFC の書きの検証の段は `external` のままです（[#794](https://github.com/zumen-jp/zumen/pull/794)）。

## 継続する制約

- LAZ の展開は停止したままです。`las.laz.unsupported` を返します（[#510](https://github.com/zumen-jp/zumen/issues/510)）。
- PDF の読み取りは各言語の入口に含めず、`zumen-pdf` も公開しません（[#521](https://github.com/zumen-jp/zumen/issues/521)）。
- Shift_JIS の日本語の要素名とボーリングの形式判定は、[#824](https://github.com/zumen-jp/zumen/issues/824) で修正を追っています。UTF-16 の対応だけで、この問題も解消したとはしません。
- View2D の巨大座標には、描画と選択の未解決の範囲があります（[#812](https://github.com/zumen-jp/zumen/issues/812)・[#827](https://github.com/zumen-jp/zumen/issues/827)・[#828](https://github.com/zumen-jp/zumen/issues/828)）。
- 新しい配布物を公開し、各レジストリと Release から取得して確認するまで、glibc の公開版の制約は解消済みとは扱いません（[#789](https://github.com/zumen-jp/zumen/issues/789)）。

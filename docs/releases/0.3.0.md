# v0.3.0 のリリースノート

v0.2.0 のあとの main を出します。壊す変更があるので、マイナーバージョンを上げます（[リリースの条件と周期](../../xtask/release/README.md#リリースの条件と周期)・[#795](https://github.com/zumen-jp/zumen/issues/795)）。ABI は 1 のまま、メッセージのスキーマは 1.65 から 1.89 になります。

## 配布物

- crates.io に出す crate は 46 個です。`zumen-live`・`zumen-scene3d`・`zumen-text`・`zumen-geojson`・`zumen-sima`・`zumen-tiff` を新しく出し、`zumen-pdf`・`zumen-sheet` は出しません。
- GNU Linux の x64・arm64 の共有ライブラリと CLI を glibc 2.28 の環境で作り、ELF の要求バージョンと Python wheel の `manylinux_2_28` タグを検査します（[#789](https://github.com/zumen-jp/zumen/issues/789)・[#793](https://github.com/zumen-jp/zumen/pull/793)）。v0.2.0 の配布物は置き換えません。
- npm の `@zumen-jp/zumen`、PyPI の `zumen`、NuGet の `Zumen`、CLI・MCP と C ABI の配布物は、v0.2.0 と同じ名前で出します。

## 移行が要る変更

- **`sheet` の op と PDF・表（xlsx・CSV）の読み取りを、コアから外しました。** JWC・JWS も対象外です。`sheet` を送ると、要求の誤りになります。DXF・DWG の PDF の下絵（PDFUNDERLAY）の枠と外部参照は保ちます。表示は呼び出す側（pdf.js など）で行ってください（[903a9ea0](https://github.com/zumen-jp/zumen/commit/903a9ea0)）。
- **IFC の 8 ビットのエスケープを、CP932 の手がかりがあれば既定で復元します。** 以前の文字列と要素のハッシュが要るときは、`open` の `ifc_text_encoding` に `iso_8859_1` を指定してください。文書のハッシュ・ID・追加する文字列の書き方は変えていません（[95bfbd18](https://github.com/zumen-jp/zumen/commit/95bfbd18)）。
- **XML の原本の文字コードに UTF-16LE・UTF-16BE を足しました。** Rust の `zumen_xml::Encoding` に `Utf16Le`・`Utf16Be` を足し、`#[non_exhaustive]` にしたので、網羅する `match` には残りの値の腕が要ります。名前は、ASCII の構造なら `parsed_local_name`、復号した名前なら `local_name_text` で取ります（[#826](https://github.com/zumen-jp/zumen/pull/826)）。
- **SDK の `Signature::XmlRoot` の `name`・`namespace` は、原本の文字コードによらず UTF-8 のバイト列で指定します。** Shift_JIS のバイト列を渡していたら、`"ボーリング情報".as_bytes()` などに変えてください（[#831](https://github.com/zumen-jp/zumen/pull/831)）。
- **BCF で、UTF-8 以外の markup の topic を変えると、`bcf.encoding.unsupported` で止めます。** 変えていない topic は原本のまま保ちます。
- **Rust の `zumen_drawing::font` と `zumen_drawing::layout` は、`zumen_text::{font, layout}` に移りました**（[#851](https://github.com/zumen-jp/zumen/issues/851)）。API・診断・ID は変えていません。
- **Rust の `CivilModel`・`Alignment`・`CrossSection`・`CrossSectionLine` に、J-LandXML の保持値と高さの基準のフィールドを足しました。** 構造体のリテラルを書いている所は、[LandXML の Rust のモデルの移行](../formats/landxml.md#rust-のモデルの移行)に従って直してください（[b5699070](https://github.com/zumen-jp/zumen/commit/b5699070)）。

対応の下限と既存の ID の契約は変えていません。

## 新しい op

- `create`: 空の図面の文書を作ります（[#857](https://github.com/zumen-jp/zumen/issues/857)）。
- `measure`: 要素の長さ・周長・面積と、2 つの要素か点の間の最短距離を測ります（[#863](https://github.com/zumen-jp/zumen/issues/863)）。
- `calibrations`・`measure_distance`: 用紙の距離の校正を返し、選んだ校正で 2 点の距離を求めます。
- `convert_estimate`: 書き出す前に、変換の忠実度と入力の診断の明細を見積もります（[#855](https://github.com/zumen-jp/zumen/issues/855)）。
- `delivery_apply`: 電子納品の管理 XML の項目を変えて書き戻します（[#866](https://github.com/zumen-jp/zumen/issues/866)）。
- `scene3d`: 建物・地物・点群を、3D のシーンとして返します。
- `raster`: TIFF・GeoTIFF の画像を読みます（[#877](https://github.com/zumen-jp/zumen/issues/877)）。

## 機能

- 図面: `entities` で要素の色・線種・線幅と拡張の値を返し、ID・レイヤ・種類・出所で絞れます。`tables` で記号の定義の一覧を、`drawing` で種類別の要素数とビューの詳細を返します。同じ `apply` で足したレイヤとスタイルを要素から指せます（[#858](https://github.com/zumen-jp/zumen/issues/858)〜[#862](https://github.com/zumen-jp/zumen/issues/862)）。
- 書き出し: `convert` で SXF（P21）と JWW に書けます（[#360](https://github.com/zumen-jp/zumen/issues/360)）。
- DXF・DWG: ハッチングの追加、弧長寸法・表の位置・旧版の表の文字セル・ペーパー空間の要素の書き戻しを足しました。DWG R2007 を読めます（[#684](https://github.com/zumen-jp/zumen/issues/684)・[#874](https://github.com/zumen-jp/zumen/issues/874)）。
- JWW・SXF: 文字の追加・置き換え・移動と、レイヤの追加・名前の変更・要素のレイヤの変更を書き戻します。JWW は文字を足すと、後ろのブロック定義の中の要素の ID が移り、`ids_shifted` で知らせます（[#861](https://github.com/zumen-jp/zumen/issues/861)）。
- 新しい形式: GeoJSON（RFC 7946）の読み書き、SIMA 共通フォーマットの読み書き、TIFF 6.0・GeoTIFF 1.1 の読み取り、AutoCAD の SHX とビッグフォントの字形（[#876](https://github.com/zumen-jp/zumen/issues/876)・[#374](https://github.com/zumen-jp/zumen/issues/374)・[#877](https://github.com/zumen-jp/zumen/issues/877)・[#875](https://github.com/zumen-jp/zumen/issues/875)）。
- LAZ: 1.0〜1.4 の展開を、外部依存のない自前の実装で戻しました（[#510](https://github.com/zumen-jp/zumen/issues/510)）。
- IFC: 表現・共有写像・曲線・断面・面集合・材料・プロパティ・設備などを、元の単位と出所を保って取得します。建物から平断面・断面・立面を切り出し、測り方を指定して面積と数量を求めます。
- 2D の幾何: 交点・トリム・延長・オフセット・フィレット・面取り・閉領域の検出と集合演算を、整数の格子で決定的に求めます（[#886](https://github.com/zumen-jp/zumen/issues/886)）。
- 表示: 既定の CAD の色の表を配り、`render` で隠すレイヤを指定できます（[#864](https://github.com/zumen-jp/zumen/issues/864)）。
- 文書エンジン: 図面を常駐させて差分で編集する `zumen-live` を足しました。Session の DXF・DWG の `apply` は、このエンジンで当てます（[#878](https://github.com/zumen-jp/zumen/issues/878)）。
- CLI: MCP の画像の応答・高水準のツール・Streamable HTTP に対応しました。JavaScript から、ネイティブの子プロセスを非同期で呼べます。
- VBA7 の宣言とラッパーを足しました。Office の実機では、まだ確かめていません（[#800](https://github.com/zumen-jp/zumen/issues/800)）。

## 修正

- スプラインとクロソイドを折れ線にする作業量の検査を直しました（[#762](https://github.com/zumen-jp/zumen/issues/762)）。
- Shift_JIS の日本語の要素名を文字の境界で読み、ボーリング交換用データの読み取りと形式の判定を直しました（[#831](https://github.com/zumen-jp/zumen/pull/831)）。

## 診断のカタログ

v0.2.0 になかった診断の `since` を `0.3.0` にそろえました。v0.2.0 にある診断の初出は変えていません。

## 続く制約

- glibc の制約は、公開した配布物を各レジストリと Release から取り、ELF の要求と wheel のタグを確かめて直ったと扱います（[#789](https://github.com/zumen-jp/zumen/issues/789)）。

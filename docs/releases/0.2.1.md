# v0.2.1 のリリースノート（準備中）

まだ公開していません。通常の公開日は 2026-11-24 です。公開する日の最新 main と検査結果に合わせて、対象と記録を最終更新します（[#795](https://github.com/zumen-jp/zumen/issues/795)）。

## 配布物

- GNU Linux の x64・arm64 の共有ライブラリと CLI を、glibc 2.28 の環境で作ります。ELF の要求バージョンと Python wheel の `manylinux_2_28` タグを、ビルドと梱包で検査します（[#793](https://github.com/zumen-jp/zumen/pull/793)）。
- 同じ環境で、梱包対象のライブラリを Python 3.9・3.14 と .NET 10 から開き、CLI とともに適合テストを流します。wheel 自体のインストールと読み込みも確認します。古いカーネルの下限で動かした結果とは区別します。
- v0.2.0 の既存の配布物は置き換えません。同バージョンの GNU Linux のライブラリと CLI は glibc 2.34 以降を要求し、Python wheel のタグは glibc 2.35 以降です。

## 機能と互換性

- Rust の `zumen-scene` に、レビューの図形をシーンにする `build_review` などを追加しました。境界 API の新しい op ではありません。新しいレビュー用の ID 名前空間を使い、既存の ID は変えません（[#771](https://github.com/zumen-jp/zumen/pull/771)）。
- レビューのシーンの生成で返す診断 7 件は、このバージョンで初めて配るため、カタログの `since` を `0.2.1` に合わせます。v0.2.0 に含まれる診断の初出は変えません。
- ABI は 1、メッセージのスキーマは 1.65 のままです。各言語の公開 API、対応下限、既存の ID の契約を変える変更は含みません。

## 開発と検証

- 公開サイトに図面ビューアーと導入先を案内し、通常ページと 404 応答で解析スクリプトの実行を拒否します。サイトが使う公開済みのコアのバージョンは、サイトの画面に別に表示します（[#782](https://github.com/zumen-jp/zumen/pull/782)・[#786](https://github.com/zumen-jp/zumen/pull/786)・[#790](https://github.com/zumen-jp/zumen/pull/790)）。
- BCF 2.1 を Autodesk Build で確認するための、オフラインの検証キットと比較器を追加しました。実製品での確認は未実施です（[#792](https://github.com/zumen-jp/zumen/pull/792)）。
- IFC4・IFC2X3 を編集し、BIM ソフトで値・形・警告を確認するための検証キットを追加しました。実機確認は未実施で、IFC の書きの検証の段は `external` のままです（[#794](https://github.com/zumen-jp/zumen/pull/794)）。

## 継続する制約

- LAZ の展開は停止したままです。`las.laz.unsupported` を返します（[#510](https://github.com/zumen-jp/zumen/issues/510)）。
- PDF の読み取りは各言語の入口に含めず、`zumen-pdf` も公開しません（[#521](https://github.com/zumen-jp/zumen/issues/521)）。
- 新しい配布物を公開し、各レジストリと Release から取得して確認するまで、glibc の公開版の制約は解消済みとは扱いません（[#789](https://github.com/zumen-jp/zumen/issues/789)）。

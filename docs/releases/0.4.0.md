# v0.4.0 のリリースノート

v0.3.0 から実行環境の下限を上げます。C ABI は 1 のままです。公開の進み具合と配布先は [#932](https://github.com/zumen-jp/zumen/issues/932) に記録します。

## 実行環境の移行

- Windows は Windows 11 または Windows Server 2022 以降の x64・ARM64、Mac は macOS 14 以降の Apple Silicon が対象です。Windows x86 と Intel Mac の利用者は v0.3.0 の配布物を使えます。
- Linux x64・arm64 には glibc 2.34 とカーネル 5.14 以降が必要です。Python wheel のタグも `manylinux_2_34` に上がります。
- 2D・3D ビューアーと React フックには WebGPU と固定幅 SIMD を使えるブラウザーが必要です。HTTPS または localhost で開き、WebGPU を使えない環境では `webgpu-unavailable` を扱ってください。言語別の下限は[対応する環境](../support.md)にあります。

## API の移行

- Rust の IFC 書き込みでは、`NewShape` の `solids`・`faces` を `body` にまとめました。押し出し・面集合・集合演算・写像を項目の木で渡せます。[IFC の変更](https://github.com/zumen-jp/zumen/commit/5740003b)
- Rust の座標変換では、JGD2011 の成果改定のファイルを `Shifts::revision` に渡します。`Shifts` を構造体の式で作る呼び出し側にも、このフィールドを追加してください。[座標変換の変更](https://github.com/zumen-jp/zumen/commit/3fb09901)
- 文書エンジンの表示色は、RGB、画層やブロックから引き継ぐ色、形式ごとの色番号を区別します。色の値を直接読んでいた場合は、`zumen_live::display::color` の定義に合わせてください。[色の符号化](https://github.com/zumen-jp/zumen/commit/3d77f4c3)
- 旧版の赤入れを変換する `cargo xtask migrate-markup` を廃止しました。[赤入れの変更](https://github.com/zumen-jp/zumen/commit/928617d5)

## 配布の追加

- Rust の ST-Bridge 対応を `zumen-stbridge` として配布対象に加えます。
- ブラウザー向けに `@zumen-jp/view2d`・`@zumen-jp/view3d`・`@zumen-jp/react` をコアと同じ版で用意します。[npm の公開状況](https://github.com/zumen-jp/zumen/issues/909)
- Java・Swift・Go・Dart・VBA の初回配布は、言語ごとに入手と動作を確かめて記録します。[言語別の公開状況](https://github.com/zumen-jp/zumen/issues/435)

# 図面モデルと SXF・JWW・DXF の対応

[決定 0022](../decisions/0022-drawing2d-semantics-and-format-mapping.md) の根拠と、実装で確かめる項目をまとめます。これはモデルの設計上の対応であり、読み書きできる形式や要素の一覧ではありません。最小の DXF の試作は [#3](https://github.com/zumen-jp/zumen/issues/3)、残るモデルの実装は [#28](https://github.com/zumen-jp/zumen/issues/28) で追います。

## 読み方と確認した資料

共通の要素は意味を保つための型、拡張は同じ系統へ返す形式固有の情報です。「専用要素なし」は、下記の範囲で直接対応する要素を使えないという意味です。線・文字・部品から、その意味を推定できるという意味ではありません。

資料は 2026-10-25 に確認しました。仕様の本文・図・表は同梱しません。形式の権利は [台帳](../../formats/ledger.toml) にあります。

## 仕様と旧版の推定を分ける

- **SXF の文字の長さ。** S-F 3-4（8）の本文 p.29 で、配置された用紙・部分図の座標系を使うことを確認しました。用紙固定の点マーカー・矢印（S-R 1-4・1-6）、用紙の線種ピッチ（S-F 3-3（4）を参照）とは区別します。ハッチングの間隔は配置の縮尺に従います（S-R 1-7）。
- **非等方の文字枠。** S-F の本文 p.30 と O-G 9（3）は、変換後の文字枠の扱いを示しています。字形全体を任意のせん断で変形する指定とは分けて保持します。
- **DXF の字形の比率。** TEXT 40 は文字の高さを指定しますが、0.88・0.72 という比率は定めていません。L-T の比率を仕様に格上げしません。フォントなしで漢字の有無だけから em へ換算する試験も正解にはしません。
- **DXF の弧長寸法。** ARC_DIMENSION は E の実装の知見に基づく候補です。D で確認した要素とは分け、対象版の最小のファイルで検証してからコーデックに加えます。
- **JWW の原点・画像の単位。** 用紙中央原点や画像の配置単位は L-J の実装・検証の知見です。J の欄の一覧だけから値の意味を確定せず、コーデックを作る際に Jw_cad が保存する最小の図面で照合します。
- **JWW の文字種。** J の CDataMoji は説明とコード例で斜体・太字の加算値の対応が食い違います。元の値を保持し、実機の検証前に一方を仕様として固定しません。
- **JWW のソリッド。** L-J は保存順を境界順とする実機の検証を記録しています。J の頂点の呼び名だけから順序を決めず、同じ最小の四角形・三角形で再確認します。
- **SXF の画像の基点。** L-S は、境界の最初の頂点を左下とする扱いを推定と明記しています。原本の境界と順を保持し、解釈を仮定した配置は診断します。
- **新しい JWW の設定・画像順。** L-J の 8 以降の制御文字の知見と、画像の描画順の未検証を、7.02 の公開説明に含めません。未対応の欄は保持し、検証するまで自動変換の根拠にしません。

これらの未確認事項は、#28 から分けた SXF・JWW のコーデック（#171・#172）と DXF・DWG の残件（#173・#174）で検証します。意味を確定できなくても元の情報を保持し、仮定を診断できることが、この設計の条件です。

## 最小の例と試験項目

以下は試験の設計です。この文書の追加だけで試験を実装・実行したとは扱いません。E1〜E3・E9 のうち #3 の範囲（等方のビュー、文字の高さの空間、文字の基本の配置、単位の不明・特異な縮尺・3D・予算）は、DXF からの変換の試験として `crates/zumen-acad/tests/drawing.rs` にあります。E1・E2 の非等方のビューでの点の配置と向きごとの長さの換算は、`crates/zumen-drawing` の試験にあります。レイヤの表・ビューごとの非表示・描く順と、E6 のうち色の符号・線種の定義・レイヤからの継承と、E4 のうち寸法の種類・定義点・保存された測定値と文字の上書きの区別・引出線の経路と注記の参照・寸法スタイルの端部記号と、記号の定義のキー・配置・属性、E5 のうち XDATA の拡張と編集での失効、ハッチングの境界・塗りとパターンとグラデーションの区別、E6 のうち同じ形で名前の違う線種と同じ RGB で符号の違う色、E8 のうち穴のある塗り、E9 のうち循環する定義・欠けた定義・有限でない尺度・展開しない大きな格子の配置は、DXF からの変換の試験にあります。E2 のうちハッチングの線の間隔のビューでの換算は、`crates/zumen-drawing` の試験にあります。JWW で表せるもののうち、E1 のレイヤグループごとの縮尺のビュー、E3 の宣言値としての文字の高さ、E4 の線形の寸法と元の値の拡張、E5 の編集状態と制御文字の拡張、E6 のペンの番号の色と番号の線種、E8 の同じブロックの定義の配置と、画像の下敷きは、`crates/zumen-jww/tests/drawing.rs` にあります。入力は各試験の中で作り、実図面を Git に入れません。L1 のバイトの往復は同じ符号化・版・文字コードで比べ、L2 は意味と出所、L3 は指定した許容差で比べます。

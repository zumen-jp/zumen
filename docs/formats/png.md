# PNG

[PNG 第 3 版](https://www.w3.org/TR/png-3/) に従い、シーンから静止画を書く。描画の判断は[決定 0277](../decisions/0277-bounded-png-rendering.md)、設定と API は[描画](../render.md)にある。

## 符号化

RGBA 8 bit、非インターレース、フィルター None を使う。IHDR、sRGB（知覚的）、gAMA（45455）、IDAT、IEND の順に書く。DEFLATE は長さ 65535 以下の非圧縮ブロックにし、RFC 1950 の Adler-32 と PNG の CRC-32 を付ける。時刻・ソフト名・ファイル名は書かない。PNG を読む API は持たない。

走査線と辺の交点は、端点を y の昇順にそろえ、走査線に近い端点から求める。元の向きは winding に使う。サンプルは左と上の端を含み、右と下の端を除く。表示範囲と図形・通常のクリップの外接範囲が重なる列と行を走査する。反転クリップはその範囲の中でサンプルごとに判定する。

## 公開サンプル

PNG の公式仕様の Test Suites と PngSuite の公式ページを調べた。後者は 2026-11-06 の取得で応答しなかった。今回の対象は書く向きなので、テスト内で作ったシーンから書き、外部のデコーダーに読ませて照らす。PNG の読み取り用のサンプルは同梱しない。

## 確かめた度合い

| 形式 | 向き | 段 |
| --- | --- | --- |
| `png` | 書き | `external` |

Chromium 156.0.8078.4 で、合成シーンから書いた PNG の寸法と RGBA を照らした。穴・字形・描画順・通常と反転のクリップ・余白を含む。不透明な出力は全画素が一致し、半透明な背景は Canvas の premultiplied RGBA の丸めによる RGB の差を 1 まで認め、alpha は一致することを確かめた。Node.js の zlib 1.3.2.1-motley-285e94b では CRC・Adler-32 と復号後の RGBA 全体が一致する。

線の butt・miter・重なる線の一度だけの alpha 合成、円・点、サンプル単位のクリップ、予算・中断・大きすぎる寸法と座標は Rust の契約テストで確かめる。SVG・PNG のバイト列・診断・使った予算はネイティブと wasm で照合する。閲覧側ごとの色管理とアンチエイリアスの一致、画像とアンダーレイの資源の読み取りは対象にしない。

# 座標系と標高

crate `zumen-crs` が持つ、座標の空間の型・座標系の名指し・平面直角座標の換算・ジオイドの格子の補間を書きます。方針は [決定 0019](../decisions/0019-coordinate-systems-and-gsi-data.md) にあります。

## 空間の型

| 型 | 空間 | 成分 |
| --- | --- | --- |
| `MapPoint` | 地図（メートル） | `northing`・`easting`。平面直角座標系の X・Y に当たる |
| `GeoPoint` | 地理（度） | `latitude`・`longitude` |
| `ProjectPoint` | プロジェクト（文書の長さの単位） | `x`・`y`・`z`（Z が上） |
| `Height` | 高さ（メートル） | 値・基準（`HeightDatum`）・成果（`Realization`） |

- 形式が書く成分の順は、`Axes`（`EastNorth`・`NorthEast`）で読み書きの所で直す。
- プロジェクトから地図への変換は `MapConversion`（IFC の `IfcMapConversion`）で表す。IFC 4.3 の定義のとおり、3 つの軸に同じ尺度（`Scale`）を掛け、地図の上の X 軸の向き（`XAxisAbscissa`・`XAxisOrdinate`）で反時計回りに回し、`Eastings`・`Northings`・`OrthogonalHeight` だけ動かす。回す角は、向きのベクトルを長さで割って余弦と正弦にし、三角関数を使わない。`IfcMapConversionScaled`（軸ごとの尺度）は、まだ扱わない。

## 座標系の名指し

| 座標系 | EPSG | `zumen-crs` |
| --- | --- | --- |
| JGD2024（JGD2011）の経緯度 | 6668 | `Crs::Geographic` |
| JGD2024（JGD2011）の平面直角座標系 I〜XIX | 6669〜6687 | `Crs::Plane(Zone)` |
| JGD2011 (vertical) height | 6695 | `VerticalCrs::Jgd2011`（測地成果2011） |
| JGD2024 (vertical) height | 11317 | `VerticalCrs::Jgd2024`（測地成果2024） |

- 名前は、`EPSG:6677`・`urn:ogc:def:crs:EPSG::6677`・`http://www.opengis.net/def/crs/EPSG/0/6677` と、EPSG の名前（`JGD2024 / Japan Plane Rectangular CS IX`）を読む。水平の座標系の `JGD2011` は `JGD2024` と同じに読む。高さの 2 つの名前は、別の成果を指す。
- JGD2000（EPSG:2443〜2461）と日本測地系（EPSG:30161〜30179）は、別の測地系なので読まない。測地系の間の変換は、その座標を持つ形式を足すときに入れる。
- 19 の系の原点は、平成 14 年国土交通省告示第 9 号の別表から書く。経度は分の整数で持ち、ラジアンにするときに π/10800 を掛ける。

## 経緯度と平面直角座標の換算

国土地理院の測量計算サイトの平面直角座標への換算と緯度・経度への換算の計算式を、そのまま書く（2026-10-31 に確かめた）。楕円体は GRS80（測量法施行令第 3 条）、X 軸上の縮尺係数は 0.9999 とする。

- 順の換算は河瀬（2011）の式。展開の項は 5 つまで。
- 逆の換算は、地心緯度を介する河瀬（2021）の式。正角緯度 χ から δ の級数で地心緯度を求め、楕円体の比 (1+n)/(1−n) を 2 回掛けて緯度にする。
- 子午線収差角は、計算式の γ を度で返す。測量計算サイトの出力（`gridConv`）は、同じ点で符号が逆になる（下の照合を参照）。
- 中央の子午線からの経度の差が ±90 度に届く点と、緯度が ±90 度の点は換算しない。

## ジオイドの格子

ISG format 2.0（ISG、2020-06-25）の格子を読み、国土地理院の「ジオイド2024日本とその周辺」の説明書（2026 年 4 月）の方法で補間する。ジオイド高・基準面補正量・その和のどれかは、渡した格子で決まる。

- 読むのは、`data format` が `grid`、`coord type` が `geodetic`、`coord units` が `deg` か `dms`、`data units` が `meters`、並びが北から南・西から東（`N-to-S, W-to-E`。仕様の例の `N-S, W-E` も読む）のもの。書かれていない項目は、ISG format 2.0 の既定とする。ほかの形は `crs.geoid.unsupported` にする。
- 格子の間隔は、範囲と行・列の数から求める。`deg` の間隔（`0.333333` など）は丸めて書かれるので、書かれた間隔が求めた間隔と半分より違うときだけ壊れているとする。
- 双一次の補間は、求める点を囲む四隅の格子点を使う。重みが 0 でない格子点のどれかが `nodata` なら、値を返さない。格子点の上や格子の線の上では、重みが 0 の点を見ない（説明書の注 6）。格子の範囲の外も返さない。
- 補間の結果は、使ったモデルの名前と年（`model name`・`model year`）を持つ。
- 見出しの前の注記は読まない。値の数は、予算のレコードで数える。見出しの行と列の数で場所を取らない。

国土地理院のジオイド・モデルは、Git・パッケージ・試験に入れない。試験（`crates/zumen-crs/tests/grid.rs`）は、ISG format 2.0 の例と同じ形の合成の格子を使う。実際のモデルで、国土地理院の内挿計算プログラムと比べる照合は、[#438](https://github.com/zumen-jp/zumen/issues/438) で行う。

## 標高の成果と基準

- `Height::difference` は、基準の違う高さの差を求めず `crs.height-datum.unsupported` を返す。成果の違う高さの差は求め、`crs.height-realization.mixed` を返す。
- `Realization::or_assume` は、形式が成果を書いていなければ、渡された成果を仮定して `crs.height-realization.assumed` を返す。

## SXF の測地座標系の部分図

SXF の測地座標系の部分図（X が北、Y が東）は、図面モデルの実寸の空間の `axes` を `Axes::NorthEast` にして持つ。空間の点は、ファイルの X・Y のまま持つ。用紙へ置くビューの変換は、`Axes::to_east_north` で東・北の順にしてから、数学座標系の部分図と同じ尺度・回転・移動で写す（[sxf.md](sxf.md)）。

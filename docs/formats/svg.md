# SVG

[SVG 1.1 Second Edition](https://www.w3.org/TR/SVG11/) に従い、`zumen-render` がシーンを SVG に書きます。SVG の読み取りは持ちません。

## 書くもの

固定の `svg`・`g`・`defs`・`clipPath`・`path`・`rect`・`circle` と数値属性を使います。線は折れ線、面は evenodd の輪、文字は nonzero の字形の輪郭です。塊と描く単位の順を保ち、切り抜きを重ねます。出力の設定と描かないものの扱いは[シーンの描画](../render.md)にあります。

- 座標と範囲: 仕様 7 章。出力はピクセル座標にし、縦を反転します。塊の原点と表示範囲の原点の差を先に計算してから相対座標を足します。
- パス: 仕様 8.3。直線と閉じる命令を使います。シーンで分割した曲線を再分割しません。
- 色と線幅: 仕様 11.2〜11.4。色は sRGB、透明度は塗り・線のそれぞれに適用し、グループの合成には変えません。
- 切り抜き: 仕様 14.3.5。共通部分は入れ子の `g`、反転は出力の長方形と多角形を evenodd のパスにして表します。

仕様の公式サイトからたどれる[文書ライセンス](https://www.w3.org/copyright/document-license-2023/)と[特許方針](https://www.w3.org/Consortium/Patent-Policy-20040205/)を確認し、権利の根拠を `formats/ledger.toml` に記録しています。仕様の本文とコードは写していません。

## 確かめた度合い

| 形式 | 向き | 段 |
| --- | --- | --- |
| `svg` | 書き | `external` |

小さいシーンをテストの中で作り、描画順・色・切り抜き・字形・予算・中断・不正な列を確かめています。書いた SVG を Chromium 156.0.8078.4 で読み、寸法と、描画順・面の穴・字形・通常と反転の切り抜きの画素を照らしました。点記号の細部と、閲覧側ごとのアンチエイリアスは照合していません。読み取りを実装しないため、SVG の公開サンプルを読むテストは対象外です。PNG は #604 で追跡します。

[render API](../render.md) は、空間・用紙・範囲・明示したフォントから SVG を作ります。共通の適合入力で、出力と診断の ID・予算の応答を native/wasm と各言語から照らします。既存の `scene` と描画部品を続けて呼んだ場合との一致、不正な指定・中断・予算超過で画像を残さないことも検査しています。

DXF の MTEXT の色の再使用と、文字の後に寸法を置いて領域で絞る経路から、unit の列が昇順でないシーンを作り、元の ID と診断件数のまま SVG に書けることも確かめています。順序索引の確保前の要素数・容量と、並べ替えの途中の作業量の予算を検査しています。

`crates/zumen-render/tests/browser.mjs` は既存の Playwright 1.64.1 を使い、ブラウザーからのネットワーク要求を拒否して実行します。PR の CI と `nightly.yml` の毎晩・手動実行で同じように照合します。再現の手順は[描画部品の README](../../crates/zumen-render/README.md)にあります。native/wasm の照合は、同じ組の SVG 全体・診断・予算・停止の記録をバイト単位で比べます。

## JSA の購入条件

2026-11-11 10:01 JST 以降、JSA Webdesk の公開ページを通常の HTTP 取得で確認しました。検索・閲覧ツールには以前のメンテナンスの案内も返りましたが、以下は公式サイトから直接取得した現行のページに基づきます。ログイン・購入・登録や、「同意する」の操作はしていません。

検索結果には、対象外のプレビュー PDF の索引断片も混ざりました。PDF 自体は開かず、その断片を根拠に使っていません。以下の条件とメタデータは、公開の利用規約と規格詳細のページで確認したものです。

- [利用規約の同意](https://webdesk.jsa.or.jp/books/W11M0110/)には、注文の前に規約への同意を求める画面があります。[電子書籍配信サービス及びネット通販サービス利用個別規約](https://webdesk.jsa.or.jp/common/W10K0030/?post_type=book_common&page_id=b_j_yakkan)の日付は 2026-10-01 です。電子書籍は注文手続きの完了時、冊子などの商品は注文確定ボタンを押した時点で契約が成立するとします（第 1 条・第 5 条）。
- 同じ規約の第 2 条は電子書籍、第 5 条は冊子などの規格について、全部・一部を AI ツールなどに入力することと、AI による翻訳などの派生物の作成を禁止しています。公開 LLM へのアップロードと AI の学習への使用も禁止しています。電子書籍と冊子のどちらも、購入品の本文をエージェントは読みません。
- [著作権・ウォーターマークの案内](https://webdesk.jsa.or.jp/common/W10K0030/?page_id=b_j_tyosakuken&post_type=book_common)も、購入した規格の利用に規約への同意を求めます。PDF には購入者などのライセンス情報を付けるとします。ウォーターマークのサンプルや規格のプレビュー PDF は開いていません。

## 次の確認

1. JISC のサービスの復旧後、上の公開ページで現行の閲覧条件と、6 件の規格・年を確認する。購入・登録・同意の操作には進まない。
2. 本文を読む必要がある場合は、入手元と、その資料に適用される条件を確認する。購入・登録・同意や、規約の読みで採否が決まる判断は、`AGENTS.md` の「並行して進める」に従って利用者に頼む。
3. JIS X 0208・JIS X 0201 の仕様の項は、この調査では台帳に足しません。販売されている年は確認できましたが、実装の出典は電子納品要領と `encoding_rs` で、要領は JIS の年を指定していません。購入品を直接の出典に置き換えず、参照元の表と購入条件で追います。JISC の条件を確認しても、実装が参照する年と出典は別に確かめます。ほかの 4 件も、参照元の表で追います。
4. 確認した条件と本文を読むかを #704 に記録し、台帳を変えたら `cargo xtask codegen` で一覧を作り直す。

JISC の復旧と現行の閲覧条件が、残る未確認部分です。再試行は[待ちを減らす手順](../work.md#待ちに当たったら)に従います。新しいコメント・関係する PR のマージ・台帳の変更がなければ、今回の試みから 14 日後の 2026-11-25 以降にあらためて確認します。既存のコードとプロファイルの規則・形式の権利の台帳は、この記録では変えていません。

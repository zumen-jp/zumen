# 実装と文書が参照する JIS

JIS の参照元と、本文の入手・閲覧条件を調べた範囲を記録します（[#704](https://github.com/zumen-jp/zumen/issues/704)）。規格の本文・表・図は収録していません。以下は 2026-11-10 の調査で、利用条件の確定には、サイトの復旧後の確認が残っています。

| --- | --- | --- |
| JIS X 0208・JIS X 0201 | [`zumen-delivery` の文字のチェック](../../crates/zumen-delivery/src/check.rs)、[工事完成図書のプロファイル](../../profiles/mlit-delivery-const/2026-02/profile.toml) | 電子納品要領の 8-2 節が指定する文字。実装は `encoding_rs` の Shift_JIS の変換と区の範囲を使い、JIS の文字表を同梱していません。JIS の年は参照元にありません |

JIS の番号を参照していることと、その本文を入手して読んだことを分けます。この調査では、6 件とも本文を取得していません。

検索結果の索引には、JISC の無償閲覧には登録・規約への同意が要り、印刷・ダウンロードはできないとあります。JSA の購入規約には、規格の全部・一部を AI ツールなどへ入力することを禁じる記述が出ています。ただし、上の取得先では現行の文を確認できていないため、本文を読めるという判断の根拠にはしません。JISC の規約の索引に AI を名指す記述が見つからないことも、AI での利用を許す根拠にはしません。

## 次の確認

1. サイトの復旧後、上の公開ページで現行の条件と、6 件の規格・年を確認する。購入・登録・同意の操作には進まない。
2. 本文を読む必要がある場合は、入手元と、その資料に適用される条件を確認する。購入・登録・同意や、規約の読みで採否が決まる判断は、`AGENTS.md` の「並行して進める」に従って利用者に頼む。
3. JIS X 0208・JIS X 0201 の仕様の項を台帳に足すかは、条件を確認したあとに決める。現在の調査では年と入手条件を確定できていないため、台帳に推定の項を足していません。ほかの 4 件は、採用しなかった案・テストの文字列・別の文書を通した参照・将来の候補として、上の表で追います。
4. 確認した条件と本文を読むかを #704 に記録し、台帳を変えたら `cargo xtask codegen` で一覧を作り直す。

サービスの復旧を待つのは、この調査の未確認部分です。既存のコードとプロファイルの規則・形式の権利の台帳は、この記録では変えていません。

# DWG

AutoCAD の系統のファイルモデル（L1）として DWG を読む規則と、仕様が決めない所の扱いを記録します。実装は `crates/zumen-acad` の `dwg` です。仕様は Open Design Specification for .dwg files 5.4.1（以下 ODS）だけを使い、GPL の実装は読みません。

## 対象

- R2000（AC1015）・R2004（AC1018）・R2010（AC1024）・R2013（AC1027）・R2018（AC1032）を読む。R2004 から後は、入れ物の区切りを展開してから読む（決定 0026・決定 0027）。ほかの版（AC1012〜AC1014・AC1021）は形式の判定には使い、読むときは `dwg.version.unsupported` を返す。
- 書くときは、元のバイトをそのまま並べる。R2000 は、オブジェクトのデータを置き換えられる（決定 0028）。
- 境界（`zumen-abi`）の `open` は、DWG の判定の規則に合う入力をこのコーデックで読む。`drawing` の op で図面モデルの要約を返し、適合試験（`bindings/conformance/cases/open_dwg.json`）でネイティブと wasm の出力を比べる。`capabilities` の `formats` は版を持たないので、読めない版があることは、ほかの版を開いたときの `dwg.version.unsupported` で分かる。

## ファイルの区切り

- 見出し（ODS の 3）から、コード・ページと区切りの記録を読む。見出しの CRC が合わないときは `dwg.crc.invalid` を返して読み続ける。終わりの印が合わないときは `dwg.file.invalid` で止める。
- クラス（ODS の 10）を、区切りの記録の 1 番から読む。始まりと終わりの印が合わないときは `dwg.file.invalid` で止め、CRC が合わないときは `dwg.crc.invalid` を返して読み続ける。区切りの記録がないか、大きさが 0 なら、クラスはないとする。
- オブジェクトの地図（ODS の 23）を、区切りの記録の 2 番から読む。地図の区切りごとの CRC も確かめる。ハンドルと位置の差分は、区切りごとに 0 から数える。
- 地図が指す位置から、オブジェクトの大きさ（MS）・データ・CRC を 1 つのレコードとして持つ。レコードの種類は、型から決めた DXF の名前。オブジェクトの CRC が合わないときは `dwg.crc.invalid` を返して読み続ける。
- 予算は、入力の大きさ、区切りの記録とオブジェクトの数（レコード）、地図の組の数（作業）で数える。

## R2004 の入れ物

- 暗号化した見出し（ODS の 4）を戻し、初めの印と CRC を確かめる。CRC が合わないときは `dwg.crc.invalid` を返して読み続ける。初めの印が合わないときは `dwg.file.invalid` で止める。
- ページの地図と区切りの地図のページの型と検査の値を確かめ、展開する。検査の値が合わないときは `dwg.crc.invalid` を返して読み続ける。型と展開が合わないときは `dwg.file.invalid` で止める。
- 区切りの名前ごとに、データのページの見出しを戻し、展開してつなげる。データのページの 2 つの検査の値を確かめ、合わないときは `dwg.crc.invalid` を返して読み続ける。暗号化した区切りは読まない。
- `AcDb:Header`・`AcDb:Classes`・`AcDb:Handles`・`AcDb:AcDbObjects` のどれかがないか空なら、`dwg.file.invalid` で止める。あれば、見出しの変数・クラス・オブジェクトの地図をそれぞれの区切りから、R2000 と同じ形で読む。地図が指す位置とレコードの位置は、`AcDb:AcDbObjects` の展開したバイト列の中の位置とする。
- 予算は、区切りとページの数（レコード）と、展開した大きさ（展開・復号のバイト数）で数える。
- 区切りの中の並びは、次が R2000 と違う（ODS の 2.11・2.12 と、各オブジェクトの R2004 の欄）。
  - 色（CMC）は、番号の後に RGB の値と印が続く。図形の色（ENC）は、印のビットで RGB の値と透明度が続くか、DBCOLOR のハンドルで指すかを表す。
  - オブジェクトと図形の共通の欄に、拡張辞書がないことを表す B がある。図形は前後の図形のハンドルを持たない。
  - クラスの区切りは、クラスの前に前置きを持ち、クラスごとに 5 つの BL が増える。
  - 見出しの変数は、いくつかの変数が増えて減る。HATCH はグラデーションの欄を、MTEXT は背景の欄を持つ。
- `ZUMEN_SAMPLES` のフォルダーにある R2004 の DWG は、診断を出さずに読めることを確かめる。
- 区切りを置き換えたときは、入れ物を組み直して書く（決定 0070）。置き換えていない区切りのページは見出しを隠し直して写し、置き換えた区切りは圧縮し直す。ページの番号を 1 から振り直し、区切りの地図・ページの地図・空のページの見出し・2 つめの見出しを終わりに置き、暗号化した見出しを書き直す。置き換えていなければ、元のバイト列を写す。
- `ZUMEN_SAMPLES` のフォルダーにある R2004 から後の DWG は、組み直して読み直し、区切りが元と同じになることを確かめる。
- オブジェクトの置き換え・除き・足しは、展開した `AcDb:AcDbObjects` の後ろに R2000 と同じ形で足し、`AcDb:Handles` を区切りの初めからの位置で作り直して、区切りを置き換える（決定 0071）。`AcDb:ObjFreeSpace` は直さない。見出しの変数の HANDSEED・INSUNITS・PLIMMIN・PLIMMAX の変更は、展開した `AcDb:Header` の中で R2000 と同じく大きさを変えずに書き直し、区切りを置き換える（決定 0078）。
- 共有の表の変更は、図形の値の変更のうち、共通の欄と、型ごとの欄が R2000 と同じ種類（LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE・TEXT）だけを書き戻す（決定 0072）。色を変えるときは、透明度を写し、RGB の値か DBCOLOR を持つ色は変えない。
- ATTRIB・ATTDEF・LWPOLYLINE・SPLINE・DIMENSION・TOLERANCE・LEADER・MLINE・SHAPE・VERTEX・INSERT・MTEXT・VIEWPORT の型ごとの欄も書き戻す（決定 0073）。属性を持つ INSERT の持つオブジェクトの数と、MTEXT の背景の欄は、元のビットを写す。HATCH は、初めのグラデーションの欄を元のビットのまま写す（決定 0074）。MINSERT・POLYLINE は、まだ書き戻さない。
- 表のレコード（LAYER・STYLE・LTYPE・VIEW・UCS・VPORT・DIMSTYLE）の欄も書き戻す。色の欄は、変わらなければ元のビットを写し、変わったものは番号の形の CMC で書く（決定 0075）。図形でないオブジェクトも、GROUP・DICTIONARYVAR・DICTIONARY・MLINESTYLE・XRECORD の欄を書き戻す（決定 0076）。LAYOUT も、R2004 の欄の並びで書き戻す（決定 0082）。
- 表から除いた図形も書き戻す。R2004 の図形は前後の図形のハンドルを持たないので、所有者のブロックのレコードの持つ図形の数（BL）とハンドルを直す（決定 0077）。
- 表の終わりに足した、すでにあるブロックの単純な図形・MTEXT・属性を持たない INSERT も書き戻す。R2004 の共通の欄で符号化し、所有者のブロックのレコードの持つ図形に加え、HANDSEED を進める（決定 0079）。属性を持つ INSERT は、型ごとの欄の終わりに ATTRIB の数（BL）を書き、すべての ATTRIB のハンドルを持たせる（決定 0080）。MINSERT・表のレコード・ブロックの足しは、まだ書き戻さない。
- 足した表のレコード（画層・文字の体裁・線種・アプリケーションの名前・寸法の体裁・ビュー・ビューポートの設定・ブロックのレコード）も書き戻す。反応子の数の後に拡張辞書を持たない印を立て、画層と寸法の体裁の色を CMC で書く。ブロックのレコードは、持つ図形の数（BL）と、持つ図形のハンドルをみな固い所有で書く（決定 0081）。

## R2010 から後の版

R2010・R2013・R2018 は R2004 と同じ入れ物を使う（決定 0027）。区切りの中の並びは、次が R2004 と違う（ODS の 2 と、各オブジェクトの R2007 から後の欄）。

- オブジェクトの初めに、ハンドルの流れの大きさ（MC）があり、型は BOT で表す。データの大きさ（RL）はない。
- 文字列（T）は、データの終わりの前に置いた文字列の流れから、TU（BS の文字の数と UTF-16LE）で読み、UTF-8 に直す。見出しの変数の区切りも、文字列の流れとハンドルの流れを分けて持つ。
- 表のレコードは xref の番号を持たない。図形の共通の欄は、資料・透明度などの印が増える。
- クラスと見出しの変数の区切りの大きさの後の上位の RL は、ない図面もある。区切りの終わりの印が、大きさの後のデータと CRC のすぐ後に来るかで、あるかないかを決める。
- R2010 から、2D の VERTEX は膨らみの後に頂点の番号（BL）を持つ。表には置かない（決定 0087）。
- R2013 から、SPLINE は「通る点だけ」の印を持ち、LTYPE の文字の印（8）を DXF の 74 に置く。
- R2018 から、MLINESTYLE の線は線種の番号を持たない。ATTRIB・ATTDEF は版の後に型の RC を持ち、型が 1 でなければ複数行の文字の欄が続く。
- `ZUMEN_SAMPLES` のフォルダーにある R2010・R2013・R2018 の DWG は、診断を出さずに読めることを確かめる。
- オブジェクトの置き換え・除き・足しは、R2004 と同じく展開したオブジェクトの区切りの後ろに足し、地図を作り直す。オブジェクトのデータは、ハンドルの流れの大きさ（MC）から CRC の前までで受け渡し、大きさ（MS）は MC を除いたバイトの数で書く。
- 見出しの変数の HANDSEED・INSUNITS・PLIMMIN・PLIMMAX も、R2004 と同じ並びで主のデータの中の位置を求めて書き換える。文字列とハンドルの流れがずれないよう、ビットの数が変わる値は受け付けない（決定 0084）。
- 共有の表からは、図形の共通の欄と型ごとの欄の変更を書き戻し、ハンドルの流れの大きさ（MC）を直す（決定 0085）。文字列を持つ TEXT・ATTRIB・ATTDEF・MTEXT は、文字列の流れも書き直す（決定 0086・0087）。DIMENSION・HATCH・TOLERANCE・VIEWPORT・SHAPE も、R2010 で増えた欄を読み分けて書き戻す（決定 0088）。LEADER などの一部の種類と、表のレコード・図形でないオブジェクトの変更と、図形の除き・足しは、まだ受け付けない。

## 変更

`DwgTxn` で、オブジェクトのデータ（大きさ（MS）の後から CRC の前まで）を置き換える（決定 0028）。

- R2000 だけを扱う。ほかの版は `dwg.edit.unsupported` を返す。名指ししたオブジェクトがなければ `dwg.object.missing`、データの初めの型（BS）を読めなければ `dwg.data.invalid` を返す。1 つでも失敗すれば、確定したときに何も反映しない。
- 確定すると、変えたオブジェクトを大きさ・データ・CRC の形でファイルの後ろに足し、オブジェクトの地図をハンドルの順に作り直してその後ろに置く。地図の区切りのデータは 2032 バイトまでとする。
- 見出しの区切りの記録の地図の位置と大きさと、見出しの CRC を直す。ほかのバイト（元のオブジェクトと地図も）は元のまま残す。
- 変えるたびにファイルは大きくなる。使わなくなったバイトは詰めない。

`DwgFile::write_back` で、共有の表の変更を書き戻す（決定 0029）。

- 表と、今のファイルから作り直した表を、元のオブジェクトごとに比べ、値の並びが違うオブジェクトだけを `DwgTxn` で置き換える。
- 今は、LINE・CIRCLE・ARC・POINT・ELLIPSE・RAY・XLINE・SOLID・TRACE・3DFACE の型ごとの欄（点・半径・角度・厚さ・押し出しの向き・見えない辺）だけを符号化し直す（決定 0030）。共通の欄までのビットと、ハンドルの流れから後ろのビットは元のまま写し、ハンドルの流れの位置（RL）を直す。厚さと押し出しの向きは、値がなければ既定の値の印を書く。LINE は、両方の Z が 0 なら Z を書かない。
- 表にない値は、読む側の既定の値として書く。SOLID・TRACE の 4 つの角の Z は、同じでなければ書き戻さない。
- どの種類の図形も、共通の欄の色（62）・線種の尺度（48）・非表示（60）を符号化し直す（決定 0031）。値がなければ ByLayer・1・0 を書く。型ごとの欄が変わっていなければ、元のビットのまま写す。
- TEXT・INSERT・MINSERT の型ごとの欄も符号化し直す（決定 0032）。TEXT の DataFlags と INSERT の尺度の印は、表の値から選ぶ。TEXT の文字列は、DXF の `^` の書き方を元に戻して書く。合わせの点の Z が標高と違う TEXT と、属性が続くか（66）の変更は書き戻さない。
- ATTRIB・ATTDEF は、TEXT の欄（縦の合わせは 74）に続けて、タグ・欄の長さ・印と、ATTDEF の問いを符号化し直す（決定 0033）。
- MTEXT も符号化し直す（決定 0034）。表にない文字の範囲の大きさと、行の間隔の後の B は、元のビットを写す。文字列は、3 と 1 をつないで書く。
- LWPOLYLINE も符号化し直す（決定 0035）。続く欄の印は、表に値があるかから選ぶ。頂点ごとの幅があるときは、表にない一定の幅を元のまま写す。
- SPLINE も符号化し直す（決定 0036）。場合は元のままとし、有理・閉じている・周期的の印は元のビットを写す。
- HATCH も符号化し直す（決定 0037）。表の値を読む側の順に読み直して書く。境界の図形の数（97）の変更は書き戻さず、そのハンドルは元のまま写す。
- POLYLINE・VERTEX も符号化し直す（決定 0038）。型は元のデータから選び、頂点が続く印（66）と、DXF に合わせて 0・64・128 とした値の変更は書き戻さない。
- DIMENSION も符号化し直す（決定 0039）。表にないブロックの挿入の尺度と回転、印のほかのビットは元のまま写す。
- TOLERANCE・LEADER・MLINE も符号化し直す（決定 0040）。表にない LEADER の点と差の欄は元のまま写し、MLINE の頂点と区切りの数は表の値の数に合わせる。
- VIEWPORT も符号化し直す（決定 0041）。表にない凍結した画層の数と後ろの欄は元のまま写す。
- SHAPE も符号化し直す（決定 0042）。表にない形の番号は元のまま写す。
- 表のレコードは、LAYER と STYLE の型ごとの欄を符号化し直す（決定 0043）。名前とハンドルから作る値の変更は受け付けない。
- LTYPE も符号化し直す（決定 0044）。要素の数と、要素ごとの形と文字の印の変更は受け付けない。
- VIEW・UCS・VPORT も符号化し直す（決定 0045）。VIEW の UCS を伴う印の変更は受け付けない。
- DIMSTYLE も符号化し直す（決定 0046）。値が変わらない欄は元のビットを写し、表にない欄は既定の値で書く。
- OBJECTS のオブジェクトは、GROUP と DICTIONARYVAR の欄を符号化し直す（決定 0047）。GROUP の図形の変更は受け付けない。
- DICTIONARY・ACDBDICTIONARYWDFLT・MLINESTYLE も符号化し直す（決定 0048）。項目と線の数と、多重線の体裁の名前の変更は受け付けない。
- LAYOUT も符号化し直す（決定 0049）。欄の追加と削除と、レイアウトの名前の変更は受け付けない。
- XRECORD も符号化し直す（決定 0050）。文字列のコード・ページは元の値のものを写す。値の追加と削除は受け付けない。
- 表から除いた図形は、オブジェクトの地図から除き、前後の図形とブロックのレコードの、図形の並びをたどるハンドルを直す（決定 0051）。除けるのは、所有者がブロックのレコードで、ほかの図形と反応子と拡張辞書を持たない、単純な種類の図形だけ。
- 表の終わりに足した、型ごとのハンドルを持たない図形は、一から符号化してオブジェクトの地図に加え、所有者のブロックのレコードの図形の並びの終わりに繋ぐ（決定 0052）。ハンドルは HANDSEED より小さくしない。HANDSEED は、見出しの変数の区切りの中でその場で進め、区切りの CRC を直す。
- 足した TEXT・ATTDEF は文字の体裁（7。なければ Standard）を、INSERT はブロック（2）を、表のレコードから名前で探して、ハンドルの流れの線種の後ろに書く（決定 0053）。
- 足した MTEXT は、表にない文字の範囲の大きさを 0、行の間隔の後の B を 0 にして書く（決定 0054）。文字の体裁は TEXT と同じく探す。
- 属性が続く（66）INSERT は、すぐ後に ATTRIB を 1 つ以上並べ、SEQEND で閉じたものだけを足せる（決定 0055）。ATTRIB と SEQEND は INSERT を所有者とし、INSERT は最初と最後の ATTRIB と SEQEND のハンドルを書く。ブロックの並びへ繋ぐのは INSERT だけにする。
- 足した LWPOLYLINE は、表にない印のビットを 0、頂点ごとの幅を持つときの一定の幅を 0 にして書く（決定 0056）。
- 足した SPLINE は、節点と制御点を持ち重みを持たないものだけを、場合を 1、有理・閉じている・周期的の印を 0 にして書く（決定 0057）。
- 足した SPLINE が重みを持てば有理の印を立て、当てはめる点を持てば場合を 2 にして書く（決定 0059）。
- 足した INSERT が列と行の数（70・71）か間隔（44・45）を持てば、MINSERT として書く（決定 0060）。属性も INSERT と同じく続けられる。
- 足した画層（LAYER）は、一から符号化してオブジェクトの地図に加え、所有者の画層の表のオブジェクトの項目の数を増やして、項目のハンドルの終わりに足す（決定 0061）。名前が表にあるもの・外部参照に依るもの・真の色を持つものは受け付けない。線種（6）は名前で探し、印刷スタイル（390）がなければ画層 0 と同じものにする。
- 足した文字の体裁（STYLE）も、画層と同じく文字の体裁の表のオブジェクトの項目の終わりに足す（決定 0062）。型ごとの欄はみな要り、印は形のファイル 1 と縦書き 4 だけを受け付ける。足したレコードの名前は、終わりに NUL を付けて書く。
- 足した線種（LTYPE）も、線種の表のオブジェクトの項目の終わりに足す（決定 0063）。要素はみな形も文字も持たないことが要り、要素の形の番号・ずれ・尺度・回転は 0・0・0・1・0 とする。
- 足したアプリケーションの名前（APPID）も、表のオブジェクトの項目の終わりに足す（決定 0064）。印（70）は 0 でなければならず、使い道の分からない RC は 0 と書く。
- 足した寸法の体裁（DIMSTYLE）も、表のオブジェクトの項目の終わりに足す（決定 0065）。印（70）は 0 でなければならず、表にない寸法の変数は既定の値で書く。文字の体裁とブロックのハンドル（340〜344）は図面にあるものを指さなければならず、参照の型 5 で書く。DIMSTYLE の表のオブジェクトは、項目の数の後に RC を持ち、項目の後にその数だけハンドルが続くので、RC とそのハンドルは残す。
- 足したビュー（VIEW）も、表のオブジェクトの項目の終わりに足す（決定 0066）。型ごとの欄をみな持たなければならず、印（70）は紙空間の 1 だけを持てる。UCS を伴うビューは、基準の UCS（346）と名前の UCS（345）を参照の型 5 で書き、それらは図面にある UCS を指さなければならない。
- 足したビューポートの設定（VPORT）も、表のオブジェクトの項目の終わりに足す（決定 0067）。型ごとの欄をみな持たなければならず、印（70）は 0 でなければならない。使い道の分からないビットは、試料の図面と同じく偽と書く。名前の UCS（345）と基準の UCS（346）は、参照の型 5 で書き、図面にある UCS を指さなければならない。
- 足したブロックのレコード（BLOCK_RECORD）も、ブロックの表のオブジェクトの項目の終わり（モデル空間と紙空間のハンドルの前）に足す（決定 0068）。それが持つ足した BLOCK と ENDBLK を 1 つずつ要り、BLOCK の名前はレコードと同じで、基点（10・20・30）はみな持つかみな持たないかでなければならない。名前が `*` で始まるものは受け付けない。BLOCK と ENDBLK は並びをたどるハンドルを持たず、ほかの図形は足した順にブロックの並びへ繋ぐ。足したブロックを挿す足した INSERT は、レコードの INSERT の並びへ加える。
- 足した UCS のレコードは、まだ受け付けない。試料の図面に UCS のレコードがなく、共通のハンドルの後のハンドルの流れを確かめられないので、試料が得られるまで後回しにする。
- 見出しの変数の INSUNITS と、用紙空間の PLIMMIN・PLIMMAX の変更は、見出しの変数の区切りの中でその場で書き直し、CRC を計算し直す（決定 0069）。INSUNITS は、BS で書いたときのビットの数が元と同じ値だけを受け付ける。PLIMMIN と PLIMMAX は、どちらも有限の 10 と 20 の実数だけを持たなければならない。ほかの見出しの変数の変更は拒む。
- 足した SHAPE は、形の番号と形のファイルを表で示せないので受け付けない（決定 0058）。
- ほかの変更は `dwg.change.unsupported` を返し、何も反映しない。

## オブジェクトの表

`DwgFile::objects` は、DXF と同じオブジェクトの表（[決定 0023](../decisions/0023-acad-shared-object-table.md)）を作ります。

- どのオブジェクトにも、地図のハンドルを 5 に置く。DIMSTYLE は DXF と同じく 105 に置く。
- 所有者（330）は、ハンドルの並びの先頭から読む。図形は entmode が 0 のときだけ持つ。entmode が 1・2 の図形（用紙空間・モデル空間の図形）の所有者は、見出しの変数が指す `*Paper_Space`・`*Model_Space` のブロックのレコードにする。見出しの変数の区切りがないか壊れていれば、所有者を置かない（壊れていれば `dwg.file.invalid` を返す）。相対のハンドルは、オブジェクトのハンドルから数える。BLOCK・ENDBLK は DWG では図形として書かれるので、図形の共通の欄を読む。
- 図形は、共通の欄のうち既定の値でない色（62）・線種の尺度（48）・非表示（60）を置く。
- 図形は、所有者の後に画層の名前（8）を置く。画層のハンドルが指す LAYER がないときは置かず、`dwg.layer.missing` を返す。
- 図形が表のレコードを指す欄（TEXT・MTEXT・ATTRIB・ATTDEF の文字の体裁 7、INSERT のブロック 2、DIMENSION の寸法の体裁 3 とブロック 2、TOLERANCE・LEADER の寸法の体裁 3）は、レコードの名前に直して値の後に置く。指すハンドルにその型のレコードがないときは置かず、`dwg.record.missing` を返す。文字の体裁が既定の Standard のときは、DXF と同じく置かない。
- 図形の線種（6）は、共通の欄の線種の印で決める。印が 1 なら ByBlock、2 なら Continuous を置き、3 ならハンドルが指す LTYPE の名前を置く。画層による線種（印が 0 か、名前が ByLayer）は、DXF と同じく置かない。
- 図形ごとの欄は、今は TEXT・INSERT・LINE・ARC・CIRCLE・POINT・MTEXT・SOLID・TRACE・3DFACE・SHAPE・ELLIPSE・RAY・XLINE・LWPOLYLINE・SPLINE・HATCH・POLYLINE・VERTEX・DIMENSION・ATTRIB・ATTDEF・TOLERANCE・LEADER・MLINE・VIEWPORT を読む。点（10・20・30 など）・半径（40）・角度（50・51）はいつも置き、厚さ（39）と押し出しの向き（210・220・230）は記録されているときだけ置く。角度は、DWG のラジアンを DXF と同じ度に直す。
- TEXT は、挿入点（10・20・30）・高さ（40）・文字列（1）をいつも置く。DataFlags のビットが立つ欄（標高・合わせの点・斜めの角度・回転・幅・生成・合わせ）は記録されていないので置かない。合わせの点の Z（31）は標高とする。
- INSERT は、挿入点をいつも置き、尺度（41・42・43）・回転（50）・押し出しの向きは既定の値（1・0・(0, 0, 1)）でなければ、属性が続くこと（66）は続くときだけ置く。MINSERT（型 0x08）は、種類を INSERT とし、列と行の数（70・71）と間隔（44・45）も既定の値（1・1・0・0）でなければ置く。
- MTEXT は、挿入点・幅（41）・高さ（40）・合わせ（71）・向き（72）・行の間隔（73・44）をいつも置き、X 軸の向き（11・21・31）と押し出しの向きは既定の値（(1, 0, 0)・(0, 0, 1)）でなければ置く。文字列は DXF と同じく、250 バイトずつの 3 と、残りの 1 に分ける。DXF にない文字の範囲の大きさは置かない。
- SOLID・TRACE は、4 つの角（10〜13 と、その 20・30 の組）をいつも置く。角の Z は標高とする。
- 3DFACE は、4 つの角をいつも置き、見えない辺の印（70）は 0 でなければ置く。
- ELLIPSE は、中心（10）・長軸の向き（11）・軸の比（40）・始まりと終わりの角度（41・42）をいつも置く。角度は DXF と同じくラジアンのまま置く。押し出しの向きは既定の値でなければ置く。
- RAY・XLINE は、始まりの点（10）と向き（11）を置く。
- LWPOLYLINE は、頂点の数（90）・印（70）・頂点（10・20）をいつも置く。DWG の印のうち、閉じていること（0x200）だけを DXF の 70 の 1 に直す。ほかの印は続く欄があるかを表すので置かない。頂点ごとの幅（40・41）がなければ一定の幅（43）を置き、膨らみ（42）は 0 でなければ置く。標高（38）・厚さ（39）・押し出しの向きは、記録されているときだけ置く。
- SPLINE は、次数（71）・節点の数（72）・制御点の数（73）・当てはめる点の数（74）・節点（40）・制御点（10）・当てはめる点（11）をいつも置く。節点で決まるときは節点の許容差（42）・制御点の許容差（43）を、重みがあるときは制御点ごとの重み（41）を置く。当てはめる点で決まるときは当てはめの許容差（44）を置き、始まりと終わりの接線（12・13）は 0 でなければ置く。印（70）と押し出しの向きは、DXF を書くときに形から決まるので置かない。
- HATCH は、クラスで決まる型なので、種類の名前で見分ける。DXF と同じく、10・20 を 0、標高を 30 に置き、模様の名前（2）・塗りつぶし（70）・連動（71）・境界の数（91）を置く。境界ごとに、印（92）と、辺の数（93）と辺の種類（72）ごとの欄か、多角形の膨らみの有無（72）・閉じていること（73）・頂点の数（93）・頂点と膨らみ（42）を置き、境界の図形の数（97）を置く。続けて、塗り方（75）・模様の種類（76）、塗りつぶしでなければ模様の角度（52）・尺度（41）・二重（77）・線の数（78）と線ごとの欄（53・43〜46・79・49）、印 4 の境界があれば画素の大きさ（47）、種の点（98・10・20）を置く。角度は度に直す。押し出しの向きは既定の値でなければ置く。境界の図形のハンドル（330）は、所有者と見分けられないので、まだ置かない。
- 表のレコードは、名前（2）と、LAYER・STYLE・LTYPE・APPID・VIEW・UCS・VPORT・DIMSTYLE の欄を置く。オブジェクトは、今は MLINESTYLE・DICTIONARY・ACDBDICTIONARYWDFLT・XRECORD・GROUP・DICTIONARYVAR・SCALE・LAYOUT の欄を置く。
- 型が 500 以上のものは、番号が型と同じクラスの DXF の名前を種類にする。図形を作るクラス（itemclassid が 0x1F2）なら図形の所に置き、図形の共通の欄を読む。そうでなければオブジェクトの所に置く。
- 合うクラスがない型と、知らない型は、種類を空にして置き、`dwg.type.unsupported` を返す。
- 欄を読めないオブジェクトは、ハンドルだけを置き、`dwg.object.invalid` を返す。
- POLYLINE と VERTEX は、型で 2D・3D・網・多面に分かれる。POLYLINE には、DXF と同じく、頂点が続く印（66）を 1、点（10・20）を 0 として置き、2D では標高を 30 に置く。2D の印（70）はそのまま置き、3D は 2 つの印から 70（3D の 8、閉じていれば 1、曲線なら 4）と曲線の種類（75）を作る。多面は 70 を 64 とし、頂点と面の数（71・72）を置く。2D の VERTEX は、始まりの幅が負なら、終わりの幅も同じ絶対値とし、幅・膨らみ・接線の向き（度に直す）を 0 でなければ置く。多面の面の VERTEX は、点を 0、70 を 128 とし、頂点の番号（71〜74）を 0 でなければ置く。
- DIMENSION は、型で寸法の種類が分かれる。DXF の 70 は、型で決まる種類（線形 0・平行 1・2 線の角度 2・直径 3・半径 4・3 点の角度 5・座標 6）に、共通の印の 1 が 0 なら 128、2 なら 32、座標寸法の印の 1 なら 64 を足して作る。文字の中点（11）の Z は標高とし、12 の点は 0 でなければ置く。測った値（42）・文字の合わせ（71）はいつも置き、行間（72・41）・利用者の文字（1）・文字の回転（53）・水平の向き（51）・回転（50）・引出線の傾き（52）は既定の値でなければ置く。角度は度に直す。寸法の体裁（3）とブロック（2）は、ハンドルからレコードの名前に直して置く。ブロックの挿入の尺度と回転は、DXF の 41・42 が別の欄に使われるので置かない。
- ATTRIB・ATTDEF は、TEXT の欄に続けて、タグ（2）・印（70）を、ATTDEF は問い（3）も置く。欄の長さ（73）は 0 でなければ置く。DXF は縦の合わせを 74 に書くので、TEXT の 73 を 74 に移す。
- SHAPE は、挿入点（10）と大きさ（40）を置き、回転（50）・幅の係数（41）・傾き（51）・厚さ（39）・押し出しの向きは既定の値でなければ置く。DXF の形の名前（2）は、DWG では形の番号と形のファイル（文字の体裁）で記録され、名前は形のファイルの中にあるので、まだ置かない。
- TOLERANCE は、挿入点（10）と文字（1）を置き、X 軸の向き（11）と押し出しの向きは既定の値でなければ置く。
- LEADER は、注釈の種類（73）・注釈の高さと幅（40・41）・鉤の線の向き（74）・注釈のハンドル（340）を置き、経路の種類（72）・押し出しの向き・X 軸の向き（211）は既定の値でなければ置く。DXF は寸法の体裁から鉤の線の点を足して書く（点の数が 1 つ多い）ので、点（10）と点の数（76）はまだ置かない。
- MLINE は、尺度（40）・合わせ（70）・開閉の印（71）・頂点の数（72）・線の数（73）・基点（10）・押し出しの向き（210）・多重線の体裁のハンドル（340）と、頂点ごとの点（11）・向き（12）・留めの向き（13）・線ごとの区切り（74・41）と塗りの区切り（75・42）を置く。体裁の名前（2）は、体裁のハンドルから名前に直して置く。
- MLINESTYLE は、名前（2）・印（70）・説明（3）・塗りの色（62）・始めと終わりの角度（51・52、度に直す）・線の数（71）と、線ごとの位置（49）と色（62）を置く。印は、DWG と DXF でビットの並びが違うので並べ直す。線ごとの線種（6）は、DWG に番号で記録されているので、まだ置かない。
- DICTIONARY は、所有する印（280）を 1 のときだけ、複製の扱い（281）をいつも置き、項目ごとに名前（3）と指すオブジェクトのハンドルを置く。ハンドルのコードは、DXF と同じく、所有する辞書なら 360、しないなら 350 とする。
- XRECORD は、複製の扱い（280）を DXF と同じくデータの前に置き、データの値を記録の順に置く。値の読み方はグループ・コードの型で決め、文字列は長さ（RS）・コード・ページ（RC）・バイト、点（10〜19）は 3RD で X・Y・Z の 3 つのコードに分け、8 ビットの整数（280〜289）と真偽（290〜299）は RC、32 ビットの整数（90〜99 など）は RL、64 ビットの整数（160〜169）とハンドルは 8 バイト、バイナリ（310〜319）は長さ（RC）とバイトとする。記録されたデータのバイト数をちょうど読み切らなければ、読めないオブジェクトとする。
- ACDBDICTIONARYWDFLT（既定の項目を持つ辞書、クラスで決まる型）は、DICTIONARY と同じ欄に続けて、既定の項目のハンドル（340）を置く。
- 表のレコードの外部参照に依る印は、DXF と同じく 70 の 16 とする。LAYER は、凍結・新しいビューポートで凍結・ロックの印（70）、色（62。表示しない画層は負）、印刷しない印（290）、線の太さ（370）、印刷スタイル（390）、線種の名前（6）を置く。STYLE は、70・高さ（40）・幅の係数（41）・傾き（50）・向きの印（71）・最後に使った高さ（42）・フォントのファイル（3・4）を置く。LTYPE は、説明（3）・揃えの印（72）・要素の数（73）・全体の長さ（40）と、要素ごとに長さ（49）・種類（74）を置き、形か文字の要素には、形の番号（75）・尺度（46）・回転（50）・ずれ（44・45）・文字（9）・文字の体裁（340）も置く。BLOCK_RECORD の印は、DXF では BLOCK の 70 に書かれるので置かない。
- VIEW と VPORT は、高さ・中心・向き・注視点・レンズ・切り取り・ねじれ・見え方の印（71）・描き方（281）と、UCS の欄（110〜112・79・146）を置く。見え方の印の 4 つめのビットは、DXF の 16（前の切り取りが目の位置にない）の逆として読む。VPORT の幅は高さとの積で記録されているので、DXF と同じく比（41）に直す。UCS に従う印は 71 の 8 とする。VIEW の紙空間の印は 70 の 1 とする。UCS は、原点と軸（10〜12）・正投影の種類（79）・高さ（146）・基準の UCS（346）を置く。DIMSTYLE は、DXF と同じく既定の値と違う欄だけを置き、文字の体裁（340）と矢印のブロック（341〜344）も置く。
- GROUP は、説明（300）・名前のない印（70）・選べる印（71）と、図形ごとのハンドル（340）を置く。
- DICTIONARYVAR（クラスで決まる型）は、値の型の印（280）と値（1）を置く。SCALE（クラスで決まる型）は、名前（300）・紙の単位（140）・図面の単位（141）・単位の尺度の印（290）と、70 を置く。
- LAYOUT は、DXF と同じく印刷の設定の欄（ページ設定の名前 1・出力の機器 2・印 70・余白 40〜43・紙の大きさ 44・45 と名前 4・原点 46・47・窓 48・49・140・141・尺度 142・143・147・印刷の体裁 7 など）を先に、レイアウトの欄（名前 1・印 70・タブの順 71・範囲 10・11・14・15・挿入点 12・UCS 13・16・17・高さ 146・正射影の種類 76）を後に置く。紙空間のブロックのレコード（330）・最後に使ったビューポート（331）・基準の UCS（346）・名前の UCS（345）は、0 でなければ置く。R2004 からは、印刷するビューの名前（6）の代わりにそのハンドルを持ち、印刷の設定の終わりに陰影の印刷の方法・解像度・DPI（76〜78）が加わり、レイアウトの欄の後にビューポートの数とハンドルが続く。印刷するビューとビューポートのハンドルは、値に置かない。R2007 からは、印刷するビューの後に表示スタイルのハンドルが続く（決定 0082）。
- VIEWPORT は、中心（10）・幅と高さ（40・41）・ビューの中心（12）・スナップ（13・14）・グリッド（15）・ビューの向きと目標（16・17）・レンズ（42）・前後の切り取り（43・44）・ビューの高さ（45）・スナップとねじれの角度（50・51、度に直す）・円の細かさ（72）・状態の印（90）・印刷スタイルの表（1）・描き方（281）・UCS（71・74・110・111・112・79・146）をいつも置く。ビューポートの番号（69）は DWG に記録されていないので、所有者ごとにハンドルの順で 1 から数えて置く（推定）。状態（68）は置かない。凍結した画層などのハンドルも、まだ置かない。
- 図形の文字列は、DXF と同じく、制御文字を `^` と文字で（改行なら `^J`）、`^` を `^ ` で書く。
- 用紙空間の図形（entmode が 1）には、DXF と同じく 67 に 1 を置く。
- 図形の区切り（`Section`）は、所有者をたどって決める。モデル空間・用紙空間のブロックのレコードに属する図形は ENTITIES、ほかのブロックのレコードに属する図形は BLOCKS に置く。所有者が分からない図形は ENTITIES に置く。
- 見出しの変数は、DXF の HEADER と同じ名前と値で表に置く。今は $ACADVER（版の名前）と、見出しの変数の区切りを読めたときの $INSUNITS（70）・$PLIMMIN・$PLIMMAX（10・20）だけを置く。
- まだ置かないもの: 印刷スタイルのハンドル、ほかの図形の欄、HATCH の境界の図形のハンドル、拡張データ、ほかの見出しの変数。

## 図面モデルへの変換

`DwgFile` の `Lift<Drawing2D>` は、DXF と同じく表から図面モデルを作る（[DXF の扱い](dxf.md)）。移す図形と診断は DXF と同じで、診断の符号も `dxf.lift.*` などを使う。元の位置は、オブジェクトのバイトの範囲を指す。型付きの見方（`Object::line`）も、DXF と同じものを使う。

## 実際の図面で確かめる

`crates/zumen-acad/tests/samples.rs` は、`ZUMEN_SAMPLES` のフォルダーにある `名前.dwg`（R2000）と `名前_ascii.dxf` の組を読み、同じハンドルのオブジェクトの種類・所有者（DWG が持つとき。図形は持たないときも）が同じか、DWG が置いた値が DXF の同じグループ・コードの最初の値と同じかを比べます。形の欄を読む図形では、DXF だけにある形の欄が既定の値かも確かめます。DXF は実数を 16 桁で書くので、実数は相対の誤差 1e-14 まで許します。所有者が DXF に書かれないとき（R2000 の DXF は、新しい版の表の中身を XRECORD の下に移す）は、所有者を比べません。辞書（既定の項目を持つ辞書も）の項目は名前とハンドルの組で比べ、DXF にないオブジェクトを指す項目は比べません（R2000 の DXF は、新しい版の見出しの変数の辞書を別のハンドルで書き、版の往復のための XRECORD を書かない）。最後に保存したときの情報の XRECORD（`ACAD_LAST_SAVED_VERSION_INFO`）は、GUID とファイルのパスが DWG と DXF で違うので比べません。フォルダーを指定しないときは何も確かめません。

```bash
ZUMEN_SAMPLES=/path/to/samples cargo test -q -p zumen-acad --test samples
```

## 実際の図面で確かめた扱い

仕様の文からは決まらず、R2000 の 6 つの図面（同じ図面の DXF との組を 1 つ含む）と R2004 の 2 つの図面（DXF との組を 2 つ含む）と、R2010・R2013・R2018 の 7 つの図面（DXF との組を 4 つ含む）で確かめたものです。

| 所 | 扱い | 確かめ方 |
| --- | --- | --- |
| 地図の区切りの大きさ | 上位のバイトから並ぶ大きさは、大きさの 2 バイトとデータを含み、CRC を含まない。大きさが 2 の区切りで終わる | 終わりの区切りの CRC の後が、区切りの記録の大きさとちょうど合う |
| 地図の区切りの CRC | 区切りの先頭（大きさ）からデータの終わりまでを、0xC0C1 から計算する | どの区切りでも合う |
| クラスの区切りの CRC | 大きさの RL からデータの終わりまでを、0xC0C1 から計算する | 6 つの図面のどれでも合う |
| クラスで決まる型 | 型が 500 以上のものは、番号が型と同じクラスの DXF の名前を種類にする | 種類がすべて DXF と合い、HATCH・ACAD_TABLE などの図形の共通の欄も DXF と合う |

| ATTRIB・ATTDEF・TOLERANCE の欄 | 縦の合わせを 74 に移し、文字列の制御文字を `^J` などと書く | 4 の ATTRIB、5 の ATTDEF、3 の TOLERANCE の欄が DXF と合う。TOLERANCE の文字の改行は DXF で `^J` |
| SHAPE の欄 | 既定の値でない欄だけを置き、形の名前は置かない | 1 の SHAPE の 10・40 が DXF と合う |
| DICTIONARY・XRECORD の欄 | 辞書の項目を名前とハンドルの組で置き、XRECORD のデータをグループ・コードの型で読む | 6 つの R2000 の図面の DICTIONARY と XRECORD をすべて読めた。`sample_AC1015` の 139 の DICTIONARY と 224 の XRECORD の欄が DXF と合う |

## 推定した扱い

まだ確かめていないものです。

| 所 | 扱い | 理由 |
| --- | --- | --- |
| 図形の属する所 | 型が BLOCK・ENDBLK のものはブロック、ほかの図形はすべて図形の所に置く | ブロックの中の図形かどうかは、所有者のブロックのレコードを見ないと決まらない |
| TEXT の DataFlags で省かれない欄 | 合わせの点・角度（度に直す）・幅・生成・合わせを、仕様の並びのまま読む | 比べた図面の TEXT は、どれもこれらの欄を省いていた |
| TRACE の欄 | 仕様の並びのまま読む | 比べた図面に、TRACE がなかった |
| MLINESTYLE の印 | DWG のビットを DXF のビットに並べ直す（1 と 2、32 と 64、512 と 1024 を入れ替える） | 比べた図面の印は 0 だった |
| VIEWPORT の角度 | スナップとねじれの角度（50・51）を度に直す | 比べた図面の角度は、どれも 0 だった |
| SPLINE の当てはめる点と重み | 当てはめる点で決まる SPLINE と、重みのある制御点の欄を、仕様の並びのまま読む。接線は 0 なら置かない | 比べた図面の SPLINE は、どれも節点で決まり、重みがなかった |
| HATCH の円弧・楕円弧・SPLINE の辺と画素の大きさ | 円弧と楕円弧の角度は度に直す。SPLINE の辺の重みは 42 に置く | 比べた図面の HATCH の辺は、どれも線分だった |
| 2D と網の POLYLINE・VERTEX | 2D の印と網の印は、DXF の 70 のまま持つとする。2D の VERTEX の Z は、仕様では 0 なので、そのまま置く | 比べた図面に、2D と網の POLYLINE がなかった |
| LWPOLYLINE の線種の生成の印 | DXF の 70 の 128 にあたる印は、まだ置かない | 比べた図面の LWPOLYLINE に、この印がなかった |
| MINSERT の欄 | INSERT の欄に続く列と行の数と間隔を、仕様の並びのまま読む | 比べた図面に、MINSERT がなかった |
| XRECORD の 64 ビットの整数と 1010〜1019 の点 | 64 ビットの整数（160〜169）を 8 バイトで、1010〜1019 を 10〜19 と同じく 3RD の点で読む | 比べた図面の XRECORD に、これらのコードがなかった |
| R2004 の LAYOUT のビューポートの数 | ODS は RL とするが、BL として読む | 試料の R2004 の図面で、欄の終わりからハンドルの流れまでが 2 か 10 ビットだった |
| LAYOUT の UCS のハンドル | 基準の UCS（346）と名前の UCS（345）を、ビューポートの後のハンドルとして読む | 比べた図面では、どちらも 0 だった |
| POINT の X 軸の角度 | ラジアンで持つとして、0 でなければ度に直して置く | 比べた図面の POINT が、どれも 0 だった |
| DXF にない表 | 型 0x46・0x47 の種類を `VP_ENT_HDR_CONTROL`・`VP_ENT_HDR` とする | DXF に対応する名前がない |
| R2004 の見出しの変数 | 仕様の順の変数に加えて、LIMCHECK と USRTIMER の間の B、PDMODE の後の 3 つの BL、TDUPDATE の後の 3 つの BL を読む。ビューポートの図形の見出しの表のハンドルはない | `sample_AC1018` と `insert_2004` の変数を最後まで読み、CRC と、範囲・単位・2 つの空間のハンドルが DXF と合う |
| R2004 の色の種類 | CMC の RGB の値の最上位のバイトの 0xC0 を ByLayer、0xC1 を ByBlock、0xC2 を真の色、0xC3 を下位のバイトが色の番号とする | 画層・図形の色が DXF の 62・420 と合う |
| R2004 のデータのページの検査の値 | 圧縮したデータの検査の値を 0 を種に求め、見出しの検査の値を、その値を種に、見出しの検査の値の欄を 0 にした戻した見出し（0x20 バイト）から求める | 試料の R2004・R2010・R2013・R2018 の図面のデータのページで、どちらも合う |
| R2004 の入れ物の組み直し | データのページと地図のページの大きさを `0x20` の倍数に切り上げ、ページの地図の自分の大きさは続く空のページの見出しを含めて切り上げる。データのページの後ろは 0 で埋める。ファイルの見出しの `0x0D` と `0x20` を、プレビューと要約のページのデータの位置とする | 試料の図面の並びと合い、組み直した図面を読み直すと区切りが元と同じになる。ページの地図の自分の大きさが合わない図面と、後ろを乱数の列で埋めた図面もある。AutoCAD では確かめていない |
| 真の色 | RGB を 420（MTEXT の背景は 421）に置き、色の番号（62・63）は置かない。DXF は近い番号を置くが、近さの決まりが分からない | 420 が DXF と合う。比べるときは、420 を持つオブジェクトの 62 を比べない |
| ENC の 0x4000 | 0x8000 も立っていても、RGB の値はデータの側になく、拡張辞書と画層のハンドルの間に DBCOLOR のハンドルが来る | 色見本帳の色を持つ図形の欄と画層が DXF と合う。DBCOLOR の色はまだ置かない |
| MTEXT の文字列の分け方 | 制御文字を ^ の形に直す前の文字列を 250 バイトずつに分ける | 改行を含む長い MTEXT の 3 が DXF と合う |
| MTEXT の段組み | R2018 の複数行の属性で、段の種類が 0 でなければ読まない | 段組みを持つ図面がない |
| SPLINE の通る点だけ | 次数 3 で 2 点のほかは、通る点と接線を DXF の 11・12・13 に置き、制御点を作らない | 制御点の作り方が分からず、その図面がない |
| 変えた DWG を AutoCAD が読むか | 地図を後ろに置き直し、区切りの記録だけを直す。第 2 の見出しなど、地図の位置を持つかもしれないほかの所は直さない | AutoCAD で開いて確かめていない |
| 地図の区切りの大きさの上限 | データを 2032 バイトまでとする | 試料の DWG の区切りが、これを超えない |

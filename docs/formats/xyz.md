# XYZ

XYZ（台帳の `xyz`、座標と属性を区切って並べた点群のテキスト）を読み、点群の領域モデル（[決定 0232](../decisions/0232-point-clouds.md)）に移す規則を記録します。実装は `crates/zumen-xyz` です。決まった仕様はないので、行ごとの数の列を推定で読みます。

## 境界

- 見分ける印がないので、判定の規則に入れない。`open` の `format` に `xyz` を書いたときだけ、XYZ として開く。`format` に書けるのは `xyz` だけで、ほかの値は `call.value.invalid` を返す。
- `pointcloud` の op で、要約と点を返す（[LAS・LAZ](las.md) と同じ）。書き出しはしない。

## 行と列

- 列は、空白・`,`・`;` で区切る。空の行と、`#` か `//` で始まる注記の行は飛ばす。
- 3 つ以上の数を並べた最初の行で、列の数を決める。数を読めない行（見出しの行など）と、列の数が違う行は読まず、最初の行の番号と行の数を `xyz.line.invalid` で返す。数の行が 1 つもなければ、`xyz.file.invalid` を返して開かない。
- 1〜3 列目を、東・北・標高にする。
- 列の数から属性を推定する。4 列なら 4 列目を強度、6 列なら 4〜6 列目を色、7 列なら 4 列目を強度・5〜7 列目を色にする。ほかの列の数では、4 列目からを移さず `xyz.column.dropped` を返す。
- 色の値がどれも 255 までなら 8 ビットとし、257 倍して 16 ビットにする。強度が 0〜1 の小数なら、65535 倍する。
- XYZ は座標系を書かないので、座標系を不明にして `xyz.crs.missing` を返す。

## まだしないこと

- JavaScript の包みが、`format` を名指した `open` で、形式を持つモジュールを選ぶこと（#380）。

# E57

E57（ASTM E2807、台帳の `e57`）の点群を読み、点群の領域モデル（[決定 0232](../decisions/0232-point-clouds.md)）に移す規則を記録します。実装は `crates/zumen-e57`、領域モデルは `crates/zumen-pointcloud` です。規格の本文は読まず、許容のライセンスの公開の実装（libE57Format・`e57` crate）と試料から読みます（`formats/ledger.toml`）。

## 境界

- `open` は、入力の初めの `ASTM-E57` で見分ける。範囲では読まず、全体を渡す。
- `pointcloud` の op は、LAS と同じく、点の数・範囲・座標系・持つ属性・八分木を返す（[LAS・LAZ](las.md)）。
- 書き出しはしない。

## スキャン

- ファイルの中のスキャン（`data3D`）を、すべて 1 つの点群にまとめる。
- 点は、直交の座標（`cartesianX`・`Y`・`Z`）があればそれを、なければ球の座標（距離・方位角・仰角）を直交の座標に換算して読む。どちらもないスキャンは、`e57.coordinates.missing` を返して移さない。
- 座標の状態（`cartesianInvalidState`・`sphericalInvalidState`）が 0 でない点（向きだけの点と無効な点）は移さず、数を `e57.point.dropped` で返す。
- スキャンの姿勢（`pose` の回転の四元数と移動）を当ててから、X を東、Y を北、Z を標高にする。四元数は正規化してから使う。
- 点のデータが、スキャンの点の数より短いか壊れていれば、読めた点だけを読んで `e57.points.invalid` を返す。

## 属性

- 強度・色・反射の番号と数・時刻は、座標を持つどのスキャンも持つときだけ移す。一部のスキャンだけが持つ属性は、`e57.attribute.dropped` を返して移さない。
- 強度と色は、スキャンの幅（`intensityLimits`・`colorLimits`）か、なければ値の型の最小と最大で、16 ビットの幅に広げる。どちらもなければ、強度は 0〜1、色は 0〜255 とする。状態（`isIntensityInvalid`・`isColorInvalid`）が 0 でない値は 0 にする。
- 反射の番号は 0 から数えるので、1 を足して LAS と同じく 1 からにする。時刻は、状態（`isTimeStampInvalid`）が 0 でない値を 0 にする。
- 行と列の番号（`rowIndex`・`columnIndex`）と、拡張の欄は移さず、欄ごとに `e57.attribute.dropped` を返す。画像（`images2D`）は移さず、枚数を `e57.image.dropped` で返す。

## 座標系

- 座標系の記述（`coordinateMetadata`）を、WKT として `AUTHORITY["EPSG",…]`・`ID["EPSG",…]` のコードで読む（LAS と同じ）。WKT でなければ、`EPSG:6677` などの EPSG のコードの書き方か、座標系の名前として読む。
- 平面直角座標系（JGD2011、EPSG:6669〜6687）だけを水平の座標系にし、ほかは `e57.crs.unsupported` を返して不明にする。記述がなければ `e57.crs.missing`、コードを読めなければ `e57.crs.invalid` を返す。高さは JGD2011・JGD2024 の標高（6695・11317）だけを受け、ほかは `e57.vertical-crs.unsupported` を返す。

## 依存

- ページ・XML・点の圧縮は、`e57` crate（0.11、MIT）で読む。依存の理由は、次のとおり。
  - 権利: `e57` は MIT で、依存の `roxmltree` も MIT・Apache-2.0 にできる（`cargo deny`）。CRC の速い計算（`crc32c`）の機能は使わず、crate の中の実装で確かめる。
  - wasm: 入出力は `std::io` の `Read`・`Seek` だけで、wasm で動く。
  - 決まった値: 点は生の値の読み取り（`pointcloud_raw`）で受け取り、浮動小数の換算は `libm` で求める。crate の簡単な読み取り（`pointcloud_simple`）は球の座標の換算に std の三角関数を使うので使わない。生の値は、整数の取り出しと、倍率とずれの掛け算と足し算だけで決まる。
- `e57` は、壊れた入力でパニックすることがある（ライブラリの中に `unwrap`・`expect`・添字がある）。wasm ではパニックで止まるので、信頼できない E57 を読む用途では、ホストの側で隔離する（LAZ と同じ）。

## まだしないこと

- スキャンを分けて持つこと（いまは 1 つの点群にまとめる）、行と列の格子（構造化の点群）、画像。
- 書き出し。
- 実データでの確かめ（CloudCompare で開いた結果と比べる）。

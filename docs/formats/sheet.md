# 表（Excel の xlsx と CSV）

内訳書・数量表・計算の入力シートを読む土台として、xlsx と CSV の表を、様式を知らずに読む規則を記録します（#391）。実装は `crates/zumen-sheet` です。境界では、`sheet` の op に表の入力の名前を渡し、シートごとのセルの値・数式・結合セルを返します。様式（どの列が何か）の読み取りは、この読み取りに入れません。仕様の本文は写しません（`formats/ledger.toml` の `xlsx`・`csv`）。

## 形式の選び方

- 要求の `format` で決める。書かなければ、ZIP の署名（`PK\x03\x04`）で始まれば xlsx、そうでなければ CSV とする。

## xlsx

- `zumen-zip` で書庫を読み、`zumen-xml` で部品を読む。要素と属性は、名前空間を問わず、接頭辞を除いた名前で見る。Transitional と Strict の両方を読むため。
- パッケージの関係（`_rels/.rels`）の officeDocument の行き先をブックとする。関係がなければ `xl/workbook.xml` とする。ブックがないか XML として読めなければ、`xlsx.file.invalid` を返して失敗する。
- ブックの関係から、シートの行き先と、共有文字列の部品を引く。関係の行き先は、`/` で始まれば書庫の根から、そうでなければ関係を持つ部品の場所からの相対とする。外部の行き先（`TargetMode="External"`）は使わない。
- シートは、ブックの `sheets` の順に読む。ワークシートでないシート（グラフのシートなど）は、`xlsx.sheet.unsupported` を返して飛ばす。シートの部品がないか読めなければ、`xlsx.part.invalid` を返して飛ばす。
- 文字の項目（共有文字列の `si` と、セルの中の `is`）は、`t` と、書式つきの区切り（`r`）の `t` をつなぐ。ふりがな（`rPh`）は含めない。`_xHHHH_` の書き方は字に戻す。

### セル

- 行（`row`）とセル（`c`）の位置は、`r` の属性（`A1` の形）から決め、なければ前のものの次とする。行と列は 0 から数えて返す。参照が読めなければ、`xlsx.cell.invalid` を返してそのセルを飛ばす。
- 値の種類は、`t` の属性で決める。
  - `s` は共有文字列の番号。範囲の外なら、`xlsx.cell.invalid` を返して飛ばす。
  - `inlineStr`・`str` は文字。`b` は真偽で、`TRUE`・`FALSE` にする。`e` はエラーの値。`d`（ISO 8601 の日時）は文字のまま返す。
  - ほかは数で、`v` の字のまま返す。
- 数式（`f`）は、先頭の `=` のない字のまま返し、計算しない。値は、保存された `v` を返す。共有の数式は、元のセルだけが字を持つので、ほかのセルは数式を返さない。
- 書式（`s` の属性）は読まない。日付の表示形式のセルも、保存された数のまま返す。
- 値も数式もないセル（書式だけのセル）は返さない。セルは、行の順、行の中は列の順に並べる。
- 結合セル（`mergeCell` の `ref`）は、両端を含む範囲にする。読めないか、始まりが終わりより後なら、`xlsx.cell.invalid` を返して飛ばす。
- 行と列の数は、返すセルと結合セルの最後の位置までとする。

## CSV

- RFC 4180 の形を読む。区切りの字は、要求の `delimiter`（`comma`・`tab`・`semicolon`、書かなければ `comma`）とする。
- 改行は CRLF・LF・CR のどれでもよい。二重引用符で始まる値は、次の二重引用符までを値とし、`""` は `"` 1 つにする。囲んだ値の中の区切りと改行は、値の一部とする。引用符で始まらない値の中の引用符は、字のまま値に入れる。
- 引用符が閉じないまま終わったら、`csv.quote.invalid`（引用符の始まりの行）を返し、終わりまでを値とする。
- 文字コードは、要求の `encoding` で決める。書かなければ、UTF-8 の BOM があるか、UTF-8 として正しければ UTF-8、そうでなければ Shift_JIS（Windows の拡張を含む）とする。BOM は値に入れない。決めた文字コードで直せないバイトは置き換えの字にし、`csv.encoding.invalid` を返す。
- 値はすべて文字とし、数として解釈しない。空の値のセルは返さない。シートは 1 つで、名前は空とする。

## 上限

- 入力の大きさを `InputBytes`、展開した xlsx の部品と、文字に直した CSV の大きさを `DecodedBytes`、セル・共有文字列・CSV の行の数を `Records` で数える。

# PDF

PDF を、ファイルモデル（L1）として読み書きし、図面モデルに移す規則と、仕様が決めない所の扱いを記録します。実装は `crates/zumen-pdf` です。ページの内容は hayro-interpret 0.9.0 で解釈します（[決定 0256](../decisions/0256-pdf-with-hayro.md)）。仕様の本文は写しません（`formats/ledger.toml`）。節の番号は ISO 32000-2:2020 のものです。

## 対象

- PDF 1.0〜2.0 の図面を読む。境界にはまだつないでいない（`open` と wasm の `pdf` のモジュールは #518）。
- 暗号は、空のパスワードで開けるものだけを読む（hayro-syntax が復号する）。
- 書き戻しは、読んだバイト列をそのまま書く（下の「書き戻し」）。

## 判定

- 先頭が `%PDF-` なら PDF とする（`Signature::Bytes`、7.5.2 節）。
- 読むときは、先頭の 1,024 バイトの中に `%PDF-` があればよい。前にあるバイト列は、読めないバイト列のレコードにする（推定。多くの読み取りが許す範囲に合わせた）。なければ `pdf.file.invalid` を返して読まない。

## レコードの区切り

- ファイルの字句（7.2〜7.3 節）をたどり、見出し・コメント・間接オブジェクト（`N G obj … endobj`、7.3.10 節）・相互参照表（`xref`、7.5.4 節）・トレーラー（7.5.5 節）・`startxref` を、それぞれ 1 つのレコードにする。どれでもないバイト列は、続く分をまとめて読めないバイト列のレコードにする。
- ストリーム（7.3.8 節）は、外側の辞書の `/Length` が直接の整数で、その後ろに `endstream` があれば、その長さで飛ばす。間接参照の長さか、長さが合わなければ、次の `endstream` を探す。
- オブジェクトのストリームと相互参照のストリーム（7.5.7・7.5.8 節）の中は分けず、1 つの間接オブジェクトのレコードにする。
- 同じ番号のオブジェクトが何度も出るときは、図面モデルへの移しで、最後のレコードを使う（増分の更新、7.5.6 節）。

## 壊れた所

- `endobj` のないオブジェクトは、次のオブジェクトの前（後ろの空白を除く）か入力の終わりまでとし、`pdf.object.repaired` を返す。
- 相互参照とページの木を読めなければ `pdf.document.invalid` を、空のパスワードで開けない暗号なら `pdf.encryption.unsupported` を返し、図面モデルに移さない。どちらも、L1 としては読める。
- ページの内容のストリームを展開できなければ、`pdf.content.invalid` を返し、そのページを空のシートにする。

## 上限

- L1 は、入力のバイト数（`InputBytes`）とレコードの数（`Records`）を予算で数える。
- 図面モデルへの移しは、ページ・パス・字形の並び・画像ごとに `Work` を、要素ごとに `Elements` を、内容のストリームの展開したバイト数を `DecodedBytes` で数える。止めたら、そのページの出所を場所にする。
- hayro の中の作業（ストリームの展開・フォントの読み・曲線の平坦化）は、予算で数えない。hayro-syntax 0.9.0 の展開は出力の大きさに上限がないので、小さいファイルから大きく展開するストリームで、予算より先にメモリを使う。止め方は #521 で決める。
- ページラベルの数の木は深さ 32 まで、文字のページラベル（`A`〜`Z`、`AA`…）は 64 文字までたどる。

## 図面モデルへの変換

### ページ

- ページを、順に図面のシートにする。名前はページラベル（12.4.2 節）とし、ラベルのないページは名前を持たない。
- 大きさは、クロップボックスとメディアボックスの重なり（14.11.2 節）を、`UserUnit`（7.7.3.3 節）と `Rotate`（時計回りに 90 度ずつ）を当てて mm にする。1 pt は 25.4/72 mm。大きさのないページは A4 とし、1 pt より短い辺は 1 pt とする（推定。hayro と同じ）。
- 座標は、表示の向きに回した用紙の mm で、クロップボックスの左下を原点、Y を上にする。hayro には 1/1024 mm を 1 装置単位として渡す（決定 0256）。

### 線と塗り

- 線を引くパスは、部分パス（8.5.2 節）ごとに要素にする。線分 1 本は線、曲線を含むものはスプライン（3 次のベジェ曲線をそのまま持つ）、ほかは折れ線にする。2 次の曲線は、同じ形の 3 次の曲線にする。閉じた部分パスは、閉じた折れ線にする。長方形（`re`）は、左下の角から始まる閉じた折れ線にする。
- 線の太さは、ユーザー空間の太さに、変換の行列式の絶対値の平方根を掛けて mm にする（推定。斜めに伸ばす変換では、向きで太さが変わる）。
- 破線（8.4.3.6 節）は、長さの並びを mm にした線種にする。名前は `[2.117 1.058]` のように mm の小数 3 桁で、実線は `[]` とする。奇数個の並びは 2 回繰り返す。すべて 0 なら実線にする。位相が 0 でなければ、位相を移さず `pdf.dash.approximated` を返す。hayro が 0 の代わりに置く 0.01 以下の長さは、0（点）に戻す。
- 塗りは、部分パスを輪にした塗りつぶしのハッチングにする（輪の中の輪を交互に埋める）。非ゼロ回転数の規則（8.5.3.3 節）で塗った、輪が 2 つ以上の形は、`pdf.fill-rule.approximated` を返す。面積のない塗りを hayro は 1 装置単位の線にするので、1/1024 mm の線になる。
- 塗りと線の両方（`B` など）は、ハッチングと線の 2 つの要素にする。

### 色と透明

- 色は、色空間の系統（8.6 節）ごとに、四則演算だけで RGB にする（決定 0256）。
  - DeviceGray・DeviceRGB は、そのままの値にする。
  - DeviceCMYK は、10 章の換算（赤 = 1 − min(1, シアン + 黒) など）にし、`pdf.color.approximated` を返す。
  - CalGray・CalRGB は、灰色・RGB の成分として読む。ICCBased は、成分の数（1・3・4）の装置の色空間として読む（8.6.5.5 節の `Alternate` の既定と同じ）。どちらも `pdf.color.approximated` を返す。
  - Lab・Indexed・Separation・DeviceN と、読めない系統は、レイヤの色にして `pdf.color.dropped` を返す。どちらの診断も、系統の名前を `space` に持つ。
- 不透明度（`ca`・`CA` と、透明のグループの不透明度）は、掛け合わせて透過性にする。不透明ならレイヤに従う。柔らかいマスクと、通常でない合成の方法（11.3・11.6.5 節）は、移さず `pdf.transparency.approximated` を返す。
- シェーディング（`sh` と、シェーディングのパターン）とタイルのパターンで塗った形は移さず、`pdf.shading.dropped`・`pdf.pattern.dropped` を返す。

### 文字

- 字形の並び（hayro が 1 回に渡す、同じフォントの字形）を、1 つの文字にする。中身は、字形の Unicode（`ToUnicode`・エンコーディング・字形の名前、9.10 節）をつないだもの。Unicode に戻せない字形は U+FFFD にし、`pdf.glyph.dropped` を返す。空白だけの並びは移さない。
- 位置は最初の字形の基点とし、横書きは左・基準線、縦書きは中央・上に合わせる。高さは em の大きさ（字形の空間の 1,000 単位）を、基準線に直交する向きで測った mm にする。
- 回転は基準線の向き、幅の倍率は基準線の向きの em の長さと高さの比（水平の伸縮 `Tz` を含む）、斜体の角度は em の上向きの傾き、裏返しは行列式が負の変換とする。埋め込みのないフォントを代わりのフォントで読むときは、hayro が字形の幅を合わせる伸縮も、幅の倍率に入る（#520）。
- 描画モード（9.3.6 節）が塗りと線の両方なら 1 つの文字に、見えない文字（モード 3）なら透過性 0 の文字にする。
- 文字スタイルの名前は、フォントの `BaseFont` から部分集合の前置き（`ABCDEF+`）を除いたものにする。縦書きは `@` を前に付ける。名前を得られるのは、Type 0 と、埋め込んだ TrueType のフォントだけで、ほかは空にする。UTF-8 でない名前は空にし、`pdf.font-name.dropped` を返す。太字は重さが 700 以上、斜体はフォントの印による。
- Type 3 のフォントの字形（9.6.4 節）は、形を移さず書体のない文字にし、`pdf.type3.approximated` を返す。hayro が読めないフォントの文字は移さず、`pdf.font.unsupported` を返す。
- 字形ごとの位置（`TJ` の隙間など）は移さない（#520）。

### 画像

- 画像（8.9 節）は、画素の格子の下敷きにする。左下・右下・左上の角は、画像の空間の単位の正方形を変換した位置にする。画像の XObject は、資源の名前を間接参照（`5 0 R`）にし、そのオブジェクトのレコードを定義にする。内容の中の画像（`BI … EI`）は、名前を持たない。
- 色を塗る画像（`ImageMask`、8.9.6.2 節）の色は、マスクを展開しないと得られないので移さず、レイヤの色にして `pdf.image-mask.approximated` を返す。

### 表示グループとレイヤ

- 表示グループ（OCG、8.11 節）を、カタログの `OCProperties` の `OCGs` の順にレイヤにする。名前は `Name` の文字列とする。表示グループの外の内容は、レイヤ `0` に置く。
- 既定の設定（`D`）の `BaseState`・`ON`・`OFF` で隠れるグループは、見えない・印刷しないレイヤにする。hayro は隠れたグループの内容を塗らないので、`pdf.optional-content.dropped` をグループの名前とともに返す（#520）。`Locked` のグループは、編集できないレイヤにする。印刷の可否は、表示と同じとみなす（推定。`Usage` の辞書は読まない）。
- 表示の規則の辞書（OCMD）は、最初の表示グループのレイヤに置き、表示グループを持つ XObject（`/OC`）の内容は、レイヤに分けない。どちらも `pdf.optional-content.approximated` を返す。

### 切り抜き

- 切り抜きのパス（8.5.4 節）は、外接矩形だけを見る。要素の外接矩形（文字は基点）が切り抜きの外なら移さず `pdf.clip.dropped` を、かかるなら切らずに移して `pdf.clip.approximated` を返す（推定。切り抜きの形ではなく外接矩形で比べる）。ページの見える範囲も、切り抜きとして扱う。

### 移さないもの

- 注釈（12.5 節）は移さず、種類（`Subtype`）ごとに `pdf.annotation.unsupported` を返す。
- 計測の辞書を持つビューポート（`VP`・`Measure`、12.9 節）の縮尺は移さず、`pdf.measure.unsupported` を返す（#520）。

### ID と出所

- 要素の出所は、そのページの最初の内容のストリームのレコードにする。内容のストリームがなければ、ページのオブジェクトのレコードにする。ID は、出所のレコードと描いた順から、決定 0156 の規則で作る（`sheet/0/r7`、`sheet/0/r7/1`…）。
- 診断は、同じ code と値の最初の 1 件にだけ、そのページの出所を添える。

### 文書の情報

- 文書の情報の辞書（14.3.3 節）の `Title`・`Author`・`Subject`・`Keywords`・`Creator`・`Producer` を文字列に、`CreationDate`・`ModDate` を ISO 8601 の日時に、ページの数を数にして、図面の拡張 `pdf.document`（版 1）に持つ。拡張の版の名前は PDF の版（見出しか、新しければカタログの `Version`、7.2.2 節）とする。

## 書き戻し

- L1 の `write` は、レコードのバイト列と、その間のバイト列をそのまま並べ、読んだバイト列と同じものを返す。
- 図面モデルの変更を PDF に書き戻す（apply・lower）ことは、しない。

## 検証

### 確かめた度合い

| 向き | 段 | 確かめたこと |
| --- | --- | --- |
| 読む | `synthetic` | 仕様と、試験の中で作ったファイルだけで確かめた（`crates/zumen-pdf/tests/pdf.rs`・`drawing.rs`）。シーンへの移しは、図面モデルから `zumen-scene` で作れることだけを確かめた |
| 書く | `synthetic` | 読んだバイト列をそのまま書けることを、自前の読み取りだけで確かめた |

- 予算と ID の契約は、テストキットの `stops_at_same_place`・`ids_match`（`crates/zumen-pdf/tests/ids/pdf.txt`）と `survives` で確かめる。fuzz の対象は `fuzz/fuzz_targets/pdf.rs`。
- 外部の実装（pdf.js）との照合は、まだしていない（#519）。

### 公開サンプル

`samples/` に PDF はない。2026-11-03 に、CC0・パブリックドメインで、CAD が出力したベクターの図面の PDF を Web で探した（CC0 の CAD の図面の PDF、Wikimedia Commons の建築の図面の分類）。Commons の分類の PDF は主にスキャンした本で、ライセンスを書かない図面の配布と、素材の販売のサイトは、決定 0171 に合わない。`samples/dwg` の CC0 の図面を PDF に印刷したものを候補として、#519 で足す。

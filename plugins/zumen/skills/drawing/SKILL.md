# 図面を確認し、編集する

1. 図面フォルダーからの相対パスを `inspect` に渡す。返ったセッションと文書の ID を以降の操作に使い、読み取り時の診断を確認する。
2. 全体や指定範囲の見た目には `render_view`、正確な座標・文字・要素 ID には `entities` を使う。位置や長さを伝えるときは図面の単位を確かめる。
3. 編集を頼まれたら、変更前の文書と要素のハッシュを取得し、対象の ID と変更を `apply` に渡す。失敗時は診断を伝える。
4. 成功したら、ほかの操作を呼ぶ前に `take` で返った blob を新しいファイル名に保存する。保存した図面を開き直し、対象要素の値を照合する。必要に応じてプレビューと診断を添える。
